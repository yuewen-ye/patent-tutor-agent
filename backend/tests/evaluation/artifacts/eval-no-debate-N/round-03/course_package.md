## 教学正文

## I — 法律问题

专利制度基础的首要问题不是立即判断某项技术能否授权，而是先确定：拟保护的成果是否属于法定专利客体；该成果将被置于怎样的制度框架和审查程序中；以及专利权为何具有独占、时间和地域三重边界。对代理人而言，这决定申请策略和文件组织；对审查视角而言，这决定先审什么、依据何种规范审查。

## R — 适用规则

### 1. 保护客体先由法定定义锁定

《专利法》将“发明创造”界定为发明、实用新型和外观设计三类。发明是对产品、方法或者其改进提出的新的技术方案；实用新型是对产品的形状、构造或者其结合提出的、适于实用的新的技术方案；外观设计则是对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

因此，分类不能只看申请人给成果贴的名称，而要看保护对象：技术方案可能进入发明；产品形状、构造及其结合的技术方案可能进入实用新型；产品视觉设计则应按外观设计的定义判断。

### 2. 制度规范与审查主体应当分层理解

中国专利制度的规范层次，以专利法作为基本法律依据；实施细则用于细化法定程序和要求；审查指南用于统一审查实践中的具体判断和操作口径。本节检索材料直接确认，国务院专利行政部门统一受理和审查专利申请，并依法授予专利权；地方管理部门负责本行政区域内的专利管理工作。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕

代理视角应当把三层规范转换成文件、期限和答复动作；审查视角则应依序确认申请客体、程序阶段、适用条款和证据范围。实施细则和审查指南的具体条目不在本节检索上下文中，不能据此展开具体条款内容。

### 3. 权利边界与制度功能

专利权的独占性，意味着在法定保护范围内，权利人可排除他人未经许可的实施；时间性意味着该排他地位不是永久存在；地域性意味着权利效力以授予国或地区的法域为边界。这三项是制度特征的概括，具体期限、权利内容和跨境效力仍须回到相应法条及目标法域规则判断。

制度上，专利以公开申请文件所载技术信息为交换条件，给予符合法定条件的成果以有限权利，从而形成“激励创造—技术公开—后续应用”的循环。申请公布或者公告前，有关人员对申请内容负有保密责任，也体现了公开发生前后制度状态的区别。〔RAG: 中华人民共和国专利法.txt — 在专利申请公布或者公告前，有关人员对其内容负有保密责任〕

### 4. 审查制度的基础定位

发明和实用新型在授权条件上须具备新颖性、创造性和实用性；外观设计则适用现有设计、明显区别以及不与在先合法权利冲突等条件。〔RAG: 中华人民共和国专利法.txt — 第二十二条、第二十三条分别规定发明和实用新型、外观设计的授权条件〕这说明“三种客体”并非仅是名称不同，也会导向不同的实体审查标准。

课程窗口所列“早期公开延迟审查、初步审查制与实质审查制并存”，可作为理解中国制度程序分工的结构线索：先处理形式和法定门槛，再在法定对象和程序中处理实体授权问题。但本节检索上下文未提供上述历史沿革、公开时点或不同客体审查程序的直接条文依据；实务中应以现行实施细则、审查指南及具体申请类型的规定复核，不宜把概括性表述直接当作个案结论。

## A — 规则适用

面对一个“新产品方案”，审查与代理应使用同一条线性核对顺序：

1. 先识别成果的核心：若核心是产品或方法的技术方案，优先按发明定义核验；若核心限于产品形状、构造或其结合且适于实用，核验实用新型；若核心是产品视觉设计，核验外观设计。
2. 再确定制度入口：由国务院专利行政部门统一受理、审查和依法授予，故申请文件和后续意见陈述必须面向法定审查程序组织。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请〕
3. 再区分权利与授权条件：独占、时间、地域回答的是“取得权利后权利到哪里、持续多久、能排除什么”；新颖性、创造性、实用性等回答的是“能否获得授权”。不得以权利特征替代授权条件，也不得把发明、实用新型的“三性”机械套用于外观设计。
4. 最后核对公开与申请日。申请文件收到之日通常为申请日；法条还规定外国或中国在先首次申请后，在相应期限内对相同主题再次申请可以享有优先权。〔RAG: 中华人民共和国专利法.txt — 第二十八条规定申请日；第二十九条规定外国优先权和本国优先权期限〕这一步为后续新颖性、优先权和跨法域布局的分析提供时间基准，但其具体判断属于后续节点。

## C — 结论

专利法律制度基础应当被掌握为一套先分类、再定位规范与主体、再区分授权条件和权利边界、最后核对时间基准的框架。审查人以此避免错用审查标准；代理人以此避免在客体选择、文件布局和时间安排上发生结构性错误。

> 常见误区 / 易混淆点
>
> 1. “发明创造”是发明、实用新型、外观设计的上位概念，并不等于仅指发明专利。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕
> 2. 独占性不等于无限期、全球有效；时间性和地域性正是其边界。
> 3. 初步审查、实质审查是程序分工概念，不能据此省略对法定客体和实体授权条件的分别判断。
> 4. 发明、实用新型的“三性”与外观设计的授权条件并不完全相同。〔RAG: 中华人民共和国专利法.txt — 第二十二条、第二十三条分别规定不同客体的条件〕

### 从一件智能设备申请看制度入口（anchor_scenario）

> 甲公司研发一款智能水表：内部的低功耗计量方法可降低误差，表壳上增加了便于读数的独特局部图案和轮廓。公司准备在中国提交申请，同时计划向境外市场销售。研发负责人问代理人：“这一件成果到底能申请什么？拿到专利后是不是所有国家、永久都不能仿？”审查人员则需要先确认申请对应的客体和应适用的审查标准。

**锚定**：该情境同时锚定三类保护客体，以及专利权独占性、时间性和地域性的边界。

**先想一想**：在审查实体条件之前，为什么必须先判断该成果的核心究竟是技术方案还是产品视觉设计？

### 法定客体与审查主体的条文锚点（legal_anchor）

- **《专利法》第二条**：发明创造法定分为发明、实用新型和外观设计；三类客体的定义不同，分类必须依成果内容判断。
- **《专利法》第三条**：国务院专利行政部门统一受理、审查申请并依法授予专利权，审查程序有明确法定主体。
- **《专利法》第二十二条、第二十三条**：发明和实用新型适用新颖性、创造性、实用性；外观设计适用现有设计、明显区别及不与在先合法权利冲突等条件。

**为何重要**：条文先确定“是什么”和“按什么标准审”，才能避免代理文件定位错误或审查标准错配。

### 同一产品中的技术方案与视觉设计分流（worked_example）

**案情/例题**：乙公司提交一组材料：其一是“通过新的信号处理步骤降低智能水表读数误差的方法”；其二是“水表正面局部采用波纹图案与弧形边框的视觉设计”。需要从专利制度基础角度判断，两项成果应如何识别保护客体，并提示后续授权条件的适用入口。
**适用规则**：《专利法》第二条关于发明、实用新型和外观设计的定义；《专利法》第二十二条、第二十三条关于不同客体的授权条件。
**分步推演**：
1. 先看第一项成果的实质内容。其核心是通过信号处理步骤降低误差，属于对方法提出的技术方案。 → *第一项应先按发明的定义判断。*
2. 再看第二项成果。其核心描述的是产品局部图案与形状形成的视觉设计，而非产品形状、构造所形成的技术方案。 → *第二项应先按外观设计的定义判断。*
3. 客体不同，后续实体审查入口也不同。发明适用第二十二条规定的授权条件；外观设计适用第二十三条规定的现有设计、明显区别和在先合法权利冲突等条件。 → *不能将发明、实用新型的三性作为外观设计的全部标准。*
**结论**：该方法成果应进入发明客体的分析路径；产品局部视觉设计应进入外观设计的分析路径，二者后续授权条件不能混同。
**本题要点**：先以成果实质完成客体分类，再选择对应的授权条件和文件组织策略。

### 把制度框架翻译成审查和代理的工作顺序（verbal_explanation）

可以把这一节理解为进入专利实务前的一道总闸门。代理人接到技术交底，不能先承诺“肯定能授权”，而要先问：客户交来的到底是产品或方法的技术方案，还是产品的视觉设计？这一步决定是走发明、实用新型还是外观设计的法定定义。审查人员也是同样顺序：先识别客体，再找对应的审查条件。专利权有排他作用，但它不是永久有效，也不会当然跨越所有国家和地区；因此，独占性必须连同时间性、地域性一起理解。规范上，专利法给出基本规则，实施细则和审查指南负责细化程序和审查操作；遇到具体案件，不能用概括口号代替对现行规则的核对。

**点破术语**：独占性；时间性；地域性；发明创造；审查指南

### 顺序记忆表：客—规—权—时（mnemonic）

**记忆锚**：四步顺序表：客—规—权—时。先看客体，再找规范，再分权利边界与授权条件，最后核对时间基准。
**映射**：
- 客
- 规
- 权
- 时
**何时用**：看到技术交底、审查意见或跨法域申请安排时，先按四步表列出待核对事项。

### 从双视角复盘分类错误的后果（reflect_prompt）

**反思问题**：若代理人把产品局部视觉设计当作技术方案撰写，而审查人员又未先校正客体分类，后续的授权判断和客户跨法域布局可能分别出现哪些偏差？

**关注要点**：先区分成果的技术内容与视觉设计内容，而非只看申请名称。；分别识别审查主体的法定职责与代理人的风险提示职责。；区分专利权地域边界与申请人商业销售地域，避免把市场计划当作权利当然覆盖。；对历史沿革和具体程序规则，应标记是否已有现行法条、实施细则或审查指南依据。

**连接**：连接学习者已有的程序法学习经验：先确定审查对象、适用规范和法定主体，再进入实体判断。

### 专利法律制度基础的结构图（knowledge_synthesis）

**知识框架**：
- 权利特征：独占性、时间性、地域性共同界定专利权不是无限、无边界的排他权。
- 制度体系：专利法确立基本规则，实施细则细化程序要求，审查指南统一审查操作口径。
- 保护客体：《专利法》第二条将发明创造分为发明、实用新型和外观设计，并分别规定定义。
- 制度作用：通过对符合法定条件成果的有限保护与申请文件公开，形成激励创造、技术公开和应用转化的制度循环。
- 程序特点：以早期公开、延迟审查以及初步审查和实质审查的分工为结构线索；具体适用须核对现行实施细则和审查指南。
**概念关系**：客体分类决定后续适用第二十二条还是第二十三条等实体条件。；专利法规定基本权利和条件，实施细则与审查指南将其转化为程序和审查操作。；申请日和优先权时间基准为后续公开、授权与跨法域布局分析提供共同时间坐标。
**必记**：客体分类是授权条件判断的前提：发明、实用新型与外观设计不能仅按名称分类。；发明和实用新型的三性，与外观设计的法定授权条件不能混同。；专利权应同时从独占性、时间性、地域性三方面理解其边界。

### 基础制度速查卡（summary_card）

**要点卡**：
- **三种客体**：发明、实用新型、外观设计是《专利法》第二条规定的发明创造类型。
- **三项权利特征**：独占性要与时间性、地域性一起理解，排他权并非永久和全球当然有效。
- **制度体系**：专利法定基本规则，实施细则细化程序，审查指南统一审查操作口径。
- **审查标准分流**：发明、实用新型看第二十二条；外观设计还须依第二十三条的专门条件判断。
- **程序线索**：早期公开、延迟审查及初步审查与实质审查的分工，具体案件须以现行规则复核。
**必背**：《专利法》第二条：发明创造包括发明、实用新型和外观设计。；《专利法》第三条：国务院专利行政部门统一受理和审查专利申请，依法授予专利权。；客体先分类，规则再匹配；权利边界与授权条件不得混同。
**一句话总结**：专利实务先定客体和规则，再辨权利边界与授权条件，最后以时间基准统摄程序判断。
