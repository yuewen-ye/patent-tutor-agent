# 专家 B 修订稿

## teaching_content

## 1. 场景导入

设想代理人收到一份便携式检测设备的研发交底：团队既改进了检测步骤，又改进了传感器支架结构，还设计了新的外壳局部图案。审查视角要问“申请主张的对象落在哪一类法定客体内”；代理视角要问“应当怎样把不同事实拆开、用恰当的制度语言表达”。同一件产品不是天然只对应一个法律标签，而且初步标签也不等于已经满足完整法定定义。

## 2. 人话解释

专利制度不是“有创意就自动获得保护”。它给的是有边界的法定权利：独占性表示权利具有排他效力，时间性和地域性提醒我们，这种效力并非永久、也并非天然覆盖全世界。处理具体项目时，先用“权—规—客—用—程”五格复盘：看权利边界，找规范依据，辨认保护客体，理解制度作用，最后整理程序阶段。

客体识别尤其要拆细，但要把“初步识别”和“完整法定认定”分开：对产品、方法或者其改进提出的新的技术方案，属于发明定义的考察方向；对产品的形状、构造或者其结合提出的适于实用的新的技术方案，属于实用新型定义的考察方向；对产品整体或局部的形状、图案及其结合等所作出的富有美感并适于工业应用的新设计，属于外观设计定义的考察方向。仅有“新的方法”“结构改进”或“图案设计”的事实描述，还不足以当然认定满足完整法定定义。〔RAG: 中华人民共和国专利法.txt — 第二条：发明是对产品、方法或者其改进所提出的新的技术方案；实用新型针对产品的形状、构造或者其结合，并要求适于实用；外观设计针对产品整体或者局部的形状、图案等作出的新设计，并有相应法定限定〕

## 3. 法条回扣

《中华人民共和国专利法》第二条明确，本法所称发明创造是发明、实用新型和外观设计。三类对象的定义不同，其中发明和实用新型均以新的技术方案为前提，实用新型还要求适于实用。〔RAG: 中华人民共和国专利法.txt — 第二条：本法所称的发明创造是指发明、实用新型和外观设计；第二条分别规定三类对象的法定定义〕 因而，代理人不能只写“这是一个创新产品”，而应当把技术事实对准相应法定定义，并逐项核对必要限定；审查也应当先确认申请对象，不能从一般事实描述直接推出完整法律结论。

《中华人民共和国专利法》第三条规定，国务院专利行政部门统一受理和审查专利申请，依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕 在规范检索上，可把专利法作为基本制度入口，并结合专利法实施细则和专利审查指南继续核对程序与审查操作。课程节点列出的早期公开、延迟审查以及初步审查制与实质审查制并存，是整理制度运行的复盘线索；本轮检索材料没有其具体规范原文，不能据此替代逐条核验。

## 4. 类比 / 口诀

可把制度理解为“公开换取法定保护机会”的规则系统：公开解释制度为何鼓励技术传播，法定保护机会解释为什么需要申请和审查。这个类比的边界是，公开技术内容不等于当然获得专利权，具体权利仍取决于法定对象、完整定义、程序和审查。

顺序口诀用“权—规—客—用—程”：权是独占性、时间性、地域性；规是专利法、实施细则、审查指南的检索主线；客是发明、实用新型、外观设计及其相应法定限定；用是激励创造、促进公开和应用的制度作用；程是按公开与审查阶段整理材料。它用于复盘顺序，不替代具体条文判断。

## 5. 应试提示

题干出现“产品、方法、改进”时，先定位发明的考察方向，但要继续检查是否是新的技术方案；出现“产品形状、构造或者其结合”时，先定位实用新型的考察方向，同时检查是否是适于实用的新的技术方案；出现“产品整体或局部的形状、图案、美感、工业应用”时，先定位外观设计的考察方向，并核对其完整法定限定。〔RAG: 中华人民共和国专利法.txt — 第二条分别规定发明、实用新型和外观设计的定义〕

双视角的稳定顺序是：先拆研发事实，再选法定客体方向，接着核对法定限定；代理人据此组织申请表达，审查人员据此确定审查入口。不要把“制度具有激励作用”误写成“所有创新都能授权”，也不要因为多个改进装在同一产品里，就忽略其可能属于不同客体层面。
