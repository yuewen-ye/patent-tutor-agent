## 教学正文

## I — 法律问题

本节的争点是：在中国专利法律制度中，如何先识别专利保护客体，再理解专利制度的基本特征、规范体系、制度作用和后续授权审查入口。核心方法是区分“保护什么”和“能否授权”两个层次。

## R — 适用规则

《中华人民共和国专利法》第二条规定：“本法所称的发明创造是指发明、实用新型和外观设计。”该条进一步规定，发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造包括发明、实用新型和外观设计，并分别规定三类客体〕

《中华人民共和国专利法》第二十二条规定，授予专利权的发明和实用新型应当具备新颖性、创造性和实用性；该条还规定现有技术是申请日以前在国内外为公众所知的技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条：发明和实用新型应具备新颖性、创造性和实用性，现有技术是申请日前在国内外为公众所知的技术〕

据此，本节点采用“先客体、后条件”的判断顺序：第一步确认对象属于哪一类专利客体；第二步再适用该类客体对应的授权和审查规则。专利法、专利法实施细则和专利审查指南构成本领域后续学习中需要分别识别的规范材料，但本轮检索上下文未提供后两者的直接原文。

关于专利权的独占性、时间性和地域性，关于激励发明创造、促进技术公开、推动技术应用和经济发展等制度作用，以及关于早期公开、延迟审查和初步审查与实质审查并存的制度沿革，本轮检索上下文未提供直接、完整的法条或历史材料。因此，本节将其作为制度框架线索，不虚构具体条文或历史细节。商标与著作权的比较也应在取得相应法律文本后，分别从保护客体、权利取得方式和保护期限等维度核验。

## A — 规则适用

面对一项同时包含控制方法、产品结构和产品外观的技术成果，应先拆分事实要素，而不能因为它们附着于同一产品就认定只能对应一种专利。控制方法属于方法层面的技术方案，应依第二条关于发明客体的定义分析；产品形状、构造或者其结合形成的适于实用的新的技术方案，应依第二条关于实用新型的定义分析；产品整体或局部的形状、图案及相关色彩结合形成的、富有美感并适于工业应用的新设计，应依第二条关于外观设计的定义分析。〔RAG: 中华人民共和国专利法.txt — 第二条：分别界定发明、实用新型和外观设计〕

完成客体分类后，不能直接得出“已经可以授权”的结论。对于发明和实用新型，还需继续依第二十二条核对新颖性、创造性和实用性。新颖性关注是否属于现有技术以及是否存在法定意义上的同样申请；创造性关注相对于现有技术的实质性特点和进步；实用性关注能否制造或者使用并产生积极效果。〔RAG: 中华人民共和国专利法.txt — 第二十二条：新颖性、创造性、实用性的定义及现有技术范围〕

在学习流程上，应把“客体识别”作为入口，把“授权实质条件”作为后续判断层。初步审查、实质审查、申请文件要求和程序衔接属于后续节点；本节不将未检索到的程序材料扩展为确定性规则。对于商标和著作权，也不能仅凭名称相似进行结论式比较，而应在后续分别核对其保护客体、权利产生机制和期限规则。

## C — 结论

专利法律制度基础的稳定主线是：先依据《专利法》第二条识别发明、实用新型和外观设计三类保护客体，再依据适用规则判断授权条件；其中发明和实用新型须进一步满足第二十二条规定的新颖性、创造性和实用性。客体分类不等于授权结论，已检索规则与待检索的制度沿革、程序细节及商标著作权比较必须严格区分。

> 常见误区 / 易混淆点
>
> 1. 把“同一产品”误认为“只能有一种专利客体”。应拆分方法、结构和外观等不同事实要素。
> 2. 把客体属于发明创造误认为当然满足授权条件。客体判断与授权条件判断是两个层次。
> 3. 把发明和实用新型的三性规则机械套用于外观设计。
> 4. 把本轮未提供直接依据的制度沿革、审查程序或商标著作权比较内容当作已经核验的法条结论。
>

### 先辨认专利保护的对象（anchor_scenario）

> 甲公司研发出一种用于工业设备的温度控制装置：装置本身包含新的结构，控制方法也包含新的技术步骤，外壳还采用了具有美感的特殊图案。公司希望通过专利保护技术方案和产品外观，但团队成员把“技术方法”“产品结构”“外观图案”统称为同一种专利。此时需要先解决的冲突是：这些内容是否属于同一类专利保护客体，以及专利制度究竟保护什么、通过什么条件授予权利。

**锚定**：用同一产品中的结构、方法和外观，锚定发明、实用新型、外观设计三类客体及专利制度基础框架。

**先想一想**：面对同一产品中的结构、方法和外观，你会先按“技术功能”还是按“保护客体”进行分类？

### 法条锚定：客体与授权门槛（legal_anchor）

- **《中华人民共和国专利法》第二条**：第二条先界定专利法上的发明创造包括发明、实用新型和外观设计，并分别说明三类客体的基本含义。
- **《中华人民共和国专利法》第二十二条**：第二十二条规定，发明和实用新型获得专利权应具备新颖性、创造性和实用性，并界定了现有技术。

**为何重要**：第二条解决“保护什么”的起点问题，第二十二条建立发明和实用新型授权条件的基本门槛。两条共同构成理解专利法律制度基础的法条入口。

### 示范：从产品事实到专利客体（worked_example）

**案情/例题**：甲公司完成一种工业温度控制产品，其中有新的控制方法、新的内部结构和具有美感的外观图案。公司拟将三种内容都笼统称为“技术专利”。请演示如何先判断其专利保护客体，再确定后续需要关注的授权条件。
**适用规则**：《中华人民共和国专利法》第二条规定发明、实用新型和外观设计的客体范围；《中华人民共和国专利法》第二十二条规定发明和实用新型的三项授权条件。关于具体审查程序的细节，本轮检索上下文未提供直接依据。
**分步推演**：
1. 先把事实拆成三个独立要素：控制方法属于方法层面的技术方案，内部结构属于产品结构层面的技术方案，外观图案属于产品外部视觉设计。分类前不能把同一产品等同于单一专利客体。 → *先拆分事实中的方法、结构和外观要素。*
2. 依据第二条，发明覆盖对产品、方法或者其改进提出的新的技术方案；实用新型针对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计针对产品的整体或局部形状、图案及相关色彩结合所作出的富有美感并适于工业应用的新设计。 → *将三个事实要素分别与第二条的客体定义对应。*
3. 完成客体分类后，再判断适用的授权条件。第二十二条明确发明和实用新型须具备新颖性、创造性和实用性，因此客体分类不能替代授权条件审查。 → *客体判断是入口，不是授权结论。*
4. 本轮材料没有提供外观设计全部审查程序、专利制度沿革或商标、著作权具体条文，故这些部分只能作为后续比较方向，不能在本例中补造具体法条结论。 → *对证据边界作出明确标记。*
**结论**：该装置的技术方法首先应按发明客体分析；产品的形状、构造或者其结合所形成的新的技术方案，可按实用新型客体分析；产品外观的形状、图案或者其结合以及色彩与形状、图案的结合所形成的新设计，可按外观设计客体分析。发明和实用新型还须进一步分别审查第二十二条所列条件；本例不据此直接作出授权结论。
**本题要点**：处理专利基础问题时，先区分保护客体，再进入相应授权条件和程序判断。

### 把法条翻译成人话（verbal_explanation）

我们先不要把“有创新”直接等同于“能拿到专利”。第一步是看它属于什么客体：如果核心是产品、方法或者改进形成的新的技术方案，先按发明方向理解；如果是产品的形状、构造或者其结合形成的适于实用的新的技术方案，再考虑实用新型；如果重点是产品的形状、图案以及相关色彩组合形成的、富有美感并适于工业应用的新设计，就进入外观设计的客体范围。第二步才是看对应的授权条件。对发明和实用新型，第二十二条把新颖性、创造性、实用性列为门槛。也就是说，分类和授权是先后两个问题，不能用一个问题的答案替代另一个问题。

**点破术语**：发明；实用新型；外观设计；新颖性、创造性和实用性；现有技术

**类比**：可将专利基础判断理解为两道不同的门：第一道门问“法律保护的对象是什么”，第二道门问“该对象是否满足相应授权条件”。这只是帮助记忆的结构类比，不能替代法条判断。

### 基础判断顺序卡（mnemonic）

**记忆锚**：“对象三分、条件三项”：先按“方法/产品技术方案/产品视觉设计”分辨发明、实用新型、外观设计；再对发明和实用新型核对“新、创、实”三项条件。
**映射**：
- 方法
- 产品技术方案
- 产品视觉设计
- 新、创、实
**何时用**：遇到“这是什么专利”时先做客体三分；遇到“能否授权”时再对发明和实用新型核对新、创、实，并注意外观设计应按其自身客体规则分析。

### 反思：先客体还是先条件（reflect_prompt）

**反思问题**：阅读一项同时包含技术结构、控制方法和产品外观的申请材料时，你会按照什么顺序拆分事实并选择法律规则？

**关注要点**：是否把产品本身误认为只有一种专利客体；是否区分发明、实用新型与外观设计的法定定义；是否把客体分类与授权条件混为同一个判断步骤；在法条未提供具体程序依据时，是否明确证据边界

**连接**：连接到法学分析中的“先定法律客体、再定适用规则”方法，也为后续学习专利法体系和专利制度概论作准备。

### 专利法律制度基础知识网（knowledge_synthesis）

**知识框架**：
- 专利制度基本特征：专利权通常表现为受法律保护的排他性权利，并具有时间和地域维度；本轮检索上下文未提供相关直接条文，具体范围需结合后续法条学习。
- 中国专利制度体系：本节点先建立专利法、专利法实施细则和专利审查指南三层规范材料的识别框架；本轮检索上下文未提供实施细则和审查指南原文。
- 三类专利保护客体：发明是产品、方法或者其改进提出的新的技术方案；实用新型是产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计是产品整体或局部形状、图案及相关色彩结合形成的富有美感并适于工业应用的新设计。
- 专利制度作用：通常围绕激励发明创造、促进技术公开、推动技术应用和经济发展理解；本轮检索上下文未提供该作用的直接法条原文。
- 中国专利制度发展与审查特点：本节仅保留“早期公开、延迟审查以及初步审查与实质审查并存”作为后续学习的制度线索；本轮检索上下文未提供可核验的历史或程序原文。
**概念关系**：先由专利制度基本概念确定保护对象，再用第二条完成发明、实用新型、外观设计的客体分类。；客体分类完成后，发明和实用新型进入第二十二条所规定的新颖性、创造性、实用性条件分析。；专利法、实施细则和审查指南的体系关系，以及初步审查与实质审查的程序边界，属于后续节点的展开内容，本节只建立识别线索。
**必记**：《专利法》第二条是三类专利保护客体的直接法条依据。；发明和实用新型的授权条件包括新颖性、创造性和实用性，不能把客体分类直接当作授权结论。；本轮材料不足以支持专利制度沿革、具体审查程序以及商标、著作权比较的具体法条结论，学习时应区分已证实规则与待检索内容。

### 专利基础速查卡（summary_card）

**要点卡**：
- **专利保护客体**：先区分发明、实用新型和外观设计，再选择后续规则。
- **发明**：对产品、方法或者其改进提出的新的技术方案。
- **实用新型**：对产品的形状、构造或者其结合提出的适于实用的新的技术方案。
- **外观设计**：对产品整体或局部的形状、图案及相关色彩结合所作出的富有美感并适于工业应用的新设计。
- **授权条件**：发明和实用新型须具备新颖性、创造性和实用性。
- **证据边界**：未检索到的制度沿革、程序细节和跨制度比较，不能用未核验法条补足。
**必背**：《专利法》第二条规定发明创造包括发明、实用新型和外观设计。；发明和实用新型的授权条件是新颖性、创造性和实用性。；客体分类与授权条件是两个不同判断层次。；本轮检索上下文未提供专利法体系、制度沿革及商标著作权比较的直接完整依据。
**一句话总结**：先按第二条确认保护客体，再按相应规则判断授权条件，并对未检索内容保留证据边界。
