## 教学正文

## I — 法律问题

专利法律制度基础首先要回答两个相互衔接的问题：一是某一技术或设计成果属于何种法定专利客体；二是申请进入制度后，由哪个机关统一受理、审查并依法授予专利权。进而，代理人与审查人员均须在同一制度框架中理解专利权的独占性、时间性和地域性，以及专利制度通过公开与授权配置激励的基本功能。

## R — 适用规则

《中华人民共和国专利法》第二条规定，本法所称发明创造包括发明、实用新型和外观设计；其中，发明针对产品、方法或者其改进提出新的技术方案，实用新型针对产品的形状、构造或者其结合提出适于实用的新的技术方案，外观设计则针对产品整体或局部的形状、图案及其结合，或者色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

《中华人民共和国专利法》第三条规定，国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，依法授予专利权；地方管理专利工作的部门负责本行政区域内的专利管理工作。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕

据此建立顺序化框架：

1. **客体层**：先按第二条判断成果是技术方案还是产品外观设计，再在发明、实用新型、外观设计之间分类。产品或方法及其改进的技术方案，才可能进入发明的定义；实用新型的对象限于产品形状、构造或者其结合；外观设计则以产品外观为对象。
2. **制度层**：专利法提供基本制度与授权依据；实施细则和专利审查指南属于将申请、审查等规则具体化的制度材料。本轮检索上下文未提供实施细则和审查指南的原文，故不对其具体条款或最新审查口径作进一步断言。
3. **权利与功能层**：独占性、时间性、地域性用于描述专利权的制度特征：权利并非对技术事实的永久、全球性自然占有，而是在法定期限和特定法域内发生效力。激励创造、促进公开、推动应用和经济发展，是理解该制度为何要求公开技术信息并设置授权程序的功能框架。本轮检索上下文未提供对应立法宗旨原文，故该功能表述仅依本节给定知识点作教学概括。
4. **程序观察层**：早期公开与延迟审查、初步审查与实质审查并存，属于理解中国专利申请程序结构的观察框架；本轮检索上下文未提供其具体程序规则或期限的直接依据，不将其延伸为具体程序结论。

## A — 规则适用

从审查视角，面对一份申请，第一步不是直接评价技术水平，而是依第二条识别申请对象：若方案的核心是“产品的形状、构造或者其结合”且属于技术方案，应优先检视其是否符合实用新型的定义；若核心是产品整体或局部的视觉设计，则应转向外观设计的定义；若涉及产品、方法或其改进提出的技术方案，则可能属于发明。分类的意义在于：它决定申请进入何种法定客体框架，而不能以“看起来新”替代客体判断。

从代理视角，申请前应将客户的技术事实拆为“技术方案”与“外观设计要素”两类，再据第二条选择相应保护路径。代理人同时应向客户说明，专利申请并不等于立即获得无限范围的技术控制；权利具有法定边界。对制度材料的使用应遵循层级意识：先以专利法确定基本法律依据，再查实施细则与审查指南处理具体程序和审查实践；对跨法域材料，则应逐一核对相应法域的现行法和官方实践，不能直接移植中国规则。

对中国制度发展特点的复盘，应把“公开—审查—授权”作为程序性理解线索：公开安排与审查安排服务于制度运行，但具体适用必须回到现行法、实施细则及审查指南的可核验文本。当前材料不足以支持关于具体公开时点、审查方式适用范围或跨法域趋势的细节结论。

## C — 结论

本节点的稳定判断链条是：**先依《专利法》第二条确认法定客体，再依第三条定位统一受理、审查和授权的制度机关，最后以权利边界、制度功能和程序结构理解专利制度。** 审查与代理虽立场不同，但都必须以客体分类和规范层级为起点；涉及具体审查实践、程序期限或跨法域动向时，应另行核验现行官方文本。

> 常见误区 / 易混淆点
>
> 1. 将“产品外形好看”当然等同于外观设计，忽略其必须是产品整体或局部的形状、图案等法定对象，并须富有美感、适于工业应用。
> 2. 将实用新型理解为一切“小发明”；第二条的文本重点是产品的形状、构造或者其结合所提出的适于实用的新的技术方案。
> 3. 把专利制度特征误作绝对权利：独占性不意味着永久性或全球自动有效，时间性和地域性正是其边界。
> 4. 把专利法、实施细则、审查指南视为可以互相替代的材料；应先识别规范层级，再处理具体程序或审查问题。

本节设有测评，请到【习题】区作答。

### 从一件智能终端申请看专利制度入口（anchor_scenario）

> 某创业团队开发了一款工业巡检终端：团队改进了机身内部的卡扣连接结构，使维护更方便；同时重新设计了终端外壳的局部图案和线条。负责人要求代理人“把这项创新申请成专利”，并问审查机关会如何处理。代理人不能只听“创新”二字，而要先把技术事实拆开：连接结构与外壳视觉设计是否属于同一种法定客体？

审查人员收到文件后，也不能先凭产品市场价值判断是否应保护，而要先确认申请对应发明、实用新型还是外观设计，并在统一受理、审查和授权的制度结构中处理申请。由此，同一事实把客体分类、机关配置、权利边界和制度功能串成一条基础判断链。

**锚定**：该情境锚定三类专利客体的分类标准，以及审查与代理都必须先做客体识别这一制度入口。

**先想一想**：面对同一产品中的内部连接结构和外壳图案，为什么不能仅因它们都“有创新”就直接适用同一类专利保护？

### 法条锚定：客体与审查机关（legal_anchor）

- **《中华人民共和国专利法》第二条**：专利法保护的发明创造分为发明、实用新型和外观设计；三者以技术方案、产品形状构造和产品外观等不同对象为界。
- **《中华人民共和国专利法》第三条**：国务院专利行政部门统一受理和审查专利申请，并依法授予专利权；地方专利管理部门承担本行政区域内专利管理工作。

**为何重要**：第二条决定申请对象能否进入相应专利客体框架，第三条定位受理、审查和授权的制度机关。审查和代理的后续判断均应以这两项基础规范为起点。

### 示例：一项产品改进如何拆分客体（worked_example）

**案情/例题**：乙公司设计了一台便携式检测仪：其内部采用新的插接锁扣结构，方便更换模块；外壳正面采用由弧线与色块组合形成的局部视觉设计。乙公司拟就两部分分别寻求专利保护。应如何依《专利法》第二条完成最初的客体分类？
**适用规则**：《中华人民共和国专利法》第二条：发明创造包括发明、实用新型和外观设计；实用新型针对产品形状、构造或者其结合提出的适于实用的新的技术方案，外观设计针对产品整体或局部的形状、图案及其结合等作出的富有美感并适于工业应用的新设计。
**分步推演**：
1. 先将事实拆分为“内部插接锁扣结构”与“外壳局部视觉设计”，避免把同一产品上的不同创新内容混为一个判断对象。 → *分类的前提是拆清保护对象。*
2. 插接锁扣属于产品内部的结构安排；若其构成适于实用的新的技术方案，应对应审查实用新型的法定定义。 → *结构性技术方案优先进入实用新型定义核对。*
3. 外壳弧线与色块属于产品局部的形状、图案及色彩结合所呈现的视觉设计；应对应审查外观设计的法定定义。 → *产品外观的视觉设计优先进入外观设计定义核对。*
4. 完成客体分类后，申请仍须由国务院专利行政部门统一受理和审查；本例不据此预断其是否最终获得授权。 → *客体分类是入口，不等同于授权结论。*
**结论**：乙公司的锁扣结构与外壳局部视觉设计应分别按照实用新型和外观设计的法定定义进行初步分类；是否授权仍须进入相应法定程序和后续审查。
**本题要点**：先拆事实、再按第二条逐项归类，是代理撰写与审查判断共同适用的第一步。

### 用审查与代理共同语言理解制度基础（verbal_explanation）

可以把这一节理解为专利工作的“入门核对表”。代理人接到客户材料，第一件事不是承诺能否拿到专利，而是问：客户交来的究竟是技术方案、产品结构，还是产品外观？审查人员做的第一步也类似：先把申请放进法律已经规定好的客体框内。发明可以涉及产品、方法或者改进；实用新型的重点是产品形状、构造或者其结合；外观设计看的则是产品整体或局部的外观设计。分清客体之后，才谈申请文件、审查程序和权利保护。还要记住，专利权有独占性，但不是无限权利：它受法定期限和法域边界约束。具体程序问题要先看专利法，再核对实施细则和审查指南，不能用概括印象代替现行依据。

**点破术语**：发明创造；实用新型；外观设计；地域性

### 顺序记忆表：客体—机关—边界—材料（mnemonic）

**记忆锚**：四格核对表：客体 / 机关 / 边界 / 材料。看到一项专利实务事实时，按此顺序记录：先定三类客体，再定受理审查机关，再看权利的时间与地域边界，最后按专利法、实施细则、审查指南的层级查找具体依据。
**映射**：
- 客体
- 机关
- 边界
- 材料
**何时用**：看到“这项成果能否申请”“由谁审查”“规则出处为何”或跨法域材料时，先按四格核对表排查。

### 反思：从分类到材料核验（reflect_prompt）

**反思问题**：复盘既往接触过的一项技术成果：其中哪些事实属于技术方案，哪些事实属于产品外观；若要提出专利建议，第一份需要核验的规范材料是什么？

**关注要点**：是否先把同一产品中的结构创新与视觉设计拆分为不同判断对象。；是否把“可能属于某类客体”误写成“当然可被授予专利权”。；是否区分专利法的基本规则与实施细则、审查指南中可能涉及的具体程序或审查要求。；涉及其他法域时，是否避免把中国规则直接当作对方国家或地区的现行规则。

**连接**：连接到学习者既有的程序法训练：先确定规范依据与处理机关，再进入实体和程序上的具体判断。

### 专利法律制度基础框架（knowledge_synthesis）

**知识框架**：
- 制度特征：独占性、时间性、地域性共同说明专利权是在法定范围内发生效力的权利，而非永久或全球自动有效的权利。
- 制度体系：专利法提供基础法律依据；实施细则和专利审查指南用于查找具体程序与审查要求，但本轮未检索到其原文。
- 法定客体：依《专利法》第二条，发明创造包括发明、实用新型和外观设计，三者的对象与定义不同。
- 制度作用：激励发明创造、促进技术公开、推动技术应用和经济发展，是理解专利制度运行逻辑的功能框架。
- 程序结构观察：以公开、审查、授权为线索理解早期公开延迟审查、初步审查与实质审查并存等特点；具体规则须另查现行规范。
**概念关系**：客体分类是申请与审查的逻辑前提：先识别发明、实用新型或外观设计，再处理相应程序。；制度特征限定权利边界；制度功能解释公开、审查和授权安排的整体目的。；专利法确定基本规则，实施细则和审查指南承接具体操作；跨法域比较应分别核验各法域现行材料。
**必记**：客体分类必须回到《专利法》第二条的法定定义，不能以技术复杂程度或市场价值替代。；国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。；具体程序与审查实践必须按规范层级和现行官方文本核验，概括性制度介绍不能替代具体依据。

### 制度基础速查卡（summary_card）

**要点卡**：
- **三类客体**：发明、实用新型、外观设计均须依《专利法》第二条的不同定义判断。
- **统一审查机关**：国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。
- **权利边界**：独占性必须与时间性、地域性一起理解，专利权并非无限或永久。
- **规范层级**：先以专利法定基本规则，再核验实施细则和审查指南的具体要求。
- **制度功能与程序结构**：以激励、公开、应用的功能框架理解公开、审查、授权的制度安排，但具体程序须查现行文本。
**必背**：《专利法》第二条：发明创造包括发明、实用新型和外观设计。；《专利法》第三条：国务院专利行政部门统一受理和审查专利申请，依法授予专利权。；先定客体，再查机关与规范层级，最后处理具体程序或审查问题。
**一句话总结**：专利制度基础的判断顺序是：依第二条定客体，依第三条定机关，再按权利边界和规范层级处理后续问题。
