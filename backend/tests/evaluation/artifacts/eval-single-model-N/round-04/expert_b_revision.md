# 专家 B 修订稿

## teaching_content

## 1. 场景导入

某科技公司研发了一套用于仓储机器人的控制方案：其中既有控制程序和控制方法，也有机器人底盘的结构改进，还有设备外壳的局部图案设计。代理人准备一次性梳理申请策略，但审查员可能分别从保护客体、授权条件和申请文件修改边界进行审查。此时，代理人不能只问“这是不是新技术”，而要先问：它属于哪一种专利客体？应当适用哪套审查路径？申请日前的资料分别能证明什么？

## 2. 人话解释

专利制度可以理解为一项“用公开换保护”的法律安排：申请人把技术方案或设计公开出来，满足法定条件后，国家在一定范围和期限内给予专利权人排他性保护。这里有三个关键词。第一是独占性，专利权人在保护期限内可以依法排除他人未经许可实施其专利；第二是时间性，专利权保护不是永久的，期限届满会发生专利权期限终止等法律效果；第三是地域性，一国授予的专利权原则上只在该国法律范围内发生效力。要特别分开两个时间维度：申请文件可能在专利权存续期间已经依法公开，技术信息并不是等到保护期限届满才首次向公众公开；期限届满的直接法律意义，是原受该专利权排他效力限制的实施行为不再受该专利权控制。〔RAG: 中华人民共和国专利法.txt — 第四十二条、第四十四条：专利权期限及专利权终止；技术公开时间与期限届满的法律效果属于不同问题〕

判断一项成果能否进入专利制度，先看保护客体。发明主要对应产品、方法或者其改进提出的新的技术方案；实用新型对应产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计对应产品整体或局部的形状、图案，或者其结合，以及色彩与形状、图案的结合形成的富有美感并适于工业应用的新设计。这里的色彩不能脱离形状、图案单独作为该条所称外观设计客体。〔RAG: 中华人民共和国专利法.txt — 第二条：发明、实用新型和外观设计的定义；外观设计的法定结构包括形状、图案或者其结合，以及色彩与形状、图案的结合〕

客体合格后，再进入授权条件判断。对发明和实用新型，核心是新颖性、创造性和实用性；新颖性重点看申请日前是否已有相同技术被公众知悉，创造性重点看相对于现有技术是否显而易见，实用性重点看能否制造或使用并产生积极效果。〔RAG: 中华人民共和国专利法.txt — 第二十二条：发明和实用新型应当具备新颖性、创造性和实用性，现有技术是申请日前在国内外为公众所知的技术〕

实务上可以采用“对象—时间—用途—结论”的顺序：先确定审查对象，再确定申请日和公开时间，接着判断某份材料只能用于新颖性、还是也能进入创造性分析，最后才作结论。特别要注意，申请日以前向国务院专利行政部门提出申请、并在申请日以后（含申请日）公布且记载同样发明的专利申请文件，可能影响新颖性判断；它不能因此当然成为创造性评价中的组合材料。〔RAG: 中华人民共和国专利法.txt — 第二十二条第二款：申请日以前提出、申请日以后（含申请日）公布且记载同样发明的专利申请文件属于新颖性判断中的特殊情形〕

代理人答复审查意见时，还要守住修改边界。申请人可以修改申请文件，但发明和实用新型的修改不得超出原说明书和权利要求书记载的范围；外观设计的修改不得超出原图片或者照片表示的范围。具体修改是否超出范围，应结合原申请文件的整体记载和适用的审查规范核验，不能把“找到相似文字”当成唯一标准。〔RAG: 中华人民共和国专利法.txt — 第三十三条：修改不得超出原说明书和权利要求书记载的范围，外观设计不得超出原图片或者照片表示的范围〕

中国专利制度的规范体系不能只看一部法律：通常要结合专利法、专利法实施细则以及专利审查指南理解申请、审查和代理操作。国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请〕

专利制度的功能也不只是“给权利人一张证书”，还包括激励发明创造、促使技术公开、推动技术应用和经济发展。至于中国制度发展中的早期公开、延迟审查，以及初步审查与实质审查并存等制度沿革，本轮检索材料没有提供足以核验的历史原文，因此这里只作为制度结构提示，具体年份、制度来源和跨法域差异应另行检索核对。

从审查视角，重点是按照法律标准拆解客体、时间、对比文件和修改内容；从代理视角，重点是提前布局权利要求、保存原始记载、识别证据用途，并在答复时把每一项修改与原申请文件建立对应关系。两种视角的共同底线是：不能把不同法律问题混成一个结论。

## 3. 法条回扣

本节以《专利法》第二条确定保护客体，以第二十二条确定发明和实用新型的三性及现有技术范围，以第三十三条控制申请文件修改边界；《专利法》第三条则帮助定位中国专利制度的行政审查体系；第四十二条和第四十四条用于区分专利权期限、终止效果与技术信息公开时间。上述条文构成“先认客体、再审三性、区分公开与期限、最后查程序动作”的基础框架。

## 4. 类比 / 口诀

可以记成“客体先分家，三性再过关，公开与期限分开看，修改看原家”。“客体先分家”是把发明、实用新型、外观设计分开；“三性再过关”是分别检查新颖性、创造性、实用性；“公开与期限分开看”提醒你技术信息可能早已公开，而期限届满主要关系专利权终止及排他效力；“修改看原家”是把改动放回原说明书、权利要求书或原图片照片的记载、表示范围中核验。

这个口诀只用于建立审查顺序，不能替代具体法律判断。尤其是“先新颖性、再创造性”的顺序是实务上的高效分析路径，并不意味着任何案件都可以脱离具体法条、审查指南和证据直接套用。

## 5. 应试提示

看到“产品、方法、形状、构造、图案、色彩”等词，先识别保护客体；看到“申请日前公开”“申请日以后（含申请日）公布”“同样的发明”等词，核对时间和材料用途；看到“补充技术特征”“增加参数”“删除限制”等修改动作，立即追问改动是否超出原说明书和权利要求书记载范围，外观设计则核对是否超出原图片或者照片表示范围。

最常见的混淆有三组：第一，新颖性通常强调单独对比，创造性则要判断相对于现有技术是否显而易见，不能把两者的证明方法混为一谈；第二，抵触申请可能用于新颖性判断，但不能直接拿来评价创造性；第三，初步审查和实质审查承担的功能不同，不能因为申请文件形式合格就推断三性已经成立。
