# 专家 A 修订稿

## teaching_content

## I — 法律问题

本节点处理的不是某一申请的具体授权结论，而是专利制度的基础定位：第一，什么成果属于专利法所称的发明创造；第二，专利权的独占性、时间性、地域性处于什么概念层级；第三，审查机关在制度中承担何种法定职权；第四，如何从代理与审查两个视角，将保护客体、制度体系、制度功能与程序结构依次区分。

## R — 适用规则

《专利法》第二条规定：“本法所称的发明创造是指发明、实用新型和外观设计。”其中，发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计则是对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计；并分别界定三类客体〕

《专利法》第三条规定，国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请，依法授予专利权；省、自治区、直辖市人民政府管理专利工作的部门负责本行政区域内的专利管理工作。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕

据此，本节点按以下要件框架学习：

1. 保护客体：先看申请所要保护的直接对象，再分别对照发明、实用新型、外观设计的法定定义。不得因其都服务于同一产品而混同。
2. 权利基本特征：独占性、时间性、地域性描述专利权的基本性质。独占性说明依法授予的权利具有排他效果；时间性说明权利并非永久存续；地域性说明其效力受法定地域范围限制。它们不构成三类保护客体。
3. 制度体系：本节将专利法、专利法实施细则、专利审查指南作为中国专利制度的规范与审查规则结构进行定位。更准确地说，《中华人民共和国专利法》提供基本规范，《中华人民共和国专利法实施细则》细化行政管理，《专利审查指南》作为审查机关办理具体审查业务的基本规范和实务指导文件。检索上下文未提供后两者的直接原文，故本节不对其具体条款作引述或推断。
4. 制度功能：专利制度通过激励发明创造、促进技术公开、推动技术应用和经济发展，协调研发激励与技术传播。这是制度目的层面的理解，不替代对具体授权条件的审查。
5. 程序结构：教学上下文提示中国制度具有早期公开、延迟审查以及初步审查制与实质审查制并存的总体特征。对发明专利申请，可以把早期公开与延迟审查理解为“先让申请内容进入公开阶段，再按法定程序推进审查”的时间轴；初步审查与实质审查则可理解为不同申请类型和程序阶段的审查层次。这里仅作框架定位，具体申请类型、适用条件和期限应在后续审查程序节点依条文和审查指南逐项核对。

## A — 规则适用

代理视角应当从客户拟保护的直接对象出发，而不是从产品名称或商业目标出发。例如，同一设备可能同时包含控制方法、产品内部连接构造和外壳视觉设计。控制方法及其改进，应依第二条中“产品、方法或者其改进所提出的新的技术方案”识别；连接构造，应依“产品的形状、构造或者其结合所提出的适于实用的新的技术方案”识别；外壳局部图案与轮廓，则应依产品整体或局部形状、图案及其结合形成的设计进行识别。〔RAG: 中华人民共和国专利法.txt — 第二条分别规定发明、实用新型、外观设计的对象〕

审查视角则要求将该客体识别置于法定职权结构中。国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕因此，代理人应提供与所选保护客体相匹配的申请表达，审查人员则依法律规定对申请进行受理、审查和授权判断；两种视角分工不同，但都以客体识别的准确性为前提。

制度功能与权利特征也应分层把握。专利制度通过法律保护激励创新，并通过申请公开与审查安排促进技术信息传播和应用；独占性、时间性、地域性则用于说明依法授予的专利权具有何种基本性质。把“发明、实用新型、外观设计”与“独占性、时间性、地域性”放在同一分类表中，属于对象分类与权利性质的层级混淆。

对于程序结构，应维持证据边界：本节可以建立“公开—审查—授权”的制度地图。在发明专利申请的总体理解中，可用“先公开、后依程序审查”的时间轴说明早期公开与延迟审查的关系；同一产品若分别提出不同类型申请，则应继续核对其适用初步审查或实质审查的具体规则。这个时间轴只是帮助定位程序阶段的教学模型，不能替代对具体审查条件和期限的法条、实施细则及审查指南核验。

## C — 结论

专利法律制度基础的判断顺序应为：先依《专利法》第二条识别保护客体；再依第三条定位受理、审查和授权的法定职权；继而将独占性、时间性、地域性作为专利权的基本特征理解；同时把专利法、专利法实施细则和专利审查指南分别放回基本规范、行政管理细化和审查业务规范及实务指导的位置；最后在制度功能和程序结构层面建立整体地图。这样，代理工作不会把不同成果混为一类，审查工作也不会脱离法定客体和职权边界。

> 常见误区 / 易混淆点
>
> 1. 将“独占性、时间性、地域性”误写成专利的三种类型。正确区分是：三类保护客体为发明、实用新型、外观设计；三项基本特征描述专利权性质。
> 2. 看到同一产品便只作一种客体判断。正确做法是拆分请求保护的直接对象，分别按第二条定义核对。
> 3. 将代理人的申请布局职责与审查机关的法定职权混同。代理人侧重准确表达和布局，国务院专利行政部门依法统一受理、审查并授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕
> 4. 将本节的程序结构概述当作具体审查规则。本节对早期公开、延迟审查以及两类审查制度仅作教学上下文中的框架定位，具体规则须在后续节点以直接法律依据核验。
> 5. 场景追问：面对同一产品中的方法、构造和外观设计，代理人首先应拆分哪些请求保护的直接对象？审查机关的受理、审查和授权职权又处于哪一环节？
> 6. 场景追问：若先把商业产品名称当作唯一客体，再讨论公开和审查程序，可能同时混淆哪两组边界？应先回到第二条的客体定义和第三条的职权定位。
