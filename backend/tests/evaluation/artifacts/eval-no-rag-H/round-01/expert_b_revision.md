# 专家 B 修订稿

## teaching_content

## 1. 场景导入

假设你在材料公司担任研发工程师，最近团队开发了一种新型复合材料，专门用于航空航天结构部件。你在公司内部会议上展示了该材料的性能数据，并计划在下个月的国际材料展会上进行现场演示。但你担心如果在展会前申请专利，展会展示会不会被视为“公开”，导致新颖性被破坏？同时你也知道专利授权不是只要“新”就行，还需要“创造”和“实用”。这个情境把材料技术的具体研发流程、公开行为的风险和三性审查的抽象规则一次性串联起来，帮助你立刻看到专利法在实际申请中的应用场景。注意：展会是否属于宽限期所覆盖的法定公开类型，不能仅凭“国际展会”或“国际会议”的名称判断，还要核对具体事实和法律条件。

## 2. 人话解释

专利授权的核心门槛可以先用“三性”概览：新颖性要求权利要求所限定的发明或实用新型，与申请日以前的现有技术相比不能已经被相同公开；创造性要求相对于现有技术，对本领域普通技术人员不是显而易见的；实用性要求能够制造或者使用，并且能够产生积极效果。这里的“现有技术”不是“只要听说过就算”，而是要结合申请日前的时间界限、公开内容和具体技术方案进行判断。

简单说，新颖性像“单独对照”检查：看一份现有技术是否已经给出了相同的技术方案；创造性像“是否容易想到”检查：在现有技术基础上判断是否显而易见；实用性像“能否落地并产生积极效果”检查。先判断对象是否属于可讨论的专利保护客体，再分别核对实用性、新颖性和创造性，是便于学习的分析框架，不表示技术方案一经成立就当然具备新颖性，也不表示法律规定了唯一固定的审查顺序。

## 3. 法条回扣

《中华人民共和国专利法》第二条解决的是“保护什么对象”，分别界定了发明、实用新型和外观设计：发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。这里不要把“保护客体”与“专利权”概念混为一谈。

《中华人民共和国专利法》第二十二条规定，授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性；实用性对应的规范表达是“能够制造或者使用，并且能够产生积极效果”。

《中华人民共和国专利法》第二十四条规定了不丧失新颖性的法定例外情形。展览、会议或发表行为是否适用，必须核对其是否属于条文列举的特定公开类型及其他条件，不能把一般国际会议展示或普通论文发表当然视为享有宽限期。

《中华人民共和国专利法》第二十五条规定，科学发现、智力活动的规则和方法、疾病的诊断和治疗方法等不授予专利权。它解决的是主题是否属于不授予专利权的范围，与第二十二条的三性要求属于不同层次的问题。

## 4. 类比 / 口诀

用“先看门，再查三性”记忆：第一步问“这是不是法律保护的对象”；第二步分别问“能不能制造或者使用并产生积极效果”“申请日前是否已有相同现有技术公开”“相对于现有技术是否显而易见”。类比边界：新颖性重点是单独对照，创造性涉及是否显而易见，实用性关注可实施性和积极效果；三者不能互相替代。口诀：“先看对象，再核实用；单独比新颖，整体问创造。”这只是学习分析顺序，不是由对象属性自动推出三性结论，也不是对所有案件审查次序的绝对规定。

## 5. 应试提示

题干关键词：申请日、公开日、现有技术、显而易见、技术方案。判断步骤：1. 看对象是否属于发明、实用新型或外观设计，且是否落入第二十五条排除范围；2. 分别核对实用性、新颖性和创造性的法律要求；3. 遇到申请日前公开，核对公开内容、公开时间以及是否属于第二十四条列举的特定情形。常见陷阱是把科学发现或智力活动规则当成技术方案，把技术方案属性直接当成新颖性结论，或把普通论文、一般会议展示当然视为享有六个月宽限期。
