## 教学正文

## 专利法律制度基础：审查与代理双视角复盘

### I｜问题入口：先判“保护什么”，再谈“能否授权”

本节点的主线不是凭技术先进性直接预测授权，而是建立一条可复核的基础路径：先识别法定保护客体，再定位中国专利制度的规范体系和审查职权，随后区分实用性、新颖性、创造性等不同授权条件，最后检查权利效力的边界。专利权的独占性、时间性、地域性是本节用于复盘权利边界的三个分析维度；本轮检索上下文未提供这三个概念的直接法条原文，因此不据此补写具体期限或跨法域效果。〔RAG: 检索上下文未提供直接依据 — 专利权三特征仅作为制度分析框架〕代理人关注如何把技术事实转化为合规的申请布局；审查人员关注申请是否符合相应法律和审查规则。二者立场不同，但不能跳过同一法条入口。

### R｜规则框架

#### 1. 三类保护客体

《专利法》第二条规定：“本法所称的发明创造是指发明、实用新型和外观设计。”发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计；发明、实用新型、外观设计分别具有相应法定定义〕

分类时不要只看产品名称，而要看申请真正要保护的内容：方法或产品技术方案首先进入发明客体分析；产品的形状、构造或者其结合首先进入实用新型客体分析；产品整体或局部的视觉设计首先进入外观设计客体分析。检索到的专题材料进一步说明，实用新型只保护产品，产品应当是经过产业方法制造、具有确定形状或构造并占据一定空间的实体；制造、使用、处理等方法不属于实用新型保护客体。〔RAG: 专利法专题讲座.txt — 实用新型专利只保护产品；一切方法不属于实用新型的保护客体〕

#### 2. 中国制度体系与审查入口

《专利法》第三条规定，国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请，并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门负责管理全国专利工作；统一受理和审查专利申请，依法授予专利权〕

实务复盘应区分规范层次：专利法提供基本法律依据，专利法实施细则承接申请、审查和程序安排，专利审查指南则用于具体审查实践的操作理解。检索材料支持这样的程序链条：申请先接受初步审查；除予以驳回的外，初步审查后将申请予以公布；发明申请还存在提出实质审查请求后进入实质审查的程序安排。〔RAG: 检索上下文chunk_id 2578 — 初步审查后公布、发明申请延迟审查请求及相关程序安排〕实施细则第五十七条还规定，发明申请人在提出实质审查请求时以及收到进入实质审查阶段通知书之日起三个月内，可以主动修改，实用新型或外观设计申请人自申请日起两个月内可以主动修改。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十七条：发明申请、实用新型和外观设计申请主动修改的相应时点〕

因此，初步审查与实质审查不能混为一谈：前者是进入后续程序前的前置审查环节，后者针对发明申请的授权条件等问题作进一步判断。这里的“早期公开、延迟审查、初步审查与实质审查并存”是对检索到的制度程序特点的概括；本轮没有足够材料支持完整历史沿革、所有适用条件或最新审查口径，不对这些部分作超出依据的确定性断言。

#### 3. 专利制度的作用

专利制度的作用可以放在“有边界的权利安排”中理解：在法定保护范围和期间内提供排他利益，形成对发明创造投入的预期回报，从而发挥创新激励作用；申请人以公开技术方案换取这种受限制的保护，公开机制使技术信息能够进入社会知识基础，减少重复探索并为后续改进提供条件；技术方案进一步通过实施、许可等方式转化，可能推动技术应用和经济发展。这里的因果链是制度机制的教学解释，不是本轮检索上下文中直接提供的法条原文。〔RAG: 检索上下文未提供直接依据 — 专利制度作用的上述表述为制度分析框架，不作为已核验法条引文〕

代理人因此不能只承诺“拿到专利就获得永久、全球保护”，而应说明权利范围、法定期间和适用法域等边界；审查人员则应围绕法定客体、程序和授权条件判断。制度的激励功能并不意味着技术先进或商业价值高就当然可以授权，公开机制也不等于公开后所有人均可无条件实施，仍需结合权利范围和适用法律分析。

#### 4. 授权实质条件、时间轴与三性边界

第二十二条规定，授予发明和实用新型专利权应当具备新颖性、创造性和实用性，并规定现有技术是申请日以前在国内外为公众所知的技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条：授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性；现有技术是申请日以前在国内外为公众所知的技术〕本节 lesson_focus 要求掌握三性的总体框架以及新颖性、创造性的区分。

在概念上可以先作如下边界区分：新颖性原则上采用单独对比，重点是单一对比文件或相应法律性质的单一材料是否公开了权利要求的全部技术内容；不能把多篇文件简单拼接后直接当作新颖性结论。创造性不是新颖性的同义重复，而是继续分析现有技术、区别特征、区别特征产生的技术效果、实际解决的技术问题以及本领域技术人员是否会得到技术启示。创造性分析可以涉及现有技术的组合，但组合并不自动等于存在技术启示。

抵触申请与现有技术要放在同一时间轴上分别核对。现有技术通常指申请日以前已经为公众所知的技术；抵触申请则涉及申请在先、公开在后的特殊时间结构。二者的法律性质、公开时点和可评价事项不能混同。根据本节教学指令，抵触申请只能用于评价新颖性，不能与其他现有技术组合用于评价创造性；具体案件仍需核对现行法和审查指南。尤其要记录申请日、优先权日、公开日和公开方式，不能只凭“对比文件”这一称呼下结论。

创造性中的“实际解决的技术问题”也有明确的推理边界：它应当从区别特征所产生的技术效果归纳，而不是把区别特征本身直接改写成问题。例如，不能仅说“增加了隔热层，所以实际问题是增加隔热层”；应继续追问该区别特征带来了什么技术效果，以及该效果所对应的客观技术问题是什么。

### A｜审查与代理双视角适用

以检测设备为例，内部信号处理方法属于方法技术方案的分析对象；壳体的可拆卸连接和加强筋属于产品形状、构造及其结合的分析对象；局部图案与形状设计属于外观设计的分析对象。它们服务同一设备，不等于必须归入同一种保护客体。若权利要求同时写入产品构造和浸泡处理步骤，代理人应识别实用新型客体风险，并依据原始披露、单一性、申请时点及现行程序规则评估分开布局或修改路径；审查人员则先按照法定客体和申请文件规则核对，不因“技术很新”或“客户想保护”而跳过客体判断。

进入三性复盘时，先建立日期表：申请日、优先权日、公开日分别记录；再判断材料究竟属于申请日前公众已知的现有技术，还是申请在先、公开在后的抵触申请；之后分别采用新颖性单独对比和创造性技术启示分析。审查结论必须说明法律性质、适用规则、证据内容和推理结果；代理意见则应在同一证据底座上提出风险等级和合规修改方案。两者不能互换。

### C｜结论与复盘口诀

本节点可压缩为六步：“客—规—轴—新—创—界”：先分发明、实用新型、外观设计；再标明专利法、实施细则和审查指南的规范来源；接着核对申请日、优先权日和公开日；然后以单独对比复盘新颖性；再以区别特征、技术效果、实际解决的技术问题和技术启示分析创造性；最后检查权利效力边界。关于独占性、时间性、地域性，本轮检索未提供直接法条原文，口诀中的“界”仅是复盘维度，不代替对具体期限和法域效果的核验。关于制度作用，应沿“有边界保护—创新激励—技术公开—实施转化”的机制链理解；该机制链同样是教学分析框架，不是本轮检索到的法条原文。

常见错误有三类。第一，误解为同一产品中的所有创新都可以统一按发明申请；正解推理是按实际保护内容分别对照第二条，方法、产品构造和视觉设计各有入口。第二，误解现有技术和抵触申请都是同一种对比文件；正解推理是分别核对公众知悉时间、申请在先与公开在后的时间结构及可评价事项。第三，误解区别特征就是实际解决的技术问题；正解推理是先找区别特征产生的技术效果，再从效果归纳客观技术问题，最后判断是否存在技术启示。

### 场景导入：从一件产品看保护客体边界（anchor_scenario）

> 甲公司研发一台便携式检测设备。研发团队一方面改进了设备内部的信号处理方法，另一方面改造了壳体的形状、内部加强构造，并设计了壳体局部的图案。产品经理认为“都是同一台设备，统一申请发明即可”；代理人则需要拆分保护重点，审查人员还要判断每项内容是否落入相应法定客体。公司准备在中国申请并在海外销售，管理层还要区分一国专利授权与其他法域保护之间的关系。冲突集中在三个入口：先辨认保护客体，再进入授权条件和审查程序，最后确认专利权效力边界。

**锚定**：用同一件检测设备锚定三类保护客体、审查与代理分工、专利权效力边界及授权条件的先后边界。

**先想一想**：如果你同时站在代理人和审查人员的角度，面对同一台设备中的方法、产品构造和视觉设计，第一步应当按什么标准拆分，而不能只看产品名称？

### 法条锚定：客体、职权与授权条件入口（legal_anchor）

- **《中华人民共和国专利法》第二条**：第二条把发明创造分为发明、实用新型和外观设计，并分别规定其保护对象：发明可涉及产品、方法或者改进的技术方案；实用新型聚焦产品的形状、构造或者其结合；外观设计聚焦产品整体或局部的形状、图案及其结合以及相关色彩设计。
- **《中华人民共和国专利法》第三条**：第三条确定国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请并依法授予专利权。
- **《中华人民共和国专利法》第二十二条**：第二十二条规定，授予发明和实用新型专利权应具备新颖性、创造性和实用性，并定义现有技术为申请日以前在国内外为公众所知的技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条：授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性；现有技术是指申请日以前在国内外为公众所知的技术〕
- **《中华人民共和国专利法实施细则》第五十七条**：实施细则第五十七条规定了不同类型申请主动修改的相应时间安排；发明申请与实用新型、外观设计申请的修改时点并不相同。

**为何重要**：本节点的共同底座是“先识别保护什么，再定位规范和程序，最后分析授权条件与权利边界”。审查人员据此确定审查对象，代理人据此组织申请和风险提示；凡涉及三性、时间轴或跨法域动向，都应以现行权威文本复核。

### 工作示例：从混合事实到客体分类（worked_example）

**案情/例题**：乙企业准备为检测设备布局专利：资料一记载提高测量精度的信号处理方法；资料二记载壳体的可拆卸连接构造；资料三记载壳体局部的图案和形状设计。另有一项草拟权利要求同时写入“圆柱形木质牙签”和“浸泡杀菌剂五至二十分钟后晾干”的步骤。请按审查与代理双视角演示客体入口和复盘顺序。
**适用规则**：《中华人民共和国专利法》第二条、第三条和第二十二条。检索到的专题材料说明：实用新型只保护产品，产品应是经产业方法制造、具有确定形状或构造并占据一定空间的实体；一切方法不属于实用新型保护客体。第二十二条的三性及现有技术定义以检索到的现行文本为准。
**分步推演**：
1. 先把技术事实按保护重点拆开，而不是按“检测设备”这一产品名称整体归类。方法步骤、产品形状构造和产品视觉设计是不同的事实表达，分别对应不同的法定客体分析入口。 → *第一步：拆分技术事实和保护重点。*
2. 资料一涉及对方法提出的技术方案，首先与第二条关于发明的定义比对；资料二强调产品形状、构造及其结合，首先与实用新型定义比对；资料三强调产品局部的形状、图案及其结合以及美感，首先与外观设计定义比对。 → *第二步：逐项对照第二条的法定定义。*
3. 混合权利要求虽然同时出现产品形状和方法步骤，但实用新型的法定对象是产品的形状、构造或者其结合。检索材料明确提示，制造、使用、处理等方法不属于实用新型保护客体，因此不能用“有产品形状”掩盖方法步骤带来的客体问题。 → *第三步：识别实用新型中的方法步骤风险。*
4. 代理人应根据原始披露、单一性、申请时点和具体程序评估是否将产品构造与方法分别布局；审查人员则先确认客体和申请文件是否符合相应规范，再进入后续授权条件判断。 → *第四步：区分布局建议与审查结论。*
**结论**：资料一的信号处理方法首先按发明的技术方案入口分析；资料二的壳体形状和加强构造首先按实用新型入口分析；资料三的局部图案和形状首先按外观设计入口分析。混合权利要求不能仅因写有产品名称就当然属于实用新型客体，须依现行审查规则具体处理。
