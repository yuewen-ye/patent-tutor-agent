指标计算口径（按顺时针顺序 幻觉 → 质量 → 覆盖 → 匹配 → 溯源）：

质量 · 1.2 谬误率汇总 [LLM] · y（总抽取条数）— 得分 = y / max_y × 100，max_y 取 5 组最大值 = 212（multi 全量有效陈述条数）；反映课程内容的陈述抽取样本量 / 教学内容密度；范围 0~100

与上一版（v2）相比的主要修正

① norag M4 检索准确率/完整率：之前 93.2% / 70.1% 来自"把课程包章节切片当代理chunk"的兜底伪数据，现标记 NA。 ② nodebate M6 异议闭环：之前 LLM 对空内容主观打 75/100 的荒谬分，现标 NA；其余 4 组0异议也统一改为 100 分（空闭环客观事实优先）。 ③ 谬误率显示：原裸%（0.6%/2.7%易误导）改为 x/y（1/125 vs 3/72，可见分母差异），新增 1.3 谬误率汇总（分母=全量陈述）统一口径。 ④ 动态迭代触发率：阈值从 |Δpl|≥0.05 改为分档（低≥0.08/中≥0.10/高≥0.12），避免 BKT 天花板噪声刷出 100%。 ⑤ PII、检索、异议的 not_applicable 识别：calculate.py 新增对 status=not_applicable 和 accurate_rate=None 的识别，报告层统一用"-"显示，不再 0.0 假占位。 ⑥ 谬误分类来源标注：LLM statement 模式的 error_type 真实标注（899 条中 factual 518 / logical 140 / instructional 240），脚本不启发式兜底。

如何解读谬误率跨组差异

1) 先看「1.3 谬误率汇总」（分母=所有有效陈述，口径稳定）， 再看 1.3.1/1.3.2/1.3.3 分子的绝对差（如果 1~2 条陈述级别的差：不构成可重复结论）。 2) logical / instructional 每轮样本量常 <5，单画像的 0/y 或 1/y 不可跨组比较；如需比较请跨 5 轮合并。 3) nodebate 的 0/149 (0.0%) 是"少说话=少犯错"的保守副产品，不是质量更优的证据； 同时 M6 异议率/闭环被消融设计直接禁用，不代表"异议闭环质量更好"。 4) norag 3/149 (2.0%) 与 multi 2/212 (0.9%) 的差距=1 条陈述量级，在 5 轮平均上仍属于"可波动不可定论"， 真实差异应看 3.1 知识点覆盖率（norag 82.4% / multi 93.8%）等"大分母"指标。
