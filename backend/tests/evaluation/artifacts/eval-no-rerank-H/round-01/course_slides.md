```json
  "bullets": [
    "① 成果主要体现产品、方法或者其改进的技术方案 → 按发明客体方向",
    "② 成果主要体现产品的形状、构造或者其结合 → 按实用新型客体方向",

```

**讲稿**
现在我们来看一个清晰的判断流程。首先区分成果属于哪类客体：产品方法属发明，形状构造属实用新型，视觉设计属外观设计。确定客体后，再进入相应的授权条件，并用申请日、公开日和优先权日建立准确的时间轴。
