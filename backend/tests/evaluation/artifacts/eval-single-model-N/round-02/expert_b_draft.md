## 教学正文

## 1. 场景导入

设想代理人收到一份便携式检测设备的研发交底：团队既改进了检测步骤，又改进了传感器支架结构，还设计了新的外壳局部图案。审查视角要问“申请主张的对象落在哪一类法定客体内”；代理视角要问“应当怎样把不同事实拆开、用恰当的制度语言表达”。同一件产品不是天然只对应一个法律标签。

## 2. 人话解释

专利制度不是“有创意就自动获得保护”。它给的是有边界的法定权利：独占性表示权利具有排他效力，时间性和地域性提醒我们，这种效力并非永久、也并非天然覆盖全世界。处理具体项目时，先用“权—规—客—用—程”五格复盘：看权利边界，找规范依据，辨认保护客体，理解制度作用，最后整理程序阶段。

客体识别尤其要拆细：新的产品、方法或改进的技术方案属于发明的定义范围；产品的形状、构造或者其结合的改进，对应实用新型；产品整体或局部的形状、图案及其结合等视觉设计，对应外观设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明是对产品、方法或者其改进所提出的新的技术方案；实用新型针对产品的形状、构造或者其结合；外观设计针对产品整体或者局部的形状、图案等新设计〕

## 3. 法条回扣

《中华人民共和国专利法》第二条明确，本法所称发明创造是发明、实用新型和外观设计。〔RAG: 中华人民共和国专利法.txt — 第二条：本法所称的发明创造是指发明、实用新型和外观设计〕 因而，代理人不能只写“这是一个创新产品”，而应当把技术事实对准相应法定定义；审查也应当先确认申请对象。

《中华人民共和国专利法》第三条规定，国务院专利行政部门统一受理和审查专利申请，依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕 在规范检索上，可把专利法作为基本制度入口，并结合专利法实施细则和专利审查指南继续核对程序与审查操作。课程节点列出的早期公开、延迟审查以及初步审查制与实质审查制并存，是整理制度运行的复盘线索；本轮检索材料没有其具体规范原文，不能据此替代逐条核验。

## 4. 类比 / 口诀

可把制度理解为“公开换取法定保护机会”的规则系统：公开解释制度为何鼓励技术传播，法定保护机会解释为什么需要申请和审查。这个类比的边界是，公开技术内容不等于当然获得专利权，具体权利仍取决于法定对象、程序和审查。

顺序口诀用“权—规—客—用—程”：权是独占性、时间性、地域性；规是专利法、实施细则、审查指南的检索主线；客是发明、实用新型、外观设计；用是激励创造、促进公开和应用的制度作用；程是按公开与审查阶段整理材料。它用于复盘顺序，不替代具体条文判断。

## 5. 应试提示

题干出现“产品、方法、改进”时，先定位发明；出现“产品形状、构造或者其结合”时，先定位实用新型；出现“产品整体或局部的形状、图案、美感、工业应用”时，先定位外观设计。〔RAG: 中华人民共和国专利法.txt — 第二条分别规定发明、实用新型和外观设计的定义〕

双视角的稳定顺序是：先拆研发事实，再选法定客体；代理人据此组织申请表达，审查人员据此确定审查入口。不要把“制度具有激励作用”误写成“所有创新都能授权”，也不要因为多个改进装在同一产品里，就忽略其可能属于不同客体层面。

### 从一件产品看三类专利（anchor_scenario）

> 某医疗器械团队完成了一种便携式检测设备：设备内部有新的传感器结构，检测步骤也经过改进，产品外壳还采用了醒目的局部图案。研发负责人希望尽快布局专利，但团队内部争论不休：这一项成果究竟应按发明、实用新型还是外观设计考虑？

代理人在准备申请前，需要先把技术成果拆开看：结构、方法和产品视觉设计并不当然属于同一种保护客体；审查人员则需要依照法定定义确认申请所主张的对象。两种视角的共同起点，都是先辨认专利制度保护什么、由什么规范审查。

**锚定**：该情境锚定三类专利保护客体、审查机关职责以及代理人先做客体识别的基础工作。

**先想一想**：面对同一件产品中的技术方案、产品结构和视觉设计，为什么不能只用一个“专利”标签笼统处理？

### 先把制度落回条文（legal_anchor）

- **《中华人民共和国专利法》第二条**：专利法中的“发明创造”不是泛指一切创意，而是发明、实用新型和外观设计三类；三类对象各有法定定义。
- **《中华人民共和国专利法》第三条**：国务院专利行政部门统一受理和审查专利申请并依法授予专利权，地方管理部门负责本行政区域内的专利管理工作。

**为何重要**：专利法第二条解决“申请的对象是什么”，第三条定位“谁负责受理、审查和授权”。代理人据此组织申请对象，审查人员据此在法定职责内处理申请。

### 把复合成果拆成三类客体（worked_example）

**案情/例题**：演示案情：某团队的便携式检测设备包含三项改进：一是新的样本检测步骤，二是传感器支架的形状与构造改进，三是外壳局部的图案设计。代理人需要先为三项改进辨认相应的专利保护客体。
**适用规则**：《中华人民共和国专利法》第二条：发明包括对产品、方法或者其改进提出的新的技术方案；实用新型针对产品的形状、构造或者其结合；外观设计针对产品整体或者局部的形状、图案及其结合等所作出的富有美感并适于工业应用的新设计。
**分步推演**：
1. 先把“检测步骤”从实体产品上单独抽出。第二条将对方法或者其改进所提出的新的技术方案纳入发明定义。 → *方法层面的技术方案，先按发明对象识别。*
2. 再看传感器支架，关注的是产品本身的形状、构造及其结合，而不是检测步骤。第二条对实用新型的定义正对应这一类有形产品结构改进。 → *产品结构层面的改进，先按实用新型对象识别。*
3. 最后看外壳局部图案，核心是产品局部的视觉设计及美感、工业应用属性，而非其技术工作原理。 → *视觉设计层面的改进，先按外观设计对象识别。*
4. 对象分类只是入口。不同申请仍须按照其适用规则经历受理、审查和授权程序，不能因属于法定客体就直接推出必然授权。 → *客体识别与最终授权是两个层次。*
**结论**：同一产品可以包含不同层面的成果：新的检测步骤可作为发明的对象考察，新的传感器结构可作为实用新型的对象考察，外壳局部图案可作为外观设计的对象考察；最终是否授权仍须分别进入相应程序和条件审查。
**本题要点**：处理研发成果时，先按“方法、产品结构、视觉设计”拆分事实，再对应第二条的三类法定客体。

### 把制度语言翻译成实务动作（verbal_explanation）

先不要把专利制度理解成“有新点子就自动受保护”。它是一套有边界的法律制度：权利有排他性，但只在法定期限和法定地域内发挥作用。代理人拿到研发材料，第一件事不是立刻堆砌技术术语，而是确认成果属于方法技术方案、产品结构方案，还是产品视觉设计；审查人员也必须从这个法定分类起步。专利法第二条把发明创造限定为发明、实用新型和外观设计，并分别给出定义。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕 中国制度的规范主线可按专利法、实施细则和审查指南逐层查找：遇到基本权利和法定客体先回到专利法，遇到程序和审查操作再核对相应规范。国务院专利行政部门统一受理和审查专利申请、依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕 制度功能则是通过公开技术信息与设置法定保护机会，激励发明创造、促进技术应用；但本次检索材料未提供该功能表述及早期公开、延迟审查、初步审查与实质审查并存的具体规范依据，实务复盘时应再核对实施细则和审查指南原文。

**点破术语**：独占性、时间性、地域性；制度体系；发明；实用新型；外观设计

**类比**：可以把专利制度理解为一套“公开换取法定保护机会”的规则系统：这个类比只帮助理解制度功能，不表示提交技术内容就当然取得专利权；具体权利是否产生仍取决于法定程序和审查。

**映射**：

### 双视角复盘（reflect_prompt）

**反思问题**：回看一份研发交底书时，代理人与审查人员分别会优先标出哪些事实，二者在哪一步必须使用同一套客体分类标准？

**关注要点**：代理人关注如何把技术事实拆为可申请的对象并安排文件准备。；审查人员关注申请所主张对象能否落入法定定义及应适用的审查路径。；两种角色都不能把产品结构、方法步骤和视觉设计混为同一客体。；制度功能说明学习专利法的目的，但不能替代具体条文和程序规则。

**连接**：连接到学习者已有的程序法经验：先确定处理机关与规范层级，再判断事实应进入哪个法律构成要件。

### 专利制度基础关系网（knowledge_synthesis）

**知识框架**：
- 权利特征：专利权具有独占性、时间性和地域性，理解时要避免把它看成永久且全球通行的技术控制权。
- 制度体系：以专利法为基本制度依据，结合专利法实施细则和专利审查指南分别查找程序和审查操作依据。
- 保护客体：第二条把发明创造分为发明、实用新型和外观设计；方法技术方案、产品结构和视觉设计要分别识别。
- 制度作用：专利制度以公开与法定保护机会相结合，服务激励发明创造、技术公开、技术应用和经济发展。
- 制度运行特点：本节以早期公开、延迟审查以及初步审查制与实质审查制并存作为复盘线索；具体适用应再核对实施细则和审查指南。
**概念关系**：先确定权利边界和规范层级，再按第二条识别保护客体，随后才进入相应申请、审查与授权问题。；制度功能解释为什么设立专利制度；保护客体和审查程序决定一项具体申请如何被处理。；早期公开与后续审查阶段属于制度运行线索，不能替代对具体客体和法定条件的判断。
**必记**：《专利法》第二条中的三类发明创造是发明、实用新型和外观设计，三者的法定对象不同。；国务院专利行政部门统一受理、审查专利申请并依法授予专利权。；审查或代理复盘的第一步是识别事实对应的保护客体与规范依据，而非直接讨论是否能够授权。

### 制度基础速查卡（summary_card）

**要点卡**：
- **权利边界**：独占性不等于永久或全球有效，时间与地域是专利权的基本边界。
- **规范主线**：先查专利法的基本制度，再按问题核对实施细则和审查指南。
- **三类客体**：发明看产品、方法或改进的技术方案；实用新型看产品形状、构造；外观设计看产品整体或局部的视觉设计。
- **制度功能**：以公开与法定保护机会促进创造、技术公开和技术应用。
- **运行线索**：用公开与审查阶段整理制度过程，具体程序规则必须回到相应规范。
**必背**：发明创造是指发明、实用新型和外观设计。；发明可以涉及产品、方法或者其改进的新的技术方案。；实用新型聚焦产品的形状、构造或者其结合。；外观设计聚焦产品整体或局部的形状、图案及其结合等视觉设计。；国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。
**一句话总结**：专利实务复盘先定“权、规、客”，再把制度功能和程序阶段放回同一张图。
