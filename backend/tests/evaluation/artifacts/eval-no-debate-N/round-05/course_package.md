## 教学正文

## I — 法律问题

本节点先解决一个基础但决定后续审查与代理分析起点的问题：面对一项技术成果，如何依次确认其是否属于专利制度所称的发明创造、应当进入何种制度框架，以及应如何理解专利制度的独占性、时间性与地域性。

从审查视角，先要核对申请客体和法定程序位置，不能把技术名称或商业价值直接等同于可受专利制度评价的客体。从代理视角，先要把客户的技术事实准确翻译为法定客体，并据此安排申请文件与程序动作。专利权特征中的独占性、时间性、地域性是理解制度运行的基础概念；但本次检索材料未提供其直接条文定义，以下仅作体系化理解，不将其作为具体法条文字的引述。

## R — 适用规则

《专利法》第二条规定，本法所称的发明创造包括发明、实用新型和外观设计；其中，发明是对产品、方法或者其改进提出的新的技术方案，实用新型是对产品的形状、构造或者其结合提出的适于实用的新的技术方案，外观设计则是对产品整体或者局部的形状、图案及其结合，以及色彩与形状、图案结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

制度主体方面，国务院专利行政部门负责全国专利工作的管理，统一受理和审查专利申请，并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕因此，专利法规定基本权利与制度边界；实施细则将程序事项具体化；审查指南则服务于审查标准的具体适用。后两者的完整规范定位，本次检索上下文未提供直接原文，不能据此扩展为具体条款结论。

程序上，实施细则显示：申请经初步审查后，除被驳回外应立即公布；发明专利申请公布后至授权公告前，任何人可以就不符合专利法规定提出意见并说明理由；国务院专利行政部门依照专利法第三十五条第二款自行审查时，应通知申请人，申请人可以请求延迟审查。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十四条至第五十六条：初步审查后公布、提出意见、通知自行审查与延迟审查〕发明专利申请人可在提出实质审查请求时及收到进入实质审查阶段通知书之日起三个月内主动修改；实用新型或外观设计申请人则可自申请日起两个月内主动修改。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十七条：不同类型申请的主动修改期间〕

制度功能可从上述规则结构理解：申请人以公开申请文件进入法定审查程序，符合条件时取得受法律保护的权利；制度因而同时形成对发明创造的激励、对技术信息公开的促进，并服务于技术实施和经济活动。此处是从法定客体、申请公布和授予机制作出的制度性归纳，而非对某一条文的直接引述。

## A — 规则适用

第一步，代理人应将客户陈述拆分为“产品、方法或改进”“产品的形状、构造”“产品整体或局部的视觉设计”三类事实。若核心贡献是产品、方法或其改进的技术方案，应先按发明的法定定义核对；若限定于产品形状、构造或其结合且适于实用，应核对实用新型定义；若核心是产品视觉设计，还必须核对美感与工业应用要素。不能仅因名称中含有“技术”或“设计”就预先定类。

第二步，审查视角应把客体判断与程序阶段分开。客体属于何种发明创造，回答的是制度评价对象；初步审查、申请公布、实质审查及申请人修改期间，回答的是申请在何种程序位置以及可以采取什么程序动作。二者不能互相替代。

第三步，理解权利特征时应避免绝对化。独占性说明专利权具有排他保护的制度属性，并不表示申请一提交即当然取得完整专利权；时间性提示保护受法定期间和程序节点约束；地域性提示权利效力须置于具体法域的法律框架中判断。跨法域比较必须分别核对各法域规则，不能仅凭中国申请程序推导其他法域的法律效果。

第四步，制度功能不是额外授权要件。审查员和代理人都应先依条文界定客体、遵循程序规则；制度对激励、公开和应用的作用，是理解规则目的的框架，不能替代对个案法定要件的核对。

## C — 结论

专利法律制度基础的正确分析顺序是：先依《专利法》第二条识别发明、实用新型或外观设计，再区分实体客体问题与程序阶段问题，最后在具体法域和法定期间内理解专利权的制度属性。代理工作以准确分类和程序安排降低风险；审查工作以法定客体与程序规则保持判断边界。本节设有测评，请到【习题】区作答。

> 常见误区 / 易混淆点
>
> 1. 将“发明创造”仅理解为发明专利。第二条将发明、实用新型、外观设计并列纳入发明创造。
> 2. 将“初步审查后公布”理解为已经授权。公布、审查和授权是不同的程序节点。
> 3. 将独占性理解为无期限、无地域的绝对控制。专利权的具体效力必须在法定期间和具体法域内判断。
> 4. 仅因客户方案具有商业价值就认定其当然属于某一专利客体。必须回到法定定义逐项核对。

### 从技术成果到法定专利客体（anchor_scenario）

> 某装备企业的研发团队完成了一套自动分拣装置：核心改进是传动组件的形状和构造；同时，团队还为设备外壳设计了局部图案与色彩组合。负责人要求代理人“尽快申请专利”，却没有说明两部分成果是否应按同一类型处理，也不清楚申请提交后何时会公开、何时可能进入进一步审查。

代理人需要先把技术事实拆开：传动组件的改进是否属于产品形状、构造的技术方案；外壳视觉设计是否属于产品局部的设计；随后还要向客户说明，提交申请、初步审查、公布和授权并非同一件事。

**锚定**：该情境锚定三类专利客体的区分，以及客体判断与申请程序阶段必须分开的基础框架。

**先想一想**：如果只能先核对一项事实，你会先核对技术方案的内容，还是先核对客户希望何时取得权利？

### 法条锚定：客体、主管机关与程序节点（legal_anchor）

- **《专利法》第二条**：专利法意义上的发明创造有三类：发明、实用新型、外观设计，且每一类都有不同的法定定义。
- **《专利法》第三条**：国家专利行政机关统一受理和审查专利申请，并依法授予专利权。
- **《专利法实施细则》第五十四条至第五十七条**：申请的公布、提出意见、审查通知、延迟审查及主动修改都有相应程序规则，不能与授权混同。

**为何重要**：审查和代理均应从法定客体与程序依据出发。掌握这些条文，才能把客户技术事实、申请类型和程序动作放进同一条可核验的分析链。

### 演示：分类后再识别程序位置（worked_example）

**案情/例题**：某公司提交申请材料，材料一记载“对产品传动部件形状和构造的改进，适于实用”；材料二记载“产品局部图案与色彩结合形成的视觉设计”。代理人还收到通知，得知申请已经完成初步审查但尚未取得授权。应如何依次说明客体分类和程序含义？
**适用规则**：《专利法》第二条；《专利法》第三条；《专利法实施细则》第五十四条至第五十七条。
**分步推演**：
1. 先看材料一的技术事实。其焦点是产品的形状和构造，并明确主张适于实用，应先与实用新型的法定定义进行核对。 → *产品形状、构造及其结合是实用新型分类的核对重点。*
2. 再看材料二的技术事实。其焦点是产品局部的图案与色彩结合形成的视觉设计，应先与外观设计的法定定义进行核对。 → *产品整体或局部的视觉设计是外观设计分类的核对重点。*
3. 对“已完成初步审查”的通知，不应直接推导已授权。实施细则规定，初步审查后除驳回外应立即公布；公布、进一步审查及授权属于需要分别确认的程序节点。 → *初步审查、公布与授权不能混为同一法律效果。*
4. 如涉及发明专利申请，程序中还应注意实质审查和主动修改的法定时间安排；代理人应以通知和适用条文为准安排后续动作。 → *分类结论必须与后续程序管理相衔接。*
**结论**：材料一应优先按实用新型定义核对，材料二应优先按外观设计定义核对；完成初步审查并不等于已经获得专利权。
**本题要点**：先以法定定义给技术成果分类，再单独确认程序阶段，是审查与代理共同适用的基础工作法。

### 用审查与代理的共同语言理解制度基础（verbal_explanation）

可以把本节的工作顺序说得很直接：先问“这到底是什么”，再问“它走到程序的哪一步”。客户说自己有一个新技术，并不自动说明它是发明、实用新型还是外观设计。代理人要把技术事实翻译成第二条中的法定语言；审查人员则据此进入相应的法定判断。接着，初步审查、申请公布、实质审查和授权也要分开看。尤其不能把“公开了”或“已经过初步审查”当成“已经获得专利权”。专利制度的独占性、时间性和地域性，是提醒我们始终把权利放回具体法律、具体期间和具体法域中理解。

**点破术语**：发明创造；实用新型；外观设计；程序阶段

### 顺序记忆表：客体—程序—权利属性（mnemonic）

**记忆锚**：三步核对表：“客—程—域”。客：先定法定客体；程：再定程序节点；域：最后在具体法域与期间内理解权利属性。
**映射**：
- 客
- 程
- 域
**何时用**：看到客户技术说明、审查通知或跨法域问题时，先按“客—程—域”逐项核对，避免跳步。

### 反思：双视角下的同一事实（reflect_prompt）

**反思问题**：面对一份同时包含结构改进和外观设计的客户材料，审查人员与代理人分别最先需要确认哪些事实，而哪些程序结论必须暂缓作出？

**关注要点**：是否已按《专利法》第二条把不同成果拆分并对应到法定定义。；是否把客体分类与初步审查、公布、实质审查、授权等程序节点分开。；是否避免把独占性理解为脱离法定期间和法域的绝对权利。

**连接**：连接既有程序法学习经验：先识别法律关系和审查对象，再确认程序阶段及其法律效果。

### 专利法律制度基础框架（knowledge_synthesis）

**知识框架**：
- 制度特征：独占性、时间性、地域性共同提示权利必须置于具体法律、期间和法域内理解。
- 制度体系：专利法规定基本制度边界，实施细则承接程序事项；审查指南的具体定位须以其原文为准。
- 保护客体：发明、实用新型、外观设计并列构成专利法所称发明创造，并各有不同法定定义。
- 制度作用：通过申请、审查、公开与依法授予权利的结构，形成激励创造、促进公开和推动应用的制度机制。
- 程序特点：检索材料显示初步审查后公布、提出意见、审查通知和主动修改等程序安排，程序节点必须分别识别。
**概念关系**：客体分类决定后续审查与代理分析的起点，但不等同于授权结论。；程序规则承接客体申请后的处理路径，不能以程序状态替代实体判断。；制度功能解释规则目的，但不替代法定要件和程序条文。
**必记**：《专利法》第二条是判断三类专利客体的首要法条依据。；初步审查、公布、实质审查和授权不是同一程序节点。；审查与代理都应坚持先客体、后程序的分析顺序。

### 基础制度速查卡（summary_card）

**要点卡**：
- **三类客体**：发明、实用新型、外观设计均属专利法所称发明创造，但定义不同。
- **制度体系**：专利法确定基本规则，实施细则承接程序事项，具体审查标准还需核对审查指南原文。
- **程序节点**：初步审查、公布、实质审查、授权与修改必须分别判断。
- **权利特征**：独占性、时间性、地域性要求在具体期间和法域中理解专利权。
- **制度功能**：激励创造、促进技术公开和推动应用是理解制度结构的功能性线索。
**必背**：《专利法》第二条：发明创造包括发明、实用新型和外观设计。；先客体、后程序；不得将公布或初步审查等同于授权。；专利权属性不能脱离法定期间与具体法域作绝对化理解。
**一句话总结**：专利实务的基础顺序是：以法条定客体，以程序定位置，以具体法域和期间定权利理解。
