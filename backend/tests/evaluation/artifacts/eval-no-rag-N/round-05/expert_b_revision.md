## teaching_content

## 1. 场景导入

某科技公司研发出一种用于储能设备的温控结构，同时制作了一张展示设备外形的宣传图。研发负责人认为，只要成果有商业价值，就可以用“一个专利”全部保护；代理人却先追问：这是发明、实用新型还是外观设计？专利权将来在哪些地方有效、能维持多久、能排除他人做什么？审查员也不会从“市场价值很高”直接跳到授权结论，而是先确认法定保护客体和案件所处的程序位置。

## 2. 人话解释

专利制度可以理解为一项有条件、有边界的交换：申请人按照规则公开技术成果，国家在满足法律条件后，给予一定范围内的排他性保护。这个保护有三条边界：独占性，说明权利人可以在法定范围内排除他人实施；时间性，说明权利不会永久存在；地域性，说明在一个国家或地区获得的专利权，不能自然变成全世界都有效。面对复杂研发成果，第一步不是急着讨论“能不能授权”，而是先问“法律上究竟保护什么”。技术方案与外观表达可能对应不同客体，不能因为它们属于同一个产品就合并成同一种专利对象。

## 3. 法条回扣

《专利法》第一条把制度目的放在入口位置。按现行条文，其制度目的包括：保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，促进科学技术进步和经济社会发展。〔RAG: 检索上下文为空 — 本句依据本轮输入提供的法条锚定要求及已知法条条文，未引用外部检索原文〕

《专利法》第二条将专利保护客体分为发明、实用新型和外观设计。其中第二条第四款进一步明确，外观设计是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 检索上下文为空 — 本句依据本轮输入提供的《专利法》第二条节点提示及互审意见，未引用外部检索原文〕因此，代理人需要把技术事实转化为相应的法律客体，审查员需要依照该客体进入相应的审查路径。专利法、专利法实施细则和专利审查指南构成实务中的主要规范输入，但三者的法律效力和使用功能不能不加区分地等同。

## 4. 类比 / 口诀

可以把专利制度想成一套有边界的公共交换机制：申请人投入公开，法律在满足条件时给予排他性保护。这个类比只帮助理解制度结构，不能直接推出具体权利期限、地域效力或授权结论。

记忆四步表：一看“保护什么”，二看“制度为什么保护”，三看“权利受什么边界限制”，四看“案件现在处于哪个程序位置”。它的用途是帮助定位问题，不是替代法条或事实判断。

## 5. 应试提示

看到“发明、实用新型、外观设计”时，先做保护客体分类；看到“独占、期限、地域”时，分别检查排他范围、存续边界和适用地域；看到申请、审查、复审、无效或侵权争议时，先定位程序阶段和判断对象。不要把“有商业价值”当成当然可授权，也不要把制度目的当成具体客体要件。不要因为材料里出现宣传图或产品外形展示，就直接把宣传图本身当成外观设计客体；外观设计保护的是产品整体或局部的设计，宣传图只是可能用来展示设计的材料。不同法域的制度动向不能仅凭名称或新闻标题类推，必须回到适用法域的最新官方规范和审查材料。
