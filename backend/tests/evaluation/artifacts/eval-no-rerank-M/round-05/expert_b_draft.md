## 教学正文

## 1. 场景导入
想象一下，在智能制造领域，一家科技公司研发出一款新型智能机器人关节模组，用于工厂自动化生产。他们在申请专利时，既担心展会展示会破坏新颖性，又想知道专利保护的对象是什么，以及制度如何给予独占权。请先思考：如果你是这家公司的专利代理人，看到‘展会展示’这个动作，第一反应是风险大还是可以申请？为什么？

## 2. 人话解释
专利制度的核心是保护发明创造的基本概念，包括独占性（别人不能随便用）、时间性（有固定期限）以及地域性（只在某个国家保护）。中国专利法是管理专利工作的法律，专利保护的三种客体分别是发明（技术方案）、实用新型（形状构造）和外观设计（美观形状）。专利制度的作用在于激励大家发明创造、促进技术公开、推动技术应用和经济发展。中国专利制度有早期公开延迟审查的特点，采用初步审查和实质审查并存的制度。

## 3. 法条回扣
《专利法》第二条：本法所称的发明创造是指发明、实用新型和外观设计。发明，是指对产品、方法或者其改进所提出的新的技术方案。实用新型，是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。外观设计，是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。

《专利法》第三条：国务院专利行政部门负责管理全国的专利工作；统一受理和审查专利申请，依法授予专利权。省、自治区、直辖市人民政府管理专利工作的部门负责本行政区域内的专利管理工作。

《专利法》第五条：对违反法律、社会公德或者妨害公共利益的发明创造，不授予专利权。

《专利法》第六条：执行本单位的任务或者主要是利用本单位的物质技术条件所完成的发明创造为职务发明创造。职务发明创造申请专利的权利属于该单位，申请被批准后，该单位为专利权人。该单位可以依法处置其职务发明创造申请专利的权利和专利权，促进相关发明创造的实施和运用。

## 4. 类比 / 口诀
口诀：三性过关像进专利大门，新（没公开）创（不显见）实（能有用）。独占时间地域像门的三个锁。适用边界：仅适用于新颖、创造、实用三关通过的发明创造；外观设计只看美观形状，不看功能。

## 5. 应试提示
题干关键词常有“公开”“侵权行为”“保护客体”“审查制”。判断步骤：先看是否属于保护客体，再确认是否公开，再看是否实用。常见陷阱是把职务发明和职务发明创造混淆，或忽略地域性只在国内保护。

### 法条锚定：专利制度基础（legal_anchor）

- **《专利法》第二条**：第二条定义发明创造的三种客体：发明、实用新型、外观设计。
- **《专利法》第三条**：第三条明确国务院专利行政部门负责管理全国专利工作。
- **《专利法》第五条**：第五条禁止授予违反公德或公共利益的发明创造。
- **《专利法》第六条**：第六条规定职务发明创造的权利归属。

**为何重要**：本节点讲授权实质条件，三性是贯穿全章的判定主线，必须先立住条文。

### 案例演示：智能制造专利保护判断（worked_example）

**案情/例题**：某智能制造公司2024年5月在政府主办国际展会上展示了新型机器人关节模组，2024年10月提出专利申请。问：展出是否影响新颖性？
**适用规则**：《专利法》第二十四条（不丧失新颖性宽限期6个月）
**分步推演**：
1. 展出日在申请日前，且属‘政府主办国际展会’法定情形 → *落入宽限期适用范围*
2. 申请日距展出日约5.5个月，在6个月宽限期内 → *在宽限期内*
3. 宽限期仅豁免该公开，不改变三性实质审查 → *仍需过创造性/实用性*
**结论**：展出不破坏新颖性，但仅豁免该次公开，实体三性仍须满足。
**本题要点**：宽限期是‘时间豁免’不是‘免死金牌’，先判范围再算日期。

### 知识框架综合（knowledge_synthesis）

**知识框架**：
- 专利制度的基本概念：独占性、时间性、地域性
- 中国专利制度体系：专利法、实施细则、审查指南
- 专利保护的三种客体：发明、实用新型、外观设计
- 专利制度的作用：激励发明、促进公开、推动应用
- 中国专利制度特点：早期公开延迟审查，初审与实审并存
**概念关系**：三性依次审查：先新颖性，再创造性，最后实用性；客体分类是授权的前提
**必记**：三性缺一不可，任一不具备即不授权；新颖性看‘公开’，创造性看‘显而易见’

### 速查卡：专利制度基础（summary_card）

**要点卡**：
- **保护客体**：能申请专利的‘东西’范围
- **三性**：新颖性/创造性/实用性三关
- **宽限期**：特定公开给6个月缓冲
- **审查制度**：初审与实审并存，早期公开延迟审查
**必背**：三性缺一不可；宽限期仅豁免特定公开且限6个月
**一句话总结**：先过保护客体之门，再过三性安检。
