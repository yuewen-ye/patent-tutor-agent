## 教学正文

## 1. 场景导入

智能制造车间里，研发工程师小林刚把一条“视觉引导+力控装配”的机器人工作站调通。领导拍板：下周就要在行业展会演示，同时问专利同事——“这套方案该申请发明还是实用新型？外观也能护吗？展完会不会把专利资格弄没？”桌面上还有三本文件：《专利法》《专利法实施细则》《专利审查指南》。小林一脸懵：先搞清“能护什么、护多久、在哪儿护”，才谈得上后面的新颖性判断和侵权判定。

## 2. 人话解释

先把专利制度想成智能工厂的三把锁：

- **独占性**：授权后，别人未经许可不能为生产经营目的“照着做、卖、用”（这是排他权，不是“我一定要用”）。
- **时间性**：保护有期限，到期进入公有领域；发明、实用新型、外观设计期限不同。
- **地域性**：中国专利原则上只在中国境内生效，换国家要另走申请路径。

中国规范是“三层楼”：**专利法**定原则与权利义务，**实施细则**把程序和条件写细，**审查指南**给审查员和代理人可操作的审查口径。三者配套，不能只背口号。

保护客体只有三类，对应《专利法》第二条：发明（产品/方法或其改进的技术方案）、实用新型（产品形状/构造或其结合的实用技术方案）、外观设计（产品外观的富有美感且适于工业应用的新设计）。〔RAG: 中华人民共和国专利法.txt — 第二条　本法所称的发明创造是指发明、实用新型和外观设计。发明，是指对产品、方法或者其改进所提出的新的技术方案。实用新型，是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。外观设计，是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〕

制度作用可以记成四步闭环：**激励创造 → 换取公开 → 促进实施应用 → 推动经济发展**。中国实践上常说“早期公开、延迟审查”，发明走实质审查，实用新型与外观设计以初步审查为主，两套审查强度并存。

## 3. 法条回扣

- **客体三分法**直接锚定《专利法》第二条原文，三类对象的定义边界必须分清：方法方案只能走发明；纯外观美感走外观设计；有形状构造的产品方案才可能走实用新型。〔RAG: 中华人民共和国专利法.txt — 第二条　本法所称的发明创造是指发明、实用新型和外观设计。〕
- **管理体制**见《专利法》第三条：国家知识产权局统一受理审查并授权，地方管理专利工作的部门负责本行政区域管理。〔RAG: 中华人民共和国专利法.txt — 第三条　国务院专利行政部门负责管理全国的专利工作；统一受理和审查专利申请，依法授予专利权。〕
- 后续侵权课会用到：发明/实用新型保护范围以**权利要求**为准，说明书附图可解释；外观设计以图片或照片中的产品外观为准。〔RAG: 专利法律知识详细解读.txt — 发明或者实用新型专利权的保护范围以其权利要求的内容为准，说明书及附图可以用于解释权利要求的内容。〕本节只先建立“权利要求才是护城河”的印象，不展开侵权比对。

检索材料未给出“独占性/时间性/地域性”的专门条文定义，本节将其作为制度特征的教学归纳；具体期限、效力与不视为侵权情形，留给下一节点《专利权保护》用第11、42、75条等条文精讲。

## 4. 类比 / 口诀

把三类客体比作智能产线的三种“护栏”：
- **发明**＝整条工艺与控制方法都能护（含方法）；
- **实用新型**＝只护“看得见摸得着的结构件/形状构造”，不护纯方法；
- **外观设计**＝只护“长什么样好看又能量产”，不护内部技术原理。

**适用边界**：类比只帮助选题型，不能替代法条。方法权利要求、软件控制流程、算法与硬件结合等，是否落入发明客体，仍要回到第二条“技术方案”标准，不能因为“看起来像产品”就改报实用新型。

记忆口诀见模块：**“独时地｜法细指｜发实外｜励公推发｜早公延审”**。

## 5. 应试提示

题干关键词对照表（视觉记忆友好）：

| 看到这些词 | 先想到 |
|---|---|
| 未经许可、排他、禁止他人实施 | 独占性 |
| 期限、到期、年费 | 时间性 |
| 仅在中国有效、跨境产线 | 地域性 |
| 方法、工艺、控制流程 | 优先考虑发明 |
| 形状、构造、结构改进 | 可能实用新型 |
| 外观、图案、色彩结合、局部外观 | 外观设计 |
| 专利法 / 细则 / 审查指南 | 三层规范体系 |

常见陷阱：
1. 把“公开换保护”理解成“公开就自动有权”——公开是制度功能，授权仍要过审查关。
2. 以为实用新型也能保护纯方法——不能。
3. 把审查指南当成“法律效力高于专利法”——层级是法律＞行政法规（细则）＞部门规章性审查操作规范（指南），指南不能抵触上位法。
4. 把“早期公开、延迟审查”说成所有专利类型都一样——发明与实用新型/外观的审查强度不同。

### 智能产线专利选型开场（anchor_scenario）

> 智能工厂项目经理老周带着视觉装配工作站方案来找你：下周要在国际工业展演示，同时准备国内专利申请。团队里有人说“先展再申也没事”，有人说“方法不能申专利”，还有人把《审查指南》当成比《专利法》更管用的“最高文件”。老周需要你先说清：这套方案里什么能护、护的是什么权、中国专利制度到底怎么分层。

**锚定**：用智能制造真实决策场景锚定三类保护客体、制度三特征与三层规范体系。

**先想一想**：如果展会演示在即，你最先要分清的是‘保护客体选哪类’，还是‘展会会不会毁掉新颖性’？为什么要先立制度框架？

### 法条锚定：第二条与制度框架（legal_anchor）

- **《专利法》第二条（发明、实用新型、外观设计的定义）**：第二条用人话讲：国家只认三类发明创造——能解决问题的技术方案（发明/实用新型）和能工业应用的外观新设计；方法主要靠发明护，结构靠实用新型，颜值靠外观。
- **《专利法》第三条（专利行政部门职责）**：第三条用人话讲：国家知识产权局统一受理审查授权，地方管本区域专利管理，不是谁都能‘发证’。

**为何重要**：本节点要先把门檻立住：不知道客体三分法和制度层级，后面的新颖性、侵权比对都会选错靶子。

### 产线方案三客体拆分演示（worked_example）

**案情/例题**：某企业智能装配单元包含：（1）机器视觉误差校正控制方法；（2）可快换的末端夹具结构；（3）示教器外壳的新造型。问：三类成果分别更适合哪类专利客体？能否都用实用新型保护？
**适用规则**：《专利法》第二条关于发明、实用新型、外观设计的定义
**分步推演**：
1. 控制方法属于方法技术方案，符合发明定义中的‘方法或者其改进’，不符合实用新型‘产品的形状、构造’要求。 → *方法→优先发明*
2. 末端夹具是产品形状/构造结合的实用技术方案，落入实用新型定义；当然也可评估发明，但不能只因为它‘在产线上用’就排除发明。 → *结构件→可实用新型（或发明）*
3. 示教器外壳若保护的是富有美感并适于工业应用的外观，则对外观设计；它本身不是‘技术方案’，不能仅凭外观去走实用新型/发明的技术路线。 → *外观造型→外观设计*
4. 因此‘全部改成实用新型’不成立：方法与纯外观都不满足实用新型客体。 → *一刀切申报错误*
**结论**：应按第二条拆分选型：方法走发明，结构可走实用新型，外观走外观设计；不能把三类都塞进实用新型。
**本题要点**：先做客体归类，再谈能否授权与是否侵权。

### 制度基础知识网络（knowledge_synthesis）

**知识框架**：
- 制度三特征：独占性（排他实施）、时间性（有期限）、地域性（原则上国内有效）
- 规范三层楼：专利法定规则 → 实施细则细化程序条件 → 审查指南提供审查操作口径
- 保护三客体：发明（产品/方法技术方案）、实用新型（形状构造技术方案）、外观设计（工业美学设计）
- 制度作用闭环：激励创造、换取公开、促进应用、服务经济发展
- 中国审查特点：早期公开与延迟审查；发明实审与实用新型/外观初审并存
**概念关系**：三特征约束权利边界，三客体决定保护入口，三层规范决定如何申请与审查；制度作用解释‘为什么要公开换保护’，与后续新颖性公开规则衔接但不在本节展开
**必记**：先分清发/实/外，再谈授权条件与侵权；方法方案不能靠实用新型保护；审查指南不能凌驾于专利法之上

### 专利法律制度基础速查卡（summary_card）

**要点卡**：
- **三特征**：独占、有期限、原则上看地域
- **三层规范**：专利法→实施细则→审查指南
- **三类客体**：发明护技术方案（含方法），实用新型护结构，外观护颜值
- **制度作用**：激励创造并以公开换保护，推动实施与发展
- **中国特点**：早期公开延迟审查，初审与实审并存
**必背**：《专利法》第二条三类发明创造定义；独时地｜法细指｜发实外；实用新型不保护纯方法
**一句话总结**：先立制度框架与客体选型，再进新颖性与侵权战场。
