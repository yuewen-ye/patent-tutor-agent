## 教学正文

## 1. 场景导入

某科技公司研发出一种用于储能设备的温控结构，同时制作了一张展示设备外形的宣传图。研发负责人认为，只要成果有商业价值，就可以用“一个专利”全部保护；代理人却先追问：这是发明、实用新型还是外观设计？专利权将来在哪些地方有效、能维持多久、能排除他人做什么？审查员也不会从“市场价值很高”直接跳到授权结论，而是先确认法定保护客体和案件所处的程序位置。

## 2. 人话解释

专利制度可以理解为一项有条件、有边界的交换：申请人按照规则公开技术成果，国家在满足法律条件后，给予一定范围内的排他性保护。这个保护有三条边界：独占性，说明权利人可以在法定范围内排除他人实施；时间性，说明权利不会永久存在；地域性，说明在一个国家或地区获得的专利权，不能自然变成全世界都有效。面对复杂研发成果，第一步不是急着讨论“能不能授权”，而是先问“法律上究竟保护什么”。技术方案与外观表达可能对应不同客体，不能因为它们属于同一个产品就合并成同一种专利对象。

## 3. 法条回扣

《专利法》第一条把制度目的放在入口位置：保护专利权、鼓励发明创造、推动发明创造的应用，并促进技术进步和经济社会发展。〔RAG: 检索上下文为空 — 本句依据本轮输入提供的法条锚定要求及已知法条条文，未引用外部检索原文〕

《专利法》第二条将专利保护客体分为发明、实用新型和外观设计。〔RAG: 检索上下文为空 — 本句依据本轮输入提供的《专利法》第二条节点提示，未引用外部检索原文〕因此，代理人需要把技术事实转化为相应的法律客体，审查员需要依照该客体进入相应的审查路径。专利法、专利法实施细则和专利审查指南构成实务中的主要规范输入，但三者的法律效力和使用功能不能不加区分地等同。

## 4. 类比 / 口诀

可以把专利制度想成一套有边界的公共交换机制：申请人投入公开，法律在满足条件时给予排他性保护。这个类比只帮助理解制度结构，不能直接推出具体权利期限、地域效力或授权结论。

记忆四步表：一看“保护什么”，二看“制度为什么保护”，三看“权利受什么边界限制”，四看“案件现在处于哪个程序位置”。它的用途是帮助定位问题，不是替代法条或事实判断。

## 5. 应试提示

看到“发明、实用新型、外观设计”时，先做保护客体分类；看到“独占、期限、地域”时，分别检查排他范围、存续边界和适用地域；看到申请、审查、复审、无效或侵权争议时，先定位程序阶段和判断对象。不要把“有商业价值”当成当然可授权，也不要把制度目的当成具体客体要件。遇到保护范围问题，应先完成权利要求解释和字面范围判断，再在满足条件时讨论等同问题。不同法域的制度动向不能仅凭名称或新闻标题类推，必须回到适用法域的最新官方规范和审查材料。

### 从研发方案到专利制度边界（anchor_scenario）

> 某科技公司研发出一种用于储能设备的温控结构。研发负责人认为，只要技术方案有价值就可以申请专利；代理人却先追问三个问题：这究竟属于发明、实用新型还是外观设计？权利产生后能否在所有国家直接主张？即使获得授权，保护是否永久存在？审查员则会从法定保护客体和制度条件出发，判断申请是否进入后续审查轨道。两人关注点不同，但冲突都指向专利制度的基础边界。

**锚定**：用研发、代理和审查三个角色锚定保护客体、专利权特征、制度体系和制度功能。

**先想一想**：面对一个新技术项目，你会先确认它属于哪一种保护客体，还是先判断它有没有商业价值？为什么？

### 先确定制度目的与保护客体（legal_anchor）

- **《中华人民共和国专利法》第一条**：第一条说明专利法的制度目的，核心是保护专利权、鼓励发明创造、推动发明创造的应用，并促进技术进步和经济社会发展。
- **《中华人民共和国专利法》第二条**：第二条划定专利保护的三类基本客体：发明、实用新型和外观设计；三者的对象形态不同，不能混为一谈。

**为何重要**：本节点是后续授权、申请、审查、保护和救济内容的总入口。先用第一条理解制度为什么存在，再用第二条确定保护什么，后续判断才不会把商业价值、技术成果和法定保护客体混为一谈。

### 案例演示：同一项目中的不同保护客体（worked_example）

**案情/例题**：甲公司研发了一种储能设备温控结构，同时制作了一张展示该设备外形的宣传图。公司负责人要求代理人把结构、设备外观和宣传图一起称为“一个专利对象”。代理人需要先判断：这些内容在专利制度中是否属于同一种保护客体，以及审查视角应从哪里开始。
**适用规则**：《中华人民共和国专利法》第二条关于发明、实用新型、外观设计三类保护客体的规定；《中华人民共和国专利法》第一条关于立法目的的规定。
**分步推演**：
1. 先看内容是否属于技术方案。温控结构解决的是设备运行中的技术问题，通常应进入发明或实用新型客体识别；不能只因为它有市场价值就直接得出可授权结论。 → *第一步：先识别内容性质，区分技术方案与外观表达。*
2. 再看外观内容的法律定位。设备形状、图案或其组合形成的具有美感并适于工业应用的设计，属于另一种保护客体；宣传图只有在其内容符合外观设计法定范围时才有进一步讨论空间。 → *第二步：把技术方案与外观设计分别归类。*
3. 最后把客体识别与制度目的分开。专利制度鼓励创新并促进公开，但制度目的不能替代具体客体要件，也不能因成果有用就跳过法定分类。 → *第三步：用制度目的解释制度功能，但仍回到客体要件。*
**结论**：本案的储能温控结构属于以技术方案为内容的成果，教学上应先按发明或实用新型的技术方案路径识别；宣传图案本身则不能因为具有商业价值就自动成为发明或实用新型。最终类别仍需结合具体申请内容和法定定义判断。
**本题要点**：遇到复杂技术材料时，先按内容性质识别保护客体，再讨论申请、审查和权利效果。

### 把专利权说成人话（verbal_explanation）

可以先把专利制度看成一项有条件的交换：申请人把技术方案按照规则公开，国家在审查并满足法律条件后，给出一种有边界的排他性权利。这个权利不是永久的，也不是全球自动有效的，而是同时受时间和地域限制。代理人面对客户时，第一句不应只是“这个技术很有价值，当然能申请”，而应先确认它属于发明、实用新型还是外观设计，再根据对应规则判断。审查员则会把这种分类当作进入后续判断的起点。

**点破术语**：独占性；时间性；地域性；保护客体

**类比**：可以把专利制度理解为一套有边界的公共交换机制：申请人以公开技术方案为一方投入，法律在符合条件时给予一定范围、一定期间和一定地域内的排他性保护。这个类比只帮助理解制度结构，不能据此推导具体权利期限、地域效力或授权结论。

### 基础判断四步表（mnemonic）

**记忆锚**：基础判断四步表：一看“保护什么”，二看“制度为什么保护”，三看“权利受什么边界限制”，四看“案件现在处于哪个程序位置”。
**映射**：
- 一看保护什么
- 二看为什么保护
- 三看边界
- 四看程序位置
**何时用**：阅读考试题干、客户咨询或审查意见时，先按“一、二、三、四”依次定位，再进入新颖性、创造性、保护范围或救济程序等后续节点。

### 复盘：同一成果的双视角（reflect_prompt）

**反思问题**：同一项研发成果交给代理人和审查员时，为什么两者都要先做客体识别，但关注重点并不完全相同？

**关注要点**：代理人需要把客户的技术事实转化为合适的法律保护对象，并控制申请表达的风险。；审查员需要依照法定客体和审查程序判断申请是否可以进入相应的审查路径。；客体识别只是入口，不能直接替代新颖性、创造性、实用性或权利范围的后续判断。

**连接**：连接到后续的专利授权实质条件、申请程序、审查程序和保护范围判断。

### 专利法律制度基础知识网（knowledge_synthesis）

**知识框架**：
- 制度目的：专利制度通过保护专利权、鼓励发明创造和促进技术应用，服务技术进步与经济社会发展。
- 保护客体：专利法基础上区分发明、实用新型和外观设计，先分类再进入具体授权或保护判断。
- 权利特征：专利权具有独占性、时间性和地域性，排他范围、存续期间和适用地域都存在边界。
- 制度体系：中国专利制度的主要规范层次包括专利法、专利法实施细则和专利审查指南；不同规范在法律效力和适用功能上应加以区分。
- 制度运行：专利申请、审查、授权以及后续救济和保护构成制度运行链条；具体程序判断要结合案件所处阶段。
**概念关系**：制度目的回答“为什么保护”，保护客体回答“保护什么”，权利特征回答“保护的边界是什么”。；先识别客体，再根据对应规范进入申请和审查判断；不能用制度目的直接替代客体要件。；申请和审查属于权利形成过程，授权后的保护与救济属于权利运行和争议处理过程，程序位置不同会导致判断对象不同。
**必记**：专利制度的基本定位是以技术公开和法律保护相联系，目的包括鼓励发明创造、促进技术应用和技术进步。；专利保护的三种基本客体是发明、实用新型和外观设计，三者不能仅凭“有商业价值”或“有创新”混为一谈。；专利权的独占性、时间性和地域性共同构成其边界，不能把专利权理解为永久、全球且不受范围限制的权利。；审查与代理都应先定位客体和程序位置，再进入具体实体或权利范围判断。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **制度目的**：保护专利权、鼓励发明创造、促进技术应用，并推动技术进步和经济社会发展。
- **三类客体**：发明、实用新型、外观设计是专利法基础分类，先分类再判断。
- **三种边界**：专利权有独占性、时间性和地域性，权利并非永久且全球有效。
- **规范体系**：专利法、实施细则和审查指南共同构成实务中的主要规范输入，但功能和效力需区分。
- **双视角入口**：代理人先把事实转成保护对象，审查员先按法定对象确定审查路径。
**必背**：《专利法》第一条体现专利制度目的。；《专利法》第二条规定发明、实用新型和外观设计三类基本客体。；专利权具有独占性、时间性和地域性。；判断专利实务问题先看保护客体和程序位置，再进入具体规则。
**一句话总结**：先问保护什么，再看为何保护、边界何在以及程序走到哪一步。
