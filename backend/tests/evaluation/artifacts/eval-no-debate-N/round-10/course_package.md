## 教学正文

## I — 法律问题

在审查与代理的双重视角下，面对一项技术方案，首先需要回答五个基础问题：专利制度保护的对象是什么；发明、实用新型、外观设计如何区分；法律、实施细则和审查指南分别承担什么规范功能；权利为何具有独占性、时间性和地域性；以及不同客体为何进入不同的审查路径。

本节点只建立制度总框架，不将新颖性、优先权、权利要求解释等后续子节点作为本节的实体讲授内容。

## R — 适用规则

### 1. 制度目的决定制度的基本平衡

《专利法》第一条将保护专利权人合法权益、鼓励发明创造、推动发明创造应用、提高创新能力，以及促进科技进步和经济社会发展并列为立法目的。由此可见，专利制度不是单纯的技术奖励，也不是当然的市场垄断；它通过依法授予有限的专利权，促成技术公开、应用与创新激励之间的平衡。〔RAG: 中华人民共和国专利法.txt — 第一条“保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用”〕

### 2. 三类保护客体是入口分类

《专利法》第二条规定的专利客体包括发明、实用新型和外观设计。审查与代理应先完成客体定位：发明着眼于产品、方法或者其改进所提出的技术方案；实用新型着眼于产品的形状、构造或者其结合所提出的适于实用的技术方案；外观设计着眼于产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的适于工业应用的新设计。本轮检索上下文未提供第二条原文，以上分类应在实务中以现行法条原文复核。

### 3. 规范体系应按层级阅读

专利法提供基本权利义务、授权和保护的法律框架；专利法实施细则细化申请和程序事项；专利审查指南用于说明审查中的操作口径和判断方法。代理人不能以审查指南替代法律，也不能只停留于抽象法条而忽略程序性文件。实施细则明确，申请专利应向国务院专利行政部门提交符合规定要求的申请文件；委托代理机构办理的，还应提交载明委托权限的委托书。〔RAG: 中华人民共和国专利法实施细则.txt — 第十七条“申请专利的，应当向国务院专利行政部门提交申请文件”〕

### 4. 权利特征必须与程序事实对应

独占性是指专利权授予后，权利人依法享有排他性利益，但其行使受法律边界限制。时间性是指专利权并非永久存在：发明专利期限为二十年，实用新型为十年，外观设计为十五年，均自申请日起计算。〔RAG: 中华人民共和国专利法.txt — 第四十二条“发明专利权的期限为二十年，实用新型专利权的期限为十年，外观设计专利权的期限为十五年”〕地域性是指权利效力以授予国或地区的法律范围为界；跨法域申请和保护不能当然互相替代，应分别核对各法域规则。

### 5. 审查路径体现三种客体的制度分工

发明专利申请在经申请人陈述意见或者修改后仍不符合规定的，应被驳回；经实质审查未发现驳回理由的，作出授予决定、登记并公告。〔RAG: 中华人民共和国专利法.txt — 第三十八条、第三十九条关于发明专利申请的修改、驳回与实质审查〕实用新型和外观设计则在初步审查未发现驳回理由时作出授予决定、登记并公告。〔RAG: 中华人民共和国专利法.txt — 第四十条“实用新型和外观设计专利申请经初步审查没有发现驳回理由的”〕

因此，代理视角的首要工作是：在申请前将技术成果准确归入可能的保护客体，并据此配置文件、期限与预期审查路径；审查视角的首要工作是：在法定程序中，依申请客体适用相应审查机制。课程上下文提到“早期公开延迟审查”的发展特点；但本轮检索材料未提供公开时点的直接条文依据，不能据此推导具体公开期限或程序后果，实务中应另行核对现行法及实施细则。

## A — 规则适用

设研发团队完成两项成果：其一是降低能耗的控制方法，其二是安装于设备外壳上的局部视觉设计。代理人不能仅因两项成果来自同一产品而把它们视为同一类申请对象。应先将控制方法放入“技术方案—发明”的分类框架，将局部视觉设计放入“产品视觉设计—外观设计”的分类框架；再分别评估所需文件和审查路径。

对于控制方法，审查程序应以发明专利的实质审查路径为制度预期；对于局部视觉设计，则应以外观设计的初步审查路径为制度预期。两条路径都以授予决定、登记和公告为权利生效的关键程序节点，但不能因此误认为两类申请受到相同深度的审查。〔RAG: 中华人民共和国专利法.txt — 第三十九条、第四十条均规定授予决定、登记和公告，且分别规定实质审查与初步审查〕

若客户拟在中国境外获得保护，代理意见还应提示地域性：在中国取得或拟取得的权利，并不当然产生其他法域的保护效果。跨法域布局应当以目标法域各自的申请、审查和权利规则为准，而不是以中国程序的结果直接替代。

## C — 结论

专利制度基础的正确判断顺序是：先确认制度目的与保护边界，再识别三类客体，随后按规范层级定位法律依据，并根据客体进入相应审查路径。独占性、时间性和地域性共同说明：专利权是依法、有限期且有地域边界的权利，而非对技术成果的无限控制。

> 常见误区 / 易混淆点
>
> 1. 将“取得专利”理解为永久、全球排他的权利，忽略期限和地域边界。
> 2. 认为实用新型、外观设计未经过与发明相同的实质审查，就等于当然没有法律效力；三类专利均须经法定程序授予、登记和公告后生效。
> 3. 将专利法、实施细则、审查指南视为同一层级的规范。处理具体问题时，应先找法律依据，再核对实施细则和审查指南的程序或操作要求。
> 4. 把课程所述的制度发展概括直接当作具体期限规则；涉及公开、审查请求或程序期限时，必须回到现行有效条文核验。

### 从一件产品拆开看三类专利问题（anchor_scenario）

> 某研发团队完成了一套智能检测设备：设备内部有一套降低误报率的信号处理方法，外壳采用了独特的局部纹理和轮廓设计。负责人拟在中国申请专利，并计划日后向海外销售。代理人需要先判断：两项成果是否属于同一保护客体、应当预期何种审查路径，以及中国申请获权后能否当然覆盖海外市场。

审查人员则需从申请文件所主张的对象出发，区分技术方案与产品视觉设计，并依不同客体适用相应法定程序。冲突点不在于团队“是否有创新意愿”，而在于其成果的法律分类、程序入口和权利边界是否被正确识别。

**锚定**：该情境锚定三类保护客体、地域性以及不同审查路径之间的对应关系。

**先想一想**：如果只能先做一项工作，你会先核对技术是否先进，还是先核对申请客体属于哪一类；为什么？

### 制度目的、客体与程序的法条锚点（legal_anchor）

- **《中华人民共和国专利法》第一条**：专利制度既保护权利人，也服务于鼓励创新、技术应用和社会发展。
- **《中华人民共和国专利法》第二条**：申请前必须先判断成果属于发明、实用新型还是外观设计，三类客体的法定定义须以第二条原文复核。
- **《中华人民共和国专利法》第三十八条至第四十条**：发明适用实质审查路径；实用新型和外观设计适用初步审查路径，授予后均须登记、公告。
- **《中华人民共和国专利法》第四十二条**：专利权有法定存续期限：发明二十年，实用新型十年，外观设计十五年，均自申请日起算。

**为何重要**：代理人据此确定申请策略和程序预期，审查人员据此确定审查入口。制度目的、客体分类、审查路径和期限共同构成专利制度基础的最小法条框架。

### 从客体分类走到审查路径（worked_example）

**案情/例题**：乙公司拟为两项成果申请专利：一项是用于降低设备能耗的控制方法，另一项是该设备外壳的局部视觉设计。现需判断两项成果在制度框架中的保护客体和审查程序预期，并判断何时产生专利权。
**适用规则**：《专利法》第二条；第三十八条至第四十条。
**分步推演**：
1. 先将控制方法与产品视觉设计分开识别。方法类技术方案应进入发明专利的分类判断；产品局部视觉设计应进入外观设计的分类判断。 → *同一产品中的不同创新成果，可能属于不同专利客体。*
2. 对控制方法，适用发明专利申请的程序预期：经陈述意见或修改后仍不符合规定的可以驳回，经实质审查未发现驳回理由的作出授予决定。 → *发明以实质审查作为法定程序路径。*
3. 对局部视觉设计，适用外观设计申请的程序预期：经初步审查未发现驳回理由的作出授予决定。 → *外观设计以初步审查作为法定程序路径。*
4. 两类申请均不能仅因提交文件而取得专利权；相应权利均在授予决定、登记和公告后，自公告日起生效。 → *申请日、授权程序和权利生效日是不同的法律时间点。*
**结论**：控制方法应按发明专利的实质审查路径处理，局部视觉设计应按外观设计的初步审查路径处理；两类专利权均自公告之日起生效。
**本题要点**：先做客体分类，再匹配审查路径和权利生效节点，是审查与代理共同适用的基础工作流。

### 用审查语言理解制度边界（verbal_explanation）

可以把专利制度先理解成一套有入口、有程序、也有边界的法律安排。入口是客体分类：你主张的是技术方案，还是产品的视觉设计？程序上，发明和实用新型、外观设计不能混为一谈，法律对它们规定了不同的审查路径。边界上，专利权不是永久权，也不是自动覆盖全世界的权利；它有法定期限，并且只在授予它的法域内发生相应效力。代理人要据此给客户管理预期，审查人员要据此选择正确的审查路径。先把这四层站稳，后续再讨论授权条件、优先权或侵权问题才不会把实体规则和程序规则混在一起。

**点破术语**：独占性；时间性；地域性；实质审查；初步审查

### 专利制度基础四栏核对表（mnemonic）

**记忆锚**：四栏核对表：目—体—程—界。每次遇到基础制度问题，依次核对制度目的、保护客体、程序路径、权利边界。
**映射**：
- 目
- 体
- 程
- 界
**何时用**：阅读申请方案、审查意见或跨法域布局建议时，先用四栏核对表避免遗漏分类、程序或边界问题。

### 从制度选择反思代理建议（reflect_prompt）

**反思问题**：当客户要求“在中国申请后马上获得全球、永久排他保护”时，你会如何按“目—体—程—界”四栏逐步纠正其预期？

**关注要点**：区分申请行为、授予决定、公告与权利生效四个不同节点。；说明独占性并不消灭时间性和地域性。；先完成客体分类，才能讨论应当适用的审查程序。；跨法域保护必须分别核对目标法域规则，不能以中国程序当然替代。

**连接**：连接学习者已有的程序法经验：先确定适用规范和程序入口，再处理实体判断与法律后果。

### 专利法律制度基础框架（knowledge_synthesis）

**知识框架**：
- 制度目的：专利法同时追求权利保护、创新激励、技术应用和社会发展。
- 权利特征：专利权具有独占性、时间性和地域性，三者共同限定权利的效力边界。
- 规范体系：专利法定基本框架，实施细则细化程序，审查指南提供审查操作口径。
- 保护客体：发明、实用新型、外观设计是申请与审查的分类入口。
- 程序分工：发明走实质审查路径，实用新型和外观设计走初步审查路径。
- 制度发展认识：课程提及早期公开延迟审查，但具体公开时点和期限必须另依现行法源核验。
**概念关系**：保护客体决定申请分类，并进一步影响审查路径。；审查路径通向授予、登记和公告；权利自公告日起生效。；制度目的解释权利保护的正当性，时间性和地域性限制独占性的外部边界。
**必记**：专利制度的基础判断顺序是：目的—客体—规范—程序—边界。；发明与实用新型、外观设计的审查路径不同，不能因均可能授权而混同。；专利权期限分别为发明二十年、实用新型十年、外观设计十五年，均自申请日起计算。

### 制度基础速查卡（summary_card）

**要点卡**：
- **制度目的**：专利法在保护权利与激励、公开、应用技术之间建立平衡。
- **三类客体**：先分发明、实用新型、外观设计，再谈申请文件与审查路径。
- **审查路径**：发明经实质审查；实用新型和外观设计经初步审查。
- **权利生效**：法定授予、登记和公告后，专利权自公告日起生效。
- **权利边界**：独占权有期限且有地域范围，不是永久、全球的绝对权利。
**必背**：发明专利权期限二十年，实用新型十年，外观设计十五年，均自申请日起计算。；发明走实质审查路径；实用新型和外观设计走初步审查路径。；法律、实施细则、审查指南的功能不同，具体结论应先回到法律依据。
**一句话总结**：专利制度的实务起点：先定客体，再循程序，并始终核对权利的时间与地域边界。
