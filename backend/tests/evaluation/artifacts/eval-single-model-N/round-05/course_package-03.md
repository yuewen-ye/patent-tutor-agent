# 专利法律制度基础：审查与代理双视角复盘

## 一、先建立判断主线

处理专利实务时，应按“客体—规则—条件—程序—边界—功能”展开。代理人侧重申请布局、文件表达和程序安排；审查员侧重依据法定规则受理、审查并作出决定。二者面对同一事实，但都不能跳过客体识别和程序定位。

专利制度通过依法授予具有期限和地域边界的排他性保护，与技术或设计信息公开相衔接，以激励发明创造、促进技术公开、推动技术应用和经济发展。制度功能用于理解制度设计，不能替代具体法条条件。

## 二、保护什么：三类法定客体

《专利法》第二条规定，发明创造包括发明、实用新型和外观设计。发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：本法所称的发明创造是指发明、实用新型和外观设计〕

分类应回到法律保护对象，而不能只看项目名称、研发部门或技术价值。方法通常先进入发明客体判断；产品形状、构造或其结合形成的技术方案通常进入实用新型客体判断；产品整体或局部外观的新设计则进入外观设计客体判断。复合项目可以包含多类成果，不能当然只选一种类型。

## 三、依据什么：制度规则层级

《专利法》第三条规定，国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕

专利法确立基本法律边界；专利法实施细则细化部分程序事项；专利审查指南服务审查实践中的具体判断和操作。三者不能互相替代。本轮检索上下文未提供审查指南具体条文，因此不能把未检索到的指南细节写成确定规则。涉及跨法域或审查实践新动向时，也须先确认目标法域、规范版本和时间点。

## 四、满足什么：授权条件

发明和实用新型适用《专利法》第二十二条规定的新颖性、创造性和实用性；现有技术是申请日以前在国内外为公众所知的技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条：授予发明和实用新型应当具备新颖性、创造性和实用性〕

外观设计不直接套用三性表述，而适用第二十三条：不得属于现有设计，与现有设计或者现有设计特征组合相比应具有明显区别，并且不得与他人在申请日以前已经取得的合法权利相冲突。〔RAG: 中华人民共和国专利法.txt — 第二十三条：外观设计不得属于现有设计，应具有明显区别且不得与在先合法权利冲突〕

客体分类只是授权判断的起点，不等于已经满足授权条件。制度鼓励创新，也不能代替对具体条件的逐项审查。

## 五、走到哪一站：公开、审查与授权

发明专利申请经初步审查认为符合要求的，自申请日起满十八个月公布；申请人可以请求早日公布。〔RAG: 中华人民共和国专利法.txt — 第三十四条：发明专利申请经初步审查认为符合本法要求的，自申请日起满十八个月即行公布〕

公布意味着申请信息进入公开环节，不等于已经取得专利权。发明申请经实质审查没有发现驳回理由的，依据第三十九条作出授予发明专利权的决定；实用新型和外观设计申请经初步审查没有发现驳回理由的，依据第四十条作出授权决定。〔RAG: 中华人民共和国专利法.txt — 第三十九条、第四十条：发明经实质审查后授权，实用新型和外观设计经初步审查后授权〕

现有材料支持早期公开、延迟审查以及初步审查与实质审查并存的程序特征。关于具体历史年份或完整制度沿革，检索上下文未提供直接依据，本节不作扩展结论。

## 六、权利边界：排他性、时间性和地域性

专利权并非无边界的绝对权利。本轮检索材料支持，排他性判断应围绕未经许可、以生产经营目的实施相应专利展开，并继续核对专利法规定的例外。〔RAG: 专利法律知识详细解读.txt — 专利权具有排他性、时间性和地域性；未经许可、以生产经营目的实施专利及先用权例外说明〕

时间性意味着保护有法定期限：发明专利权为二十年，实用新型专利权为十年，外观设计专利权为十五年，均自申请日起计算。〔RAG: 中华人民共和国专利法.txt — 第四十二条：发明专利权期限为二十年，实用新型专利权期限为十年，外观设计专利权期限为十五年，均自申请日起计算〕

地域性意味着一国或地区授予的专利权，仅在相应法律范围内发生效力，不当然使其他国家或地区产生相同权利。跨法域布局应按目标法域法律和国际规则另行核对。

## 七、审查与代理的共同顺序

第一，拆分研发事实并识别保护客体。第二，匹配发明、实用新型或外观设计各自的授权条件。第三，定位申请所处程序阶段，严格区分公开、审查和授权。第四，判断权利边界时核对未经许可、生产经营目的、法定例外、期限和地域。第五，再以制度功能理解公开与有限保护的平衡。

### 专利制度基础的法条锚点（legal_anchor）

- **《专利法》第二条**：第二条规定发明创造包括发明、实用新型和外观设计，并分别规定三类客体。
- **《专利法》第三条**：第三条规定国务院专利行政部门统一受理和审查专利申请，依法授予专利权。
- **《专利法》第二十二条**：第二十二条规定发明和实用新型应具备新颖性、创造性和实用性。
- **《专利法》第二十三条**：第二十三条规定外观设计不得属于现有设计，应具有明显区别且不得与在先合法权利冲突。
- **《专利法》第三十四条**：第三十四条规定发明申请经初步审查合格后公开，公开不等于授权。
- **《专利法》第三十九条、第四十条**：第三十九条规定发明经实质审查后授权；第四十条规定实用新型和外观设计经初步审查后授权。
- **《专利法》第四十二条**：第四十二条规定发明、实用新型、外观设计期限分别为二十年、十年、十五年，均自申请日起计算。
- **《专利法实施细则》第五十六条**：实施细则第五十六条涉及延迟审查请求，具体适用应以当时有效规范为准。

**为何重要**：法条锚点帮助代理人安排申请和沟通风险，也帮助审查员区分客体、实体条件、程序节点与法律后果。

### 公开不等于授权（worked_example）

**案情/例题**：乙公司发明专利申请经初步审查合格后请求早日公布。市场部门准备宣称乙公司已获得专利权，并可禁止任何第三人使用该技术。
**适用规则**：《专利法》第三十四条规定发明申请公开；第三十九条规定发明经实质审查没有发现驳回理由后作出授权决定；第四十二条规定期限。
**分步推演**：
1. 第三十四条规定的是申请公开节点，事实尚未表明已作出授权决定。 → *公布是信息公开，不是授权。*
2. 发明申请须依第三十九条经实质审查并作出授权决定，不能从公布直接跳到授权。 → *授权须另有法定决定。*
3. 对第三人行为还须检查实施目的、法定例外、期限和地域。 → *权利边界不能被省略。*
**结论**：公开的发明申请尚不等于已获专利权。即使以后授权，排他性也须结合未经许可、生产经营目的、法定例外、期限和地域边界判断。
**本题要点**：按“辨公布性质—查授权决定—核权利边界”复盘程序信息。

### 用两副眼镜理解制度（verbal_explanation）

先问成果是什么，再问需要满足什么条件，随后确认申请走到哪个程序阶段，最后核对权利的边界。发明和实用新型要看三性，外观设计要看现有设计、明显区别和在先合法权利。代理人侧重申请布局、文件表达和时间安排；审查员侧重依法受理、审查和作出决定。专利权并非永久或全球有效，也不能把排他性理解为对任何行为的绝对禁止。

**点破术语**：保护客体；三性；公布；地域性

**类比**：把专利实务看作四个站点：客体站、条件站、程序站、边界站。该类比只帮助记忆顺序，不能代替具体法条判断。

### 五格复盘口诀（mnemonic）

**记忆锚**：五格口诀：“客—规—条—程—界”。客为客体，规为规则层级，条为授权条件，程为程序阶段，界为权利边界。
**映射**：
- 客
- 规
- 条
- 程
- 界
**何时用**：遇到申请、审查或权利问题时，按五格依次核对，缺少任何一格都不直接下结论。

### 审查与代理双视角反思（reflect_prompt）

**反思问题**：代理人和审查员面对同一成果时，各自首先要确认什么？把公布、授权和中国有效混在一起会遗漏哪些法律问题？

**关注要点**：客体分类是后续授权条件与程序判断的入口。；公布与授权的法律效果不同。；排他性还要结合实施目的、法定例外、期限和地域判断。

**连接**：连接到“先确定适用规范，再区分实体条件、程序阶段与法律后果”的法律分析方法。

### 专利制度基础关系框架（knowledge_synthesis）

**知识框架**：
- 保护客体：第二条将发明创造分为发明、实用新型和外观设计。
- 制度体系：专利法确立基本边界，实施细则细化部分程序，审查指南服务审查实践中的具体适用。
- 制度作用：有限排他性保护与技术或设计信息公开相衔接，服务于激励创造、促进公开和技术应用。
- 授权条件：发明和实用新型适用三性；外观设计适用第二十三条条件。
- 程序特点：发明公开不等于授权，发明以实质审查为授权路径，实用新型和外观设计以初步审查为授权路径。
- 权利特征：排他性、时间性和地域性共同构成专利权边界。
- 发展与跨法域：本轮材料支持早期公开、延迟审查和两类审查并存的程序特征；历史沿革及其他法域具体规则需另行检索。
**概念关系**：先识别保护客体，再匹配授权条件和程序。；客体分类不能替代实体审查。；公布服务于信息公开，授权才产生专利权。；制度目的不能替代具体法定条件。；中国授权不当然使其他法域产生相同权利。
**必记**：第二条是三类保护客体判断的起点。；发明和实用新型看三性，外观设计适用第二十三条条件。；公布不等于授权。；专利权受期限、地域和法定例外限制。；未检索到的审查指南具体内容不得作为确定规则。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **三类保护客体**：发明、实用新型和外观设计应按第二条的法定对象区分。
- **规则层级**：专利法定基本边界，实施细则细化部分程序，审查指南服务具体适用。
- **授权条件**：发明和实用新型看三性，外观设计看第二十三条条件。
- **程序分段**：发明申请公布不等于授权；发明实质审查，实用新型和外观设计初步审查。
- **权利边界**：排他性受实施目的、法定例外、期限和地域共同限制。
**必背**：《专利法》第二条规定发明创造包括发明、实用新型和外观设计。；发明和实用新型看三性，外观设计适用第二十三条条件。；发明申请公布不等于授权。；三类专利期限分别为二十年、十年、十五年，均自申请日起计算。
**一句话总结**：先定客体，再配规则、条件和程序，最后核对权利边界。
