## 教学正文

## 一、从审查与代理的共同起点出发

[A+B融合] 面对一项技术成果，审查员与代理人都不能先凭“这是发明专利”这一称呼下结论。更稳妥的顺序是先核对保护客体，再匹配程序，随后区分权利生效与期限起算，最后检查地域边界。对代理人而言，这一顺序用于类型选择、材料准备和日期管理；对审查员而言，这一顺序用于确认应适用的法定定义和程序路径。

## 二、制度目的与规范体系

[A] 《专利法》第一条说明，中国专利制度并非只为授予排他权而设；其目标包括保护专利权人合法权益、鼓励发明创造、推动发明创造应用、提高创新能力，并促进科学技术进步和经济社会发展。〔RAG: 中华人民共和国专利法.txt — 第一条：保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，促进科学技术进步和经济社会发展〕

[A+B融合] 在中国制度体系中，专利法是基本法律规范；专利法实施细则和专利审查指南构成重要配套规范与操作依据。本轮检索上下文未提供后二者的完整具体条文或口径，故不作条款号和操作细节的扩展。

## 三、先定客体：三类发明创造

[A] 《专利法》第二条规定，发明创造包括发明、实用新型和外观设计。发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计，并分别规定三类定义〕

[B] 可以把这一步理解成“先找对入口”：技术方案涉及产品、方法或其改进时，要进入发明的定义判断；产品的形状、构造或其结合的适于实用的新技术方案，要进入实用新型的定义判断；产品的视觉外观设计，则要进入外观设计的定义判断。这个“入口”类比只帮助记忆分类次序，最终仍要逐字回到第二条的法定要素。

## 四、权利的三项边界：独占、时间、地域

[A] 专利权具有排他性、时间性和地域性。排他性也称独占性，指除专利法另有规定外，未经专利权人许可，他人不得实施其专利；时间性指权利仅在法律规定期限内存在；地域性指专利权由各国家或地区依其法律授予，只在相应地域范围内有效。〔RAG: 专利法律知识详细解读.txt — 专利权具有排他性、时间性和地域性；一项专利权在一个国家有效，并不意味着在其他国家有效〕

[A+B融合] 因而，“中国已经授权”不能自动推出其他国家或地区也受保护。代理人在考虑境外展示、销售或许可时，应把目标法域作为独立核对对象；审查员在中国程序中也只能依据中国法上的申请与审查事实作出判断。

## 五、再定程序：发明与另外两类申请的审查路径

[A] 发明专利申请经实质审查没有发现驳回理由的，由国务院专利行政部门作出授予发明专利权的决定，同时登记和公告。〔RAG: 中华人民共和国专利法.txt — 第三十九条：发明专利申请经实质审查没有发现驳回理由的，作出授予发明专利权的决定，同时予以登记和公告〕实用新型和外观设计专利申请经初步审查没有发现驳回理由的，作出授予相应专利权的决定，同时登记和公告。〔RAG: 中华人民共和国专利法.txt — 第四十条：实用新型和外观设计专利申请经初步审查没有发现驳回理由的，作出授予决定，同时予以登记和公告〕

[A+B融合] 并不是所有专利申请都走同一种审查路径。发明对应实质审查；实用新型和外观设计对应初步审查。代理工作中的类型选择会影响后续程序预期；审查工作中的程序选择则必须以法定类型为基础。

## 六、两个日期必须分开：公告生效，申请日起算期限

[A] 第三十九条和第四十条规定，相应专利权自公告之日起生效。〔RAG: 中华人民共和国专利法.txt — 第三十九条、第四十条：相应专利权自公告之日起生效〕第四十二条规定，发明专利权期限为二十年，实用新型专利权期限为十年，外观设计专利权期限为十五年，均自申请日起计算。〔RAG: 中华人民共和国专利法.txt — 第四十二条：二十年、十年、十五年，均自申请日起计算〕

[B] 最简洁的区分是：“公告看能否行使权利，申请日看期限从哪里开始跑。”这不是两个可互换的日期。

## 七、制度发展、审查实践与跨法域证据边界

[A+B融合] 当前教学窗口将“早期公开延迟审查”列为中国专利制度发展特点，同时本节已有第三十九条和第四十条的直接依据说明发明实质审查与实用新型、外观设计初步审查并存。对于“早期公开延迟审查”，本轮检索上下文未提供具体历史阶段、条件或程序细节的直接材料，因此只能作窗口层面的概括识别。

[A+B融合] 跨法域实务的已检索锚点是：目标国保护不能从中国授权当然推出；如希望在目标国家同时得到保护，可在目标国提出专利申请，或者通过《巴黎公约》或PCT方式进行国际专利申请。〔RAG: 专利法律知识详细解读.txt — 如希望在目标国家同时得到保护，应当在目标国提出专利申请，或者通过《巴黎公约》或PCT的方式进行国际专利申请〕这反映的实务方向是先确定目标法域，再选择相应申请路径和逐国程序管理，而不是把国际申请误解为自动取得各法域实体权利。

[A] 术语比较也须保持边界：检索材料指出，TRIPS中的“专利”仅代表发明专利，而中国专利法中的“专利”表示发明、实用新型、外观设计三种类型。〔RAG: 专利法律知识详细解读.txt — TRIPS中“专利”仅代表“发明专利”，中国专利法中“专利”表示发明、实用新型、外观设计三种专利类型〕本轮未提供PCT、TRIPS的现行官方指南文本、链接或具体更新规则，故不能将上述基础路径延伸为未经核验的“最新政策”结论；后续跟踪应以世界知识产权组织、世界贸易组织及目标法域官方主管机关发布的现行文本为准。

## 八、结论

[A+B融合] 本节主线是：先定客体，再定程序；公告看生效，申请日看期限；独占权受时间和地域限制。跨法域布局先核对目标法域并选择可用申请路径，PCT或《巴黎公约》路径不替代目标法域的独立审查与权利确认。对实施细则、审查指南、早期公开延迟审查的具体历史规则以及跨法域最新动向，应坚持“有文本再下结论”的证据边界。

> 某机器人企业完成了一款关节模组：内部减速器的结构作了改进，外壳也设计了新的线条和图案。研发负责人希望尽快在中国申请专利，并计划把产品带到境外展会展示。代理人需要先判断哪些内容对应何种申请；审查员则要依照法定客体和相应程序审查。团队还误以为“中国授权后，海外也当然受保护”。

### 核心法条锚定（legal_anchor）

- **《专利法》第一条**：专利法以保护专利权人合法权益、鼓励发明创造、推动应用、提高创新能力并促进科技进步和经济社会发展为制度目标。
- **《专利法》第二条**：发明创造分为发明、实用新型和外观设计；三类客体的法定定义不同。
- **《专利法》第三十九条**：发明经实质审查没有发现驳回理由的作出授予决定并公告；实用新型和外观设计经初步审查没有发现驳回理由的作出授予决定并公告。
- **《专利法》第四十条**：三类专利权均自公告日起生效；一般期限分别为二十年、十年、十五年，均自申请日起计算。
- **《专利法》第四十二条**：

**为何重要**：这些条文把本节点的客体、制度目的、审查路径、生效时点与期限连接成可核验的规则链。

### 外观设计申请的完整判断链（worked_example）

**案情/例题**：乙公司于2024年3月1日提交一项产品整体外观的新设计申请。该设计具备富有美感并适于工业应用的事实前提；经初步审查没有发现驳回理由，于2025年6月1日登记并公告。现需依次判断其类型、审查路径、权利生效时点和期限起算点。
**适用规则**：《专利法》第二条、第四十条、第四十二条。
**分步推演**：
1. 事实描述聚焦产品整体外观的新设计，且具备富有美感、适于工业应用的前提，符合第二条中外观设计的定义方向。 → *先按法定定义确定为外观设计。*
2. 第四十条明确规定外观设计申请经初步审查没有发现驳回理由时作出授予决定。 → *类型决定初步审查路径。*
3. 第四十条规定外观设计专利权自公告之日起生效。 → *公告日决定权利何时生效。*
4. 第四十二条规定外观设计专利权期限为十五年且自申请日起计算。 → *申请日决定期限起算。*
**结论**：在该示例假定下，该申请按外观设计的初步审查路径处理；专利权于2025年6月1日公告时生效，但十五年期限仍从2024年3月1日申请日起计算。
**本题要点**：用“客体定类型、类型定程序、公告定生效、申请日定期限”完成基础日期与程序判断。

### 把规则讲成人话（verbal_explanation）

专利基础可先拆成五件事：先分发明、实用新型、外观设计三类；再理解独占性、时间性和地域性；随后按类型区分审查路径；再把公告日与申请日分开；最后处理境外布局。中国授权不等于海外自动受保护。检索材料列出在目标国申请以及通过《巴黎公约》或PCT进行国际申请的路径，但没有提供最新官方操作规则，因此不能把经验说成已核验的新趋势。

**点破术语**：独占性；时间性；地域性；审查路径；跨法域申请路径

**类比**：可把专利制度想成一张“有边界的法律通行证”：先确认拿的是哪种证，再看要走哪条审查通道、何时生效、在哪些地域可用。该类比只帮助记忆顺序，不能替代法条和目标法域规则。

### 客—程—效—期复盘表（mnemonic）

**记忆锚**：基础复盘四格：“客—程—效—期”。客体先分类；程序按类型；生效看公告；期限看申请日。跨境另加一格：“域”，目标法域另核验。
**映射**：
- 客
- 程
- 效
- 期
- 域
**何时用**：看到申请类型、授权公告、保护期计算或海外布局材料时，按五格逐项核对；它是核对表，不是替代法条或目标法域规则的结论。

### 审查与代理的双视角反思（reflect_prompt）

**反思问题**：同一项成果交到审查员和代理人手中，两种角色分别应先核对哪些共同事实，又分别要承担哪些程序与跨法域风险控制任务？

**关注要点**：是否先把成果放入发明、实用新型或外观设计的法定定义，而非先凭名称判断。；是否依类型区分发明的实质审查与实用新型、外观设计的初步审查。；是否把公告生效与申请日起算期限分别记录。；涉及境外时，是否把目标国家或地区作为独立法域核对，而不从中国授权直接推论。；是否将《巴黎公约》或PCT理解为申请路径，而非目标法域自动授权的结论。

**连接**：连接技术研发、申请准备、海外展示或许可时的类型选择、日期管理和目标法域布局。

### 专利法律制度基础与跨法域动向概览（knowledge_synthesis）

**知识框架**：
- 基本特征：独占性限定未经许可实施的排他边界，时间性限定权利存续期间，地域性限定权利有效的空间范围。
- 制度体系：中国专利制度以专利法为基本法律规范，并由专利法实施细则、专利审查指南等形成配套规范与操作框架；本轮未对后二者具体规则作扩展。
- 保护客体：第二条将发明创造分为发明、实用新型、外观设计，并以法定要素区分。
- 制度作用：第一条所示制度目标包括保护合法权益、鼓励发明创造、推动应用、提高创新能力及促进科技进步和经济社会发展。
- 发展与审查特点：发明的实质审查与实用新型、外观设计的初步审查并存；早期公开延迟审查的具体历史阶段和程序细节未获直接依据。
- 跨法域实践锚点：专利权具有地域性；为在目标国家取得保护，可在目标国申请，或者通过《巴黎公约》或PCT方式进行国际专利申请。
- 跨法域术语边界：检索材料指出，TRIPS中的“专利”仅代表发明专利，而中国专利法中的“专利”包括发明、实用新型、外观设计；比较规则前应先核对语境。
**概念关系**：先依第二条确定客体，再按类型匹配审查路径；客体分类不能由申请人自称替代。；公告日决定专利权生效，申请日决定一般期限的起算；两个日期承担不同法律功能。；独占性必须与时间性、地域性一起理解，不能推出永久或全球有效。；跨法域布局先确认目标法域，再选择目标国申请、《巴黎公约》或PCT路径；申请路径不等于各目标法域自动授予实体权利。；TRIPS术语与中国专利法术语的类型范围不完全相同，不能脱离文本语境直接等同。
**必记**：发明创造包括发明、实用新型和外观设计。；发明申请经实质审查没有发现驳回理由的作出授予决定；实用新型和外观设计申请经初步审查没有发现驳回理由的作出授予决定。；专利权自公告日起生效；发明、实用新型、外观设计的一般期限分别为二十年、十年、十五年，均自申请日起计算。；中国授权不当然在其他国家或地区发生效力；可在目标国申请，或者通过《巴黎公约》或PCT方式进行国际专利申请。；本轮检索未提供PCT、TRIPS的现行官方指南、官方链接或最新修订规则；跨法域新动向必须以世界知识产权组织、世界贸易组织及目标法域主管机关的现行官方文本后续核验。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **三项特征**：独占性、时间性、地域性共同说明专利权不是永久且全球通行的绝对权利。
- **规范体系**：专利法是基本法律规范，实施细则和审查指南是配套与操作依据；具体口径须以可核验文本为准。
- **三类客体**：发明、实用新型、外观设计同属发明创造，但其法定定义不同。
- **审查路径**：发明申请适用实质审查；实用新型和外观设计申请适用初步审查。
- **生效与期限**：公告决定权利生效，申请日决定一般期限起算；发明二十年、实用新型十年、外观设计十五年。
- **跨法域路径**：中国授权不当然覆盖海外；目标国申请、《巴黎公约》或PCT是已检索到的申请路径，具体规则仍须逐法域核验。
**必背**：发明、实用新型、外观设计是第二条规定的三类发明创造。；发明实质审查；实用新型和外观设计初步审查。；公告决定生效，申请日决定期限起算。；专利权具有独占性、时间性和地域性。；跨法域保护不能由中国授权当然推出；国际申请路径不等于目标法域自动授权。
**一句话总结**：先定客体与程序，再分清公告生效和申请日起算的期限；跨境保护另核目标法域与申请路径。

**三类覆盖**：backward_review、forward_probe、weakness_probe
