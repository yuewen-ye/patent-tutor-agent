# First-party resources for academic paper writing with Agents

**Scope.** This inventory distinguishes reusable Agent skills (packaged instructions/resources/scripts loaded by an Agent host) from official APIs, MCP reference servers, and authoring-tool documentation. Sources are first-party repositories or documentation only. None of the sources below, by itself, establishes that a paper's claims are true or that a citation supports a claim.

## Executive findings

The official Anthropic and OpenAI skill catalogs provide general document/PDF skills and skill-authoring scaffolds, but the sources reviewed did not identify a first-party, academic-specific skill covering literature search, citation management, IMRaD/paper structure, language polishing, and fact verification end-to-end. A defensible academic workflow therefore combines a custom local skill with scholarly metadata APIs, a citation manager, and deterministic document compilers. Each claim still needs human/source review.

## Recommended evidence protocol (workflow, not a claim of official endorsement)

1. Discover candidates with arXiv and Semantic Scholar; preserve query, date, API response, and paper version.
2. Verify title/authors/year/DOI using Crossref and the publisher or proceedings record; retain both records when they disagree.
3. Store reviewed records in Zotero, preferably with DOI and stable URLs; avoid granting a writing Agent unrestricted write access.
4. Draft in Markdown or LaTeX; use a custom local skill created with Anthropic/OpenAI `skill-creator` to enforce claim preservation, uncertainty labels, no invented citations, and an evidence table.
5. Render with Pandoc/LaTeX and inspect the output, bibliography, equations, tables, and links. Use PDF/docx skills only as document-processing aids.
6. Treat every generated summary, paraphrase, citation context, and polished sentence as a draft requiring source-level and human review.

## Sources and confidence notes

All links above point to first-party vendor/project documentation, official GitHub repositories, or official APIs. Search results did not establish a first-party reusable skill dedicated specifically to academic prose polishing, IMRaD structure, or fact-checking. That absence is a search finding, not proof that no such skill exists. Community marketplaces and unofficial collections were intentionally excluded from the candidate list because the requested trust boundary was primary sources only.
