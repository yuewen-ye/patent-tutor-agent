# 画像级评估提示词（对应 profile 模式）

> 本提示词用于评估跨轮次的画像级指标，包含：
> - **1.6 跨轮自洽率**：多轮课程在关键知识点上的一致性，是否出现前后矛盾
> 
> **注：画像级指标需要结合同一画像的多轮课程内容进行评估。统一 100 分制评分，5 分为步进单位。**

## 通用评分规则

1. 所有评分均为 **0-100 分制**，以 5 分为步进单位（如 85, 90, 95），100 分为满分
2. 评分必须客观、有据可查，每个评分维度必须附带具体文字评价
3. 如果信息不足，请说明原因并保守评分
4. 指出具体的问题（issues）和亮点（highlights）
5. 严格区分"事实错误"与"表述瑕疵"：前者扣分，后者不影响理解时不扣分
6. 严格区分"表述差异"与"逻辑矛盾"：前者不扣分，后者扣分

### 评分等级通用 Rubric
- **90-100分 (Excellent)**：完全一致，无任何矛盾
- **80-89分 (Good)**：基本一致，有极少量不影响理解的表述差异
- **70-79分 (Acceptable)**：部分一致，存在少量表述差异但无实质矛盾
- **60-69分 (Needs Improvement)**：存在明显的表述差异，部分可能涉及逻辑矛盾
- **50-59分 (Poor)**：多处表述不一致，存在明显的逻辑矛盾
- **0-49分 (Unacceptable)**：严重矛盾，核心结论前后不一

## 核心任务

分析同一画像在多个轮次中学习的课程内容，判断：
1. **是否存在直接矛盾**：不同轮次对同一知识点给出相反的结论
2. **是否存在间接矛盾**：A轮陈述和B轮陈述在逻辑上互斥
3. **是否存在表述差异**：措辞不同但语义相同（不算矛盾）
4. **是否存在知识漂移**：对同一概念的定义或解释在不同轮次中发生变化

## 评估标准

### 1. 跨轮一致性评估（consistency_score）

#### 1.1 直接矛盾检测
检查不同轮次是否对同一知识点给出了相反的结论。
- **检测规则**：
  - 同一知识点的核心结论必须一致
  - 同一法条的引用和解释必须一致
  - 同一案例的引用和解读必须一致
  - 同一概念的定义和使用必须一致

#### 1.2 间接矛盾检测
检查A轮的陈述与B轮的陈述是否在逻辑上互斥。
- **检测规则**：
  - A轮的陈述若为真，则B轮的陈述必须为假，反之亦然
  - 不同轮次的规则适用条件不能互相矛盾
  - 不同轮次的例外情况不能互相矛盾

#### 1.3 表述差异识别
识别措辞不同但语义相同的陈述，这些不算矛盾。
- **识别规则**：
  - 同义改写（如"新颖性"vs"新颖程度"）不算矛盾
  - 简化表述（如省略修饰词）不算矛盾
  - 角度不同（如从申请人角度vs从审查员角度）不算矛盾

### 2. 跨轮自洽率评分规则

#### 2.1 完全自洽（100分）
- 所有轮次的知识点、法条、案例引用完全一致
- 无任何直接或间接矛盾
- 表述差异均为合理的简化或角度变化

#### 2.2 基本自洽（80-89分）
- 核心知识点和法条引用完全一致
- 存在极少量表述差异但不影响理解
- 无直接或间接矛盾

#### 2.3 部分自洽（70-79分）
- 大部分知识点引用一致
- 存在少量表述差异
- 无明显的逻辑矛盾，但有个别可能引起混淆的表述差异

#### 2.4 待改进（60-69分）
- 存在明显的表述差异
- 部分差异可能涉及逻辑矛盾
- 需要人工确认是否为真正的矛盾

#### 2.5 不一致（50-59分）
- 多处表述不一致
- 存在明显的逻辑矛盾
- 学员可能困惑

#### 2.6 严重不一致（0-49分）
- 核心结论前后矛盾
- 多处直接和间接矛盾
- 严重影响学习效果

### 3. 常见矛盾场景

#### 3.1 法条引用矛盾
- A轮引用"第42条"，B轮引用"第43条"讨论同一问题
- A轮对某条款的解读与B轮完全相反

#### 3.2 案例解读矛盾
- A轮引用案例X说明"应授予专利权"，B轮引用同一案例说明"不应授予"
- A轮对案例事实的描述与B轮不一致

#### 3.3 概念定义矛盾
- A轮定义"发明"为"技术方案"，B轮定义为"产品或方法"
- A轮对"创造性"的判断标准与B轮不同

#### 3.4 规则适用矛盾
- A轮说"适用于发明专利"，B轮说"仅适用于实用新型"
- A轮说"例外情况包括X"，B轮说"例外情况不包括X"

## 字段说明

### direct_contradictions 结构
```json
{
  "round_a": 1,
  "round_b": 2,
  "topic": "矛盾的知识点/主题",
  "statement_a": "A轮的原文陈述",
  "statement_b": "B轮的原文陈述",
  "contradiction_type": "direct",
  "reasoning": "为什么判定为直接矛盾",
  "severity": "high"
}
```

### indirect_contradictions 结构
```json
{
  "round_a": 1,
  "round_b": 2,
  "topic": "矛盾的知识点/主题",
  "statement_a": "A轮的原文陈述",
  "statement_b": "B轮的原文陈述",
  "contradiction_type": "indirect",
  "reasoning": "为什么判定为间接矛盾",
  "severity": "medium"
}
```

### expression_differences 结构
```json
{
  "round_a": 1,
  "round_b": 2,
  "topic": "差异的知识点/主题",
  "statement_a": "A轮的原文陈述",
  "statement_b": "B轮的原文陈述",
  "difference_type": "synonym",
  "reasoning": "为什么判定为表述差异而非矛盾",
  "impact": "low"
}
```

### consistency_verdict 取值
- `consistent`：完全自洽，score ≥ 80
- `mostly_consistent`：基本自洽，60 ≤ score < 80
- `inconsistent`：不一致，score < 60

### severity 取值
- `high`：直接矛盾，涉及核心知识点
- `medium`：间接矛盾，涉及非核心知识点
- `low`：轻微表述差异

## 注意事项

1. **宽容原则**：
   - 表述差异（措辞不同但语义相同）不应判定为矛盾
   - 对同一知识点的不同角度解读不应判定为矛盾
   - 简化表述不应判定为矛盾

2. **上下文理解**：
   - 不同轮次的教学目标可能不同，应结合上下文判断
   - 学员的学习进度可能影响表述的详细程度
   - 复习和巩固轮次可能简化之前的详细表述

3. **客观依据**：
   - 判定必须基于陈述的字面意思和逻辑关系
   - 不应主观推测系统的意图
   - 有疑问时倾向于判定为表述差异

4. **中文输出**：
   - `reasoning`、`summary`、`issues` 等文字字段使用中文
   - `statement_a`、`statement_b` 保留原文

5. **评分一致性**：
   - 所有评分为 0-100 分制，5 分为步进单位
   - 判定必须具体，不能笼统

6. **逐条比对**：
   - 对每个知识点进行跨轮比对
   - 标注所有发现的矛盾和差异
   - 不要遗漏关键知识点
