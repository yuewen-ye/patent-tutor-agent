## 教学正文

## 从审查与代理的共同起点出发

专利实务的第一步不是笼统判断一项成果“是否先进”，而是识别它在法律上是什么。代理人需要把技术交底拆成可以布局的申请客体，并在公开前提示风险；审查人员需要以同样的客体分类选择授权条件。一个商业产品可以同时具有构造改进、外观变化和方法改进，不能因为它们装在同一产品上就只作一种判断。

专利制度通常具有独占性、时间性和地域性：专利权具有排他属性，受法定期间限制，并通常依各法域法律分别取得和行使。这个制度定位不能直接替代个案中的权利范围判断，具体边界仍须回到法律和授权文件。

## 制度体系与机关定位

中国专利制度以专利法为基本法律规则，专利法实施细则和专利审查指南承担规则细化与审查操作功能。关于后二者的具体条文和具体程序期限，本次检索上下文未提供直接原文，不能据此作无来源的细化断言。

国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，并依法授予专利权；地方管理专利工作的部门负责本行政区域内的专利管理工作。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门统一受理和审查专利申请，依法授予专利权〕

对代理人而言，这意味着申请布局、文件准备和公开管理必须围绕法定申请程序展开；对审查人员而言，这意味着审查必须在法定职权和相应客体规则内进行。先确认对象与程序入口，再进入实体标准，能避免“先背三性、后找对象”的串扰。

## 三类保护客体

《中华人民共和国专利法》第二条规定，发明创造是指发明、实用新型和外观设计。发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

因此，面对一件智能设备，应把“新增卡扣连接构造”与“局部图案和颜色搭配”以及“自动调整运行参数的方法”分开看。前者首先进入实用新型的定义分析，第二项进入外观设计的定义分析，第三项进入发明中方法技术方案的定义分析。分类是后续审查和代理布局的前提，而不是形式上的标签。

## 授权条件：先分客体，再选标准

发明和实用新型适用第二十二条：应当具备新颖性、创造性和实用性。新颖性要求该发明或者实用新型不属于现有技术，也不存在任何单位或者个人就同样发明或者实用新型在申请日前提出、并在申请日后公布或公告的专利文件；现有技术是申请日前在国内外为公众所知的技术。创造性要求发明相对于现有技术具有突出的实质性特点和显著进步，实用新型具有实质性特点和进步；实用性要求能够制造或者使用，并能产生积极效果。〔RAG: 中华人民共和国专利法.txt — 第二十二条：发明和实用新型应具备新颖性、创造性和实用性；现有技术是申请日前在国内外为公众所知的技术〕

外观设计不适用上述三性框架。第二十三条要求其不属于现有设计，不存在同样外观设计的申请在先、公开在后文件，与现有设计或者现有设计特征的组合相比具有明显区别，并且不得与申请日前他人已经取得的合法权利相冲突。现有设计是申请日前在国内外为公众所知的设计。〔RAG: 中华人民共和国专利法.txt — 第二十三条：外观设计的现有设计、明显区别和合法权利冲突条件〕

新颖性与创造性必须分开。新颖性先处理“是否已有同样方案”的问题，审查中应特别辨认单一对比资料以及第二十二条所述申请在先、公开在后的文件。创造性则以现有技术为基础评价；检索材料说明，创造性可以将一份或者多份现有技术中的不同技术内容组合起来评价，而申请在先、公开在后的专利文件不能用于评价创造性。〔RAG: 专利法专题讲座.txt — 新颖性“单独对比”；创造性可组合一份或者多份现有技术；申请在先公开在后的专利文件不能用于评价创造性〕

这一区分既是审查路径，也是代理答复和检索报告的写作边界：先问材料属于哪一类，再决定它能回答新颖性、创造性还是其他问题，不能只因材料“很接近”就随意混用。

## 公开风险与不丧失新颖性例外

第二十四条规定，申请专利的发明创造在申请日前六个月内，有下列情形之一的，不丧失新颖性：在国家出现紧急状态或者非常情况时为公共利益目的首次公开；在中国政府主办或者承认的国际展览会上首次展出；在规定的学术会议或者技术会议上首次发表；他人未经申请人同意而泄露内容。〔RAG: 中华人民共和国专利法.txt — 第二十四条：申请日前六个月内的四类情形不丧失新颖性〕

代理工作不能把这一规则简化成“展会公开有六个月保护”。必须逐项核对公开是否属于法定类型、是否为首次公开，以及申请日是否落在六个月内。审查视角同样要审查这些事实，而非仅凭“参加展会”这一名称作结论。

宽限期也不等于优先权。检索材料明确指出，不丧失新颖性仅使符合条件的公开在一定期限内不视为损害该申请新颖性和创造性的现有技术，并不把公开日视为申请日；在公开到申请之间，如果第三人独立完成同样发明创造并先提出申请，申请人仍可能因先申请原则无法取得专利权。〔RAG: 专利法专题讲座.txt — 宽限期不把公开日看作申请日；第三人独立完成并在申请前提出申请时，申请人可能不能取得专利权〕

## 制度目的、发展定位与实务主线

专利制度通过公开与保护的安排，服务激励发明创造、促进技术公开、推动技术应用和经济发展。制度目的有助于理解为何法律同时关心公开、授权与权利保护，但它不能替代第二条的客体判断或第二十二条、第二十三条的逐项审查。

课程材料将早期公开、延迟审查，以及初步审查制与实质审查制并存列为中国专利制度发展历程与特点。本次检索上下文未提供对应规范原文，因此本节仅将其作为制度定位，不据此推导具体公开期限、审查步骤或不同客体的适用范围。

用审查与代理共同适用的顺序收束本节：先分客体，后选标准；先核对公开事实和日期，再判断公开的法律后果。对发明和实用新型，继续区分新颖性、创造性、实用性；对外观设计，回到第二十三条的专门条件；对申请在先、公开在后的文件与现有技术，始终先确认其法律角色。

### 从一件产品进入专利制度（anchor_scenario）

> 甲公司研发一款智能净水设备：滤芯与机身之间新增了卡扣连接构造，机身局部采用新的波纹图案和颜色搭配，控制程序还能依据传感器数据自动调整冲洗时间。研发负责人计划在中国政府主办或者承认的国际展览会上展示样机，再决定是否提交申请。

代理人必须先把同一产品中的构造、外观和方法拆开，判断它们各自可能对应的保护客体，并提醒客户展示公开的时间风险；审查人员则要依客体选择对应的授权条件，不能把所有内容放进同一套标准中判断。

**锚定**：该场景同时锚定三类专利客体、不同授权框架，以及公开前的申请风险识别。

**先想一想**：看到“同一产品、三种改进、拟在展会展示”这组事实时，应当先判断客体类别，还是先直接判断新颖性？为什么？

### 法条锚定：客体、机关、授权条件与公开例外（legal_anchor）

- **《中华人民共和国专利法》第二条**：发明创造包括发明、实用新型和外观设计；三类客体分别围绕产品或方法技术方案、产品形状构造、产品外观设计作出界定。
- **《中华人民共和国专利法》第三条**：国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。
- **《中华人民共和国专利法》第二十二条**：发明和实用新型须具备新颖性、创造性和实用性；现有技术是申请日前在国内外为公众所知的技术。
- **《中华人民共和国专利法》第二十三条**：外观设计适用现有设计、明显区别和不与在先合法权利冲突的专门条件。
- **《中华人民共和国专利法》第二十四条**：申请日前六个月内发生法定四类首次公开情形的，申请专利的发明创造不丧失新颖性。

**为何重要**：审查与代理都必须先以法定客体确定适用规则。第二十二条、第二十三条和第二十四条分别决定实体审查的基本路径与特定公开的风险边界。

### 演示：复合产品分类与展会公开风险（worked_example）

**案情/例题**：甲公司于2026年5月1日在中国政府承认的国际展览会上首次展出智能净水设备，并于2026年10月20日提交专利申请。设备包含滤芯新增卡扣连接构造、机身局部波纹图案和颜色搭配，以及自动依据传感器数据调整冲洗时间的方法。应如何从代理与审查双视角确定保护客体，并判断该次展出的初步影响？
**适用规则**：《中华人民共和国专利法》第二条界定三类客体；第二十四条规定申请日前六个月内在中国政府主办或者承认的国际展览会上首次展出的，不丧失新颖性。
**分步推演**：
1. 先按直接指向的技术事实拆分，不以“它们装在同一产品上”为由合并分类：卡扣指向产品构造，波纹与颜色指向产品局部外观，自动调整指向方法。 → *先拆事实，再分客体。*
2. 依据第二条，产品形状、构造或者其结合所提出的适于实用的新的技术方案进入实用新型定义；产品整体或者局部图案及色彩与图案结合的美感设计进入外观设计定义；方法或者其改进的新的技术方案进入发明定义。 → *构造、外观、方法分别进入不同定义。*
3. 展会首次展出日在申请日前，申请日距展出日不足六个月，且事实设定为中国政府承认的国际展览会，落入第二十四条所列情形。 → *该次公开符合不丧失新颖性的时间与情形条件。*
4. 不丧失新颖性宽限期的效力不等于把公开日视为申请日；检索材料说明，这类公开在一定期限内不视为影响该申请新颖性和创造性的现有技术，但第三人在此期间独立完成并先提出相同申请，仍可能依先申请原则影响取得专利权。 → *宽限期是对特定公开的有限豁免，不是全面的程序保护。*
**结论**：卡扣连接构造应按实用新型的法定定义分析，局部图案和颜色搭配应按外观设计的法定定义分析，自动调整冲洗时间的方法应按发明中“方法或者其改进”的定义分析。若样机在符合第二十四条的国际展览会上首次展出且申请日在六个月内，该次展出不使申请丧失新颖性；但仍须分别满足相应授权条件。
**本题要点**：面对复合产品，先按客体拆分，再核对公开类型和日期，最后分别进入对应授权审查。

### 口头拆解：先分客体，再分审查问题（verbal_explanation）

先把专利制度看成一套“分类后再审查”的规则。不是客户说“这是新产品”，就能直接讨论有没有专利。代理人先问：核心是产品或方法的技术方案、产品的形状构造，还是产品的外观？审查人员也从这里起步，因为发明和实用新型适用第二十二条的三性，外观设计适用第二十三条的专门条件。新颖性和创造性尤其不能混：新颖性通常问一项对比资料能否给出同样方案；创造性才会围绕现有技术判断技术进步，并可能组合一份或者多份现有技术。申请在先、公开在后的文件在新颖性中要特别识别，但它不是现有技术，不能被拿去评价创造性。公开风险也不能只看“是否公开”，还要看是否属于第二十四条列举情形及是否在六个月内。

**点破术语**：独占性；时间性；地域性；现有技术；抵触申请

**类比**：可将新颖性暂时理解为“查重”：看申请日前是否已有一项公开信息给出了同样的技术方案；创造性则不是查重，而是判断相对于现有技术是否仍有法定程度的技术进步。这个类比只帮助区分审查问题，不能替代以权利要求、现有技术和法条为依据的正式判断。

### 记忆锚：分、对、创、例（mnemonic）

**记忆锚**：四步辨析表：“分—对—创—例”。先分客体；新颖性看单一对比资料或第二十二条所述申请在先、公开在后的文件；创造性只以现有技术评价，可考虑一份或者多份现有技术；最后核对第二十四条的公开例外。
**映射**：
- 分
- 对
- 创
- 例
**何时用**：遇到新颖性、创造性、抵触申请或展会公开的题目、审查意见和客户咨询时，按“四步辨析表”逐项定位。

### 反思：把公开计划变成风险核对表（reflect_prompt）

**反思问题**：复盘客户拟公开技术的计划时，如何把“公开内容、公开地点或会议性质、首次公开日期、申请日期、不同技术改进的客体类别”整理为一张核对表，以免把公开例外、客体分类和授权标准混为一谈？

**关注要点**：第二十四条只列举四类公开情形，不能把所有展会、论文或宣传当然视为宽限期事由。；宽限期不把公开日改写为申请日，且不当然排除第三人在公开与申请之间独立申请的风险。；同一商业产品中的构造、外观和方法，应分别标记并匹配相应授权条件。

**连接**：连接到已有的项目管理和程序法经验：先固定关键日期与事实来源，再为每一种法律后果选择对应的规则。

### 本节点知识综合（knowledge_synthesis）

**知识框架**：
- 制度特征：独占性、时间性和地域性说明专利权具有排他属性、受法定期间限制，并通常依各法域分别取得和行使；具体权利边界仍须回到法律和授权文件。
- 制度体系：专利法提供基本法律规则，专利法实施细则和专利审查指南承担规则细化与审查操作功能；本次检索未提供后二者直接原文，不能据此推导具体程序期限。
- 保护客体：第二条将发明创造分为发明、实用新型和外观设计，分别以产品或方法技术方案、产品形状构造、产品整体或局部外观为定义重点。
- 制度功能：专利制度通过公开与保护的安排，服务激励发明创造、促进技术公开、推动技术应用和经济发展；该功能用于理解制度目的，不替代授权要件判断。
- 制度发展与审查特点：课程材料将早期公开、延迟审查以及初步审查制与实质审查制并存列为制度特点；本次检索没有对应规范原文，本节仅作制度定位，不推导具体期限、审查步骤或客体范围。
- 实体审查框架：发明和实用新型依第二十二条审查新颖性、创造性和实用性；外观设计依第二十三条审查现有设计、明显区别和在先合法权利冲突。
- 公开例外：第二十四条对申请日前六个月内发生的四类法定首次公开规定不丧失新颖性；其效力与优先权不同。
**概念关系**：代理与审查的共同顺序是：先拆分技术事实并确定客体，再选择第二十二条或第二十三条的实体审查框架。；新颖性与创造性不能混同：新颖性侧重同样方案及第二十二条规定的申请在先、公开在后文件；创造性只以现有技术评价，并可考虑一份或者多份现有技术。；抵触申请不等于现有技术：申请在先、公开在后的文件可进入第二十二条的新颖性定义，但不能用于评价创造性。；第二十四条宽限期是对特定公开的有限处理，不等于优先权，也不将公开日视为申请日。
**必记**：发明、实用新型与外观设计必须按第二条分别判断；同一产品可以含有不同客体性质的改进。；发明和实用新型适用第二十二条三性，外观设计适用第二十三条专门条件，二者不得相互替代。；现有技术是申请日前在国内外为公众所知的技术；申请在先、公开在后的文件与现有技术必须区分。；第二十四条只处理申请日前六个月内的法定四类首次公开，不能将其泛化为一切公开的豁免。

### 专利法律制度基础速查卡（summary_card）

**要点卡**：
- **制度特征**：独占性、时间性、地域性提示专利权具有排他性但并非永久、当然跨域的权利。
- **制度体系**：专利法是基本法律规则，实施细则与审查指南承担细化和操作功能；具体程序须核对直接规范依据。
- **三类客体**：发明重产品或方法技术方案，实用新型重产品形状构造，外观设计重产品整体或局部外观。
- **授权条件**：发明和实用新型审查新颖性、创造性、实用性；外观设计审查现有设计、明显区别和在先权利冲突。
- **新颖性与创造性**：新颖性先辨单一对比和申请在先公开在后文件；创造性只以现有技术评价，可考虑多份现有技术。
- **公开例外**：第二十四条的六个月宽限期只适用于四类法定首次公开，不等同于优先权。
- **制度功能与发展特点**：公开与保护服务创新和技术应用；早期公开、延迟审查及两类审查并存仅作本节制度定位，具体规则须另有直接依据。
**必背**：《中华人民共和国专利法》第二条：发明创造包括发明、实用新型和外观设计。；《中华人民共和国专利法》第三条：国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。；发明、实用新型适用第二十二条三性；外观设计适用第二十三条专门条件。；第二十四条宽限期仅限申请日前六个月内的四类法定首次公开。
**一句话总结**：专利制度基础的实务主线是：先分客体，后选标准；先核日期与公开类型，再判断公开的法律后果。
