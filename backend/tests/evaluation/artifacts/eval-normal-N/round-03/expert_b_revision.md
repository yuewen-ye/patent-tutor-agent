# 专家 B 修订稿

## teaching_content

## 1. 场景导入
某初创团队做出一款可折叠手机支架：支架臂采用新型铰链结构，外观曲面很抓人，还附带一套调节姿态的控制方法。产品马上要上电商，也想投国际展会。创始人同时找了代理人和审查员朋友：代理人问“这三项能怎么拆成发明、实用新型、外观设计去布局？独占权能管多久、管到哪？”，审查员提醒“先弄清客体边界和制度框架，再谈后续审查节奏——我国发明走早期公开延迟审查，实用新型和外观设计多走初步审查”。双视角一碰头，问题就落到本节：专利法律制度到底保护什么、怎么搭起来、有什么基本特征和作用。

## 2. 人话解释
专利制度可以先记三件事。第一，基本特征：独占性——别人未经许可一般不能实施；时间性——保护有期限，过期进公有领域；地域性——一国授权原则上只管本国。第二，中国制度体系像“三层楼”：专利法是顶层原则，实施细则把程序填实，审查指南给审查和代理可操作的尺子（审查指南属于操作规范文件，必须在法律和实施细则范围内适用，不能替代或修改上位法）。第三，保护客体只有三类：发明（产品、方法或其改进的新技术方案）、实用新型（产品形状/构造或其结合的适于实用的新技术方案）、外观设计（形状、图案、色彩结合的富有美感且适于工业应用的新设计）。制度作用也很直白：激励创造、逼着技术公开、推动应用和经济发展。我国特点则是发明“早期公开、延迟审查”，实用新型与外观设计以初步审查为主、发明另有实质审查，两套节奏并存。

## 3. 法条回扣
客体边界直接看《专利法》第二条：发明创造指发明、实用新型和外观设计，并分别给出定义。〔RAG: 中华人民共和国专利法.txt — 第二条　本法所称的发明创造是指发明、实用新型和外观设计。发明，是指对产品、方法或者其改进所提出的新的技术方案。实用新型，是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。外观设计，是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〕管理与审查分工见第三条。〔RAG: 中华人民共和国专利法.txt — 第三条　国务院专利行政部门负责管理全国的专利工作；统一受理和审查专利申请，依法授予专利权。省、自治区、直辖市人民政府管理专利工作的部门负责本行政区域内的专利管理工作。〕授权实质条件（尤其发明和实用新型的三性）见第二十二条，其中也界定了现有技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条　授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性。……本法所称现有技术，是指申请日以前在国内外为公众所知的技术。〕权利期限见第四十二条：发明专利权二十年、实用新型十年、外观设计十五年，自申请日起计算。制度作用见《专利法》第一条。这些条文是代理布局和审查判断的共同锚点。

## 4. 类比 / 口诀
把三类客体想成“能做什么”：发明像完整菜谱（产品+方法都行）；实用新型像只改锅铲形状构造、必须能用的“小改款产品”；外观设计像餐具的造型配色，看美感和工业可复制。制度三层楼口诀（教学框架顺序）：专利法—实施细则—审查指南。特征口诀：“独时地”——独占、时间、地域。边界提醒：类比只帮助入门，正式判断仍回第二条文字，方法方案进不了实用新型，纯美感不够还得“适于工业应用”。审查指南是操作手册，不能用来修改法律或替代实施细则。

## 5. 应试提示
题干出现“产品/方法/形状构造/美感工业应用”先对号入座客体；出现“保护多久、管哪国、能否排他”先对“独时地”；出现“依据哪部文件审查”先分清法、细则、指南层级。常见陷阱：把方法/算法塞进实用新型（实用新型明文限于产品形状构造）；把“算法”直接说成发明（必须判断是否构成发明定义的技术方案）；把方法技术方案当然归入发明（需确认是否符合发明定义的其他条件）；把“早期公开延迟审查”说成三种专利都一样；把审查指南效力口语化成“专利法＞实施细则＞审查指南”（审查指南必须在法律范围内适用）。代理视角先想布局组合，审查视角先核客体与审查类型是否匹配。

## 6. 互动提问
本节设有测评（覆盖向后复习/向前探测/薄弱点），请到【习题】区作答。先在心里用双视角过一遍：若你是代理人，你会如何拆分上述支架的三类申请；若你是审查员，你会先核哪一层规范、哪种审查程序。
