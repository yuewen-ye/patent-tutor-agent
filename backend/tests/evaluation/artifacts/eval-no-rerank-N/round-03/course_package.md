## 教学正文

## I — 法律问题

本节点讨论专利法律制度基础。面对同一产品中的方法改进、产品结构改进和视觉设计，审查人员与专利代理人都必须先确定其是否属于中国专利法承认的法定保护客体，并同时避免把专利权的独占性误解为永久、绝对或跨法域当然有效的权利。本节点只建立客体、制度主体、权利边界、制度作用和制度发展特点的基础坐标，不替代后续节点对授权条件、申请程序、审查指南具体条款或跨法域规则的专门分析。

## R — 适用规则

《中华人民共和国专利法》第二条规定，本法所称的发明创造是指发明、实用新型和外观设计。发明，是指对产品、方法或者其改进所提出的新的技术方案；实用新型，是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计，是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：本法所称的发明创造是指发明、实用新型和外观设计；发明是指对产品、方法或者其改进所提出的新的技术方案；实用新型是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是指对产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计〕

第三条规定，国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请，依法授予专利权；省、自治区、直辖市人民政府管理专利工作的部门负责本行政区域内的专利管理工作。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门负责管理全国的专利工作；统一受理和审查专利申请，依法授予专利权〕

检索材料将专利权概括为具有排他性、时间性和地域性的权利。排他性是指在法律规定的边界内，专利权人可以排除他人未经许可实施其专利，但材料同时提示先用权等法定情形会限制“任何人都不能实施”的绝对化表述。时间性意味着专利权有法定期限，超过保护期限后进入公有领域；地域性意味着专利权效力受授权国家或地区的法律范围限制，中国授权不当然扩及其他法域。〔RAG: 专利法律知识详细解读.txt — 专利权具有排他性、时间性和地域性的特征；超过法律规定的保护期限，即进入公有领域〕

教学上下文列出专利法、专利法实施细则和专利审查指南作为中国专利制度体系的组成部分。本节以专利法作为法条锚点；由于当前检索上下文没有提供实施细则和审查指南的完整、具体条文，不能据此展开未经核验的条款层级或最新审查口径。遇到具体案件，应核对适用时点的现行规范和可核验材料。

检索学习材料把制度作用概括为保护专利权人的合法权益、鼓励发明创造、推动发明创造的应用、提高创新能力，并最终促进科学技术进步和经济社会发展。其逻辑不是“只给权利”，而是通过一定期限的法律保护与技术公开，形成激励创造、促进应用和技术进步的制度联系。〔RAG: 专利法律知识详细解读.txt — “保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，促进科学技术进步和经济社会发展”〕

关于制度发展，检索材料记载中国专利制度在同一部法律中包含发明、实用新型和外观设计三种专利类型，并形成发明专利初步审查与实质审查、实用新型和外观设计初步审查并存的制度特点。〔RAG: 专利法律知识详细解读.txt — “同一部法律，包含三种专利类型”；“发明专利为实质审查制，实用新型和外观设计为初步审查制”〕这属于制度背景和审查安排的概括，不能直接替代对特定申请适用的现行程序规则。

## A — 规则适用

### 1. 审查与代理的共同起点

审查视角首先要确定申请内容对应的法定客体。审查人员应把权利要求、说明书、图片或照片中的事实拆开，判断其究竟是产品、方法或其改进形成的技术方案，产品形状或构造，还是产品整体或局部的视觉设计。代理视角的起点相同，但工作重点是把客户的商业名称、功能宣传和设计描述翻译成法律定义可以承接的事实，并据此组织技术交底、申请类型和风险提示。

一个产品可以同时包含方法改进、结构改进和视觉设计。产品存在于同一个商业项目中，不代表所有创新都只能使用同一种专利类型。相反，应先按事实单元分别匹配第二条的定义，再讨论后续申请策略。实用新型只保护产品；检索材料还明确，一切方法，包括制造、使用、通信、处理、计算机程序以及特定用途方法，不属于实用新型保护客体。〔RAG: 专利法专题讲座.txt — “实用新型专利只保护产品”；“一切方法不属于实用新型的保护客体”〕

### 2. 保护客体不等于授权结论

“属于发明”“进入实用新型定义方向”或“属于外观设计方向”，都只是基础层面的客体识别。它们不等于已经满足全部授权条件。后续还需要根据适用规则判断例如新颖性、创造性、实用性、现有设计或其他法定排除事项。专利法本身规定，授予发明和实用新型专利通常还涉及新颖性、创造性和实用性等条件；本节只提示这一推理边界，不在当前节点展开后续条件的完整教学。

### 3. 双视角中的权利边界

代理人不能向客户承诺“取得中国专利就能在全球永久排除他人”。审查人员和代理人都应把独占性、时间性、地域性放在同一判断框架中：独占性说明法律保护的排他效果，时间性说明保护有终点，地域性说明效力有法域范围。制度目的则解释了为什么法律保护与技术公开、发明创造和技术应用相联系；制度目的不能被用来扩大具体专利权的法律边界。

## C — 结论

本节点的稳定结论是：第一，以《专利法》第二条识别发明、实用新型和外观设计三类法定保护客体；第二，以第三条定位国务院专利行政部门统一受理、审查和授权的制度主体；第三，同时用独占性、时间性和地域性限定专利权的效力表述；第四，将客体识别与后续授权条件严格区分；第五，把制度目的和历史审查特点作为理解制度的背景，而不是替代现行具体规则。

审查人员的工作重点是依法律定义确定审查对象并继续适用相应法定条件，代理人的工作重点是拆解技术交底、匹配可能的保护客体并如实提示边界。关于专利法实施细则、专利审查指南的具体适用、当前审查实践和跨法域新动向，本次检索上下文未提供直接且足够的依据，应在取得对应现行文本、审查材料或域外法源后另行核验。

## 常见误区

1. 误解原话：“只要技术很新，就当然属于发明专利客体并且可以授权。”正解推理：先依第二条判断是否形成产品、方法或其改进的新的技术方案，再进入其他授权条件审查。区分判据是“客体定义”和“授权条件”回答的是两个不同问题。

2. 误解原话：“一个产品只能选择一种专利类型。”正解推理：应把方法、产品结构和视觉设计拆成事实单元，分别核对第二条定义。区分判据是所保护的具体创新事实，而不是商业项目或产品名称是否相同。

3. 误解原话：“实用新型可以保护产品的制造或处理方法，只要权利要求前面写了产品。”正解推理：实用新型只保护产品，方法步骤不能因附着在产品描述之后就自动成为实用新型客体。区分判据是权利要求是否实质上要求保护方法或方法步骤，而非是否同时出现了产品名称。

4. 误解原话：“专利权具有独占性，所以在中国获权后能永久、全球排除他人。”正解推理：独占性必须与时间性、地域性同时理解，并受法律规定的例外和边界约束。区分判据是分别检查保护期限、授权法域和具体法定限制。

5. 误解原话：“历史资料记载的审查安排就是所有现行案件的完整处理规则。”正解推理：历史材料只能提供制度发展背景，具体案件仍要核对适用时点的现行法律、实施细则、审查指南和事实。区分判据是资料的时间、法源性质和案件适用范围。

### 从一个产品看专利制度入口（anchor_scenario）

> 某智能穿戴团队完成了一款可折叠柔性电池模组。研发负责人发现，模组内部有新的层叠与连接结构，控制器还采用了新的充放电控制方法，外壳局部则形成了圆角、图案和色彩组合。老板要求“全部申请专利”，但代理人必须先拆清每项创新对应的法定保护客体；审查人员也要判断申请内容是否落入专利法规定的类型。团队还担心中国取得专利后能否在其他国家永久排除他人。

**锚定**：该情境同时锚定三类保护客体、审查与代理的共同起点，以及专利权独占性、时间性和地域性的边界。

**先想一想**：面对同一产品中的方法、结构和视觉设计，为什么不能只依据“这是一个创新”就直接确定申请类型？

### 法条锚定：客体与制度主体（legal_anchor）

- **《中华人民共和国专利法》第二条**：专利法把发明创造分为发明、实用新型和外观设计，并分别规定三类客体的法定定义：发明针对产品、方法或者其改进的新的技术方案，实用新型针对产品形状、构造或者其结合的适于实用的新的技术方案，外观设计针对产品整体或局部的、富有美感并适于工业应用的新设计。
- **《中华人民共和国专利法》第三条**：国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请并依法授予专利权；省、自治区、直辖市人民政府管理专利工作的部门负责本行政区域内的专利管理工作。
- **《中华人民共和国专利法》第八十二条**：检索材料引述专利法自1985年4月1日起施行；该历史信息用于理解制度发展，不替代对现行适用规范的核验。

**为何重要**：第二条决定审查与代理处理技术交底时首先面对的客体分类问题，第三条定位统一受理、审查和授权的制度主体。掌握法条锚点，才能避免把商业名称、技术宣传或历史材料直接当作法律结论。

### 演示：将产品改进对应法定客体（worked_example）

**案情/例题**：某团队的设备包含三项改进：第一项是降低能耗的充放电控制方法，第二项是传感器外壳与底座的可拆卸连接结构，第三项是外壳局部的图案与色彩组合。请从代理和审查两个视角，完成专利制度基础层面的保护客体初步识别。
**适用规则**：《中华人民共和国专利法》第二条：发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案结合所作出的富有美感并适于工业应用的新设计。检索材料进一步说明，实用新型只保护产品，一切方法不属于实用新型保护客体。
**分步推演**：
1. 先把控制方法、产品连接结构和局部视觉效果拆成三个事实单元，不能因它们存在于同一产品中就把它们强行归为一个客体。 → *事实拆分是客体判断的第一步。*
2. 控制方法属于对方法或者其改进提出的技术方案时，进入第二条关于发明的定义方向；是否具有新颖性、创造性和实用性，要留待后续授权条件审查。 → *方法性技术方案先按发明方向核对。*
3. 可拆卸连接结构聚焦产品的形状、构造或者其结合，并且需要继续核对适于实用和其他法定条件，因此进入实用新型的定义方向。 → *产品结构先按实用新型方向核对。*
4. 局部图案与色彩组合聚焦产品局部的形状、图案或色彩结合，还要核对富有美感和适于工业应用等定义要素，因此进入外观设计方向。 → *视觉设计先按外观设计方向核对。*
5. 代理人应将技术交底按客体拆分并提示后续申请与审查风险；审查人员应以第二条法定定义核对申请内容，不能把客体归类直接等同于授权。 → *双视角起点一致，职责和后续工作不同。*
**结论**：该团队的控制方法、连接结构和局部视觉设计应分别依第二条作发明、实用新型和外观设计方向的初步客体识别。若某项实用新型权利要求同时写入制造或处理方法步骤，还需重新检查其是否仍属于实用新型保护客体；上述分类本身不等于已经满足新颖性、创造性、实用性或其他授权条件。
**本题要点**：训练从事实拆分、法定定义匹配到保留后续授权条件审查的完整判断链。

### 文字讲解：审查与代理的共同起点（verbal_explanation）

可以先把专利制度看成一套有入口、有主管机关、也有边界的规则。代理人拿到客户的技术交底，第一步不是听到“创新”就承诺一定能授权，而是把事实拆开：它究竟是产品、方法或改进形成的技术方案，还是产品的形状构造，或者是整体、局部的视觉设计。审查人员做的是同一条法律定义下的客体核对。专利权的独占性也要和时间性、地域性一起说：它是在法律边界内排除未经许可的实施，有期限，而且中国的授权不会自动变成其他国家的授权。检索材料还记载，中国制度把三种专利类型放在同一部法律中，并形成发明专利实质审查、实用新型和外观设计初步审查并存的制度特点。至于实施细则、审查指南的具体条款以及最新跨法域实践，本节检索上下文没有提供足够直接依据，不能把它们说成已经核验的具体规则。

**点破术语**：保护客体；独占性；时间性；地域性；技术方案；国务院专利行政部门

**类比**：可以把三类客体理解为三种不同的法律入口：发明入口覆盖产品、方法或者其改进的技术方案，实用新型入口聚焦有形产品的形状和构造，外观设计入口聚焦产品整体或局部的视觉设计。这个类比只用于记忆，真正判断仍须回到《专利法》第二条及可核验的审查材料。

### 顺序记忆：客体三分与权利三性（mnemonic）

**记忆锚**：三组三分核对表：第一组“独—时—地”，核对专利权的独占性、时间性、地域性；第二组“法—细—指”，核对专利法、专利法实施细则、专利审查指南在制度学习中的位置；第三组“发—实—外”，依次核对发明、实用新型、外观设计。使用时按“先客体、再边界、后规范”顺序逐项检查。
**映射**：

**何时用**：阅读技术交底、判断中国专利制度的规范入口，或遇到“专利权能否永久、全球排除他人”的表述时，先按“发实外”定客体，再按“独时地”查边界，最后按“法细指”确认应查的规范材料。

### 反思：同一规则下的双视角清单（reflect_prompt）

**反思问题**：复盘一份同时包含方法、产品结构和视觉设计的技术交底时，代理人与审查人员虽然都依据专利法基础规则，各自应如何组织判断清单？

**关注要点**：是否已经把商业名称和宣传语还原为方法、产品结构或视觉设计等具体事实。；三类事实是否分别匹配《专利法》第二条的法定定义，尤其没有把方法直接归入实用新型。；客体初步识别是否被错误地当成新颖性、创造性、实用性或其他授权条件已经满足。；独占性是否与时间性、地域性同时说明，避免作出永久有效或全球当然有效的表述。；制度历史和审查特点是否注明资料依据与适用时点，避免以历史概括替代现行规范核验。

**连接**：连接到本节点的法条优先方法：先确定客体和制度主体，再区分权利边界与审查安排；也为后续相关法律知识中“基础法律框架服务于专利代理执业”的学习作准备。

### 知识综合：制度、客体、权利与审查（knowledge_synthesis）

**知识框架**：
- 专利制度的基本概念与特征：专利权具有独占性、时间性和地域性，三者共同限定权利效力边界，不能只强调排他效果。
- 中国专利制度体系：教学上下文列出专利法、专利法实施细则和专利审查指南；本节以专利法作为法源锚点，具体细则和指南条款须结合现行文本继续核验。
- 专利保护的三种客体：根据《专利法》第二条，发明创造包括发明、实用新型和外观设计，三者具有不同法定定义。
- 专利制度的作用：检索材料将保护专利权人的合法权益、鼓励发明创造、推动发明创造的应用、提高创新能力并促进科学技术进步和经济社会发展连接为制度目的链条。
- 中国专利制度发展历程与特点：检索材料记载同一部法律包含三种专利类型，并形成发明专利初步审查与实质审查、实用新型和外观设计初步审查并存的制度特点；历史概括不能替代现行案件的规范核验。
**概念关系**：先以第二条拆分并识别法定保护客体，再进入相应申请程序和授权条件的具体判断。；第三条用于定位统一受理、审查和授权的制度主体，连接法定客体与制度运行。；制度目的解释公开、激励和应用之间的政策联系；独占性、时间性和地域性则限定保护效果，二者不能混同。；审查制度的历史特点帮助理解制度安排，但不能替代对具体申请适用的现行法律、实施细则和审查指南。；相关法律知识属于后续节点，本节只作范围定位，不把前向探测内容扩展为当前节点的主教学内容。
**必记**：《专利法》第二条规定的发明创造类型是发明、实用新型和外观设计，客体判断必须回到法定定义。；发明可针对产品、方法或者其改进的新的技术方案；实用新型针对产品的形状、构造或者其结合；外观设计针对产品整体或局部的视觉设计。；专利权的独占性必须与时间性、地域性一并理解，不能表述为永久、绝对或全球当然有效。；国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。；客体初步识别不等于已经满足新颖性、创造性、实用性或其他授权条件。

### 速查卡：专利法律制度基础（summary_card）

**要点卡**：
- **三类保护客体**：发明、实用新型、外观设计是《专利法》第二条规定的三类发明创造。
- **客体识别方法**：先把技术交底拆成方法或技术方案、产品结构、视觉设计，再分别匹配法定定义。
- **专利权三项特征**：独占性受法律边界约束，时间性意味着期限有限，地域性意味着效力受授权法域限制。
- **中国制度体系**：本节以专利法为法源锚点，实施细则和审查指南的具体适用须查验现行文本。
- **制度作用与发展特点**：制度通过保护、激励、公开和应用促进发展，检索材料并记载三类专利及初步审查、实质审查并存的制度特点。
**必背**：《专利法》第二条：发明创造是指发明、实用新型和外观设计。；发明看产品、方法或者其改进的新的技术方案；实用新型看产品形状、构造或者其结合的适于实用的新的技术方案；外观设计看产品整体或局部的形状、图案或者其结合以及色彩与形状、图案结合所作出的富有美感并适于工业应用的新设计。；专利权具有独占性、时间性和地域性。；客体分类只是基础入口，不等于已经通过全部授权条件审查。
**一句话总结**：专利制度基础的判断顺序是：先定法定客体和制度主体，再理解权利边界与审查制度位置，并以可核验的现行材料处理具体案件。
