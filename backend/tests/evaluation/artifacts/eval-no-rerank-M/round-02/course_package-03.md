## 教学正文

## I — 法律问题

本节点聚焦专利法律制度的基础：在智能制造项目中，首先要确认技术成果属于哪类专利客体，随后了解专利制度的运行机制以及独占性、时间性、地域性三大属性如何为后续的新颖性判断和侵权分析提供制度前提。

学习者希望结合智能制造领域的真实案例，但本轮检索上下文只提供法条、学习材料和抽象练习，未提供可核验的智能制造专利新颖性或侵权裁判案例、案号或公开链接。因此，本节的机器人视觉定位系统仅为教学情境，不是实际裁判案例，也不据此作出真实案件结论。后续检索真实案例时，可在中国裁判文书网、人民法院案例库、国家知识产权局专利行政裁决或无效决定公开渠道，以“工业机器人”“机器视觉”“智能制造”分别结合“专利侵权”“新颖性”“无效宣告”等精确词检索，并逐案核对案号、权利要求、对比文件和裁判日期。

## R — 适用规则

1. **立法目的**：
《专利法》第一条规定，制定本法是为了保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，促进科学技术进步和经济社会发展。〔RAG: 中华人民共和国专利法.txt — 第一条：为了保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，促进科学技术进步和经济社会发展，制定本法〕

2. **三类保护客体**：
《专利法》第二条明确，发明是指对产品、方法或者其改进所提出的新的技术方案；实用新型是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：外观设计，是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计〕

3. **制度运行层级**：
《专利法》第三条规定，国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请，依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门负责管理全国的专利工作；统一受理和审查专利申请，依法授予专利权〕专利法提供基本法律规范，专利法实施细则和专利审查指南属于配套制度材料；涉及具体程序、期限或审查标准时，必须逐项核验相应直接依据。

4. **权利属性**：
专利权的独占性、时间性、地域性分别体现在：权利人在法定保护范围内享有排他使用权；保护期限受法律规定限制；权利仅在授权国或地区有效。把专利制度类比为一张“时间限定、地域限定的独占许可凭证”有助于记忆，但类比的边界是：申请不等于授权，授权后的具体保护范围和侵权与否仍须依据具体专利权及法律规则判断。

5. **制度功能与发展特点**：
专利制度通过授予排他权利换取技术公开，进而激励研发、促进技术应用并推动经济发展。〔RAG: 中华人民共和国专利法.txt — 第一条：保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，促进科学技术进步和经济社会发展〕学习材料说明，中国专利法自1985年4月1日起施行，并历经四次修改；材料将中国专利制度概括为具有早期公开、延迟审查，以及初步审查制与实质审查制并存的特点。〔RAG: 专利法律知识详细解读.txt — 第一章专利基础知识：详细介绍我国专利制度的发展历史，总结我国专利法历经四次修改的主要修改内容，进而介绍我国的专利制度特点〕这一概括仅用于建立制度运行的总体认识；检索上下文未提供足以支持具体审查对象、程序步骤或期限的直接材料，本节不作进一步推演。

## A — 规则适用

以智能制造中的机器人视觉定位系统为例：若创新体现在图像处理、特征识别与控制指令的流程，应归入“发明”客体；若创新体现在传感器外壳整体或局部的形状、图案或者其结合，以及色彩与形状、图案的结合，则属于“外观设计”客体。此判断仅确定保护客体，不等同于已满足新颖性、创造性或侵权成立的条件。

可按三个动作完成基础定位：先把创新内容从行业名称中抽离，判断其是技术方案、产品形状构造，还是产品外观；再找到《专利法》、实施细则或审查指南中与该问题相对应的材料；最后把授权条件与侵权判定留给后续专题。对于中国制度发展特点，只需在本节点识别早期公开、延迟审查以及初步审查制与实质审查制并存这一总体框架，不能据此跳过对具体案件事实和规则的核对。

本节设有测评，请到【习题】区作答。

## C — 结论

专利制度的基础判断顺序为：先识别保护客体（发明、实用新型、外观设计），再确认适用的制度材料与制度运行入口，最后依据客体进入授权条件（新颖性、创造性、实用性）或侵权分析（具体保护范围）。本节不对新颖性或侵权作具体判定，但为后续章节提供必要的制度入口。

### 专利制度法条锚定（legal_anchor）

- **《中华人民共和国专利法》第一条**：第一条说明专利制度要保护权利人、鼓励创新、推动应用并促进科技进步和经济社会发展。
- **《中华人民共和国专利法》第二条**：第二条把专利保护客体分为发明、实用新型和外观设计，并分别界定三者；外观设计包括产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。
- **《中华人民共和国专利法》第三条**：第三条确定国务院专利行政部门负责全国的专利管理、统一受理和审查申请并依法授予专利权。

**为何重要**：这些条文分别解决专利制度为什么存在、保护什么以及由谁实施管理三个基础问题。只有先完成客体和制度定位，后续的新颖性判断与侵权判定才有明确的法律对象。

### 机器人视觉系统的客体识别（worked_example）

**案情/例题**：某企业研发机器人视觉定位系统。其第一项创新是通过图像采集、特征识别和控制指令调整机器人动作的流程；第二项创新是传感器外壳局部的形状、图案及配色组合。现需在提交专利申请前确定两项创新分别应从哪类专利保护客体进入分析。该案情为教学演示，不是检索上下文中的真实案件；检索上下文未提供可供替换的智能制造真实新颖性或侵权案件。
**适用规则**：适用《专利法》第二条关于发明、实用新型和外观设计的定义；本例只进行保护客体识别，不据此判断新颖性、创造性、实用性或侵权是否成立。
**分步推演**：
1. 先把第一项创新拆成其法律上真正被主张的内容：它描述的是图像处理、识别和控制动作之间的流程，而不是仅描述设备外形。 → *第一项创新的核心是方法或技术方案内容。*
2. 《专利法》第二条将对产品、方法或者其改进提出的新的技术方案纳入发明定义，因此应从发明客体角度继续分析。 → *第一项创新进入发明客体分析。*
3. 第二项创新的核心是传感器外壳局部的形状、图案及配色组合，判断重点是产品外观而非控制功能。 → *第二项创新的核心是产品外观设计内容。*
4. 《专利法》第二条规定，外观设计包括对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。 → *第二项创新进入外观设计客体分析。*
**结论**：在仅识别保护客体的范围内，控制流程应按发明客体进入后续分析，外壳局部的形状、图案或者其结合，以及色彩与形状、图案的结合所形成的外观，应按外观设计客体进入后续分析；该分类本身不等于已经满足授权条件。
**本题要点**：判断专利类型先看创新内容，再看产品名称；客体分类和授权条件必须分开。

### 专利法律制度基础框架（knowledge_synthesis）

**知识框架**：
- 专利保护客体：发明、实用新型和外观设计分别对应产品、方法或者其改进的技术方案，产品形状、构造或者其结合的技术方案，以及产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所形成的外观设计。
- 专利制度规范体系：专利法提供基本法律规范，专利法实施细则和专利审查指南构成配套制度材料；具体条文及其适用条件须逐项核验。
- 专利权基本属性：独占性、时间性和地域性共同限定专利权的权利边界，不能把权利理解为无限、永久或者当然跨境有效。
- 专利制度功能：通过权利保护、技术公开和技术应用之间的制度安排，鼓励发明创造并促进科技进步和经济社会发展。
- 中国专利制度发展与审查特点：学习材料说明中国专利法自1985年4月1日起施行、历经四次修改，并将我国制度概括为早期公开、延迟审查，以及初步审查制与实质审查制并存；本节只建立识别框架，不在缺少直接细则依据时推演具体程序、期限或适用对象。
- 专利审查与管理：国务院专利行政部门负责全国专利工作，并统一受理和审查专利申请、依法授予专利权。
**概念关系**：先识别保护客体，再确定适用的专利制度材料和审查入口。；专利制度的立法目的解释其功能，三类客体规则确定保护对象，行政管理规则确定受理审查主体。；中国制度发展历程和审查特点说明制度运行的总体背景，但不替代对具体申请程序、授权条件和证据材料的逐项判断。；完成制度基础后，才能分别进入授权条件中的新颖性判断和专利权保护中的侵权判定。
**必记**：识别专利类型必须看创新内容，不能只看所属行业或产品名称。；发明、实用新型、外观设计是《专利法》第二条规定的三类专利保护客体。；外观设计包括产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案的结合所作出的设计。；客体分类不等于已经满足新颖性、创造性、实用性，也不等于已经构成侵权。；中国专利法自1985年4月1日起施行、历经四次修改；早期公开、延迟审查以及初步审查制与实质审查制并存属于本节点应识别的中国专利制度特点，具体规则必须另行核对依据。

### 专利制度基础速查（summary_card）

**要点卡**：
- **三类保护客体**：发明看产品、方法或者其改进的技术方案，实用新型看产品形状、构造或者其结合，外观设计看产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合。
- **三项基础属性**：专利权具有独占性、时间性和地域性，权利边界并非无限或永久。
- **制度规范体系**：专利法是基本法律规范，实施细则和审查指南是需要结合具体条文核验的配套材料。
- **制度功能**：专利制度以权利保护促进创新，同时通过公开和应用推动科技与经济发展。
- **制度发展与审查特点**：中国专利法自1985年4月1日起施行、历经四次修改；本节点识别早期公开、延迟审查以及初步审查制与实质审查制并存的制度特点，具体程序须另查直接依据。
- **管理审查主体**：国务院专利行政部门负责全国专利工作并统一受理、审查申请和依法授予专利权。
**必背**：《专利法》第二条规定发明、实用新型和外观设计三类保护客体。；外观设计包括产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案的结合。；判断专利类型先看创新内容，不以智能制造等行业名称直接决定。；客体分类、授权条件和侵权成立是三个不同层次的问题。；专利权的基础属性是独占性、时间性和地域性。；中国专利法自1985年4月1日起施行、历经四次修改；早期公开、延迟审查以及初步审查制与实质审查制并存是本节点需要识别的制度特点。
**一句话总结**：先确认保护什么，再确认制度如何运行，最后分别进入授权条件和权利保护判断。
