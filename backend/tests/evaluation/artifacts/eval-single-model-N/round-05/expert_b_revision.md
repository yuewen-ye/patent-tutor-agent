# 专家 B 修订稿

## teaching_content

## 1. 场景导入
一家智能硬件公司研发了三项成果：一是让设备更省电的控制方法；二是设备内部一种新的卡扣结构；三是设备外壳的局部图案与形状组合。代理人要先把三项成果分别放入正确的专利类型，再决定申请文件和程序节奏；审查员则要依据法律、实施细则和审查指南，在相应程序阶段审查申请。公司还关心：既然申请信息会被公开，为何仍能获得排他保护；这种保护是否能当然延伸到国外、并永久持续？

这个场景提示我们，专利制度基础不是孤立背诵术语，而是用“客体—规则体系—程序—制度目的”四个视角，把代理人的申请布局和审查员的审查职责放在同一张地图上。

## 2. 人话解释
先把专利理解为一种以公开申请信息与依法授予有限保护相衔接的制度安排：申请人把相应成果写入申请文件，符合条件并被依法授予后，才能在法定期限和适用地域范围内主张专利权。这里不能把三类成果一概称为“技术方案”：发明和实用新型的定义语境中使用“技术方案”，外观设计则是就产品整体或局部外观作出的新设计。独占性要结合《专利法》第十一条理解，即专利权授予后，未经许可不得实施相应专利；时间性由《专利法》第四十二条规定的法定期限体现；地域性提醒我们，权利效力依具体国家或地区法律制度而定，不能把一国授权自动当作全球通行证。〔RAG: 中华人民共和国专利法.txt — 第十一条、第四十二条：专利权的实施边界与期限〕

三类保护客体要按“保护对象”分开看。发明可以针对产品、方法或者其改进，核心是新的技术方案；实用新型聚焦产品的形状、构造或者其结合；外观设计则聚焦产品整体或局部的形状、图案及其组合，或者色彩与形状、图案的结合，并要求富有美感且适于工业应用。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

制度体系也要分层。专利法确立基本规则和授权边界；实施细则把部分程序要求具体化；审查指南用于把审查中的判断标准和操作口径落到申请材料与审查流程。审查视角关注“此时依什么规则、审什么内容”；代理视角关注“应提交什么材料、何时行动、如何让申请表达经得起审查”。国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕

程序上，要特别避免把“公开”“初步审查”“授权”混成同一件事。《专利法》第三十四条规定，发明专利申请经初步审查合格后，自申请日起满十八个月即行公布；申请人也可以请求早日公布。〔RAG: 中华人民共和国专利法.txt — 第三十四条：发明专利申请经初步审查合格后的公布〕 这说明公布是促进技术信息传播的法定程序环节，不等于专利权已经被授予。本节不以未经逐项核验的实施细则条文区间推导实质审查请求或主动修改的具体规则；这些细节应在后续程序学习中结合完整规范掌握。

## 3. 法条回扣
《专利法》第二条直接规定，发明创造包括发明、实用新型和外观设计，并分别界定三者的对象范围。〔RAG: 中华人民共和国专利法.txt — 第二条：发明、实用新型和外观设计的定义〕 因而，无论代理人做申请类型判断，还是审查员做客体识别，都应先回到该条的文字边界，而非仅按“技术含量高低”贴标签。

《专利法》第三条规定国务院专利行政部门负责管理全国专利工作，统一受理、审查申请并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕 这为理解审查职能和专利授权的公法程序属性提供了制度锚点。

《专利法》第三十四条直接规定发明专利申请经初步审查合格后的公布条件和时间。〔RAG: 中华人民共和国专利法.txt — 第三十四条：初步审查合格后的公布〕 本节据此建立“公开与授权相区分”的基础认识；各专利类型的完整审查规则和具体期限，需在后续程序节点结合完整规范进一步学习。

## 4. 类比 / 口诀
用“物—规—程—用”四格表收口：物，先辨保护的对象属于发明、实用新型还是外观设计；规，找专利法、实施细则和审查指南各自提供的依据；程，看受理、初步审查合格后的公布与授权如何区分；用，理解公开技术信息、激励创新和促进应用的制度功能。

口诀是“客体先分，规则分层，程序分段，公开促用”。它只是帮助建立答题和办案的检查顺序，不能替代具体法条：例如，不能仅凭“结构”二字就当然认定实用新型，也不能把公开和授权混为同一法律效果。

## 5. 应试提示
面对基础题，先锁定题干问的是“什么能保护”“依据什么规范”“处于什么程序阶段”还是“制度为何如此设计”。问保护客体时，抓住产品、方法、形状构造、整体或局部外观等词；问制度体系时，区分上位法律规则、程序细化规则与审查操作依据；问程序时，尤其不要把初步审查合格后的公布等同于最终授权。

从代理视角，先做类型识别和文件、时间安排；从审查视角，先确认申请所属类型和适用规则，再依程序阶段处理。二者共享同一法律框架，但关注点不同。关于跨法域比较，本节只保留地域性这一基础视角；具体国际条约和其他法律部门的规则不在本节展开。
