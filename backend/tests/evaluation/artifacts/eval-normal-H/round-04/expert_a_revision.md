# 专家 A 修订稿

## teaching_content

## I — 法律问题

材料领域的专利申请，基础判断应按四层展开：第一，识别要求保护的客体；第二，了解中国专利制度的规范层级及制度目的；第三，对发明和实用新型的授权三性作总框架核对；第四，将申请类型与审查制度、权利期限对应起来。本节点只建立这些基础边界，具体的新颖性比对方法和创造性判断步骤在后续专门节点展开。

## R — 适用规则

### 1. 三类保护客体

《专利法》第二条规定，发明是对产品、方法或者其改进提出的新的技术方案；实用新型是对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案、色彩及其结合所作的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条〕

因此，材料组成、配方、制备方法及其改进，通常首先从产品或方法技术方案角度识别；不能仅因名称中出现“材料”二字，就直接认定为实用新型。最终仍应结合权利要求限定的内容判断。

### 2. 中国专利制度的规范层级

可以用“三层结构”理解制度体系：专利法提供基本法律规范；专利法实施细则对申请、审查和实施等事项作补充规定；专利审查指南为具体审查判断提供操作层面的指引。三者的功能不同，不能把指南、实施细则和法律条文视为同一层级。当前检索上下文未提供完整现行文本，涉及具体程序操作时应进一步核验相应规范。

### 3. 授权三性总框架

授予发明和实用新型专利权，应当具备新颖性、创造性和实用性。新颖性、创造性和实用性是三个不同的授权条件；本节点只需记住其功能区分：新颖性关注是否属于现有技术，创造性关注相对于现有技术是否具有法定的实质性特点和进步，实用性关注能否制造或者使用并产生积极效果。现有技术是申请日以前在国内外为公众所知的技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条〕具体比较步骤不在本节点展开。

### 4. 审查制度与期限

发明专利申请经实质审查没有发现驳回理由的，由国务院专利行政部门作出授予发明专利权的决定；实用新型和外观设计专利申请经初步审查没有发现驳回理由的，作出相应授权决定。〔RAG: 中华人民共和国专利法.txt — 第三十九条、第四十条〕发明专利权期限为二十年，实用新型为十年，外观设计为十五年，均自申请日起计算。〔RAG: 中华人民共和国专利法.txt — 第四十二条〕

## A — 规则适用

以电池隔膜复合涂层为例，可按以下顺序处理：

1. 若权利要求限定涂层组成、材料配比或制备步骤，先按技术方案识别保护客体；若主要限定产品形状、构造或其结合，再考虑实用新型客体；若限定产品整体或局部的形状、图案、色彩及其结合形成的设计，则考虑外观设计。
2. 确定属于发明或实用新型后，依《专利法》第二十二条分别核对新颖性、创造性和实用性。材料性能改善可以是技术效果事实，但不能单独替代三性中的任何一项完整判断。
3. 再将申请类型与审查程序对应：发明申请对应实质审查；实用新型和外观设计申请对应初步审查。
4. 用申请日前的时间标准理解现有技术，用申请日起计算的期限理解专利权存续时间，二者不能混同。

当前材料没有提供该复合涂层的完整权利要求、申请日前公开事实、对比文件及充分技术效果证据，因此不能据此断言其已经具备或不具备新颖性、创造性。制度作用可以用“研发投入—申请保护—技术公开—促进应用”作概括性理解，但该概括不替代具体法条依据。关于早期公开、延迟审查等发展与程序特点，当前仅能作专题材料所载的概括，具体细节应以现行法律、实施细则和审查指南核验。

## C — 结论

本节点应固定“客体—制度层级与作用—三性总框架—程序和期限”四层结构：先识别保护客体，再分别认识授权三性，随后对应审查制度并核对时间边界。具体比对方法与创造性判断步骤在后续专门节点展开。
