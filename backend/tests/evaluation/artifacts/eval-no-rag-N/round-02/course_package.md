## 教学正文

## I｜本节主线：先定对象，再看制度和程序

本节围绕唯一主节点“专利法律制度基础”建立一条可复盘的主线：**保护客体—法源体系—审查阶段—权利边界**。审查视角关心申请对象是否落入法定保护客体、当前阶段应审查什么；代理视角则要把客户的技术事实拆开，选择合适的申请方向，并如实提示授权、时间和地域风险。

专利制度的基本作用可以先作制度层面的理解：通过技术公开与一定范围、一定期间的排他保护，激励发明创造、促进技术公开，并推动技术应用和经济发展。这里的“公开换保护”是帮助理解制度功能的概括，不意味着完成研发即可自动取得专利，也不意味着提交申请就已经取得完整权利。

## R｜法条与制度框架

### 1. 保护客体：先判断“要保护什么”

本轮教学材料以《中华人民共和国专利法》第二条作为三类保护客体的法条入口。〔本轮检索上下文未提供该条原文，具体条文措辞须以现行官方文本核对〕

基础归类上，发明、实用新型和外观设计是三类专利保护客体。审查人员不能只看产品名称，而要识别申请文件所对应的技术方案、产品结构或外观设计特征。代理人也不能因为成果都被称为“产品创新”，就用同一种申请类型整体包装：控制方法、结构改进和外观图案可能分别需要不同方向的客体分析。

客体归类只是制度入口。一个对象属于某类保护客体，并不等于已经满足全部授权条件；后续还要根据相应专利类型、申请文件和现行法律判断具体授权问题。

### 2. 制度法源：区分法律、实施细则和审查指南

中国专利制度的学习和实务核对材料包括专利法、专利法实施细则和专利审查指南。可以用三层方式理解：专利法提供基本制度和权利义务框架；实施细则对制度运行和程序事项作进一步细化；审查指南则用于理解审查实践中的操作和判断路径。三者不能简单视为同一层级，也不能把指南中的操作表达直接当作法律条文本身。

当审查意见、代理方案或客户咨询涉及具体期限、程序效果、法定例外或法律效力时，应回到现行正式文本核验。本轮没有提供可直接引用的检索原文，因此不对未核验的具体期限和程序细节作扩展结论。

### 3. 专利权的基本特征：独占性、时间性、地域性

独占性说明：在权利有效且适用范围内，专利权人对法律规定的相关实施行为具有排他控制力。它不是“任何相关行为都绝对禁止”，具体边界仍要结合权利要求、法律规定和案件事实判断。

时间性说明：专利权不是永久存在的，权利存续受法定期限以及权利是否有效、是否终止等状态影响。本节只建立时间性概念，不补充未经核验的具体期限。

地域性说明：专利权原则上依授予该权利的国家或地区的法律发生效力。在中国获得专利，不等于自动在其他国家或地区取得同等专利权；跨法域保护需要另行依据相应法域的法律和程序分析。

因此，“独占”不能理解为无条件，“时间性”不能被遗漏，“地域性”也不能被全球化想象替代。审查和代理工作都必须把三者放回具体权利状态与法域中判断。

## A｜审查与代理双视角适用

### 审查视角

第一步，拆分申请文件中的技术事实，确认其指向发明、实用新型还是外观设计。第二步，定位程序阶段，区分申请提交、初步审查、实质审查和授权；不同阶段的审查任务不同，进入审查程序不等于已经满足全部授权条件。第三步，在涉及授权实质条件时，依据现行法条和审查材料继续判断，不能由客体归类直接跳到授权结论。第四步，若讨论权利保护，则还要核对权利的有效状态、保护范围、时间限制和地域范围。

### 代理视角

第一步，从客户提供的技术事实出发，而不是从产品名称出发，分别提取方法、结构和外观特征。第二步，根据事实选择相应的申请和保护策略，并把不同申请类型的审查要求告知客户。第三步，按案件所处阶段准备文件、回应审查意见或评估授权风险。第四步，对客户明确说明：中国申请、进入审查、获得中国专利和在其他法域获得保护，是四个不能互相替代的结论。

### 三性在本节点中的位置

本轮教学材料以《专利法》第二十二条作为发明和实用新型授权实质条件的法条入口。〔本轮检索上下文未提供该条原文，具体条文措辞及适用范围须以现行官方文本核对〕本节只固定其在整体框架中的位置：三性属于授权实质判断的后续问题，不能替代保护客体归类，也不能把“提交申请”直接转化为“三性已经满足”。新颖性、创造性、实用性的具体判断标准和易混淆点，应在后续相应节点依检索材料展开。

## C｜结论与复盘

专利法律制度基础不是把若干术语孤立背下来，而是形成四步判断：**先定客体，继而查法源；再定位程序阶段，最后核对权利边界**。制度功能则解释了为什么专利制度要在技术公开与有限排他保护之间取得平衡。

审查人员用这条链判断“现在应审什么”；代理人用这条链判断“应如何申请、如何沟通风险”。特别要避免三组跳步：属于保护客体不等于必然授权，提交申请不等于取得专利权，取得中国专利不等于全球有效。

本节设有测评，请到【习题】区作答。

### 从技术事实看专利制度入口（anchor_scenario）

> 某智能制造企业完成了三项成果：一套用于控制机器人动作的控制方法、夹爪内部的结构改进，以及设备外壳的流线型图案。研发负责人认为“技术做出来就等于拿到专利”，市场负责人又准备在中国申请后立即参加境外展会。审查人员需要先判断申请对象和所处程序阶段，代理人则要向客户解释申请类型、授权条件以及中国专利权的地域边界，双方对“能否申请”“是否已授权”和“能否在境外主张权利”发生了混淆。

**锚定**：用同一组技术事实锚定三类保护客体、专利权独占性与时间性和地域性，以及申请、审查、授权之间的程序边界。

**先想一想**：面对这三项成果，你会先按什么标准区分保护客体，并如何区分申请提交、审查通过和取得专利权这三个结论？

### 法条入口与证据边界（legal_anchor）

- **《中华人民共和国专利法》第二条**：第二条是识别专利保护对象的入口：本节按发明、实用新型和外观设计三类来归类申请对象。
- **《中华人民共和国专利法》第二十二条**：第二十二条提供发明和实用新型授权实质条件的法条入口；三性判断的具体标准、时间基准和例外应在后续节点结合现行文本展开。
- **《中华人民共和国专利法》第一条**：第一条是理解制度目的的法条入口：专利制度在保护权利的同时，服务于创新、公开和技术应用等制度目标。

**为何重要**：先固定法条入口，才能把客体归类、授权条件、制度目的与程序审查分开处理。因本轮没有提供检索原文，所有具体条文措辞、期限和适用例外都必须以现行官方文本复核。

### 从技术事实到制度判断（worked_example）

**案情/例题**：甲公司完成一套机器人控制方法、夹爪机械结构改进和设备外壳图案，拟在中国提交申请。公司负责人问：三项成果应如何初步归类？申请提交后是否已经取得专利权？若取得中国专利，是否当然可以在其他国家主张同等专利效力？
**适用规则**：以《中华人民共和国专利法》第二条的三类保护客体框架为入口，结合第二十二条所对应的授权实质条件入口，并结合专利权独占性、时间性、地域性的基础特征；本轮未提供具体法条原文，细节须核对现行官方文本。
**分步推演**：
1. 先拆分技术事实，不以“机器人设备”这一产品名称整体归类：控制方法、机械结构和外观图案是三个不同的事实单元。 → *第一步：从具体技术或外观特征，而不是产品名称，识别申请对象。*
2. 控制方法体现方法技术方案，优先进入发明方向；夹爪结构体现产品结构改进，可进一步判断实用新型或发明；外壳图案体现外观设计方向。最终归类仍须结合申请文件和现行法条。 → *第二步：将各事实单元分别与三类保护客体比对。*
3. 申请提交只是启动相应程序，不能替代客体判断，也不能直接证明已经满足全部授权实质条件。初步审查和实质审查承担的任务不同，不能混为最终授权结论。 → *第三步：区分申请行为、审查阶段和授权结果。*
4. 专利权的独占性是在权利有效及其适用范围内排他控制相关实施行为；时间性和地域性意味着还要核对存续期间及授予法域，不能从中国权利自动推导其他国家的专利效力。 → *第四步：检查权利的时间与地域边界。*
**结论**：代理人应将三项成果分别拆分并按其技术或外观特征选择分析方向：控制方法优先按发明方向分析，夹爪结构可按实用新型或发明方向进一步判断，外壳图案按外观设计方向判断。提交申请并不等于已经完成授权，取得中国专利权也不当然产生境外法域的同等效力。
**本题要点**：先拆事实定客体，再按程序阶段判断授权，最后核对专利权的时间和地域边界。

### 把四层判断说成人话（verbal_explanation）

我们先不要把“做出技术”“提交申请”“拿到专利”当成同一件事。第一问是：你到底要保护什么，是方法、产品结构，还是产品外观；第二问是：现在依据哪一层规范处理，专利法、实施细则和审查指南各有自己的功能；第三问是：案件走到哪一步，申请提交和最终授权之间还隔着相应审查；第四问是：即便权利成立，它也不是永久、全球、毫无限制地存在。审查人员要沿着这四步检查，代理人要沿着这四步向客户解释风险。后续学习三性、申请程序和侵权保护时，也要不断回到这条主线。

**点破术语**：保护客体；制度法源；审查阶段；独占性、时间性与地域性

**类比**：可以把专利制度理解为一套有条件的交换安排：申请人以公开技术进入制度程序，国家依法律条件决定是否授予一定期限和地域范围内的排他权。这个类比只能帮助理解“公开—审查—保护”的关系，不能替代具体法条，也不能推出任何自动授权或全球保护结论。

### 客源阶界四格复盘表（mnemonic）

**记忆锚**：“客—源—阶—界”四格复盘表：先看客体，再查法源；再定位阶段，最后核对权利边界。涉及授权时，在“客体”之后加做“三性”核对，但不把三性判断替代客体归类。
**映射**：
- 客
- 源
- 阶
- 界
- 三性
**何时用**：复盘一个专利案件、阅读审查意见或向客户解释申请风险时，按“客—源—阶—界”逐格检查；只有进入授权实质判断时，再单独核对“三性”，避免把保护客体、授权条件和程序阶段混为一谈。

### 在审查与代理之间切换视角（reflect_prompt）

**反思问题**：同一项技术成果交给审查人员和专利代理人时，两种角色各自首先要核对什么？如果客户把“已经提交申请”说成“已经获得全球专利”，你会如何拆开这句话？

**关注要点**：审查人员首先要识别申请对象并确定当前程序阶段及相应审查任务。；代理人除客体归类外，还要根据技术事实选择申请策略，并向客户说明授权条件、时间性和地域性风险。；保护客体、授权实质条件、申请或审查阶段和最终权利效力是彼此关联但不能互相替代的判断层次。

**连接**：连接到本节点的保护客体、制度法源、权利三性和审查阶段，并为后续专利制度概论、专利法体系与申请审查程序建立入口。

### 专利法律制度基础知识网络（knowledge_synthesis）

**知识框架**：
- 基本概念与权利特征：专利权的独占性、时间性和地域性共同限定其排他保护的范围、持续期间和法域边界。
- 中国专利制度体系：专利法提供基本制度框架，专利法实施细则和专利审查指南分别承担制度细化及审查操作指引功能，具体规则须核对现行文本。
- 三类保护客体：发明、实用新型和外观设计是本节点进行申请对象归类的基本入口，具体适用要结合技术事实和现行法条。
- 制度作用：通过技术公开、权利保护和后续应用之间的制度安排，服务于激励发明创造、促进技术公开、推动技术应用和经济发展。
- 中国制度发展与审查特点：早期公开、延迟审查，以及初步审查制与实质审查制并存，说明不同程序阶段承担不同审查任务；具体程序细节须以现行制度文本为准。
**概念关系**：先识别保护客体，再选择相应法源和审查问题；客体归类不是授权结论。；在客体判断之后定位程序阶段，区分申请提交、初步审查、实质审查和授权。；授权实质条件与权利特征属于不同层次：前者回答能否授权，后者帮助理解权利成立后的范围和限制。；制度作用解释为什么专利制度同时强调公开和保护，但制度功能不能替代个案中的法条适用。
**必记**：发明、实用新型和外观设计是本节点必须掌握的三类保护客体。；专利法、专利法实施细则和专利审查指南应区分来源、功能和核验方式。；专利权具有独占性、时间性和地域性；中国申请或中国专利权不当然等于全球专利保护。；申请进入审查程序不等于已经满足全部授权条件，客体判断、授权判断和程序阶段判断不能互相替代。

### 专利基础四步速查卡（summary_card）

**要点卡**：
- **保护客体**：先从技术事实判断是发明、实用新型还是外观设计。
- **制度法源**：专利法、实施细则和审查指南要区分来源与功能，并以现行文本核验。
- **专利权三性**：独占性、时间性和地域性分别提示排他控制、存续期限和授予法域边界。
- **审查机制**：早期公开、延迟审查以及初步审查与实质审查并存，不能把一个阶段当成最终授权。
- **制度作用**：专利制度通过公开与有限保护的安排激励创新、促进技术公开和技术应用。
**必背**：先识别保护客体，再确定法源和程序阶段，最后核对权利边界。；申请提交或进入审查不等于已经取得有效专利权。；中国专利权具有地域性，不当然产生其他法域的同等专利效力。；具体法条、期限、例外和审查细节必须回到现行官方文本核对。
**一句话总结**：专利基础复盘遵循“客体—法源—阶段—边界”，并以公开与有限保护的制度逻辑贯穿始终。

**三类覆盖**：backward_review、forward_probe、weakness_probe
