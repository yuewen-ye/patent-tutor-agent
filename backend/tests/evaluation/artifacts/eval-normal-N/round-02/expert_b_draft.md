## 教学正文

## 1. 场景导入
小张，某AI芯片初创团队的工程师，2024年5月1日在政府主办的国际半导体展会上首次展示了他们研制的谐波减速器新方案原型。2024年10月1日，他们向国家知识产权局提交了专利申请。展出后，他们在内部会议上反复讨论：这个公开会不会让申请失败？同时，他们担心如果把申请日定为优先权日，是否能享受6个月缓冲？团队里有人提议“先申请再说”，但他们清楚，保护客体、授权条件和公开行为的时间界限三者密不可分，如果判断错了，专利就可能被拒或被宣告无效。

## 2. 人话解释
咱们把专利保护客体想象成‘什么东西可以申请专利’的大门。发明是最宽的‘门’——只要是产品、方法或其改进的新的技术方案（用技术手段解决技术问题，产生自然规律效果），就行；实用新型是‘窄门’——只保护有确定形状、构造、占据空间的实体产品，方法、形状+方法组合都不行；外观设计是‘美观门’——产品整体或局部的形状、图案、结合及色彩搭配的富有美感并适于工业应用的东西。申请前，审查员要先看你投的‘什么货’。再看三性：新颖性是‘查重’——申请日前有没有一模一样的公开？创造性是‘不显而易见’——本领域技术人员从已有技术组合中是否容易想到？实用性是‘能做有用’——能不能制造、使用并产生积极效果？诚实信用原则是贯穿始终的‘品质把关’，申请时不能弄虚作假，授权后也不能滥用权利。公开行为（比如展会展示）只在特定情况下给6个月缓冲，但不改变三性。简单说，先确定保护客体，再过三性关，最后看时间线和诚实信用。

## 3. 法条回扣
《专利法》第二条规定发明、实用新型、外观设计三类保护客体；《专利法》第二十二条规定新颖性、创造性、实用性三性；《专利法》第二十四条规定政府主办国际展览会公开6个月不丧失新颖性；《专利法》第二十条规定诚实信用原则。审查指南第二部分第十一章第2节进一步明确发明专利保护对象的判断标准。

## 4. 类比 / 口诀
三性记忆表：新（未公开）/创（不显而易见）/实（能做有用）。保护客体分类：发（产品/方法/改进）/实（形状/构造）/外观（美感+工业应用）。宽限期是临时通道，6个月内走即可。

## 5. 应试提示
题干关键词：保护客体（发明/实用新型/外观设计）、三性（新颖性/创造性/实用性）、公开行为（政府主办国际展览会）、诚实信用原则。判断步骤：先判保护客体，再判三性，最后看公开时间。常见陷阱：把方法当作实用新型客体；混淆现有技术与抵触申请；忘记宽限期仅限特定公开。

### 场景导入（anchor_scenario）

> 小张，某AI芯片初创团队的工程师，2024年5月1日在政府主办的国际半导体展会上首次展示了他们研制的谐波减速器新方案原型。2024年10月1日，他们向国家知识产权局提交了专利申请。展出后，他们在内部会议上反复讨论：这个公开会不会让申请失败？同时，他们担心如果把申请日定为优先权日，是否能享受6个月缓冲？团队里有人提议“先申请再说”，但他们清楚，保护客体、授权条件和公开行为的时间界限三者密不可分，如果判断错了，专利就可能被拒或被宣告无效。

**锚定**：用同一个技术事实（展会公开 + 专利申请）同时锚定“保护客体”（是否属于发明）与“授权条件”（新颖性、创造性、实用性）两个抽象模块，帮助感知式学习者从具象情境中快速看见问题核心。

**先想一想**：如果你是小张，第一反应是担心‘新颖性被破坏’还是‘保护客体判断’？为什么？请结合展出日期和申请日期的区别思考。

### 法条锚定（legal_anchor）

- **《专利法》第二条**：发明专利保护对象是产品、方法或其改进的新的技术方案；实用新型只保护产品形状、构造或其结合的适于实用的新方案；外观设计是产品整体或局部形状、图案、结合及色彩与形状、图案结合的富有美感并适于工业应用的新设计。
- **《专利法》第二十二条**：新颖性：该发明或实用新型不属于现有技术，也没有同样的发明或实用新型在申请日以前向国务院专利行政部门提出过申请并记载在申请日以后公布的专利申请文件或公告文件中。
- **《专利法》第二十四条**：创造性：同申请日以前已有的技术相比，发明有突出的实质性特点和显著的进步，实用新型有实质性特点和进步。
- **《专利法》第二十条**：实用性：能够制造或使用，并且能够产生积极效果。
- **《专利审查指南》第二部分第十一章第2节**：在申请日以前六个月内，在中国政府主办或承认的国际展览会上首次展出的，不丧失新颖性。

**为何重要**：本节点是专利法律制度基础的‘闸门’：先通过保护客体判断是否能进入审查，再过三性（新颖性、创造性、实用性）安检，最后检查诚实信用和公开行为的时间界限。掌握这些条文是后续审查/代理实务的根基，否则任何后续判断都会偏离轨道。

### 案例演示（worked_example）

**案情/例题**：某团队2024年5月1日在政府主办国际半导体展首次展出谐波减速器新方案原型，2024年10月1日向国家知识产权局提交发明专利申请。请判定展出是否破坏新颖性，申请日应如何确定？（假设申请人未行使优先权）
**适用规则**：《专利法》第二十四条、《专利法》第二十二条、《专利法》第二条、《专利审查指南》第二部分第十一章第2节
**分步推演**：
1. 展出日在申请日前（5月1日 < 10月1日），且属于中国政府主办国际展览会首次展出，符合《专利法》第二十四条第（二）项规定 → *落入宽限期适用范围，不丧失新颖性*
2. 申请日是国务院专利行政部门收到申请文件之日（10月1日），如未行使优先权，则优先权日与申请日相同；优先权日若行使，需在优先权日起18个月内请求实质审查 → *申请日确定完成，现有技术时间界限为申请日（或优先权日）*
3. 保护客体判断先于三性审查：该方案为产品改进的技术方案，属于发明专利保护对象；实用性、诚实信用原则需在实质审查前先查 → *展出仅豁免新颖性公开，不改变三性实质审查顺序*
**结论**：展出不破坏新颖性（宽限期适用），但申请仍需经过初步审查、实质审查与复审/无效程序，最终仍须满足三性及诚实信用原则。
**本题要点**：宽限期是‘时间豁免’而非‘免死金牌’，必须先判公开范围、再算日期、再过三性安检；优先权制度可提前申请日，但本质仍是申请日前的公开行为。

**类比**：保护客体像‘专利产品的分类门牌’：发明是最宽的门，实用新型是产品形状门，外观设计是美观形状门；三性像‘安检三关’（查重、不显而易见、能做有用）；公开行为像‘临时免检通道’——只能走特定出口，6个月内用。

### 反思提示（reflect_prompt）

**反思问题**：如果你的团队在展会展示后同时提交了发明专利申请和实用新型专利申请，你会如何调整策略？

**关注要点**：保护客体判断的差异：方法是否属于发明客体？；宽限期与审查制度的不同：发明用早期公开+实质审查，实用新型用初步审查；现有技术与抵触申请的区分：展会公开是现有技术还是仅豁免？

**连接**：连接到本节点的核心：先确定保护客体，再过三性，最后考虑公开行为时间界限与诚实信用。

### 知识综合（knowledge_synthesis）

**知识框架**：
- 保护客体：专利法第二条规定的发明、实用新型、外观设计三类范围，是审查第一个门槛。
- 三性条件：新颖性（无公开与抵触申请）、创造性（不显而易见）、实用性（能制造/使用并产生积极效果），贯穿授权全过程。
- 公开行为时间界限：申请日/优先权日为基准，特定公开（国际展等）给予6个月宽限期。
- 诚实信用原则：贯穿申请、审查、授权、行使全流程，违反即被驳回或宣告无效。
- 中国专利制度体系：专利法、实施细则、审查指南构成基础框架。
**概念关系**：保护客体判断先于三性审查；公开行为仅影响新颖性豁免，不改变三性顺序；诚实信用原则优先于一般形式审查。；发明专利采用早期公开+实质审查，实用新型/外观设计采用初步审查，共同服务于激励与公开双目标。
**必记**：先确定保护客体，再过三性安检，最后检查公开与诚实信用。；新颖性单独比对现有技术，创造性可组合对比；抵触申请仅用于新颖性，不能与其他文件混用于创造性。

### 速查卡（summary_card）

**要点卡**：
- **保护客体**：能申请专利的‘东西’范围
- **三性**：新颖性/创造性/实用性三关
- **公开行为宽限期**：政府主办国际展览会等6个月缓冲，仅豁免新颖性
- **诚实信用原则**：申请与行使必须真实，违反即驳回或无效
**必背**：三性缺一不可；保护客体先判，公开仅影响新颖性，诚实信用贯穿始终；申请日/优先权日为现有技术基准
**一句话总结**：先过保护客体之门，再过三性安检，最后看公开时间线与诚实信用。
