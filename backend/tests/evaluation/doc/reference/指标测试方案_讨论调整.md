## 1. 赛题硬指标（7 项）

### M1　专业知识谬误率（幻觉率）　目标 < 5%

- **定义**：产物中“可被客观核验的专业陈述”里，错误 / 无依据 / 虚构的比例。
- **分母（可核验陈述）抽取位置**：
  - `course_package.md` → `## legal_basis` 的 `article`（法条号）
  - `## 教学正文` 与 `## risks` 中的期限天数、程序规则、判断主体等断言
  - `## interactive_questions` 的题干/选项（含具体法条表述的）
- **测量方法（外部 LLM 做判定）**：
  1. 脚本从 30 轮抽取 **200–300 条**可核验陈述，按 10 画像 × 3 轮分层抽样。
  2. 每条送外部 LLM（建议 gpt-5.5 或更强），附权威法条原文（可附带 retrieval_context 作为参考），输出 `正确 / 错误 / 存疑` + 理由。
  3. **人工抽检 10%** 做与 LLM 的一致性校验（Kappa ≥ 0.7 方可采信），否则评委可直接不认。
- **公式**：`幻觉率 = 错误陈述数 / 可核验陈述总数 × 100%`
- **阈值**：`< 5%`
- **当前状态**：❌ 未测。需新跑。与 M9 可合并抽样（同一条陈述加一列“是否带来源”），人力省一半。
《备注》：把数据跑出来后让外部大模型进行一次评定，我们总结出哪些是影响教学准确性的严重错误，和不影响知识教学的一般谬误。然后我们试着去确定外部大模型评定所用的提示词。幻觉率不从此指标单一判定，结合多项指标加权计算(稍后我会给出相关的提示词)。

### M2　画像-资源难度适配准确率　目标 ≥ 85%

- **定义**：生成的习题难度落在“学员当前能力区间”内的比例。
- **数据来源**：
  - 习题难度：`course_package.md` → `interactive_questions[].difficulty`（L1/L2/L3）
  - 节点难度上限：`path_decision.md` → `question_scope[].难度` 或 `learning_path.md` → 难度上限
  - 学员能力下限：`feedback/learner_profile_update.md` → `five_dimensions[node].pl`（掌握概率）
- **公式（双边区间匹配，修复旧报告单边口径）**：
  - 学员适配下限 `L_low` = 由 pl 按系统自身规则映射：`pl<0.15→L1`，`0.15≤pl<0.30→L2`，`pl≥0.30→L3`（薄弱点强制 ≥L3）
  - 节点适配上限 `L_high` = 节点难度上限
  - `单题适配 = (L_low ≤ 题.difficulty ≤ L_high)`
  - `难度适配准确率 = 适配题数 / 总题数 × 100%`
- **阈值**：`≥ 85%`
- **当前状态**：⚠️ 旧报告 98.9% 仅判“题难度 ≤ 上限”单边，全出 L1 也能 100%。改双边重算后数值会回落，但站得住。建议同时用 `source_tag` 角色约束做交叉校验（backward_review 不应高于当前掌握、forward_probe 应为 L1、weak 应 ≥L3）。

### M3　核心知识点覆盖率　目标 ≥ 90%

- **定义**：系统覆盖的“核心知识点节点”占应覆盖节点的比例。
- **期望集（必须重定义，旧报告分母定义错）**：
  - **推荐口径（累计路径覆盖，最贴合赛题“实用价值”语境）**：`期望 = learning_path.md 全部 14 个节点`；`实际 = 该画像各轮 knowledge_points.node_id 的并集`。
  - 备选口径（当轮覆盖）：`期望 = path_decision 当前主教学节点 + 其先修节点`；`实际 = 当轮 knowledge_points.node_id`。
- **关键修正**：用知识图谱的**祖先-后代关系**做匹配，不要把子节点（如 `novelty`）当“未覆盖”父节点（`patentability-substantive`）。
- **公式**：`覆盖率 = |实际 ∩ 期望（支持祖先匹配）| / |期望| × 100%`
- **阈值**：`≥ 90%`
- **当前状态**：⚠️ 旧报告 10% 因精确匹配 + `section_kcs` 错填“整路径终点”导致分母错。按累计路径 + 祖先匹配重算后预期可显著提升。
《备注》：提前模拟的标准答案内容，有些过激，第一节课偶尔跳过基础内容普及，导致本节覆盖率偏低，需调整标准答案（该任务会由后续的协同者完成而非现在）。
《备注》：依旧保留本节知识点覆盖率/薄弱点命中率/混淆对覆盖率，但对于指标的设计做重新的检查！（该任务会由后续的轮次完成而非现在）

### M9　知识溯源可验证率　建议 ≥ 95%

- **定义**：`legal_basis` 中引用的法条，条号真实存在且与内容对应的比例。
- **数据来源**：`course_package.md` → `## legal_basis`（article, source）。

### M11　动态迭代触发率（进阶 / 上升）　建议进阶触发率 ≥ 90%

- **定义**：学员作答后，知识追踪（BKT）掌握度 pl 是否按预期**跨阈值上升（进阶）**，并驱动下一轮难度/路径调整。**本指标只测上升，不测下降（降维）**。
  - **进阶**（advancement）：节点 pl 从 <0.30 升到 ≥0.30（弱→已掌握），且下一轮该节点习题降为复习/L1。
- **数据来源**：`feedback/learner_profile_update.md` → `five_dimensions[node].pl`（跨轮比对 r01↔r02↔r03）；辅助看 `interactive_questions[].difficulty` 与 `path_decision` 的 question_scope 是否随 pl 上升而调整。
- **公式**：
  - `进阶触发率 = (pl 从弱升到已掌握的节点数) / (r01 中处于“弱”状态的节点数) × 100%`
- **阈值**：建议进阶触发率 `≥ 90%`。
- **当前状态**：🔶 **进阶已实测可观测**——10 画像 r01→r02 全部有节点 0.15→0.785（弱→已掌握），进阶机制成立。⚠️ `iteration_directive` 字段是写死模板，不可用；以 pl 增量 + 难度变化为准。⚠️ round-03 反馈缺失，进阶证据仅 r01→r02 两段。
《备注》：因测试初步设定是对于课后题全部标为正确，然后进行新课程的产生。所以只有进阶这个过程。如果增加降维判断，可能要增加一轮反面的全错输入。考虑修改测试集合为8个学员，10轮进阶学习+10轮降维学习的可能性。
