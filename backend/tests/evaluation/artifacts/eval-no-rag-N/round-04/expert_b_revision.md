# 专家 B 修订稿

## teaching_content

## 1. 场景导入

你是刚入职的专利代理人。客户研发团队拿来一份技术方案：一种改进型机器人关节模组（产品结构+控制方法）。他们问三件事：这东西能不能申请专利？该申请发明还是实用新型还是外观设计？仅获中国专利时境外仿造是否构成侵权？同时老板还想知道，中国专利制度为什么要“早公开、延迟审查”，审查指南和专利法到底谁说了算。这些正是专利法律制度基础要回答的问题：客体是什么、权利有什么特征、制度为什么这么设计、法律体系怎么分层。

## 2. 人话解释

专利制度，说白了就是国家给发明人一段时间的“法定排他权”，换取他把技术写清楚公开。排他效力=别人未经许可不能实施（见《专利法》第十一条）；时间性=保护有期限（发明专利通常自申请日起满十八个月后公布，实用新型和外观设计直接进入初步审查，保护期发明通常20年、实用新型10年、外观设计15年，从申请日起算，见《专利法》第四十二条）；地域性=中国专利只在中国境内有效，管不了美国本土制造销售。

保护客体只有三种：发明（产品或方法的新技术方案）、实用新型（产品形状构造的实用新方案）、外观设计（富有美感的工业设计）。此外，科学发现、疾病诊断治疗方法等不授予专利权（详见《专利法》及其他规定，本节不展开）。

中国专利制度体系像三层楼：最上层是《专利法》（人大常委会制定），中间是《专利法实施细则》（国务院），底层是《专利审查指南》（国家知识产权局）。审查员日常主要看指南，但指南必须符合上位法。

制度作用四件事：激励创造、促进公开、推动应用、服务经济社会发展。中国特点是“早期公开、延迟审查”：发明专利申请通常自申请日起满十八个月后公布，实质审查由申请人依法请求并受法定期限约束；实用新型和外观设计主要走初步审查。这样既让技术早公开，又避免所有申请都堆到实质审查。

## 3. 法条回扣

《专利法》第一条点明立法目的：保护专利权人合法权益、鼓励发明创造、推动应用、提高创新能力、促进科技进步和经济社会发展。这就是“作用”的法条锚点。

《专利法》第二条直接定义三种客体：发明=产品、方法或其改进的新技术方案；实用新型=产品形状、构造或其结合的适于实用的新技术方案；外观设计=产品整体或局部形状、图案或其结合以及色彩与形状、图案结合的富有美感并适于工业应用的新设计。

《专利法》第十一条规定专利权禁止他人未经许可实施的效力；第四十二条规定专利权期限（发明通常20年等）；第三十四条和第三十五条规定发明专利申请的公布程序及实质审查请求期限。这些条款共同构成本节核心特征与制度安排的法条基础。

## 4. 类比 / 口诀

把专利想成“国家发的临时领地许可证”：独占性=这块地你说了算；时间性=许可证有到期日；地域性=许可证只在本国地图有效。三种客体像三种“地契类型”：发明地契最全（产品+方法），实用新型只管产品形状构造，外观设计管“长得美不好看”。

口诀（边界：仅帮记忆分类，不替代法条判断）：“独时地，三客体；法细指，三层楼；发明早公开请求实质审查；初实并，促公开。”适用边界：口诀不解决新颖性创造性具体比对，只帮你先把框架立住。

## 5. 应试提示

题干关键词：“独占/排他”“保护期限”“中国专利在境外”“发明/实用新型/外观设计定义”“专利法与审查指南关系”“早期公开延迟审查”。

判断步骤：①先定客体类型（看是技术方案还是设计、有无方法）；②再问权利特征（时间从哪起算、效力到哪）；③体系题看效力位阶（法>细则>指南）；④历程题抓“早期公开+请求审查”和“初审/实审并存”。

常见陷阱：把地域性理解成“国际自动生效”；把实用新型当成可保护方法；以为审查指南可以突破专利法；把制度作用只说成“保护权利人”而漏掉公开与经济社会发展。

## 6. 互动提问

学完后先自问：如果客户只想快速拿证、技术主要是产品结构改进，优先建议哪种客体？为什么中国专利拦不住美国本地仿造？审查指南和专利法冲突时听谁的？本节设有测评，请到【习题】区作答。
