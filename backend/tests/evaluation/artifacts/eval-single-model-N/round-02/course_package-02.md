## 教学正文

## I — 法律问题

本节点围绕五项基础问题展开：专利权的独占性、时间性和地域性如何限定权利边界；中国专利制度由哪些规范材料构成；技术成果如何对应发明、实用新型和外观设计；制度为何以公开与法定保护相结合；以及中国制度如何在立法与修法发展中形成现行审查运行特点。

代理人与审查人员的职业视角不同，但共同起点都是把研发事实放入法定客体、现行规范和程序节点中判断。专利并非“有创意即自动取得”的标签；初步客体识别、初步审查、申请公布与最终授权也不是同一法律动作。

## R — 适用规则

《专利法》第二条规定，发明创造是指发明、实用新型和外观设计。发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计，并分别规定三类客体定义〕

中国专利制度的规范主线是专利法、专利法实施细则和专利审查指南：专利法规定基本制度、客体和程序框架；实施细则细化申请文件和程序事项；审查指南用于理解审查实践中的适用口径。国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕

发明申请经初步审查认为符合要求的，自申请日起满十八个月即行公布，申请人可以请求早日公布；申请人可以自申请日起三年内请求实质审查，无正当理由逾期不请求的，申请被视为撤回。〔RAG: 中华人民共和国专利法.txt — 第三十四条、第三十五条：发明申请经初步审查后公布，并可在申请日起三年内请求实质审查〕发明申请经实质审查、实用新型和外观设计申请经初步审查没有发现驳回理由后，作出授权决定、登记和公告；专利权自公告之日起生效。〔RAG: 中华人民共和国专利法.txt — 第三十九条、第四十条：相应申请经审查没有发现驳回理由后作出授权决定，专利权自公告之日起生效〕

## A — 双视角适用

制度发展历程应与现行制度特点连起来理解。检索材料记载，中国于1984年制定专利法，并在后续发展中经历修法。〔RAG: 专利法专题讲座.txt — chunk 2530、1941：1984年立法及后续修法信息〕因此，现行规则并不是孤立的技术性流程：发明申请采用早期公开、延迟实质审查的实质审查制，实用新型和外观设计申请采用初步审查制，反映了现行制度对不同客体配置不同审查路径的特点。〔RAG: 专利法专题讲座.txt — 发明专利申请采用早期公开、延迟审查的实质审查制；实用新型和外观设计申请采用初步审查制〕本节仅据已提供材料说明1984年立法和后续修法这一沿革主线，不补写未获核验的具体修法年份、改革事件或跨法域结论。

专利权具有独占性、时间性和地域性。独占性意味着权利在授权范围内具有排他保护功能；时间性意味着权利不永久存在；地域性意味着其效力与特定授权法域相联系。现行材料显示，发明、实用新型和外观设计的保护期限分别为二十年、十年和十五年，均自申请日起计算；但专利权本身自授权公告之日起生效。〔RAG: 专利法专题讲座.txt — 《专利法》第42条第1款：三类专利权期限分别为20年、10年、15年，均自申请日起计算；专利权自授权公告之日起生效〕

制度功能可概括为以公开换取法定保护机会：通过技术公开与法定保护安排，激励发明创造、促进技术公开、推动技术应用和经济发展。这个说法是制度功能的教学类比，不表示公开技术或提交申请即可当然取得专利权。〔RAG: 专利法律知识详细解读.txt — 专利权的取得本质是“以公开换保护”〕

具体处理研发成果时，代理人应先拆分方法步骤、产品结构和视觉设计，再根据第二条选择发明、实用新型或外观设计的核对方向，并组织申请文件；审查人员则依据同一法定分类、申请文件和适用规范确定审查入口。随后才核对完整法定限定、初步审查事项、公布、实质审查请求和授权前提。历史沿革帮助理解制度为何形成现行结构，却不能替代对现行有效规范的具体适用。

## C — 结论

本节点的稳定判断链是：“拆分技术事实—识别保护客体—核对法定限定—确定审查路径—确认授权前提—把握权利边界”。同时，用“1984年立法起步、后续修法发展、现行不同客体适用不同审查路径”理解中国专利制度的发展历程与特点。发明、实用新型和外观设计不能混同；初步识别、审查、公布和授权不能混同；制度功能和历史背景也不能代替具体申请的法定审查。

### 从一件产品看专利制度基础（anchor_scenario）

> 某团队研发便携式检测设备：既有新的检测步骤，也有传感器支架的形状、构造改进，还有外壳局部图案。代理人需要拆分事实并选择申请表达；审查人员需要依照法定客体和程序审查。

**锚定**：该场景同时连接三类客体、规范体系、审查路径以及专利权的独占性、时间性和地域性。

**先想一想**：面对方法步骤、产品结构和视觉设计，应如何依次识别保护客体？为什么初步识别后仍不能断言已获专利权？

### 法条锚定：客体、职责与审查程序（legal_anchor）

- **《中华人民共和国专利法》第二条**：发明创造包括发明、实用新型和外观设计；三类客体的法定定义和限定不同。
- **《中华人民共和国专利法》第三条**：国务院专利行政部门统一受理和审查专利申请，依法授予专利权。
- **《中华人民共和国专利法》第三十四条、第三十五条**：发明申请经初步审查符合要求后，自申请日起满十八个月公布；申请人可在申请日起三年内请求实质审查。
- **《中华人民共和国专利法》第三十九条、第四十条**：发明经实质审查、实用新型和外观设计经初步审查没有发现驳回理由后，作出授权决定、登记和公告；专利权自公告日起生效。
- **《中华人民共和国专利法实施细则》第五十条**：初步审查涉及申请文件和必要文件是否具备、格式是否符合规定及相关法定事项。

**为何重要**：法条界定客体、机关职责和程序节点，防止把事实分类、初步审查、公布和最终授权混为一谈。

### 示范推演：从技术事实到审查制度（worked_example）

**案情/例题**：某检测设备包含新的检测步骤、传感器支架的形状与构造改进以及外壳局部图案设计。如何识别客体并连接相应审查制度？
**适用规则**：《专利法》第二条分别规定发明、实用新型和外观设计的法定客体；第三十四条、第三十五条规定发明申请的公布和实质审查请求；第三十九条、第四十条规定不同类型申请的授权程序。
**分步推演**：
1. 将检测步骤从设备实体中抽出。方法事实应按发明对象方向考察，但“新的步骤”不能替代对新的技术方案的核对。 → *方法事实先按发明方向考察。*
2. 支架改进涉及产品的形状、构造或者其结合，应按实用新型方向考察，并核对适于实用的新的技术方案。 → *结构事实先按实用新型方向考察。*
3. 局部图案属于产品视觉设计，应按外观设计方向考察，并核对富有美感和适于工业应用等限定。 → *视觉设计先按外观设计方向考察。*
4. 客体初步识别后才进入相应程序判断。发明要区分初步审查、公布、实质审查请求和授权；实用新型、外观设计适用初步审查制。 → *客体分类、审查路径和授权结论是不同层次。*
**结论**：检测步骤可按发明对象方向考察，支架结构可按实用新型对象方向考察，外壳局部图案可按外观设计对象方向考察；但仍须核对相应完整法定限定和其他审查条件。
**本题要点**：固定使用“拆分事实—识别客体—核对限定—对应程序—确认授权前提”的判断链。

### 把制度语言翻译成实务动作（verbal_explanation）

专利实务不是“有新点子就自动受保护”。代理人先把研发事实拆成方法、产品结构和视觉设计，再按法定定义组织申请；审查人员依据同一套定义、申请文件和程序规则审查。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计，并分别规定三类客体定义〕中国专利制度以专利法、实施细则和审查指南构成规范主线。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门统一受理和审查专利申请，依法授予专利权〕制度沿革上，检索材料记载中国于1984年制定专利法，并在后续发展中多次修法；因此应将现行的客体规则、审查程序和期限安排理解为持续制度演进后的规范结果，而不能把某一程序特点当作完整历史。〔RAG: 专利法专题讲座.txt — chunk 2530、1941：1984年立法及后续修法信息〕

**点破术语**：独占性；时间性；地域性；制度体系；发展历程与制度特点

**类比**：专利制度可理解为“公开换取法定保护机会”的规则系统。该类比仅说明制度功能；公开或提交申请不等于当然获得专利权，仍取决于法定客体、程序和审查结论。

### 五格复盘：权—规—客—用—程（mnemonic）

**记忆锚**：“权—规—客—用—程”五格复盘：先看权利边界，再找规范依据；接着辨认客体，理解制度作用，最后核对制度沿革与程序。口诀仅用于组织复盘顺序，不替代具体条文。
**映射**：
- 权
- 规
- 客
- 用
- 程
**何时用**：复盘研发交底、申请文件或审查记录时，先默写“权—规—客—用—程”，再逐项回到法条、历史材料和具体事实。

### 双视角复盘：谁先看什么（reflect_prompt）

**反思问题**：回看同一份研发交底，代理人与审查人员分别先标出什么？为什么在知道中国专利制度经历立法与后续修法后，仍必须以现行法条判断具体申请？

**关注要点**：方法、产品结构和视觉设计应分别识别，初步分类不等于最终授权。；发明申请的初步审查、公布、实质审查请求和授权是不同节点。；1984年立法和后续修法说明制度具有演进性；具体案件仍应适用现行有效规范。；制度功能和历史背景不能替代对法定客体、文件和程序条件的审查。

**连接**：代理人与审查人员使用同一客体分类标准，但分别承担事实表达和法定审查任务；二者都应把现行程序放在制度沿革和规范层级中理解。

### 专利制度基础关系网（knowledge_synthesis）

**知识框架**：
- 权利特征：专利权具有独占性、时间性和地域性；时间性在现行法上体现为不同类型专利权有不同保护期限。
- 制度体系：专利法提供基本制度，实施细则细化程序事项，审查指南用于理解审查实践的具体适用口径。
- 三类保护客体：发明、实用新型、外观设计的法定对象和限定不同。
- 制度作用：通过技术公开与法定保护安排，激励发明创造、促进技术公开、推动技术应用和经济发展。
- 制度发展历程与特点：中国于1984年制定专利法，后续经历修法发展；现行制度中，发明申请采用早期公开、延迟实质审查的实质审查制，实用新型和外观设计申请采用初步审查制。
**概念关系**：制度沿革解释现行规则的形成背景，但具体审查与代理必须回到现行有效法条、实施细则和审查指南。；先拆分技术事实并识别客体，再核对完整法定限定，最后确定审查程序。；发明申请的初步审查、公布、实质审查请求和授权彼此不同；初步审查制不意味着当然授权。；制度作用说明公开与保护的政策逻辑，不能直接推出个案必然授权。
**必记**：专利权具有独占性、时间性和地域性；发明、实用新型、外观设计的期限分别为二十年、十年、十五年，均自申请日起计算。；中国专利制度以1984年制定专利法为起点，并在后续修法中持续发展；学习历史沿革时应区分已核验材料与未提供的具体改革细节。；中国专利制度的基本规范主线包括专利法、专利法实施细则和专利审查指南。；《专利法》第二条规定发明、实用新型、外观设计三类发明创造，三者的客体和法定限定不同。；发明申请经初步审查符合要求后公布，并可在法定期间请求实质审查；实用新型和外观设计申请采用初步审查制。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **权利边界**：专利权具有独占性，但其效力受期限和地域限制。
- **规范主线**：先查专利法基本制度，再按问题核对实施细则和审查指南。
- **三类客体**：发明看产品、方法或其改进的新的技术方案；实用新型看产品结构的适于实用的新的技术方案；外观设计看产品整体或局部的视觉设计。
- **制度沿革**：中国专利制度以1984年制定专利法为起点，经后续修法发展；学习沿革不能脱离现行规范。
- **审查路径**：发明区分初步审查、公布、实质审查请求和授权；实用新型、外观设计采用初步审查制。
**必背**：发明创造是指发明、实用新型和外观设计。；中国专利制度于1984年制定专利法起步，并经后续修法发展。；发明申请自申请日起满十八个月即行公布，申请人可以请求早日公布。；发明申请自申请日起三年内可以请求实质审查。；专利权自授权公告之日起生效；保护期限从申请日起计算。
**一句话总结**：先以现行规范拆分事实和判断程序，再把早期公开、延迟审查等特点放回中国专利制度的立法与修法沿革中理解。
