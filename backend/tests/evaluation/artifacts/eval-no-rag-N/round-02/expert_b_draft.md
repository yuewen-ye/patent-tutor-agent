## 教学正文

## 1. 场景导入
假设你是一个发明家，刚刚完成了一款新型减速器的研发。你想申请专利来保护你的发明，但担心如果在行业技术交流会上公开演示，会不会破坏新颖性？同时，你也想了解专利制度的基本特征，以便更好地理解专利权的本质。

## 2. 人话解释
专利法律制度基础是整个专利法学习的起点。我们把专利制度想成一种交易：发明人公开技术，国家评估后授予有限独占权。具体来说，专利权有三个基本特征：独占性、时间性和地域性。保护的客体是发明、实用新型和外观设计三种。专利制度的作用是激励创新、促进技术公开和经济发展。中国专利制度的特点是早期公开延迟审查、初步审查与实质审查并存。

## 3. 法条回扣
根据《专利法》第二条，专利保护的三种客体是发明、实用新型和外观设计。根据《专利法》第二十二条，发明专利授权需满足新颖性、创造性和实用性。

## 4. 类比 / 口诀
可以将专利制度类比为借用自然资源的授权：公开如借用资源，专利权如使用权，但有期限限制。三性记忆口诀：新-未公开、创-非显见、实-能用有用。

## 5. 应试提示
在判断专利授权时，先看保护客体是否符合，再判断三性是否满足。注意宽限期只影响新颖性，不影响其他。

## 6. 互动提问

**锚定**：这个场景同时引入了专利保护客体和专利三性（新颖性、创造性、实用性）的概念，为后续学习奠定基础。

**先想一想**：如果你是专利代理人，看到‘技术交流会公开’这个行为，第一反应是风险还是安全？为什么？

### 法条锚定（legal_anchor）

- **《专利法》第二条**：专利保护的三种客体是发明、实用新型和外观设计
- **《专利法》第二十二条**：发明专利授权需满足新颖性、创造性和实用性

**为何重要**：本条规定了专利法的客体和实质审查标准，是理解专利制度基础的核心条款。

### 案例演示（worked_example）

**案情/例题**：甲公司2024年1月1日在国内技术会议上展示其新型减速器，2024年7月1日提出专利申请。问：此次展示是否影响新颖性？
**适用规则**：《专利法》第二十四条
**分步推演**：
1. 展示日在申请日前，属于政府或国际会议公开 → *符合宽限期适用范围*
2. 从展示到申请约6个月，等于6个月 → *在法定宽限期内*
3. 宽限期仅不丧失新颖性，创造性实用性仍需判断 → *未完全免除审查*
**结论**：展示不破坏新颖性，但仍需满足创造性和实用性。
**本题要点**：宽限期是时间上的豁免，需结合具体事实判断。

**知识框架**：
- 专利制度的基本概念与特征：独占性、时间性、地域性
- 中国专利制度体系：专利法、实施细则、审查指南
- 专利保护的三种客体：发明、实用新型和外观设计
- 专利制度的作用：激励发明创造、促进技术公开、推动技术应用和经济发展
- 中国专利制度发展历程与特点：早期公开延迟审查、初步审查制与实质审查制并存
**概念关系**：三性是授权实质条件的基石，三种客体是保护范围的基础；制度体系是法源基础
**必记**：三性缺一不可，任何一项不满足则不授权；专利权具有地域性和时间性限制

### 速查卡（summary_card）

**要点卡**：
- **专利制度**：以公开换保护的制度
- **专利权特征**：独占性、时间性和地域性
- **保护客体**：发明、实用新型和外观设计
- **中国专利特点**：实质审查为主，初步审查为辅
**必背**：三性缺一不可；宽限期仅豁免特定公开且限6个月
**一句话总结**：先过保护客体之门，再过三性安检。
