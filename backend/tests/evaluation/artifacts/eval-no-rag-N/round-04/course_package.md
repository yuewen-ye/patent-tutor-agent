## 教学正文

# 专利法律制度基础：审查与代理的共同起点

## 一、先把问题放回制度入口

处理一项技术成果时，代理人与审查员的起点相同：都不能仅凭“技术先进”“投入很大”或“市场前景好”直接下专利结论。代理人要把客户提交的机械结构、控制方法、产品外观等技术事实拆开；审查员要将这些事实放回法定要件和适用规范中核验。先完成这一入口工作，才谈得上申请策略、审查程序或后续专利性判断。

《中华人民共和国专利法》第一条所载立法目的包括保护专利权人的合法权益、鼓励发明创造、推动发明创造的应用、提高创新能力、促进科学技术进步和经济社会发展。第二条所称的发明创造包括发明、实用新型和外观设计。由于本轮检索上下文为空，以上法条内容来自专家 B 草稿的援引；正式实务引用前应以现行官方文本核验。

## 二、保护什么：三种法定客体

本节以第二条的分类作为入口。发明对应对产品、方法或者其改进提出的新的技术方案；实用新型对应对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计对应产品整体或者局部的形状、图案等形成的富有美感并适于工业应用的新设计。对同一产品，结构、方法、外观可能分别对应不同的拟保护对象，不能用一个笼统标签替代分类。

代理视角下，客体归类决定如何组织技术交底、如何选择可能的申请路径。审查视角下，客体归类决定先依据何种法定定义核验。两种视角都遵守同一顺序：先识别具体对象，再对应法定定义；不能从商业需求倒推出法律分类。

## 三、权利边界与制度目的

理解专利权时，要同时记住独占性、时间性和地域性。独占性提示权利具有排他效力；时间性提示权利不永久存续；地域性提示一国或地区授权的权利原则上只在相应法域内发生效力。因而，向客户说明保护范围时，不能把中国专利说成在其他国家或地区当然有效；跨法域布局与跨境侵权分析必须另行依据目标法域的法律和事实判断。

专利制度也不只是为个别权利人提供排他空间。第一条所体现的制度目标还包括鼓励创造、推动应用、提高创新能力以及促进科技和经济社会发展。教学上可以把它理解为权利保护与技术公开、技术应用之间的制度安排；但制度目的不能替代个案中对保护客体、授权要件或程序条件的核验。

## 四、依据什么运行：规范体系与程序概括

中国专利制度的基础规范体系包括专利法、专利法实施细则和专利审查指南。专利法提供基本法律框架；实施细则和审查指南服务于具体申请、审查和代理活动。实务中应同时关注三者，但不能混同其规范功能，也不能脱离上位法理解具体操作要求。

本节教学上下文还将中国制度特点概括为早期公开、延迟审查，以及初步审查制与实质审查制并存。这一概括帮助建立制度地图：程序安排一方面连接技术公开，另一方面配置审查资源。具体申请类型、公开安排、审查请求和期限等问题，必须回到现行法条、实施细则和审查指南核验；本轮检索上下文未提供直接依据，不能将概括扩张为具体程序结论。

## 五、进入检索比对前：先固定时间与证据类型

虽然新颖性、创造性、抵触申请等内容会在后续节点进一步展开，但本轮的薄弱点提示要求先建立最小边界。拿到检索报告后，第一步不是把所有文件堆在一起，而是固定申请日或适用的优先权日，逐份记录公开时间，并辨认材料的证据类型。

随后要分清问题。若问“有没有一份材料已经公开相同方案”，是在做新颖性的单独对比，不能把多份文件拼接后直接得出不具新颖性的结论。若问“本领域技术人员是否容易想到”，才进入创造性的分析，并可能讨论组合推理。遇到申请在先、公开在后的材料，应先标记为抵触申请，不应不加区分地当作创造性组合中的现有技术。上述判断顺序来自用户提供的教学规划和薄弱点指导；本轮检索上下文未提供相关审查指南原文，具体案件仍须核验现行规则。

## 六、双视角的工作清单

代理人的顺序可以概括为：拆分客户技术事实，完成客体归类，说明权利的地域与时间边界，选择需要核验的规范和程序，再对检索材料做时间与类型标注。审查员的顺序可以概括为：核验申请所主张对象是否落入法定分类，按适用规范审查申请材料，并在后续实体判断中严格区分不同证据与不同法律问题。

把这两条工作线合在一起，本节最重要的不是记住孤立术语，而是形成稳定的判断顺序：先定客体，再定规范与权利边界；进入对比分析时，先定日期、类型和问题。这样才能避免把市场判断代替法律判断，把不同规范层次混为一谈，或把新颖性、抵触申请和创造性的分析方法错用。

### 从机器人关节模组进入专利制度（anchor_scenario）

> 某机器人企业完成了一套关节模组：机械结构经过改进，控制程序也有新的运算步骤，产品外壳还做了辨识度很高的视觉设计。代理人准备帮助企业申请，研发负责人却认为“技术好、能卖钱，就应当获得全球专利保护”。审查员则需要先核对拟保护内容属于什么法定客体，并按照适用规范和程序处理申请。

企业又收到竞争对手的检索报告：其中有一份申请日前公开的文件，还有一份申请在先、公开在后的材料。代理人和审查员都不能直接把它们混在一起下结论，而要先厘清专利制度的客体、权利边界、规范体系和证据用途。

**锚定**：该情境锚定法定保护客体、专利权三项特征、规范体系及新颖性与创造性判断边界。

**先想一想**：面对这套“结构、方法、外观”并存的成果，审查与代理工作的共同第一步为什么不是直接判断技术是否先进？

### 立法目的与法定保护客体（legal_anchor）

- **《中华人民共和国专利法》第一条**：第一条说明制度不只保护权利人，也以鼓励发明创造、推动应用、提高创新能力和促进发展为立法目标。
- **《中华人民共和国专利法》第二条**：第二条将本法所称的发明创造界定为发明、实用新型和外观设计，并分别给出三类客体的定义。

**为何重要**：第一条为制度作用提供法条锚点，第二条为保护客体的分类提供法条锚点。由于本轮检索上下文为空，正式实务引用前仍应以现行官方法条文本核验。

### 从技术事实到归类与证据分流（worked_example）

**案情/例题**：机器人企业拟保护关节模组的新机械结构、控制方法和外壳设计。检索报告显示：文件甲在相关基准日前已公开；文件乙申请在先、公开在后。代理人需要提出申请策略，审查员需要确定后续比对的起点。待解决的问题是：应如何先完成客体归类，并如何避免在后续专利性判断中混淆不同文件的用途？
**适用规则**：《中华人民共和国专利法》第二条；关于新颖性、抵触申请和创造性判断方法，本轮检索上下文未提供审查指南原文，以下仅依用户提供的 planner_guidance 进行边界训练，不替代具体案件的现行规则核验。
**分步推演**：
1. 先把客户交付的材料拆开：机械结构、控制方法、外壳设计分别是不同的拟保护内容。此时只识别对象，不以“研发投入高”或“市场前景好”直接推出可专利性。 → *第一步：从技术事实中分离拟保护对象。*
2. 再回到《中华人民共和国专利法》第二条：发明涉及产品、方法或者其改进的新的技术方案；实用新型以产品形状、构造或者其结合的适于实用的新的技术方案为对象；外观设计以产品整体或者局部的形状、图案等形成的富有美感并适于工业应用的新设计为对象。 → *第二步：逐项按法定定义归类。*
3. 进入检索材料分析前，先固定申请日或适用的优先权日，再标注每份材料的公开时间及证据类型。文件甲与文件乙不能仅因都涉及类似技术而被当成同一类证据。 → *第三步：先定时间基准和证据类型。*
4. 依用户提供的训练规则，新颖性问的是是否存在单独公开相同方案；创造性才讨论本领域技术人员是否容易想到及必要的组合推理。申请在先、公开在后的材料先标记为抵触申请，不应未经具体规则核验而进入创造性组合。 → *第四步：按问题类型选择单独对比或组合分析。*
**结论**：该企业应先将结构、方法和外观分别进行法定客体归类：不能把商业价值当作客体结论。对检索报告则应先固定相关基准日并区分文件类型；不能把两份文件拼接后直接否定新颖性，也不能未经证据类型核验就把申请在先、公开在后的材料纳入创造性组合。
**本题要点**：专利实务的基础链条是“拆技术事实—定法定客体—定时间基准—定证据用途”，不要跳步下结论。

### 用审查员与代理人的语言读制度（verbal_explanation）

先把主线压缩成一句话：专利制度不是看一项成果“值不值钱”，而是先看它能否被放入法定保护客体，再看适用什么规范和程序。发明、实用新型、外观设计是《中华人民共和国专利法》第二条给出的三种基本分类。专利权还要同时从独占性、时间性、地域性理解：它有排他效力，但不是永久有效，也不能把中国授权自动当成全球有效。

审查员的工作，是依据法定要件和适用规范核验申请；代理人的工作，是把客户的技术事实拆准确、归类准确，再组织申请和应对审查。专利法提供基本法律框架，实施细则和审查指南承接具体运行；后两者的适用不能脱离上位法。制度之所以设置权利保护与技术公开的安排，是为了同时服务于创新激励、技术公开、技术应用和经济发展。

遇到检索材料时，先别急着说“没有新颖性”或“没有创造性”。先固定申请日或优先权日，再问现在处理的是“有没有一份材料单独公开相同方案”，还是“基于现有技术是否容易想到”。前者对应新颖性的单独对比，后者才可能进入创造性组合分析；申请在先、公开在后的材料还要先辨认其抵触申请属性。关于这些具体判断规则，本轮检索上下文未提供直接依据，实务中必须复核现行审查指南。

**点破术语**：独占性；时间性；地域性；规范体系；抵触申请

**类比**：可以把专利制度理解为一套有“入口、规则表、运行路径”的法律系统：保护客体决定能否从入口进入，专利法、实施细则和审查指南构成不同层次的规则来源，申请和审查程序是运行路径。类比只帮助理解制度结构，不能替代法条和现行审查规则。

### 双视角复盘：先问什么、后做什么（reflect_prompt）

**反思问题**：回看机器人关节模组场景：代理人为了避免给客户过度承诺，应怎样排列“客体归类、地域边界、程序选择、检索材料用途”的说明顺序？审查员又会在哪一步要求补足可核验事实？

**关注要点**：是否把商业价值、技术先进性与法定保护客体混为一谈。；是否把中国专利权的地域性误解为境外自动生效。；是否把专利法、实施细则和审查指南的规范功能混同。；是否先固定日期和文件类型，再区分新颖性的单独对比与创造性的组合分析。

**连接**：连接到已有的研发沟通经验：代理人先把技术与商业需求转化为法律问题，审查员再以法定客体、规范依据、时间事实和证据类型逐项核验。

### 专利法律制度基础框架（knowledge_synthesis）

**知识框架**：
- 基本概念与特征：专利权应从独占性、时间性、地域性三个边界理解；有关具体效力和期限，实务中应对应现行法条核验。
- 中国制度体系：专利法提供基本法律框架，专利法实施细则和专利审查指南承接具体申请、审查和代理运行；不得将不同规范层次混同。
- 三种保护客体：《中华人民共和国专利法》第二条所称发明创造包括发明、实用新型和外观设计，并分别界定技术方案或设计的对象范围。
- 制度作用：《中华人民共和国专利法》第一条将保护合法权益、鼓励发明创造、推动应用、提高创新能力、促进科学技术进步和经济社会发展列为立法目标。
- 制度发展与审查机制：本节教学上下文将制度特点概括为早期公开、延迟审查以及初步审查制与实质审查制并存；具体适用范围和程序细节不在本轮检索证据范围内。
**概念关系**：先以第二条完成保护客体归类，再定位相应的规范体系和申请、审查路径。；权利特征限定代理建议的效力边界；制度目的解释权利保护与技术公开并存的制度逻辑，但不能替代具体授权要件。；后续遇到新颖性与创造性问题时，必须先固定申请日或优先权日和文件类型；新颖性采用单独对比，创造性才可能进行组合推理。；申请在先、公开在后的材料应先识别为抵触申请；其具体法律用途须依现行规则核验，不能当然作为创造性组合材料。
**必记**：商业价值和技术先进性不能替代对发明、实用新型、外观设计的法定客体归类。；专利法、实施细则和审查指南共同构成制度运行中需要关注的规范层次，具体适用不能脱离上位法。；专利权的独占性、时间性、地域性应结合具体法源理解，尤其不能把一国专利误认为全球自动有效。；新颖性不能以多份文件拼接后直接否定；创造性才讨论是否容易想到及必要的组合分析。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **三项特征**：独占性、时间性、地域性共同限定专利权的效力边界。
- **规范体系**：专利法定基本框架，实施细则与审查指南支撑具体申请和审查运行。
- **三种客体**：发明、实用新型、外观设计是第二条列明的基本分类。
