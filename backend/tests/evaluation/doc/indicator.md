### 1.2 三类谬误率 \[LLM]

> 基于 `statement` 模式的外部 LLM 陈述级判定。每条陈述由 LLM 标注 `error_type`（factual/logical/instructional/other），按类型分组计算谬误率。未返回评估结果的陈述（reasoning="LLM 未返回评估结果"）从分母中剔除。
>
> **表现格式**：所有 1.2.x 及 1.2 汇总指标均以「谬误条数 / 总抽取条数（x/y）」形式展示，不再显示裸百分比。平均列（跨画像/跨组）聚合为「总谬误条数合计 / 总抽取条数合计（谬误比例%）」，即 x/y(p%)。合格判定依据括号内百分比。

#### 1.2.1 事实性谬误率

| 项目         | 说明                                                                         |
| ---------- | -------------------------------------------------------------------------- |
| **计算公式**   | `事实性错误陈述数 / 事实性陈述总数 × 100%`（error\_type=factual）                           |
| **展示格式**   | 单元格：`x/y`（x=事实性谬误条数，y=该类陈述总数）；平均列：`x/y(p%)`（p=合计谬误比例%）                     |
| **数据来源**   | `round_indicator_{model}_{profile}_{round}.json` → `statement.evaluations` |
| **合格标准**   | ≤5%（以平均列括号内百分比判定）                                                          |
| **N/A 条件** | 该轮次无 factual 类型陈述时显示 `-`（分母为 0 无法计算）                                       |

#### 1.2.2 逻辑性谬误率

| 项目         | 说明                                                                         |
| ---------- | -------------------------------------------------------------------------- |
| **计算公式**   | `逻辑性错误陈述数 / 逻辑性陈述总数 × 100%`（error\_type=logical）                           |
| **展示格式**   | 单元格：`x/y`；平均列：`x/y(p%)`                                                    |
| **数据来源**   | `round_indicator_{model}_{profile}_{round}.json` → `statement.evaluations` |
| **合格标准**   | ≤5%（以平均列括号内百分比判定）                                                          |
| **N/A 条件** | 该轮次无 logical 类型陈述时显示 `-`                                                   |

#### 1.2.3 指令性谬误率

| 项目         | 说明                                                                         |
| ---------- | -------------------------------------------------------------------------- |
| **计算公式**   | `指令性错误陈述数 / 指令性陈述总数 × 100%`（error\_type=instructional）                     |
| **展示格式**   | 单元格：`x/y`；平均列：`x/y(p%)`                                                    |
| **数据来源**   | `round_indicator_{model}_{profile}_{round}.json` → `statement.evaluations` |
| **合格标准**   | ≤5%（以平均列括号内百分比判定）                                                          |
| **N/A 条件** | 该轮次无 instructional 类型陈述时显示 `-`                                             |

#### 1.2 谬误率汇总

| 项目         | 说明                                                                         |
| ---------- | -------------------------------------------------------------------------- |
| **计算公式**   | `(事实性+逻辑性+指令性+other 谬误陈述数合计) / 全量有效陈述总数 × 100%`                            |
| **展示格式**   | 单元格：`x/y`（x=全部分类谬误条数，y=全部有效陈述条数）；平均列：`x/y(p%)`（p=跨画像/跨组合计谬误比例%）            |
| **数据来源**   | `round_indicator_{model}_{profile}_{round}.json` → `statement.evaluations` |
| **合格标准**   | 参考值 -（无强制合格线，用于整体观察谬误密度）                                                   |
| **N/A 条件** | 该轮次无任何有效陈述时显示 `-`                                                          |

| **合格标准**   | ≥90分                                                                |
| **N/A 条件** | 无交叉评审文件或实验组未启用辩论时显示 `-`                                             |
