## 教学正文

## I — 法律问题

本节点要解决的核心问题是：面对一项研发成果，如何先确定其是否属于专利法保护的客体，再理解专利权的基本特征、中国专利制度的规范体系、制度功能以及申请与审查的基本位置。审查与代理虽然立场不同，但都必须先回答“保护什么、权利边界在哪里、案件进行到哪一步”。

## R — 适用规则

### 1. 专利制度的目的

根据本轮教学材料列明的《专利法》第一条，专利制度旨在保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，并促进科学技术进步和经济社会发展。由于检索上下文未提供该条原文，本处仅按输入材料作制度框架说明，不扩展未核验的条文措辞。

制度目的回答的是“为什么建立专利制度”，不能直接替代具体的保护客体、授权条件或侵权判断。

### 2. 三类专利保护客体

《专利法》第二条列明专利保护的三种客体：发明、实用新型和外观设计。〔RAG: 本轮检索上下文为空，无法提供可直接引用的检索原文；该三类客体来自用户提供的当前节点知识点清单〕

其中，发明和实用新型通常围绕技术方案进行客体识别；外观设计则围绕产品的整体或者局部的形状、图案或者其结合，以及色彩与形状、图案的结合所形成的设计进行识别。〔RAG: 本轮检索上下文为空，无法提供《专利法》第二条第四款的原文；该内容来自专家 B 草稿列明的法条概括〕宣传图可以展示产品外形，但宣传图本身不当然等于外观设计客体，仍须回到具体产品设计及法定定义判断。

### 3. 专利权的基本特征

本节点要求掌握独占性、时间性和地域性。独占性说明专利权在法定权利范围内具有排除他人实施的效果；时间性说明这种效果不是永久存在；地域性说明专利权原则上依授予权利的国家或地区发生法律效力，不能当然推及全球。具体期限、地域规则和例外事项必须依据适用法域的现行法条核验。

### 4. 中国专利制度体系

中国专利制度的基本规范与审查材料包括专利法、专利法实施细则和专利审查指南。专利法提供上位法律规范，实施细则承担程序和操作层面的衔接，审查指南用于理解审查机关在具体案件中的审查方法和判断路径。三者在法律效力和使用功能上不能简单等同，审查指南也不能脱离上位法被理解为独立创设授权条件的依据。

### 5. 制度运行特点

根据当前节点材料，中国专利制度具有早期公开、延迟审查，以及初步审查制与实质审查制并存等运行特点。本轮检索上下文未提供具体历史年份、程序期限或审查案例，因此这里只保留制度层面的概括，不据此推导具体案件结论。

## A — 规则适用

### 分析顺序：客体—阶段—边界—功能

第一步，看保护客体。代理人要把客户的技术事实转化为法律上的保护对象，先区分发明、实用新型和外观设计；审查员则以法定客体为入口，确定申请进入何种审查路径。

第二步，看程序阶段。研发完成是技术事实，提出申请是程序行为，审查是行政审查过程，授权是取得专利权的法律结果。研发完成不能自动产生专利权，提出申请也不等于已经取得完整的专利权。不同阶段对应的权利效果、审查事项和代理任务并不相同。

第三步，看权利边界。专利权的独占性必须与时间性、地域性同时理解。看到“排他”或“独占”时，不能直接推导出全球有效、永久存在或不受范围限制；具体权利范围、保护期限和法域效力，应分别核对适用法律。

第四步，看制度功能。专利制度通过权利保护与技术公开相联系，发挥激励发明创造、促进技术应用和推动经济社会发展的作用。但制度目的只能解释制度设计，不能证明某项成果当然属于专利客体或当然符合授权条件。

### 审查与代理双视角

从代理视角，重点是准确识别成果性质、选择合适的保护类型、按程序阶段准备申请和回应材料，并避免把商业价值当成法律结论。从审查视角，重点是依照法定保护客体、适用规范和相应程序，判断申请是否满足进入及继续审查的条件。两种视角共同遵循同一条主线：先定客体，再辨阶段，最后核对权利边界。

### 常见误区与区分判据

误解一：“研发完成就已经取得专利权。”正解推理是：研发完成只是技术事实，专利权的取得还涉及申请、审查和授权等法律程序。区分判据是看题干是否已经出现授权这一法律结果，不能只看技术是否完成。

误解二：“专利权就是全球永久排他权。”正解推理是：独占性只是专利权的一项属性，还要受时间性、地域性及具体权利范围限制。区分判据是分别追问“在哪个法域”“持续多久”“排除何种实施行为”。

误解三：“成果有商业价值，所以必然应当授予专利。”正解推理是：商业价值可以说明申请动机或市场意义，但不能替代法定客体和授权条件。区分判据是把制度目的与具体法律要件分开。

误解四：“宣传图本身就是外观设计。”正解推理是：外观设计保护的是符合定义的产品整体或局部设计，宣传图只是可能承载或展示该设计的材料。区分判据是看是否存在对应的产品设计及其法定设计要素，而不是只看是否有一张图片。

误解五：“专利法、实施细则和审查指南可以互相替代。”正解推理是：三者在规范层级、程序衔接和审查说明方面功能不同。区分判据是先确定问题属于法律原则、程序操作还是审查判断方法，再查相应材料。

## C — 结论

专利法律制度基础的稳定判断框架是“客体—阶段—边界—功能”：先识别发明、实用新型和外观设计，再区分研发、申请、审查和授权，继而在时间性和地域性边界内理解独占性，最后把具体问题放回专利法、专利法实施细则和专利审查指南构成的制度体系中。专利制度具有激励创新、促进公开、推动应用和促进经济社会发展的功能，但这些功能不能替代具体法定要件。

### 从研发方案到专利制度边界（anchor_scenario）

> 某科技公司研发出一种用于储能设备的温控结构，同时制作了一张展示设备外形的宣传图。研发负责人认为，只要成果具有商业价值，就可以用“一个专利”全部保护，并且技术完成后即可在全球永久排除他人。代理人却先追问：技术方案与外观表达是否属于同一种保护客体？如果准备在中国申请，案件现在处于研发、申请、审查还是授权阶段？审查员则需要从法定保护客体和适用程序出发，判断申请应进入何种审查路径。

**锚定**：用研发、代理和审查三个角色锚定三类保护客体、专利权独占性及其时间地域边界、程序阶段和制度功能。

**先想一想**：面对同一产品中的技术结构和外观展示材料，你会先确认保护客体，还是先判断商业价值？为什么？

### 法条入口：制度目的与保护客体（legal_anchor）

- **《专利法》第一条**：第一条用于理解专利制度为什么存在：保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，并促进科学技术进步和经济社会发展。
- **《专利法》第二条**：第二条确定专利保护的三类基本客体：发明、实用新型和外观设计，先完成类型识别，再进入相应的申请、审查和保护判断。
- **《专利法》第二条第四款**：第二条第四款围绕产品整体或局部的形状、图案、色彩及其结合规定外观设计的对象范围；宣传图可以展示设计，但宣传图本身不当然等于外观设计客体。

**为何重要**：制度目的回答“为什么保护”，第二条回答“保护什么”，二者共同构成后续授权、申请、审查和保护课程的入口。掌握这一入口，才能避免把商业价值、技术事实、宣传材料和法定保护客体混为一谈。

### 案例演示：从同一项目识别不同客体（worked_example）

**案情/例题**：甲公司研发了一种储能设备温控结构，同时制作了一张展示该设备外形的宣传图。负责人要求代理人把结构、设备外观和宣传图都称为“一个专利对象”，并主张研发完成后即可在所有国家永久排除他人。请演示审查与代理双视角下的基础判断顺序。
**适用规则**：《专利法》第一条关于制度目的的规定；《专利法》第二条关于发明、实用新型和外观设计三类保护客体的规定；《专利法》第二条第四款关于外观设计对象的规定。关于具体期限、程序期限和跨法域效力，本轮检索上下文未提供直接依据。
**分步推演**：
1. 先区分事实内容。温控结构解决设备运行中的技术问题，教学上应先进入发明或实用新型的技术方案客体识别；设备外观则可能涉及外观设计，但仍须核对是否对应产品整体或局部的法定设计对象。 → *第一步：区分技术方案与外观表达。*
2. 再处理宣传图。宣传图是展示或记录外观的材料，不因为具有商业价值或展示了产品外形，就自动成为外观设计客体；需要回到其所对应的产品设计和法定定义。 → *第二步：材料载体不当然等于受保护客体。*
3. 随后区分程序阶段。研发完成属于技术事实，提出申请属于程序行为，审查属于行政审查过程，授权才是取得专利权的法律结果；不能把研发完成直接等同于专利权产生。 → *第三步：把研发、申请、审查和授权分开。*
4. 最后检查权利边界。即使将来取得专利权，独占性仍须与时间性、地域性和具体权利范围一起理解，不能由此推出全球永久排他。制度目的可以解释公开与保护的交换关系，但不能替代客体识别和其他法定条件。 → *第四步：在时间、地域和法定范围内理解独占性。*
**结论**：代理人应先将温控结构与设备外观分别进行客体识别，再按照案件所处阶段处理申请和审查问题；宣传图本身不当然构成外观设计客体。研发完成不能直接产生专利权，未来的专利权也不是全球永久权利。
**本题要点**：遇到复杂研发材料时，按“客体—阶段—边界—功能”顺序组织事实和法律判断。

### 把专利制度骨架翻译成人话（verbal_explanation）

我们先不急着把所有专利条文都背下来，先把骨架立住。第一问是“法律上到底要保护什么”，也就是先区分发明、实用新型和外观设计。第二问是“案件走到哪一步”，研发完成只是技术事实，提出申请是程序动作，经过审查并获得授权才涉及专利权的取得。第三问是“权利边界在哪里”，专利权虽然有排他性，但不是全球自动有效，也不是永久存在，还要看具体法域、期限和权利范围。最后再问“制度为什么这样安排”，专利制度通过保护与公开的制度安排鼓励创新、推动应用和技术进步。代理人要把客户的事实翻译成合适的保护对象，审查员要按法定对象和程序判断能否继续审查；两者都不能只凭商业价值或一个关键词下结论。

**点破术语**：保护客体；独占性；时间性；地域性；程序阶段

**类比**：可以把专利制度理解为一套有条件、有边界的公共交换机制：申请人按规则公开成果，国家在满足法律条件后给予一定范围、一定期间和一定地域内的排他性保护。这个类比只用于理解结构，不替代法律要件。

### 专利基础四问表（mnemonic）

**记忆锚**：专利基础四问表：一问“保什么”，二问“走到哪”，三问“边界在哪”，四问“为何保护”。复盘时必须按此顺序检查，不以口诀直接替代法条和事实判断。
**映射**：
- 保什么
- 走到哪
- 边界在哪
- 为何保护
**何时用**：阅读客户咨询、申请文件、审查意见或考试题干时，先用四问表定位问题，再进入后续的授权条件、保护范围或程序救济节点。

### 复盘同一成果的审查与代理视角（reflect_prompt）

**反思问题**：同一项研发成果交给代理人、审查员和权利人时，为什么三者都要先定位保护客体和程序阶段，但各自的关注重点并不完全相同？

**关注要点**：代理人是否先把技术事实或外观表达转化为合适的法定保护对象；审查员是否依据法定客体和案件阶段确定相应审查路径；权利人是否把独占性与时间性、地域性及具体保护范围同时理解；是否把制度目的或商业价值误当成当然授权或当然侵权结论

**连接**：连接到本节点的三类保护客体、专利权独占性与时间地域边界、中国专利制度体系，并为后续授权条件、申请程序、保护范围和救济节点建立接口。

### 专利法律制度基础关系网（knowledge_synthesis）

**知识框架**：
- 专利制度基本概念与特征：专利权具有独占性，但其法律效果受时间性、地域性和具体权利范围限制。
- 中国专利制度体系：专利法、专利法实施细则和专利审查指南共同构成实务中的主要规范与审查材料体系，三者功能和效力需要区分。
- 专利保护的三种客体：发明、实用新型和外观设计是专利法上的基础分类，客体识别是申请和审查的入口。
- 专利制度的作用：通过保护专利权人合法权益、鼓励发明创造、促进技术应用和推动科学技术进步等机制发挥制度功能。
- 中国专利制度发展历程与特点：当前节点材料概括了早期公开、延迟审查，以及初步审查制与实质审查制并存；具体历史和程序细节仍需核验权威材料。
**概念关系**：制度目的回答“为什么保护”，保护客体回答“保护什么”，专利权特征回答“保护边界是什么”。；先识别保护客体，再按照案件所处阶段进入申请、审查或权利运行判断。；独占性提供排他效果，时间性和地域性限定其边界；制度目的解释制度安排，但不替代具体法定要件。；代理人负责将事实转化为适当的保护对象并组织程序策略，审查员负责依照法定对象和程序判断审查事项，二者共同依赖同一制度框架。
**必记**：发明、实用新型和外观设计是本节点必须掌握的三类专利保护客体。；专利权具有独占性，但不能由此推出全球有效、永久存在或不受具体范围限制。；研发完成、提出申请、审查和授权是不同的事实或程序阶段，不能相互替代。；专利法、实施细则和审查指南要结合问题类型分别使用，不能简单互相替代。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **三类保护客体**：先区分发明、实用新型和外观设计，再进入具体申请、审查和保护判断。
- **专利权三项特征**：专利权具有独占性，但同时受时间性和地域性限制。
- **中国制度体系**：专利法、专利法实施细则和专利审查指南共同构成主要规范与审查材料体系，但功能和效力不同。
- **制度作用**：专利制度通过权利保护与技术公开，鼓励发明创造、促进应用并推动科学技术进步和经济社会发展。
- **程序阶段**：研发、申请、审查和授权各有不同法律意义，不能把技术完成或提交申请等同于取得专利权。
**必背**：专利保护的三类基本客体是发明、实用新型和外观设计。；专利权的基本特征是独占性、时间性和地域性。；判断专利基础问题时先看客体，再看程序阶段，最后看权利边界。；制度目的不能替代具体保护客体、授权条件和程序要求。
**一句话总结**：专利制度基础的主线是：先定保护客体，再辨程序阶段，并在时间与地域边界内理解专利权及其制度功能。
