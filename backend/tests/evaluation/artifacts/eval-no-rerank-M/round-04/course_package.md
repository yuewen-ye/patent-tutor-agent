## 教学正文

## I：法律问题

本节唯一主节点是“专利法律制度基础”。面对智能制造方案，首先要解决四个基础问题：它可能属于哪类专利保护客体；专利制度具有什么基本特征和作用；中国专利制度由哪些规范文件构成；申请、审查、公布和授权分别处于什么阶段。新颖性、创造性、优先权和侵权判定将在后续节点中分别学习，本节只建立进入这些问题的制度入口。

## R：适用规则

### 1. 三类专利保护客体

《专利法》第二条规定，发明创造包括发明、实用新型和外观设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

发明是对产品、方法或者其改进提出的新的技术方案；实用新型是对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计则针对产品整体或局部的形状、图案、色彩及其结合，要求适于工业应用并富有美感。〔RAG: 中华人民共和国专利法.txt — 第二条：发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计〕

用智能制造方案举例：机器人关节的机械连接结构，应从产品结构和技术方案角度识别可能的发明或实用新型客体；视觉检测和控制方法，应从方法或控制技术方案角度分析发明客体；产品外壳的形状、图案或色彩组合，则进入外观设计客体的识别。不能仅凭“智能制造”这个行业标签决定专利类型，也不能把自然现象、单纯信号或单纯能量直接当作发明技术方案；具体判断仍须结合申请文件和正式审查标准。

### 2. 专利制度的基本特征和作用

专利制度的三个基础特征可以这样理解：独占性是指在法定保护范围内具有排他效果；时间性是指保护并非无限期存在；地域性是指保护效果受具体法域边界限制。三者必须合并理解，不能把专利权理解为无期限、无地域限制的绝对垄断。

专利制度通过一定期限和范围内的排他保护激励发明创造，并通过申请文件的公开促进技术传播、技术应用和经济发展。这里是制度功能的学习性概括，检索上下文没有提供一条专门概括该功能的法条原文，因此不把它伪装成逐字法条。

### 3. 中国专利制度体系

中国专利制度以《专利法》为基本法律，以《专利法实施细则》细化申请、审查等程序，并由《专利审查指南》提供审查操作层面的规则说明。遇到具体问题时，可以采用“三层检索法”：先找《专利法》的基本权利和授权条件，再找实施细则中的程序要求，最后核对审查指南对具体审查事项的解释。审查指南是审查操作的重要材料，但不能替代法律和实施细则本身。

### 4. 申请、审查、公布与授权

《专利法实施细则》第五十条规定，初步审查包括审查申请是否具备规定文件和其他必要文件、文件是否符合规定格式，并审查该条列明的事项。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十条：初步审查是审查专利申请是否具备专利法第二十六条或者第二十七条规定的文件和其他必要的文件、这些文件是否符合规定的格式，并审查列明事项〕

因此，“已提交申请”只说明申请程序启动；“通过初步审查”主要说明相应文件、格式及列明事项经过了该阶段审查，不能直接替代全部授权条件判断。检索材料还显示，发明申请经初步审查后，除予以驳回的外，应当立即予以公布。〔RAG: 中华人民共和国专利法实施细则.txt — 国务院专利行政部门对该申请进行初步审查后，除予以驳回的外，应当立即将申请予以公布〕公布是申请文件向社会公开的程序节点，不等于已经授予专利权。

检索材料说明，实用新型和外观设计申请以初步审查为主要授权前程序，授权前不进行与发明相同的全面实质审查；这不意味着它们不受专利条件约束，也不意味着通过初步审查即可当然证明权利稳定。〔RAG: 专利法律知识详细解读.txt — 实用新型、外观设计申请进行初步审查，授权前未对其实质性授权条件进行审查；权利评价报告可对可专利性进行检索、分析和评价〕关于“早期公开、延迟审查”的具体历史年代和制度变迁，当前检索上下文未提供足够资料，本节不作超出证据范围的历史断言；只需先掌握现行制度中公开、初步审查、实质审查和授权程序的区别。

## A：规则适用

对一套机器人装配单元，应按以下顺序处理：

1. **拆分技术内容。** 把机械结构、控制方法和产品外观分别列出，判断各自可能对应的保护客体，而不是用行业名称一概归类。
2. **定位程序阶段。** 查明材料说的是提交申请、初步审查、发明申请公布、实质审查还是授权。不同阶段的法律效果不同。
3. **核对授权条件。** 发明和实用新型的三性属于《专利法》第二十二条规定的后续实体判断入口。〔RAG: 中华人民共和国专利法.txt — 第二十二条：授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性〕本节不提前用一个具体公开文件去完成新颖性判断，也不把创造性和新颖性混为一谈。
4. **确认权利效力。** 只有在明确授权状态和适用保护范围后，才进入专利权保护和侵权判定。申请提交或申请公布本身不能直接等同于完整专利权。

可以把这条主线固定为：**客体—阶段—条件—效力**。客体回答“保护什么”；阶段回答“程序走到哪里”；条件回答“是否满足授权要求”；效力回答“是否已经产生以及如何行使专利权”。

## C：结论

专利法律制度基础的核心不是把所有专利问题混在一起，而是建立稳定的分类顺序。对智能制造复合技术，应先依据具体技术内容识别发明、实用新型或外观设计，再区分申请、初步审查、公布、实质审查和授权，之后才分别讨论新颖性、创造性、优先权、保护范围和侵权。

常见误区及区分判据如下：

1. **误解原话：**“只要属于智能制造，就当然是发明专利。”
   **正解推理：**专利类型取决于具体保护对象和技术内容，不取决于行业名称；机械结构、控制方法和外观设计可能需要分别分析。
   **区分判据：**先问“权利要求或申请内容具体保护什么”，再问“属于哪类客体”。

2. **误解原话：**“申请提交后就已经获得专利权。”
   **正解推理：**提交申请只是启动程序；申请还要经历相应审查和授权，公布也只是程序公开节点。
   **区分判据：**看到“提交”“公布”“授权”时，分别记录日期和法律事件，不使用一个词替代另一个词。

3. **误解原话：**“初步审查通过就证明新颖性、创造性和实用性全部成立。”
   **正解推理：**初步审查关注文件、格式及法律规定的明显事项；它不能概括为对全部授权条件作出最终肯定结论。
   **区分判据：**先查看审查类型和适用专利类别，再判断该程序节点能够支持多大的法律结论。

4. **误解原话：**“新颖性、创造性和侵权判定只是同一个‘是否相同’问题。”
   **正解推理：**它们的判断对象、时间基准和法律后果不同；本节只建立制度入口，后续节点再分别学习公开信息、在先申请和权利要求比对。
   **区分判据：**先确认问题是在讨论授权条件、申请程序，还是授权后的权利保护，不能跨问题直接套用结论。

### 专利制度基础的法条锚定（legal_anchor）

- **《专利法》第二条**：第二条把发明创造分为发明、实用新型和外观设计：发明针对产品、方法或者其改进提出新的技术方案，实用新型针对产品的形状、构造或者其结合提出适于实用的新的技术方案，外观设计针对产品整体或局部的形状、图案、色彩及其结合提出适于工业应用并富有美感的新设计。
- **《专利法》第二十二条**：第二十二条规定发明和实用新型授权应具备新颖性、创造性和实用性，并分别规定现有技术和申请日以前在先申请后来公开的处理方式；这三性和时间规则属于后续实体判断的入口。
- **《专利法实施细则》第五十条**：第五十条说明初步审查主要检查申请文件和其他必要文件是否齐备、格式是否符合规定，并审查该条列明的明显不符合事项。
- **《专利法实施细则》第五十二条**：检索材料显示，发明申请经初步审查后，除予以驳回的外，应当立即公布；公布是程序节点，不等于已经授权。

**为何重要**：本节点的主线是先识别客体，再区分制度和程序阶段，最后理解授权条件与权利效力。掌握这些法条入口，才能在后续学习新颖性、创造性、优先权和侵权判定时避免把不同问题混为一谈。

### 从机器人系统事实到制度定位（worked_example）

**案情/例题**：某智能制造企业提交一份申请，文件同时描述机器人本体的机械连接结构、视觉检测控制方法和产品外观。项目负责人认为“智能制造”已经决定了专利类型，并认为文件通过形式检查后就获得完整专利保护。请演示如何进行制度基础定位。
**适用规则**：《专利法》第二条用于识别发明、实用新型和外观设计客体；《专利法实施细则》第五十条用于理解初步审查范围；《专利法实施细则》第五十二条用于区分发明申请公布与授权。
**分步推演**：
1. 先拆分技术事实。机械连接结构属于产品结构层面的内容，可能进入发明或实用新型的客体分析；视觉检测控制方法属于方法或控制技术方案，应进入发明客体分析；产品外观的形状、图案或色彩组合属于外观设计客体分析。行业名称本身不能替代对具体技术内容的识别。 → *第一步：按技术内容识别可能的保护客体。*
2. 再定位程序阶段。提交申请只表示申请程序已经启动；初步审查依照第五十条检查文件、格式及列明的明显事项，不能直接等同于完成全部授权条件审查。 → *第二步：区分申请提交、初步审查与实体授权条件。*
3. 如涉及发明申请，还要区分初步审查后的公布与之后的实质审查、授权。第五十二条所涉公布是向社会公开申请文件的程序节点，并不等于专利权已经产生。 → *第三步：区分公布和授权。*
4. 完成制度定位后，才分别进入新颖性、创造性、实用性或外观设计相应条件的判断。不能因为申请文件涉及多个技术内容，或者已经完成某一程序步骤，就直接得出专利有效或侵权成立等结论。 → *第四步：将后续实体判断与基础制度定位分开。*
**结论**：该申请应先按机械结构、控制方法和产品外观分别识别可能的保护客体，再确认每一申请所处的审查阶段。提交申请或通过初步审查，均不能单独推出已经取得完整、稳定的专利权；新颖性、创造性和实用性仍需依据相应规则另行判断。
**本题要点**：面对智能制造复合技术，固定使用“客体—阶段—条件—效力”的顺序，避免由行业标签或程序节点跳到授权结论。

### 专利基础四问表（mnemonic）

**记忆锚**：专利基础四问表：客体—阶段—条件—效力。每遇到一个专利问题，依次填写四栏，不用前一栏的答案替代后一栏。
**映射**：
- 客体
- 阶段
- 条件
- 效力
**何时用**：阅读智能制造研发记录、申请文件或专利争议材料时，先写出四栏，再分别填入事实和依据；尤其在看到“已申请”“已公开”“已授权”等表述时使用。

- 专利制度基本概念与特征：专利权具有独占性、时间性和地域性，排他效果受法定期限、法域和保护范围共同限制。
- 中国专利制度体系：专利法规定基本制度，专利法实施细则细化申请和审查程序，专利审查指南提供审查操作层面的说明。

- 专利制度的作用：通过法定期限和范围内的排他保护激励发明创造，并通过申请文件公开促进技术传播、技术应用和经济发展；检索上下文未提供关于该制度功能的单独法条原文，故此处作为制度目的概括。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **三类保护客体**：发明、实用新型、外观设计；先看具体技术内容，再确定制度入口。
- **三项制度特征**：独占性说明排他效果，时间性说明保护有期限，地域性说明保护受法域限制。
- **制度体系**：专利法定基本规则，实施细则细化程序，审查指南说明审查操作。
- **审查阶段**：申请提交、初步审查、发明申请公布、实质审查和授权彼此不同。
- **制度功能与历史边界**：以有限排他权促进技术公开和应用；历史沿革的具体细节须以可靠资料核验。
**必背**：专利基础四问：客体—阶段—条件—效力。；发明、实用新型和外观设计是《专利法》第二条规定的三类客体。；初步审查不当然等于完成全部授权条件审查，发明申请公布也不等于授权。；专利制度的独占性必须和时间性、地域性一起理解。
**一句话总结**：先辨具体客体与所处阶段，再谈授权条件和权利效力；专利制度以有限保护促进技术公开与应用。
