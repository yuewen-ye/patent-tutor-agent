## teaching_content

## 1. 场景导入
某研发团队做完一款关节模组，既想尽快申请专利，又计划下月参加国际展会现场演示。他们一边问：这个技术方案到底能走发明、实用新型还是外观设计？另一边又怕演示把新颖性毁掉。代理视角要先把保护客体和制度特点讲清；审查视角则盯申请日、公开日与早期公开延迟审查如何影响后续流程。

## 2. 人话解释
专利制度给发明创造人一段‘时间限定的独占权’，核心特征是独占性、时间性和地域性：专利权人在法定保护期限和地域范围内，对未经许可实施其专利的行为享有排他性控制或请求权。具体权利内容和限制留待相应节点展开。中国专利制度以《专利法》为骨架，配套《专利法实施细则》和《专利审查指南》，形成‘法律—细则—指南’三层体系。保护客体只有三种：发明、实用新型和外观设计。制度作用是激励创造、促进公开、推动应用与经济发展。中国特色还包括早期公开、延迟审查，以及发明走实质审查、实用新型与外观设计主要走初步审查的并存安排。

## 3. 法条回扣
《专利法》第二条把发明创造限定为发明、实用新型和外观设计，并分别给出定义：发明是产品、方法或其改进的新的技术方案；实用新型是产品形状、构造或其结合的适于实用的新的技术方案；外观设计是产品整体或局部的形状、图案或其结合以及色彩与形状、图案的结合作出的富有美感并适于工业应用的新设计。〔RAG: 专利法.txt — 第二条〕授权实质条件则由第二十二条（发明和实用新型）和第二十三条（外观设计）分别规定。〔RAG: 专利法.txt — 第二十二条；专利法.txt — 第二十三条〕

## 4. 类比 / 口诀
把三种客体想成三种‘门票’：发明票覆盖产品和方法；实用新型票只管产品形状构造；外观设计票卖的是工业上可应用的美观设计。口诀用‘独一时地 + 三客三层 + 早公延审’：独占、时间、地域；发明/实用新型/外观设计；专利法/细则/指南；早期公开、延迟审查（发明专利申请通常程序）、初审与实审并存。类比边界：这只帮助记忆制度轮廓，不替代新颖性、创造性的具体对比规则。

## 5. 应试提示
看到‘保护什么’先锁定第二条三种客体；看到‘权利有什么特点’答独占性、时间性、地域性；看到‘中国专利怎么管’答法律—细则—指南，以及早期公开延迟审查、初审与实审并存。代理逻辑先选客体、估保护期、排公开节奏；审查逻辑先核申请文件与公开时点，再进入三性。常见陷阱是把商业方法等非法定客体硬塞进三种客体，或把‘早期公开’误说成‘一申请就授权’。
