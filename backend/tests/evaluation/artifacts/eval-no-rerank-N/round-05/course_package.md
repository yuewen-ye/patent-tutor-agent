## 教学正文

## I — 法律问题

以审查与代理双视角复盘专利实务，首先要解决四个相互衔接但不能混同的问题：第一，技术交底属于哪一种法定保护客体；第二，发明或实用新型是否进入新颖性、创造性和实用性的判断框架；第三，公开事实是否可能触发法定的不丧失新颖性宽限期；第四，案件处于何种审查或救济程序。专利实务的基本顺序是“先定判断对象，再定法律规则，最后形成结论”。

## R — 适用规则

### 1. 三类保护客体：先问“要保护什么”

〔RAG: 中华人民共和国专利法.txt — 第二条：本法所称的发明创造是指发明、实用新型和外观设计〕《专利法》第二条把“发明创造”作为三类法定客体的总称：发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明、实用新型和外观设计的分别定义〕

因此，代理人拿到技术交底时，应把“产品名称”拆解为具体方案：方法或产品技术改进，先走发明客体判断；产品的形状、构造或其结合，才进入实用新型客体判断；产品整体或局部的视觉设计，进入外观设计客体判断。审查人员也应从同一法定分类起步。商业价值、技术名称新颖或附有图纸，都不能替代客体要件。

### 2. 授权条件：客体成立后再分辨“三性”

〔RAG: 中华人民共和国专利法.txt — 第二十二条：授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性〕对于发明和实用新型，第二十二条确立了新颖性、创造性和实用性三个不同判断门槛。新颖性关注该发明或者实用新型是否属于现有技术，以及是否存在同样发明创造的申请在先、申请后公布情形；创造性关注相对于现有技术是否达到法律要求的实质性特点和进步；实用性关注能否制造或者使用并产生积极效果。〔RAG: 中华人民共和国专利法.txt — 第二十二条：现有技术是申请日以前在国内外为公众所知的技术；实用性是能够制造或者使用并且能够产生积极效果〕

三性不能用一句“有对比文件”概括。新颖性重点是公开内容与判断对象的对应；创造性不是看到一份材料就机械否定，而要依其专门规则评价相对于现有技术的实质性特点和进步；实用性则处理方案能否制造或使用及其效果问题。抵触申请属于新颖性判断中的特殊申请在先、申请后公开情形，不能直接替代创造性评价。

### 3. 公开例外：六个月不是普遍安全期

〔RAG: 中华人民共和国专利法.txt — 第二十四条：申请专利的发明创造在申请日以前六个月内，有四种法定情形之一的，不丧失新颖性〕第二十四条列举的情形包括：国家出现紧急状态或者非常情况时为公共利益目的首次公开；在中国政府主办或者承认的国际展览会上首次展出；在规定的学术会议或者技术会议上首次发表；以及他人未经申请人同意而泄露其内容。

所以，“申请日前六个月内公开”只是时间条件的一部分，不是自动享有宽限期。还要核对公开类型、是否首次公开及相应手续。例如检索材料显示，首次展出情形要求申请人在提出申请时声明，并在申请日起两个月内提交由展览会主办单位或组委会出具的证明材料。〔RAG: 专利法专题讲座.txt — 首次展出宽限期：提出申请时声明，并自申请日起两个月内提交展出及日期证明材料〕普通商业展会不能仅凭“展会”二字直接归入第二十四条。

宽限期只处理特定公开对新颖性的法定影响，不等于把公开日改成申请日，也不等于免除创造性、实用性或其他授权条件。〔RAG: 专利法律知识详细解读.txt — 宽限期的效力：仅针对特定公开在一定期限内不视为影响申请人的新颖性和创造性的现有技术，并非把公开日看作申请日〕

### 4. 不授权主题与实用性的区分

〔RAG: 中华人民共和国专利法.txt — 第二十五条：对科学发现、智力活动的规则和方法、疾病的诊断和治疗方法等不授予专利权〕不授权主题是客体层面的排除问题，不能与实用性混为一谈。疾病的诊断和治疗方法可能具有实际用途，但仍须先核对第二十五条的法定排除；反过来，某一技术方案没有达到实用性要求，也不意味着它必然属于第二十五条列举的主题。判断时先问“这是什么法律客体”，再问“是否满足三性及其他条件”。

### 5. 规范层级和程序定位

中国专利制度的基础规范包括专利法、专利法实施细则和专利审查指南。专利法提供基本实体和程序框架，实施细则细化申请、审查及实施事项，审查指南为审查实践提供操作性标准；具体指南章节仍应以当时有效文本核验。

〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请，依法授予专利权〕主管机关并非抽象背景，而是确定案件受理、审查和授权路径的程序基础。〔RAG: 中华人民共和国专利法实施细则.txt — 第四十二条：在初步审查、实质审查、复审和无效宣告程序中，法定情形下审查、审理人员应当自行回避〕程序公正还体现在回避等保障上。

检索材料还表明，发明专利申请经初步审查后，除予以驳回外应当公布；申请人可以提出延迟审查请求；不同类型申请的主动修改期间也有区别。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十六条、第五十七条：申请人可以提出延迟审查请求；发明申请在实质审查请求时及进入实质审查阶段通知书之日起三个月内可以主动修改，实用新型或外观设计自申请日起两个月内可以主动修改〕这说明公开时机、审查层次和修改节点不能相互替代。关于中国制度完整历史沿革，当前检索上下文未提供直接依据，本节不对具体历史年份和阶段作断言；“早期公开、延迟审查以及初步审查与实质审查并存”仅作为程序结构的学习提示。

## A — 双视角适用

代理视角的工作底稿可以按四步展开：一是将交底拆成方法、产品结构和视觉设计等事实单元；二是分别匹配发明、实用新型或外观设计客体；三是针对发明和实用新型分别核对新颖性、创造性、实用性，并针对外观设计适用相应规则；四是建立公开时间和证据清单，检查是否存在第二十四条法定情形及声明、证明要求。

审查视角则要确认申请客体、适用法源、程序阶段和证据材料是否对应。遇到“已展出所以一定丧失新颖性”或“六个月内所以一定安全”的说法，都应回到公开类型、时间、首次公开和手续逐项核验。遇到疾病诊疗方法、科学发现或智力活动规则等内容，则先处理第二十五条的客体排除问题，而不是直接跳到实用性结论。

## C — 结论

本节点应形成一条稳定主线：专利制度以独占性、时间性和地域性描述权利边界，以专利法、实施细则和审查指南构成规范体系，以发明、实用新型和外观设计组织保护客体；对发明和实用新型，再分别进入新颖性、创造性和实用性的判断。申请日前公开时，必须单独核对第二十四条的法定宽限期，不能把普通公开、抵触申请、创造性对比和不授权主题混成一个问题。审查与代理虽承担不同职责，但都应遵守“客体—规则—程序—证据—结论”的顺序。

### 从智能保温杯交底看三类保护客体（anchor_scenario）

> 晨星公司研发了一款智能保温杯，技术团队提交了三部分交底：第一部分是根据液体温度自动调整加热功率的控制方法；第二部分是杯体外侧防滑凹凸结构；第三部分是杯身局部图案与色彩组合形成的视觉设计。公司只说“要申请专利”，代理人却不能直接按产品名称作出结论，还要判断三部分分别属于什么法定客体，并进一步考虑公开时间、授权条件和申请文件安排。审查人员也要先确定客体，再依据相应程序和实体规则审查。

**锚定**：用同一产品中的方法、结构和视觉设计，锚定发明、实用新型、外观设计的客体边界以及代理与审查的共同起点。

**先想一想**：面对同一产品中的方法、结构和视觉设计，为什么不能只凭产品名称决定申请类型，还要分别识别其法律客体？

### 法条锚定：客体、三性、例外与程序（legal_anchor）

- **《中华人民共和国专利法》第二条**：第二条把发明创造分为发明、实用新型和外观设计：发明重在产品、方法或其改进的技术方案，实用新型限于产品形状、构造或其结合的技术方案，外观设计重在产品整体或局部的视觉设计。
- **《中华人民共和国专利法》第二十二条**：第二十二条规定发明和实用新型应具备新颖性、创造性和实用性，并把申请日前在国内外为公众所知的技术界定为现有技术。
- **《中华人民共和国专利法》第二十四条**：第二十四条规定申请日前六个月内发生法定四种公开情形之一的，在符合要求时不丧失新颖性；这是一项特定公开的时间例外，不是全面免除授权条件。
- **《中华人民共和国专利法》第二十五条**：第二十五条列举不授予专利权的主题，包括科学发现、智力活动的规则和方法、疾病的诊断和治疗方法等，并规定动物和植物品种的生产方法可以依照本法授予专利权。
- **《中华人民共和国专利法》第三条**：第三条规定国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请并依法授予专利权。
- **《中华人民共和国专利法实施细则》第四十二条**：实施细则第四十二条规定，在初步审查、实质审查、复审和无效宣告程序中，具有法定利害关系等情形的审查、审理人员应当自行回避，相关当事人或者利害关系人也可以要求回避。

**为何重要**：本节点的核心不是凭“创新”直觉下结论，而是先用法条确定保护客体，再区分三性、不授权主题和程序位置。掌握这些条文，才能同时满足代理布局的可操作性与审查复检的可核验性。

### 示范：从技术交底到客体与公开风险判断（worked_example）

**案情/例题**：甲公司提交智能料理机技术交底：第一，控制程序根据食材温度自动调整搅拌功率；第二，刀头连接部设置防松结构；第三，机身面板局部使用特定图案与色彩组合形成视觉效果。甲公司还称，方案已在申请日前四个月的普通商业展会上展示，询问三部分是否都能用同一种专利申请，以及展示是否当然不影响授权。请演示审查与代理共同采用的判断顺序。
**适用规则**：先适用《专利法》第二条识别发明、实用新型和外观设计的法定客体；再对发明和实用新型适用第二十二条的新颖性、创造性和实用性要求；若存在申请日前公开事实，再核对第二十四条的六个月法定情形及相应手续；涉及排除主题时核对第二十五条。
**分步推演**：
1. 先拆开“智能料理机”这一产品名称，分别确认每一部分实际要保护的是方法性技术方案、产品形状或构造，还是产品整体或局部的视觉设计。产品名称本身不能替代第二条的客体判断。 → *第一步：先定保护对象，不以产品名称归类。*
2. 自动根据食材温度调整搅拌功率，若其采用技术手段解决技术问题并形成技术方案，可进入发明客体分析；刀头连接部防松结构若保护产品形状、构造或其结合，可进入实用新型客体分析。 → *第二步：方法性技术方案看发明，产品形状构造方案看实用新型。*
3. 局部图案与色彩组合若主张的是产品局部的视觉设计，则沿外观设计客体分析；不能因为它附着在技术产品上，就自动改按发明或实用新型处理。 → *第三步：产品视觉设计沿外观设计路径处理。*
4. 展示发生在申请日前四个月，只能说明时间上落入“六个月内”的可能范围；还必须核对公开是否属于第二十四条列举的法定情形，例如中国政府主办或者承认的国际展览会上首次展出，并核对声明和证明材料要求。普通商业展会不当然等于法定国际展览会。 → *第四步：公开例外要同时核对公开类型、首次公开、时间和手续。*
5. 即使第二十四条例外成立，其作用也只是针对符合条件的特定公开不丧失新颖性，不替代第二十二条的创造性、实用性判断，也不排除第二十五条等其他审查问题。 → *第五步：宽限期是特定公开例外，不是全面授权通行证。*
**结论**：自动控温方法可以沿发明客体路径分析，防滑结构可以沿实用新型客体路径分析，局部图案色彩组合可以沿外观设计客体路径分析。普通商业展会公开通常不能仅凭“展会”二字适用第二十四条，是否属于法定国际展览会及是否完成声明、证明等手续必须进一步核验；即使宽限期成立，也不等于当然具备创造性、实用性或其他授权条件。
**本题要点**：处理专利交底时按“客体—三性与排除主题—公开例外—程序手续”的顺序核对，才能避免把申请类型、公开风险和授权条件混为一谈。

### 把客体、三性与公开例外讲成人话（verbal_explanation）

咱们处理一份专利交底，第一步不要急着问“这个想法新不新”，而要先问“客户到底要保护什么”。如果保护的是产品、方法或者改进形成的技术方案，走发明的客体判断；如果重点是产品本身的形状、构造或结合，才考虑实用新型；如果重点是产品整体或局部的图案、形状、色彩视觉效果，就看外观设计。客体放对以后，再看新颖性、创造性和实用性。客户说“我在展会上公开过，应该有六个月保护”，也不能直接答应，因为还要核对是否属于第二十四条列出的法定公开情形、是否是首次公开、是否及时声明并提交证明。最后要记住，审查人员和代理人的视角不同：审查人员重在按权限和程序核对规则，代理人重在把事实拆清、选择合适路径并提示证据风险；两者共同的起点仍然是法条。

**点破术语**：发明创造；发明；实用新型；外观设计；新颖性；不丧失新颖性宽限期

**类比**：可以把审查与代理共同使用的判断流程理解为“先分诊、再做检查”：客体识别像把患者分到正确科室，三性和不授权主题是后续检查项目，宽限期只是对特定公开事实的专门核对，不代表所有检查自动合格。该类比只帮助记忆流程，不能替代法条要件。

### 顺序记忆表：客—规—程—功与新—创—实—例（mnemonic）

**记忆锚**：两张顺序核对表。第一张是“客—规—程—功”：先定客体，再找规范，继而定程序，最后理解制度功能；第二张是“三性与例外”：新看公开、创看显而易见、实看能制造或使用并产生积极效果，另问“宽限是否法定、六个月、手续齐”。口诀只用于召回核对项目，不替代逐条适用。
**映射**：
- 客
- 规
- 程
- 功
- 新
- 创
- 实
- 例
**何时用**：复盘技术交底、判断申请类型或回答“公开后还能不能申请”时，先按“客—规—程—功”定位，再按“新—创—实—例”逐项检查；尤其不要把新颖性的单独对比、创造性的评价和宽限期的公开例外混成一个问题。

### 反思：同一技术交底如何用双视角复盘（reflect_prompt）

**反思问题**：如果客户同时提交了技术交底、展会展示记录和论文发表记录，作为代理人或审查人员，你会如何分别整理客体、公开日期、公开类型和适用规则？

**关注要点**：先把方法、产品结构和视觉设计分开，不让同一产品名称掩盖不同保护客体。；每一次公开都要单独核对日期、是否首次、面向公众的方式以及是否落入第二十四条法定情形。；新颖性、创造性和实用性解决的问题不同，不能因某一次公开可能适用宽限期就推定整体能够授权。；代理人关注申请布局、声明和证明材料，审查人员关注法定客体、审查程序和证据是否满足规则。

**连接**：连接到代理实务中的申请前风险评估和程序法学习经验：先固定事实、时间和主管程序，再选择规范并作结论。

### 专利法律制度基础的六层关系框架（knowledge_synthesis）

**知识框架**：
- 制度特征：专利权具有独占性、时间性和地域性，表示权利排他范围、存续边界和法域边界；具体期限和效力仍须回到法源核验。
- 规范体系：中国专利制度以专利法为基本规范，实施细则细化实施和程序事项，专利审查指南为审查实践提供操作性指引；具体指南条文需核对原文。
- 保护客体：专利法第二条将发明创造分为发明、实用新型和外观设计，分别对应产品或方法技术方案、产品形状构造技术方案和产品视觉设计。
- 制度作用：通过申请、公开和审查机制，在保护权利与公开技术信息之间建立制度联系，以激励发明创造、促进技术公开、推动技术应用和经济发展；这属于制度功能解释，不替代个案法条判断。
- 制度运行与发展特点：检索材料支持发明申请初步审查后公布、发明申请可请求延迟审查以及不同类型申请主动修改期间不同；初步审查、实质审查、复审和无效宣告是不同程序环节。关于更完整的历史沿革，检索上下文未提供直接依据，不作细化断言。
- 授权实质条件与例外：发明和实用新型通常要分别核对新颖性、创造性和实用性；申请日前六个月内的法定特定公开可能适用第二十四条，但必须核对公开类型、首次公开、声明和证明等条件。
**概念关系**：先定法定客体，再匹配申请类型和相应文件；客体识别不能由产品名称或商业价值替代。；确定发明或实用新型客体后，再区分新颖性、创造性和实用性的判断对象；新颖性不能与创造性混用，单一对比与组合评价的规则应在后续专门节点继续训练。；公开风险判断先核对公开方式和时间，再核对第二十四条例外及手续；宽限期不改变公开事实，也不替代创造性、实用性和其他授权条件。；专利法设定基本权利义务和实体门槛，实施细则细化程序事项，审查指南提供审查操作指引；审查人员和代理人虽职责不同，但都必须以可核验规范为起点。
**必记**：发明创造是发明、实用新型和外观设计的总称；发明、实用新型和外观设计的保护对象不能仅凭产品名称混同。；发明和实用新型的授权判断要区分新颖性、创造性和实用性：新颖性主要处理现有技术和法定申请在先公开问题，创造性处理相对于现有技术的实质性特点和进步，实用性处理能否制造或使用并产生积极效果。；抵触申请属于新颖性判断中的特殊申请在先、申请后公开情形，不能因此直接把它当作创造性评价材料；创造性是否成立仍须依适用规则评价现有技术。；第二十四条六个月宽限期只针对法定特定公开，并要求核对首次公开、时间及声明和证明手续；普通公开不能仅凭发生在六个月内就当然享有宽限期。；初步审查、实质审查、复审和无效宣告是不同程序；早期公开、延迟审查描述公开时机或审查安排，不能与具体审查环节互相替代。

### 速查卡：专利法律制度基础（summary_card）

**要点卡**：
- **制度特征**：独占性、时间性、地域性用于把握专利权边界，具体期限和效力须回到法源。
- **规范体系**：专利法定基本规则，实施细则细化程序，审查指南提供审查操作指引。
- **三类客体**：发明看产品、方法或改进的技术方案，实用新型看产品形状构造，外观设计看产品视觉设计。
- **三性判断**：新颖性、创造性、实用性各有判断对象，不能把公开、显而易见和可实施混为一谈。
- **公开例外**：第二十四条是六个月内特定公开的不丧失新颖性例外，必须同时核对法定情形和手续。
- **程序结构**：初步审查、实质审查、复审、无效宣告以及公开和延迟审查各有位置，不能机械等同。
**必背**：《专利法》第二条：发明创造包括发明、实用新型和外观设计，三者保护对象不同。；《专利法》第二十二条：发明和实用新型应具备新颖性、创造性和实用性，现有技术是申请日前在国内外为公众所知的技术。；《专利法》第二十四条：申请日前六个月内的法定特定公开，在满足法定条件和手续时不丧失新颖性。；先识别客体，再区分三性；看到公开事实时再单独核对第二十四条，不能把宽限期当作全面授权例外。
**一句话总结**：专利实务先以法定客体定方向，再以三性、公开例外和程序规则定路径。
