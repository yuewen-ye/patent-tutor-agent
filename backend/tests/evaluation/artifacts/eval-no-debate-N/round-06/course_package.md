## 教学正文

## I — 法律问题

本节点首先解决一个基础但决定后续审查与代理分析起点的问题：面对一项技术成果，应先确认其是否属于法定的发明创造类型；随后才可能讨论申请、审查、授权及权利保护。专利制度并非对一切创意当然给予保护，而是在法定客体、法定程序和法定授权条件之内运行。

从审查视角，应当先核对申请对象属于何种法定客体，并按法定职责受理、审查和授予专利权；从代理视角，应当在撰写和申请策略形成前，准确把技术成果放入发明、实用新型或外观设计的适当类别，避免把保护对象与申请路径混同。

## R — 适用规则

1. 《专利法》第二条规定，发明创造包括发明、实用新型和外观设计；其中，发明是对产品、方法或者其改进提出的新的技术方案；实用新型是对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计则是对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

2. 国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕 这意味着审查机关的判断必须有法定对象和法定标准；代理人的材料组织则应当服务于该判断。

3. 对发明和实用新型，授权还须具备新颖性、创造性和实用性；现有技术是申请日以前在国内外为公众所知的技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条：授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性〕 本节只将其作为制度基础中的授权门槛定位；具体的新颖性、创造性及优先权判断留待相应子节点展开。

4. 制度规范层面，本节点的知识框架列出专利法、专利法实施细则和专利审查指南。可作审慎区分：专利法提供基本法律依据；实施细则和审查指南承担程序与审查操作的细化功能。本节检索上下文未提供实施细则及审查指南的原文，故不据此推导其具体条款内容。

5. 专利制度通常以公开与保护的制度安排服务于激励发明创造、促进技术公开、推动技术应用和经济发展。本节将该项作为制度功能框架理解，不将其替代为具体授权要件。关于“早期公开延迟审查、初步审查制与实质审查制并存”的历史与程序特点，当前检索上下文未提供直接原文依据；学习时应将其作为待在后续程序材料中核验的制度线索，而不应据此自行补充具体制度细节。

## A — 规则适用

以一项智能穿戴设备成果为例，代理人不能仅因其“具有创新性”便笼统选择申请类别，而应当拆分技术贡献：如果贡献在于降低能耗的控制方法，应优先按“方法或者其改进的技术方案”检视发明定义；如果贡献在于设备外壳的形状、构造或二者结合，应检视其是否符合实用新型的对象表述；如果贡献仅在产品整体或局部的视觉设计，则应检视外观设计定义中的形状、图案、色彩、美感和工业应用要素。〔RAG: 中华人民共和国专利法.txt — 第二条分别界定发明、实用新型和外观设计〕

审查端的顺序是：先确定申请文件所主张的对象，再适用相应类型的审查标准；代理端的顺序是：先识别技术事实，再选择法定客体和相适应的文件表达。两端的共同边界是：法定客体分类不是营销标签，而是后续审查标准与权利形态的入口。

就发明和实用新型而言，分类完成并不等于能够授权。审查人仍须依第二十二条审查三性；代理人则须在提交前识别可能影响新颖性、创造性和实用性的风险。特别是，申请日前已向公众公开的技术，与申请日前提出、但在申请日后公布的同样发明或者实用新型申请，均是新颖性条文需要分别核对的事实来源。〔RAG: 中华人民共和国专利法.txt — 第二十二条：不属于现有技术；也没有任何单位或者个人就同样的发明或者实用新型在申请日以前提出过申请，并记载在申请日以后公布的专利申请文件或者公告的专利文件中〕

## C — 结论

专利法律制度基础的核心不是记住抽象口号，而是建立一条可复核的起点链：先识别法定客体，再理解审查机关与代理工作的制度位置，继而进入相应的授权条件和程序规则。对法条已有明确规定的内容，应以条文为准；对本节材料未提供直接依据的历史或细化程序表述，应保留证据边界，待后续节点核验。

> 常见误区 / 易混淆点
>
> - 将“技术上有价值”直接等同于“当然可以获得专利权”。法定客体识别与授权条件审查是不同层次。
> - 将发明、实用新型、外观设计理解为同一对象的任意名称。三者在第二条中的对象表述不同，应回到技术事实逐项判断。
> - 将申请日前公众已知的技术与申请日前提出、申请日后公布的同样申请混为一类。二者在第二十二条中具有不同的事实表述，但都可能影响新颖性判断。
> - 将制度发展特点当作具体法律结论。当前材料没有提供相关历史与细化程序的直接原文，不应擅自补足。

### 从一件智能穿戴设备看客体识别（anchor_scenario）

> 甲公司研发一款智能穿戴设备：研发人员同时改进了设备的能耗控制方法、腕带连接结构和表盘视觉图案。公司准备参加融资展示，负责人要求代理人“把所有创新都申请成一个专利”。代理人需要先厘清三个事实：控制方法是否属于技术方案，连接结构是否属于产品形状或构造，表盘图案是否属于产品的视觉设计。

审查人员收到申请后，也不能只看产品名称或商业宣传，而应依申请文件主张的内容判断其落入何种法定客体，并据此进入后续审查。冲突点在于：同一产品可能包含不同层面的创新，但不同创新不当然适用同一法定客体和同一审查入口。

**锚定**：该情境锚定发明、实用新型、外观设计的客体区分，以及审查与代理均须先做客体识别的基础规则。

**先想一想**：如果只能先核对一项事实，你会先看技术贡献体现为方法、产品结构，还是产品视觉设计？

### 法条锚定：客体、审查职责与三性入口（legal_anchor）

- **《中华人民共和国专利法》第二条**：发明创造分为发明、实用新型和外观设计，三类客体的法定定义不同。
- **《中华人民共和国专利法》第三条**：国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。
- **《中华人民共和国专利法》第二十二条**：发明和实用新型授权须具备新颖性、创造性和实用性；申请日前公开技术及特定在先申请事实均须核对。

**为何重要**：第二条决定先把成果放入哪个法定客体，第三条定位审查机关职责，第二十二条则说明发明和实用新型在客体识别后仍须经过授权条件审查。

### 示例：拆分同一产品中的不同创新（worked_example）

**案情/例题**：某智能穿戴设备包含三项改进：一是根据传感数据调整能耗的控制步骤；二是使腕带更稳固连接的卡扣结构；三是表盘局部的图案与色彩组合。代理人需要为三项改进分别确定应当优先检视的法定客体；审查人员则须据此确定后续审查的入口。
**适用规则**：《中华人民共和国专利法》第二条关于发明、实用新型和外观设计的定义；《中华人民共和国专利法》第三条关于统一受理和审查专利申请的规定。
**分步推演**：
1. 先将“控制步骤”与产品外观、产品结构分离。第二条将对方法或者其改进所提出的新的技术方案列入发明定义。 → *控制方法优先按发明客体检视。*
2. 再识别卡扣改进的贡献是否体现为产品形状、构造或者二者结合。第二条将该类适于实用的新的技术方案列入实用新型定义。 → *卡扣结构优先按实用新型客体检视。*
3. 最后识别表盘图案与色彩组合是否体现为产品整体或局部的形状、图案、色彩及其结合，并具有美感和工业应用属性。 → *视觉设计优先按外观设计客体检视。*
4. 客体识别仅确定审查入口；对属于发明或实用新型的部分，仍要继续审查第二十二条规定的三性。 → *分类不是授权结论，后续仍有授权条件审查。*
**结论**：同一产品中不同创新可以分别对应发明、实用新型或外观设计的法定定义；应以具体技术或设计贡献分类，而不能以产品名称一概而论。
**本题要点**：训练“先拆分事实、再匹配法定定义、最后进入后续审查”的代理与审查共同工作链。

### 用审查语言理解制度入口（verbal_explanation）

可以把专利制度基础理解为一套先分类、后审查的工作秩序。代理人拿到研发成果，第一步不是急着写一份“万能申请”，而是问：贡献究竟是解决技术问题的方法，是产品本身的形状或构造，还是产品呈现出来的视觉设计。审查人员面对申请文件也做同样的入口判断。分类之后，才谈得上适用何种审查规则。对于发明和实用新型，即使已经属于法定客体，也还要过新颖性、创造性和实用性这三道授权门槛。制度体系中的专利法提供基本依据，实施细则和审查指南负责进一步细化；但本节没有提供后二者的原文，所以不能把未见原文的细节当成已核实规则。

**点破术语**：法定客体；发明；实用新型；外观设计；三性

### 顺序记忆表：客—制—审—效—程（mnemonic）

**记忆锚**：顺序记忆表：客—制—审—效—程。先看“客”体，再看“制”度规范层级，再看“审”查与授权条件，继而理解制度“效”用，最后以“程”序和发展线索作定位。
**映射**：
- 客
- 制
- 审
- 效
- 程
**何时用**：阅读申请文件、审查意见或复盘制度基础时，先按五个位置定位问题，再进入具体法条。

### 反思：代理与审查的共同起点（reflect_prompt）

**反思问题**：复盘一件你熟悉的技术成果时，若代理人和审查人员对其法定客体分类不同，最应回到申请文件中的哪一类技术事实进行核对？

**关注要点**：是否清楚区分了方法、产品形状或构造、以及产品视觉设计。；客体分类是否被错误地当成了授权结论。；哪些判断已有《专利法》条文支撑，哪些制度细节仍缺乏本节直接材料。

**连接**：连接到既有的程序法训练：先确定审查对象与法律依据，再评价实体要件和程序后果。

### 专利法律制度基础框架（knowledge_synthesis）

**知识框架**：
- 专利权特征：以独占性、时间性、地域性理解专利权的制度边界；本节不延伸其具体期限和地域规则。
- 制度规范层级：专利法提供基本法律依据，专利法实施细则和专利审查指南构成细化规范框架；具体细则与指南内容须查阅原文。
- 保护客体：发明、实用新型、外观设计三类客体的定义以《专利法》第二条为准。
- 制度作用：通过保护与公开的制度安排，服务激励发明创造、促进技术公开、推动技术应用和经济发展。
- 制度发展与程序线索：以早期公开延迟审查、初步审查制和实质审查制并存作为后续核验线索；当前材料未提供其直接历史与程序依据。
**概念关系**：客体识别是审查与代理工作的第一入口；授权条件审查在客体识别之后展开。；专利法提供基本规则，实施细则和审查指南承接细化适用；未取得原文时不得虚构细化内容。；制度功能说明制度目的，但不替代具体授权要件和程序规则。
**必记**：先识别法定客体，不能把“有创新”直接等同于“可获专利权”。；发明和实用新型属于法定客体后，仍须依第二十二条审查新颖性、创造性和实用性。；审查与代理的共同起点是以申请文件和技术事实为基础，匹配法定定义与法律依据。

### 基础制度速查卡（summary_card）

**要点卡**：
- **专利权特征**：独占性、时间性、地域性共同提示专利保护不是无限、当然或无边界的权利。
- **制度体系**：以专利法为基本依据，实施细则和审查指南承担细化功能；具体内容应回到原文。
- **三类客体**：发明看产品、方法或改进的技术方案；实用新型看产品形状或构造；外观设计看产品视觉设计。
- **审查入口**：国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。
- **三性门槛**：发明和实用新型在客体识别后，仍须具备新颖性、创造性和实用性。
**必背**：《专利法》第二条规定的三类发明创造及其基本区分。；《专利法》第三条所示统一受理、审查和依法授予专利权的职责定位。；《专利法》第二十二条所示发明和实用新型的三性要求。
**一句话总结**：专利制度基础应按“客体识别—制度依据—审查入口—授权条件—证据边界”顺序复核。
