## 教学正文

## 1. 场景导入
某研发团队做完一款关节模组，既想尽快申请专利，又计划下月参加国际展会现场演示。他们一边问：这个技术方案到底能走发明、实用新型还是外观设计？另一边又怕演示把新颖性毁掉。代理视角要先把保护客体和制度特点讲清；审查视角则盯申请日、公开日与早期公开延迟审查如何影响后续流程。

## 2. 人话解释
专利制度给发明创造人一段‘时间限定的独占权’，核心特征是独占性、时间性和地域性：只有权利人能决定谁可以用，保护有明确年限，效力原则上限于授权国。中国专利制度以《专利法》为骨架，配套《专利法实施细则》和《专利审查指南》，形成‘法律—细则—指南’三层体系。保护客体只有三种：发明、实用新型、外观设计。制度作用是激励创造、促进公开、推动应用与经济发展。中国特色还包括早期公开、延迟审查，以及发明走实质审查、实用新型与外观设计主要走初步审查的并存安排。

## 3. 法条回扣
《专利法》第二条把发明创造限定为发明、实用新型和外观设计，并分别给出定义：发明是产品、方法或其改进的新的技术方案；实用新型是产品形状、构造或其结合的适于实用的新的技术方案；外观设计是产品整体或局部的形状、图案或其结合以及色彩与形状、图案的结合作出的富有美感并适于工业应用的新设计。〔RAG: 专利法.txt — 第二条〕授权实质条件则由第二十二条统领，新颖性、创造性、实用性构成后续审查主线。〔RAG: 专利法.txt — 第二十二条〕

## 4. 类比 / 口诀
可把三种客体想成三种‘门票’：发明票覆盖产品和方法、保护期最长；实用新型票只管产品形状构造、审查更侧重初步审查；外观设计票卖的是工业上可应用的美观设计。口诀用‘独一时地 + 三客三层 + 早公延审’：独占、时间、地域；发明/实用新型/外观设计；专利法/细则/指南；早期公开、延迟审查、初审与实审并存。类比边界：这只帮助记忆制度轮廓，不替代新颖性、创造性的具体对比规则。

## 5. 应试提示
看到‘保护什么’先锁定第二条三种客体；看到‘权利有什么特点’答独占性、时间性、地域性；看到‘中国专利怎么管’答法律—细则—指南，以及早期公开延迟审查、初审与实审并存。代理逻辑先选客体、估保护期、排公开节奏；审查逻辑先核申请文件与公开时点，再进入三性。常见陷阱是把商业方法等非法定客体硬塞进三种客体，或把‘早期公开’误说成‘一申请就授权’。

### 展会前的双视角选择题（anchor_scenario）

> 某机电团队刚做出新型关节模组，代理建议尽快交申请，市场部却坚持下月去政府主办国际展会现场演示拉订单。负责人同时抛出三个问题：这算发明还是实用新型？演示会不会把新颖性打穿？中国专利是“公开了就有权”还是“审过才有权”？审查员日后会从客体、公开时点与审查制度三条线核同一事实；代理人现在就要用基础制度把风险讲清楚。

**锚定**：用同一研发—展会事实锚定保护客体、制度特征与中国早期公开延迟审查安排。

**先想一想**：若你先站在代理人角度，面对“展会演示”，你会先问客体类型，还是先问公开是否落入可豁免情形？为什么？

### 第二条与制度骨架（legal_anchor）

- **《专利法》第二条**：第二条用封闭列举划定三种客体：发明、实用新型、外观设计，并分别定义技术方案或设计的边界。
- **《专利法》第二十二条**：第二十二条提示授权仍需满足新颖性、创造性、实用性，基础制度与后续三性审查相互衔接。

**为何重要**：本节点的教学主线就是“保护什么、制度有何特征、中国如何审查”；没有第二条和体系定位，后续新颖性、代理答复都会失焦。

### 关节模组该走哪类客体（worked_example）

**案情/例题**：公司提交的技术交底书记载：一种机器人关节模组，通过改变壳体与传动件的形状、构造降低回差，并附带可选择的控制方法改进。问：若主要贡献在产品构造，应优先考虑哪种专利客体？若同时写入纯商业促销方法，审查上会如何看待？
**适用规则**：《专利法》第二条关于发明、实用新型、外观设计的定义
**分步推演**：
1. 先看技术贡献落点：形状、构造及其结合且适于实用，符合实用新型定义；若还包含方法改进，则可评估发明。 → *客体判断看贡献落点*
2. 实用新型不保护方法本身，因此“控制方法改进”不能单独支撑实用新型；需要方法保护时应转向发明。 → *方法内容影响客体选择*
3. 纯商业促销方法本身通常不构成第二条意义上的技术方案或设计，不能靠塞进权利要求变成专利客体。 → *非法定主题不能借壳*
**结论**：构造改进优先评估实用新型或发明；纯商业方法不能借助第二条变成可授权客体。
**本题要点**：代理先定性客体，审查先核是否落入第二条。

### 把制度说成人话（verbal_explanation）

你就记三句话。第一，专利不是“什么好点子都能保”，而是只认发明、实用新型、外观设计这三种门票。第二，拿到票也不等于永久霸占，它有独占性、有年限、原则上只在授权地域管用。第三，中国玩法是法律定原则、细则作配套、审查指南给操作手册；发明多半先公开、再排队做实审，实用新型和外观设计更侧重初步审查。代理说话要会翻译成客户听得懂的风险；审查看案子则先问：你到底买的是哪张门票，有没有按中国流程走。

**点破术语**：独占性；时间性；地域性；早期公开延迟审查

**类比**：像先把发明说明书贴到公告栏（早期公开），再预约专家体检（实质审查）；贴公告不等于已经发营业执照。

### 基础制度记忆锚（mnemonic）

**记忆锚**：独一时地｜三客三层｜早公延审
**映射**：

**何时用**：选择题出现“专利特征/中国专利制度特点/保护客体”时先默念此锚。

### 审查逻辑对照代理逻辑（reflect_prompt）

**反思问题**：若客户既要展会演示又要尽快获权，你如何用本节点的基础制度给客户做一张“审查员会怎么看”的对照表？

**关注要点**：先定客体，再谈公开时点；区分早期公开与授权效力；说明初审/实审并存如何影响时间预期

**连接**：连接本节点的客体、制度特征与中国审查安排，并为后续相关法律框架学习预留接口

### 基础制度关系网（knowledge_synthesis）

**知识框架**：
- 制度特征：独占性、时间性、地域性，决定权利强度与边界
- 规范体系：专利法—实施细则—审查指南，分层提供实体与操作规则
- 保护客体：发明、实用新型、外观设计，分别对应不同技术/设计贡献
- 制度功能：激励创造、促进公开、推动应用与经济发展
- 中国安排：早期公开延迟审查，初审与实审并存
**概念关系**：先客体后三性；先体系定位后审查操作；公开促进扩散，但不等于已经授权
**必记**：客体判断以第二条为门，进不了门谈不上三性；中国专利制度是三层规范加上早期公开延迟审查的组合拳；代理选客体、控公开；审查核客体、看程序时点

### 专利基础速查卡（summary_card）

**要点卡**：
- **三特征**：独占性、时间性、地域性
- **三客体**：发明、实用新型、外观设计
- **三层规范**：专利法、实施细则、审查指南
- **中国特点**：早期公开延迟审查，初审与实审并存
**必背**：《专利法》第二条三种客体；专利制度=激励创造+促进公开+推动应用；独一时地；早公延审
**一句话总结**：先进第二条的门，再顺着三层规范和中国审查时间线往下走。
