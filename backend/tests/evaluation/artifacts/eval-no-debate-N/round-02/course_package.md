## 教学正文

## I — 法律问题

面对一项技术成果，审查视角首先要定位其是否属于法定发明创造类型；代理视角则要据此选择恰当的申请客体、准备相应技术表达，并在程序上预判申请会经过何种审查。进一步说，专利制度为何以一定期限、一定地域内的排他保护来交换技术公开，以及制度文件、审查环节和授权条件如何形成一条完整链条，是本节点要解决的基础问题。

## R — 适用规则

1. **法定保护客体。**《专利法》第二条将“发明创造”限定为发明、实用新型和外观设计三类；其中，发明是对产品、方法或者其改进提出的新的技术方案，实用新型是对产品的形状、构造或者其结合提出的适于实用的新的技术方案，外观设计则是就产品整体或者局部的形状、图案及其结合，或色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

2. **管理与审查的制度起点。**国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕 因而，代理工作的文件准备和陈述，应以可供统一审查的申请文本为对象；审查工作的核心则是以法定条件审查申请而非替申请人重新设计技术方案。

3. **制度文件框架。**本节点将《专利法》、其实施细则和《专利审查指南》作为中国专利制度的基础文件框架：法律提供基本权利义务与制度边界，实施细则和审查指南服务于程序及审查操作的具体化。本轮检索上下文未提供实施细则和审查指南的原文，故不对其具体条款、效力层级或最新修改内容作超出材料的断言。

4. **制度属性与功能。**独占性、时间性、地域性是理解专利制度的三个观察标签：排他保护不是对技术事实本身的无限占有，而是依法授予的、受期限和地域边界约束的权利安排。本轮检索上下文未提供专利权期限及地域效力的直接条文，故本节不推定具体年限或域外效力。制度功能上，可将其理解为“公开—审查—授权保护—促进实施运用”的结构：技术公开使公众能够获得技术信息，依法授予的权利提供激励；这一功能性说明不替代具体权利范围的法条判断。

5. **程序与实体的分层。**从制度发展和运行特征观察，申请公开、审查与授权并非同一概念。早期公开、延迟审查以及初步审查与实质审查并存，提示代理人必须分别核对时间点、审查对象和法律后果。本轮检索上下文没有提供有关公开、审查请求及审查程序的直接条文，故本节仅建立分层框架，不据此给出具体期限或程序结论。作为实体审查的参照，《专利法》第二十二条明确：发明和实用新型获得专利权须具备新颖性、创造性和实用性；现有技术是申请日以前在国内外为公众所知的技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条：发明和实用新型应当具备新颖性、创造性和实用性〕

## A — 规则适用

以一项“带有新型内部结构且外壳图案独特的设备”为例，审查与代理应按同一顺序拆解事实，但关注点不同：

- **第一步：先定技术贡献的对象。**若贡献在于产品内部结构或其结合，应优先按发明或实用新型的定义核对；若贡献在于产品整体或局部的视觉设计，应按外观设计定义核对。不能仅因方案“看起来新”就混同三类客体。〔RAG: 中华人民共和国专利法.txt — 第二条分别规定发明、实用新型、外观设计的定义〕
- **第二步：再定审查层次。**审查人员需要区分“文件和程序是否进入相应环节”与“实体条件是否满足”；代理人则应把技术事实、申请文本和程序节点分别整理。将初步审查直接等同于对全部实体条件的最终判断，或将公开等同于授权，都会破坏判断顺序。
- **第三步：对发明、实用新型进入实体门槛。**应以申请日为基准，分别审查新颖性、创造性、实用性。新颖性关注是否属于现有技术及同样发明创造的在先申请公开；创造性关注相对现有技术的实质特点与进步；实用性关注能否制造或使用并产生积极效果。〔RAG: 中华人民共和国专利法.txt — 第二十二条关于新颖性、创造性、实用性及现有技术的规定〕
- **第四步：回到制度目的审视代理方案。**代理并非只追求“提交申请”，还要将应当公开的技术内容与拟请求保护的对象对应起来；审查亦非只作形式筛查，而要在法定标准内判断是否能依法授予权利。两者在角色上不同，但都以法定客体、申请文本和审查标准为共同边界。

## C — 结论

专利法律制度基础的判断起点是：先辨明申请对象是否属于发明、实用新型或外观设计，再区分制度文件、程序环节和实体授权条件。对发明与实用新型，第二十二条的三性是明确的实体授权门槛；对制度的独占性、时间性、地域性以及公开和审查的程序安排，应坚持“属性不等于具体规则、程序不等于实体、公开不等于授权”的分层分析。

> 常见误区 / 易混淆点
>
> 1. 将“发明”当作一切创新成果的统称。法律上的发明、实用新型、外观设计有不同定义，须先按技术事实归类。
> 2. 将专利的独占性理解为永久、全球、无边界的控制。独占性必须与时间性、地域性共同理解；具体范围和期限须回到相应法条。
> 3. 将初步审查、实质审查和授权混作同一事件。它们是程序节点或法律结果，分析时应分别核对对象、时间点和后果。
> 4. 将新颖性与创造性混同。新颖性重点是是否已被公开或落入法定在先申请情形；创造性重点是相对现有技术是否具有法定程度的实质特点和进步。〔RAG: 中华人民共和国专利法.txt — 第二十二条分别定义新颖性与创造性〕

### 从一件设备申请看制度基础（anchor_scenario）

> 甲公司研发一台工业检测设备：工程师改进了设备内部的传动结构，使其运行更稳定；设计团队同时为外壳局部制作了新的图案和配色。公司准备提交专利申请，但负责人只说“这是一个很新的产品”。代理人必须先把“新”拆成不同法律对象，审查人员也必须知道申请究竟请求保护什么。

与此同时，公司担心一经提交就必然获得权利。实际流程中，提交、公开、审查和授权并不是同一件事；不同类型的成果对应不同的法定定义，发明和实用新型还会进入三性判断。

**锚定**：该情境锚定“先识别法定保护客体，再区分程序节点与实体授权条件”的基础框架。

**先想一想**：如果只用“产品很新”描述该方案，审查和代理各会遗漏哪个关键判断环节？

### 制度基础的法条锚点（legal_anchor）

- **《中华人民共和国专利法》第二条**：发明创造有三类：发明侧重产品、方法或其改进的技术方案；实用新型侧重产品形状、构造；外观设计侧重产品视觉设计。
- **《中华人民共和国专利法》第三条**：国务院专利行政部门统一受理、审查专利申请，并依法授予专利权，申请、审查与授权须作程序区分。
- **《中华人民共和国专利法》第二十二条**：发明和实用新型要通过新颖性、创造性、实用性三项实体门槛；现有技术以申请日前公众已知技术为基准。

**为何重要**：第二条解决“申请的是什么”，第三条提示“谁审查、如何进入制度”，第二十二条提示“发明和实用新型为何可能不被授权”。三者构成本节点从客体到程序再到实体标准的法条骨架。

### 结构改进与外观设计的双重识别（worked_example）

**案情/例题**：乙公司拟为一款便携检测仪申请保护：其内部新增了传动部件的连接结构，外壳局部则采用独特的图案与色彩组合。现需在申请前判断：应当如何从制度基础层面识别其可能的保护客体，并为何不能把“已提交申请”直接当作“已经取得专利权”？
**适用规则**：《专利法》第二条关于发明、实用新型和外观设计的定义；《专利法》第三条关于统一受理、审查与依法授予专利权；《专利法》第二十二条关于发明和实用新型的三性。
**分步推演**：
1. 先把事实拆为内部传动连接结构与外壳局部图案、色彩两部分，而不以“整台产品很新”作笼统归类。 → *分类的对象是具体贡献，不是产品名称。*
2. 内部结构属于产品形状、构造或者其结合时，应对照实用新型定义；如主张的是产品、方法或改进的技术方案，也须对照发明定义。外壳局部图案与色彩结合的视觉设计，则应对照外观设计定义。 → *第二条要求按不同法定定义分别识别。*
3. 即使申请已提交，第三条所示的受理、审查和依法授予仍是不同环节；提交本身不是授权结论。 → *程序状态不能替代权利状态。*
4. 对最终按发明或实用新型提出的部分，还须依第二十二条面对新颖性、创造性、实用性判断。 → *客体识别之后，仍有实体授权门槛。*
**结论**：该检测仪的结构改进与外观视觉设计应依各自事实分别对照第二条的不同类型；提交申请不等于授权，对发明或实用新型还须满足第二十二条规定的三性。
**本题要点**：审查与代理均应坚持“拆事实、定客体、分程序、核实体”的线性判断链。

### 把制度框架说清楚（verbal_explanation）

可以把专利制度基础理解为四个连续动作。先问：客户到底创造了什么？是产品或方法的技术方案、产品的形状构造，还是产品的视觉设计；这一步对应三类法定客体。再问：现在处于提交、公开、审查还是授权的哪个阶段，不能因为材料已交就说权利已经取得。随后才问：如果是发明或实用新型，是否能通过新颖性、创造性、实用性三关。代理人负责把技术贡献和文件表达对准这些问题，审查人员负责按法定标准审查它们。至于实施细则、审查指南以及具体公开、审查期限，本轮材料没有原文，应在实务中另行核对，不能靠印象补全。

**点破术语**：保护客体；独占性；程序节点；三性

### 制度基础四步核对表（mnemonic）

**记忆锚**：四步核对表：客—程—审—界。
**映射**：
- 客
- 程
- 审
- 界
**何时用**：看到“一个成果能否申请、处于什么状态、为什么可能不授权”的题干或代理咨询时，先按四步核对表逐项定位。

### 审查与代理的同题异视角（reflect_prompt）

**反思问题**：复盘一项同时含结构改进和外观变化的产品时，审查人员与代理人分别会在“客—程—审—界”四步中优先核对哪些材料？

**关注要点**：是否已将结构技术贡献与视觉设计贡献拆分，而非以产品名称替代分类。；是否把申请提交、公开、审查和授权作为不同程序节点。；对发明和实用新型，是否已将三性作为独立实体判断，而非用“技术看上去先进”替代法定标准。；对本轮未提供原文的实施细则、审查指南和程序期限，是否明确保留核验边界。

**连接**：连接到学习者已有的程序法分析习惯：分别核对主体、对象、时间点和法律后果。

### 专利法律制度基础的关系网（knowledge_synthesis）

**知识框架**：
- 制度属性：独占性、时间性、地域性共同描述专利保护的边界；不得只强调排他性而忽略其他限制。
- 制度文件：以专利法为基本法律依据，实施细则和审查指南服务于程序与审查操作的具体化；具体内容须以原文核验。
- 保护客体：《专利法》第二条将发明创造分为发明、实用新型、外观设计，并按技术方案、产品形状构造、产品视觉设计作不同界定。
- 制度作用：通过技术公开与依法授予权利的制度安排，形成激励发明创造、促进技术传播和应用的结构性功能。
- 程序特点：申请公开、审查、授权须分层观察；初步审查与实质审查并存的具体程序规则应另查直接规范。
**概念关系**：客体识别在前：只有明确拟保护的对象，才能选择相应申请表达和审查路径。；程序分层居中：受理、公开、审查、授权构成不同节点，不能用前一节点直接推出后一节点。；实体审查在后：对发明和实用新型，第二十二条三性是授权判断的实体门槛。；制度功能贯穿全程：技术公开与依法授予权利共同构成激励和传播的制度逻辑。
**必记**：先按《专利法》第二条识别客体，不能以“成果很新”替代法律分类。；提交申请、公开、审查、授权不是同义概念，程序判断须区分时间点、对象和法律后果。；发明和实用新型的实体授权条件包括新颖性、创造性、实用性；三性各有不同判断对象。

### 制度基础速查卡（summary_card）

**要点卡**：
- **三项制度属性**：独占性必须与时间性、地域性一起理解，具体边界以相应规范为准。
- **制度文件框架**：专利法提供基本规则；实施细则和审查指南的具体内容须查原文。
- **三类保护客体**：发明看产品、方法或改进的技术方案；实用新型看产品形状构造；外观设计看产品视觉设计。
- **制度运行层次**：提交、公开、审查、授权应分开分析，不能把程序状态当作授权结论。
- **发明和实用新型的实体门槛**：新颖性、创造性、实用性缺一不可，且判断对象各不相同。
**必背**：《专利法》第二条：发明创造包括发明、实用新型和外观设计。；《专利法》第二十二条：发明和实用新型应具备新颖性、创造性和实用性。；四步核对表：客—程—审—界。
**一句话总结**：专利制度基础的正确起手式：先定客体，再分程序，继而核实体条件，并始终注意权利边界。
