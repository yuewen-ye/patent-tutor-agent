## 教学正文

## I — 法律问题

本节点聚焦专利法律制度的基础：在智能制造项目中，首先要确认技术成果属于哪类专利客体，随后了解专利制度的运行机制以及独占性、时间性、地域性三大属性如何为后续的新颖性判断和侵权分析提供制度前提。\n\n## R — 适用规则\n\n1. **立法目的**：\n《专利法》第一条规定，制定本法是为了保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，促进科学技术进步和经济社会发展。〔RAG: 中华人民共和国专利法.txt — 第一条：为了保护专利权人的合法权益，鼓励发明创造，推动发明创造的应用，提高创新能力，促进科学技术进步和经济社会发展，制定本法〕\n\n2. **三类保护客体**：\n《专利法》第二条明确，发明是指对产品、方法或者其改进提出的新的技术方案；实用新型是指对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计是指对产品整体或局部的形状、图案以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：本法所称的发明创造是指发明、实用新型和外观设计；并分别规定发明、实用新型和外观设计的定义〕\n\n3. **制度运行层级**：\n《专利法》第三条规定，国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请，依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门负责管理全国的专利工作；统一受理和审查专利申请，依法授予专利权〕\n\n4. **权利属性**：\n专利权的独占性、时间性、地域性分别体现在：权利人在法定保护范围内享有排他使用权；保护期限受法律规定限制（发明20年、实用新型10年、外观设计15年，自申请日起计算）；权利仅在授权国或地区有效。当前检索上下文未提供具体期限细则，故此处仅作概念性说明。\n\n5. **制度功能**：\n专利制度通过授予排他权利换取技术公开，进而激励研发、促进技术应用并推动经济发展。检索上下文提供了制度宗旨及历史沿革的材料，足以支撑此概念。\n\n## A — 规则适用\n\n以智能制造中的机器人视觉定位系统为例：若创新体现在图像处理、特征识别与控制指令的流程，应归入“发明”客体；若创新体现在传感器外壳的形状、图案或配色，则属于“外观设计”。此判断仅确定保护客体，不等同于已满足新颖性、创造性或侵权成立的条件。\n\n## C — 结论\n\n专利制度的基础判断顺序为：先识别保护客体（发明/实用新型/外观设计），再确认适用的制度材料（《专利法》条文、实施细则、审查指南），最后依据客体进入授权条件（新颖性、创造性、实用性）或侵权分析（权利要求范围）。本节不对新颖性或侵权作具体判定，但为后续章节提供必要的制度入口。

### 智能制造专利分类情境（anchor_scenario）

> 某智能制造企业为汽车装配线研发了一套机器人视觉定位系统：研发团队一方面改进了图像处理与控制流程，另一方面重新设计了传感器外壳的形状、图案和配色。企业准备申请专利，但工程师、产品经理和法务人员对申请类型、专利制度保护的对象以及以后如何判断他人是否落入保护范围存在不同理解。此时需要先厘清技术成果的法律客体，而不能仅凭“智能制造”这一行业标签作结论。

**锚定**：该情境锚定专利保护客体、专利制度功能及后续新颖性和侵权分析的基础入口。

**先想一想**：面对同一智能制造项目中的控制流程和设备外观，你会先依据技术内容还是产品名称来区分专利类型？

### 专利制度法条锚定（legal_anchor）

- **《中华人民共和国专利法》第一条**：第一条说明专利制度要保护权利人、鼓励创新、推动应用并促进科技进步和经济社会发展。
- **《中华人民共和国专利法》第二条**：第二条把专利保护客体分为发明、实用新型和外观设计，并分别界定三者。
- **《中华人民共和国专利法》第三条**：第三条确定国务院专利行政部门负责全国的专利管理、统一受理和审查申请并依法授予专利权。

**为何重要**：这些条文分别解决专利制度为什么存在、保护什么以及由谁实施管理三个基础问题。只有先完成客体和制度定位，后续的新颖性判断与侵权判定才有明确的法律对象。

### 机器人视觉系统的客体识别（worked_example）

**案情/例题**：某企业研发机器人视觉定位系统。其第一项创新是通过图像采集、特征识别和控制指令调整机器人动作的流程；第二项创新是传感器外壳的局部形状、图案及配色组合。现需在提交专利申请前确定两项创新分别应从哪类专利保护客体进入分析。
**适用规则**：适用《专利法》第二条关于发明、实用新型和外观设计的定义；本例只进行保护客体识别，不据此判断新颖性、创造性、实用性或侵权是否成立。
**分步推演**：
1. 先把第一项创新拆成其法律上真正被主张的内容：它描述的是图像处理、识别和控制动作之间的流程，而不是仅描述设备外形。 → *第一项创新的核心是方法或技术方案内容。*
2. 《专利法》第二条将对产品、方法或者其改进提出的新的技术方案纳入发明定义，因此应从发明客体角度继续分析。 → *第一项创新进入发明客体分析。*
3. 第二项创新的核心是传感器外壳的局部形状、图案及配色组合，判断重点是产品外观而非控制功能。 → *第二项创新的核心是产品外观设计内容。*
4. 《专利法》第二条规定，外观设计包括对产品整体或局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的设计。 → *第二项创新进入外观设计客体分析。*
**结论**：在仅识别保护客体的范围内，控制流程应按发明客体进入后续分析，外壳的形状、图案及配色组合应按外观设计客体进入后续分析；该分类本身不等于已经满足授权条件。
**本题要点**：判断专利类型先看创新内容，再看产品名称；客体分类和授权条件必须分开。

### 专利法律制度基础框架（knowledge_synthesis）

**知识框架**：
- 专利保护客体：发明、实用新型和外观设计分别对应方法或产品技术方案、产品形状构造及产品外观设计。
- 专利制度规范体系：专利法提供基本法律规范，专利法实施细则和专利审查指南构成配套制度材料；具体条文须逐项核验。
- 专利权基本属性：独占性、时间性和地域性共同限定专利权的权利边界。
- 专利制度功能：通过权利保护、技术公开和技术应用之间的制度安排，鼓励发明创造并促进科技进步和经济发展。
- 专利审查与管理：国务院专利行政部门负责全国专利工作，并统一受理和审查专利申请、依法授予专利权。
**概念关系**：先识别保护客体，再确定适用的专利制度材料和审查入口。；专利制度的立法目的解释其功能，三类客体规则确定保护对象，行政管理规则确定受理审查主体。；完成制度基础后，才能分别进入授权条件中的新颖性判断和专利权保护中的侵权判定。
**必记**：识别专利类型必须看创新内容，不能只看所属行业或产品名称。；发明、实用新型、外观设计是《专利法》第二条规定的三类专利保护客体。；客体分类不等于已经满足新颖性、创造性、实用性，也不等于已经构成侵权。

### 专利制度基础速查（summary_card）

**要点卡**：
- **三类保护客体**：发明看产品、方法或其改进的技术方案，实用新型看产品形状构造，外观设计看产品整体或局部外观。
- **三项基础属性**：专利权具有独占性、时间性和地域性，权利边界并非无限或永久。
- **制度规范体系**：专利法是基本法律规范，实施细则和审查指南是需要结合具体条文核验的配套材料。
- **制度功能**：专利制度以权利保护促进创新，同时通过公开和应用推动科技与经济发展。
- **管理审查主体**：国务院专利行政部门负责全国专利工作并统一受理、审查申请和依法授予专利权。
**必背**：《专利法》第二条规定发明、实用新型和外观设计三类保护客体。；判断专利类型先看创新内容，不以智能制造等行业名称直接决定。；客体分类、授权条件和侵权成立是三个不同层次的问题。；专利权的基础属性是独占性、时间性和地域性。
**一句话总结**：先确认保护什么，再确认制度如何运行，最后分别进入授权条件和权利保护判断。
