# 专家 B 修订稿

## teaching_content

## 1. 场景导入
一家科技公司研发了新型关节模组的谐波减速器，希望申请发明专利，但担心在专业展会展示是否会影响新颖性。他们还需判断这是发明还是实用新型，以及是否满足授权条件。这是一个典型的专利申请前风险评估场景，涉及保护客体选择与三性判断。

## 2. 人话解释
专利法律制度基础是理解专利权的核心。专利保护的客体主要有三种：发明是指对产品、方法或者其改进所提出的新的技术方案；实用新型是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是指对产品的形状、图案或者其结合所提出的新的且适合工业应用的外观设计。授权需要通过新颖性、创造性和实用性三关。新颖性要求申请前未公开，创造性要求不是本领域技术人员显而易见，实用性要求能制造或者使用并产生积极技术效果。中国专利制度强调早期公开、并存审查，兼顾效率与质量。

## 3. 法条回扣
《专利法》第二条规定：发明是指对产品、方法或者其改进所提出的新的技术方案；实用新型是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是指对产品的形状、图案或者其结合所提出的新的外观设计。

## 4. 类比 / 口诀
把专利授权比作办公司：保护客体是‘公司类型’（发明像高科技公司，实用新型像中型制造企业），三性是‘入园条件’（新颖性=没被别人办过，创造性=不是显而易见，实用性=能赚钱）。口诀：‘三客三性，边界要辨’——发明看技术方案，实用新型看形状构造，外观看美观；新颖别混淆公开，创造别看显而易见，实用别忘积极效果。适用边界：仅限实体技术方案，程序方法或纯理论不适用，但法定排除的是科学发现、智力活动的规则和方法、疾病的诊断和治疗方法等特定主题。

## 5. 应试提示
题干关键词：保护对象是产品形状还是技术方案；判断对象是‘技术手段’还是‘自然规律’；常见陷阱是把疾病诊疗方法当发明，或把已有材料改进当形状改进。步骤：先看是否技术方案，再分发明/实用新型，最后过三性。边界案例如：形状+材料改进属于实用新型，但纯方法不给。需核实具体事实条件。

## 6. 互动提问
思考：如果客户申请的外观设计专利被拒，你会如何回应代理？如何把保护客体判断与三性辨析结合起来？
