## teaching_content

## I — 法律问题

本节点需要解决五个相互衔接的问题：第一，专利制度保护什么，以及专利权具有什么基本特征；第二，中国专利制度由哪些规范层级构成；第三，发明、实用新型、外观设计的保护客体如何区分；第四，专利制度为何同时要求技术公开并给予一定期限、地域范围内的排他保护；第五，在授权实质条件中，如何按顺序区分新颖性、创造性、现有技术与抵触申请。

## R — 适用规则

1. **保护客体**。根据《专利法》第二条，发明是“对产品、方法或者其改进所提出的新的技术方案”；实用新型是“对产品的形状、构造或者其结合所提出的适于实用的新的技术方案”；外观设计是对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明、实用新型和外观设计的定义〕

2. **发明和实用新型的授权三性**。《专利法》第二十二条规定，授予专利权的发明和实用新型应当具备新颖性、创造性和实用性；新颖性要求其不属于现有技术，也不存在申请日前提出、申请日后记载于公布或公告文件中的同样发明或者实用新型；创造性要求发明相对于现有技术具有突出的实质性特点和显著的进步，实用新型具有实质性特点和进步；实用性要求能够制造或者使用并产生积极效果。〔RAG: 中华人民共和国专利法.txt — 第二十二条：新颖性、创造性、实用性及现有技术定义〕

3. **现有技术与抵触申请的区分**。现有技术的核心是申请日前已经在国内外为公众所知的技术。抵触申请的核心是：在涉案申请日前已有同样发明或者实用新型向国务院专利行政部门提出申请，但相关内容在涉案申请日之后才被记载于公布或者公告文件中。二者均可影响新颖性，但法律性质和时间结构不同。〔RAG: 中华人民共和国专利法.txt — 第二十二条：申请日前为公众所知的技术及申请日前提出、申请日后公布或公告的同样申请〕

4. **外观设计的授权条件**。《专利法》第二十三条规定，外观设计不得属于现有设计，不得存在同样外观设计的抵触申请；同时，外观设计与现有设计或者现有设计特征的组合相比，应当具有明显区别。现有设计是申请日前在国内外为公众所知的设计。〔RAG: 中华人民共和国专利法.txt — 第二十三条：外观设计的新颖性、明显区别、合法权利冲突及现有设计〕

5. **专利制度体系与基本特征**。本节点应将《专利法》作为基础规范，将《专利法实施细则》作为程序和制度细化依据，将《专利审查指南》作为审查实践中的重要解释和操作材料。对于“独占性、时间性、地域性”以及中国制度发展历程，当前检索上下文未提供直接法条或官方材料依据，因此这里只作制度分析框架，不将其表述为本轮已核验的具体法条结论。

## A — 规则适用

### 1. 先判断保护客体，再判断授权条件

代理人面对一项技术成果时，第一步不是立即讨论新颖性，而是确认其是否属于专利法规定的发明、实用新型或外观设计。若是产品、方法或其改进形成的技术方案，通常进入发明判断；若重点在产品形状、构造或者其结合，并且属于适于实用的技术方案，进入实用新型判断；若重点在产品整体或局部的形状、图案、色彩及其结合所形成的视觉设计，进入外观设计判断。客体判断错误，会导致后续适用的授权条件和比较方法错误。

### 2. 再按照“有没有被公开—是否容易想到—是否能够实施”的顺序审查

对于发明和实用新型，先围绕新颖性确定申请日前是否存在同样方案。如果一份单独的现有技术已经公开了权利要求所要求保护的全部技术特征，通常应先处理新颖性问题；不能因为技术方案“看起来容易”就跳过新颖性分析。新颖性判断的基本方式是单独对比，不应把多份文件拼接后制造出一份事实上不存在的对比文件。

在新颖性成立后，再讨论创造性。创造性解决的不是“有没有出现同样方案”，而是相对于现有技术，本领域技术人员是否容易得到该方案。创造性分析可以涉及现有技术之间的组合，但组合分析不能反向替代新颖性判断。当前检索上下文未提供三步法的完整官方原文，因此本轮不进一步展开三步法的具体步骤。

最后判断实用性，即方案是否能够制造或者使用，并能产生积极效果。授权条件是并列门槛，不能把创造性成立理解为自动满足实用性，也不能把具备实用性理解为当然具备新颖性。

### 3. 单独对比与组合对比必须分开

可以用以下线性流程复盘：

- 若问题是“申请日前是否已经有同样方案”，进入新颖性判断，原则上逐一审查单份对比文件；
- 若问题是“本领域技术人员是否容易从现有技术得到该方案”，进入创造性判断，才讨论技术启示及适当的组合关系；
- 若文件是在申请日前提交、申请日后公开或公告，且记载同样发明创造，先按抵触申请处理其新颖性效力；
- 不得把抵触申请与其他文件组合评价创造性，因为抵触申请的制度功能是排除同样申请重复获得新颖性基础上的授权，而不是作为创造性组合材料使用。

### 4. 审查员与代理人的双视角

从审查员视角，应先固定判断客体、申请日、对比文件公开时间及文件内容，再选择新颖性或创造性标准，避免先有结论后拼接证据。从代理人视角，应在撰写和答复中分别回应：对比文件是否真的公开了全部必要技术特征；其公开时间是否具有相应法律效力；若属于抵触申请，是否仅能用于新颖性；若审查意见转入创造性，应明确指出组合依据、技术启示和区别特征的作用，不能用“没有完全公开”直接代替创造性论证。

## C — 结论

专利法律制度基础的核心判断顺序是：先确认保护客体，再确认适用的授权条件；对发明和实用新型，围绕新颖性、创造性、实用性分别判断；新颖性原则上进行单份文件的同样方案对比，创造性才讨论是否容易想到及适当组合；现有技术与抵触申请都可能影响新颖性，但抵触申请具有“申请日前提交、申请日后公开或公告”的特殊时间结构，不能与其他文件组合评价创造性。外观设计则适用《专利法》第二十三条的现有设计、抵触申请和明显区别框架。

> 常见误区 / 易混淆点
>
> 1. 把“申请日前公众已知的技术”与“申请日前提交、申请日后公开的在先申请”混为一谈；前者是现有技术，后者可能构成抵触申请。
> 2. 用多份对比文件拼接后评价新颖性；新颖性首先要求对单份文件进行完整比对。
> 3. 把抵触申请与其他对比文件组合评价创造性；抵触申请的本轮教学定位仅限于新颖性效力。
> 4. 只记住“专利具有独占性”，忽略其时间性和地域性；具体权利范围、期限和地域仍须以适用法律及授权文本为准。
>
