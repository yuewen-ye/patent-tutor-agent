## 教学正文

## I — 法律问题

面对一项技术成果，审查与代理的共同起点不是立即讨论“能否授权”，而是先确定：该成果是否属于专利法上的发明创造、应进入何种专利类型与审查程序，以及制度中的法律文件各自承担什么功能。

本节的结论先行：专利制度以法定客体为入口，以法定程序为载体；代理人应把技术事实翻译为申请文件，审查人员则依照法定标准对申请进行审查。对于本节涉及的独占性、时间性、地域性以及制度发展沿革，检索上下文未提供直接条文依据，以下仅作制度框架说明，不将其表述为具体法条内容。

## R — 适用规则

### 1. 专利法上的保护客体

《专利法》第二条规定，本法所称“发明创造”包括发明、实用新型和外观设计。发明是对产品、方法或者其改进提出的新的技术方案；实用新型是对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计则是对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计〕

因此，代理视角应先识别技术方案究竟涉及产品、方法、产品的形状构造，还是产品视觉设计；审查视角则先核对申请所主张的对象能否被归入相应法定客体。不能把三种类型仅理解为名称不同：发明可以覆盖产品、方法及其改进；实用新型的法定定义聚焦于产品的形状、构造或者其结合；外观设计聚焦于产品视觉设计。

### 2. 制度体系与审查职责

中国专利制度的规范体系可按效力层级理解为：专利法确立基本制度和核心规则，专利法实施细则对程序与法定事项作进一步规定，专利审查指南用于细化审查实践中的操作标准。关于实施细则和审查指南的具体条文、版本及其法律定位，检索上下文未提供直接依据，本节不作超出该框架的具体断言。

《专利法》第三条规定，国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，并依法授予专利权；地方管理部门负责本行政区域内的专利管理工作。〔RAG: 中华人民共和国专利法.txt — 第三条：统一受理和审查专利申请，依法授予专利权〕 这构成“代理提交—行政审查—依法授权”的基本制度链条。

### 3. 制度特征与制度功能

从制度结构看，专利权具有三项基本特征：其一，独占性，指权利经依法授予后形成具有排他性的专有权；其二，时间性，指保护并非无限持续，而受法定期限限制；其三，地域性，指权利效力依各法域法律发生。上述三项是理解专利制度的概念性框架，检索上下文未提供其直接条文依据，实务中仍须回到具体权利类型、授权状态和适用法域核验。

专利制度通常通过授予有限期限内的专有权，激励研发主体披露技术信息，并促进技术实施、转化与经济发展。这是制度目的层面的概括；本轮检索材料未提供关于制度目的及发展历程的直接原文依据。

### 4. 程序结构的基础辨识

中国专利申请程序中存在初步审查与实质审查的制度区分。就本节而言，应先掌握其功能差异：初步审查侧重法定形式和应先行核验的事项；实质审查则面向授权条件作进一步审查。关于两类审查适用到何种专利类型、具体启动条件及审查事项，检索上下文未提供直接依据，办理具体案件必须以现行法、实施细则和审查指南核验，不能仅凭本节概括作结论。

## A — 规则适用

设某团队完成一项智能设备改进：一部分是新的控制方法，一部分是设备外壳的结构改进，另有一套可见的图案布局。代理人不能用“创新程度高”替代客体识别，而应逐项拆分：控制方法是否属于对方法或改进提出的技术方案；外壳结构是否属于产品形状、构造或其结合的技术方案；图案布局是否构成产品整体或局部的外观设计。该拆分直接影响申请类型、文件准备与后续审查路径。

审查人员的分析顺序同样应先从法定定义出发：先识别申请实际主张的对象，再将其与第二条的类型定义比对，最后才进入相应程序与授权条件的审查。代理人则应在申请前完成同一轮核对，以避免技术交底中的“方法、结构、视觉设计”混杂，导致权利布局与保护目标脱节。

对于“专利制度为何要求公开”的问题，应区分制度目的与个案结论：制度层面可将公开、激励和应用理解为相互关联的政策目标；个案层面是否能够授权，仍必须依照具体法定授权条件和程序材料判断，不能仅因技术具有市场价值或研发投入巨大即当然获得专利权。

## C — 结论

专利法律制度基础的核心不是背诵名词，而是形成固定的双视角工作顺序：先按《专利法》第二条识别保护客体，再按规范层级定位适用文件，并在代理端预先校验表达与布局、在审查端依法核验申请。专利的独占性、时间性、地域性说明其权利边界；初步审查与实质审查的区分说明其程序边界。

本节设有测评，请到【习题】区作答。

> 常见误区 / 易混淆点
>
> 1. 把“发明创造”误等同于“任何新想法”。专利法第二条要求的是法定类型中的对象，且三类客体的定义并不相同。〔RAG: 中华人民共和国专利法.txt — 第二条：发明、实用新型和外观设计的定义〕
> 2. 把实用新型与发明仅按技术价值高低区分。依第二条的定义，关键首先在于所主张对象是否为产品的形状、构造或者其结合。〔RAG: 中华人民共和国专利法.txt — 第二条：实用新型的定义〕
> 3. 把专利审查指南当作可脱离专利法单独适用的规范。本节仅确认其属于制度框架中的实践性文件；具体依据、版本与效力边界须以现行规范核验。
> 4. 把“初步审查”和“实质审查”理解为同义反复。二者功能不同，具体案件中应按现行程序规定确认适用范围。

### 从一份技术交底看三类专利客体（anchor_scenario）

> 甲公司研发智能仓储设备，技术人员提交的交底材料包含三部分：一是根据温度数据自动调整运行参数的控制步骤；二是让设备外壳便于拆装的新型卡扣结构；三是外壳面板上具有辨识度的局部图案。公司希望尽快申请专利，并要求代理人说明应当如何布局。

代理人首先不能只回答“技术很新，所以可以申请”。审查人员也不能先评价市场价值，而要分别识别：每一部分究竟是方法、产品结构还是产品视觉设计；不同客体将进入何种法定分类，并接受何种程序审查。

**锚定**：该情境将同一产品中的方法、结构和视觉设计对应到发明、实用新型、外观设计三类法定客体。

**先想一想**：如果只能先做一步判断，你会先根据哪些技术事实把三部分内容分别归类？

### 法条锚定：客体与审查职责（legal_anchor）

- **《中华人民共和国专利法》第二条**：专利法上的发明创造只有发明、实用新型、外观设计三类；三类的法定定义决定了技术成果首先应如何归类。
- **《中华人民共和国专利法》第三条**：国务院专利行政部门统一受理和审查专利申请，并依法授予专利权，构成行政审查的法定职责基础。

**为何重要**：第二条是识别保护客体的起点，第三条说明申请并非当然取得权利，而要经过法定行政审查。代理布局与审查判断均须先回到这两条。

### 演示：将混合技术交底拆分为法定客体（worked_example）

**案情/例题**：乙公司拟就一款便携式检测仪申请保护。交底载明：其一，仪器通过一组数据处理步骤自动输出检测结果；其二，仪器外壳采用便于固定的凹槽与卡扣组合；其三，仪器正面局部采用具有美感的图案设计。需要先判断三部分分别可对应何种专利法客体。
**适用规则**：《专利法》第二条：发明包括对产品、方法或者其改进提出的新的技术方案；实用新型包括对产品形状、构造或者其结合提出的适于实用的新的技术方案；外观设计包括对产品整体或者局部的形状、图案等作出的富有美感并适于工业应用的新设计。
**分步推演**：
1. 先把交底内容按事实拆开，避免把“同一产品”误当作只能采用同一种专利类型。数据处理步骤、外壳结构和面板图案的保护对象不同。 → *先拆分技术事实，而非整体贴标签。*
2. 数据处理步骤属于对方法提出的技术方案，符合第二条中“发明”可涉及方法的定义方向。 → *方法性技术方案优先按发明客体核对。*
3. 凹槽与卡扣组合描述的是产品外壳的形状、构造及其结合，应按实用新型的法定定义核对。 → *产品形状、构造的技术方案是实用新型识别重点。*
4. 正面局部图案属于产品局部的视觉设计，应按外观设计关于产品整体或者局部图案的定义核对；其是否最终获得授权仍须满足其他法定条件。 → *视觉设计不因附着于技术产品就自动成为发明。*
**结论**：该交底可分别形成发明、实用新型和外观设计的客体识别方向；最终申请策略及授权结论仍须结合完整技术内容、现行程序规定和其他法定条件确定。
**本题要点**：先按第二条拆分并匹配客体，是代理撰写和审查判断的共同前置步骤。

### 用审查语言理解制度入口（verbal_explanation）

可以把这一节理解为办案时的第一道分流。拿到技术交底后，先别急着问“能不能授权”，而是问“你要保护的到底是什么”。如果重点是一个产品、方法或者改进的技术方案，就先从发明的定义核对；如果重点是产品的形状、构造或者其结合，就核对实用新型；如果重点是产品整体或局部的外观设计，就核对外观设计。代理人这样做，是为了让申请布局与客户的技术成果相匹配；审查人员这样做，是为了让后面的审查建立在正确对象上。专利法负责定基本边界，实施细则和审查指南承担进一步的程序和实践细化，但具体适用时要核对现行文本，不能只凭概念记忆。

**点破术语**：发明创造；发明；实用新型；外观设计；统一受理和审查

### 顺序记忆表：客体—规范—程序（mnemonic）

**记忆锚**：三步核对表：“客—规—程”。客：先识别发明、实用新型、外观设计；规：再定位专利法、实施细则、审查指南等规范层次；程：最后核对受理、审查与依法授权的程序位置。
**映射**：
- 客
- 规
- 程
**何时用**：看到技术交底、申请布局或审查意见时，先按“客—规—程”检查是否跳过了客体识别这一前提。

### 反思：代理预判与审查核验如何对照（reflect_prompt）

**反思问题**：回看你曾接触过的一项技术成果：若其中同时有技术方法、产品结构和产品外观，你会如何按“客—规—程”重新整理其申请与审查问题？

**关注要点**：不要把同一产品中的不同技术事实混为单一客体。；区分制度特征的概念性说明与可直接援引的具体法条依据。；区分代理人前置布局职责与审查人员依法核验职责。

**连接**：连接到你已有的程序法学习经验：先确定处理对象与法定依据，再进入相应程序，而不是从结果倒推依据。

### 制度基础知识框架（knowledge_synthesis）

**知识框架**：
- 权利特征：独占性、时间性、地域性用于理解专利权的边界；本轮检索未提供其直接条文依据。
- 规范体系：专利法提供基本制度框架，实施细则和审查指南细化程序与审查实践；具体内容应核验现行规范。
- 保护客体：发明、实用新型、外观设计是《专利法》第二条规定的三类发明创造。
- 制度作用：制度通常通过公开与有限期限内权利激励创造、促进应用；本轮检索未提供该制度目的的直接原文依据。
- 程序特点：初步审查与实质审查功能不同；具体适用范围应依现行规范确认。
**概念关系**：技术事实是起点：先拆分方法、产品结构和视觉设计，再对应三类法定客体。；客体识别在前，规范定位与程序审查在后；错误分类会使代理布局和审查路径同时偏离。；权利边界、制度目的和程序阶段共同构成理解专利制度的基础框架，但具体结论须有相应规范依据。
**必记**：客体识别必须从《专利法》第二条的法定定义开始，而非从技术价值或产品名称开始。；国务院专利行政部门依法统一受理和审查专利申请，并依法授予专利权。；制度概括不能替代具体案件中的现行法条、实施细则和审查指南核验。

### 专利法律制度基础速查卡（summary_card）

**要点卡**：
- **三类保护客体**：发明、实用新型、外观设计均有《专利法》第二条规定的独立定义。
- **发明**：可以是对产品、方法或者其改进提出的新的技术方案。
- **实用新型**：重点是产品的形状、构造或者其结合所形成的适于实用的新的技术方案。
- **外观设计**：重点是产品整体或局部的形状、图案等视觉设计，并要求富有美感、适于工业应用。
- **审查职责**：国务院专利行政部门统一受理和审查专利申请，并依法授予专利权。
- **制度框架**：专利法定基本规则，实施细则与审查指南的具体内容须按现行文本核验。
**必背**：《专利法》第二条：发明创造包括发明、实用新型和外观设计。；先识别法定客体，再定位规范和程序。；制度特征与目的的概括不能替代具体法条和现行规范核验。
**一句话总结**：专利制度基础的办案顺序是：以法定客体为入口，以规范依据为准绳，以行政审查程序为路径。
