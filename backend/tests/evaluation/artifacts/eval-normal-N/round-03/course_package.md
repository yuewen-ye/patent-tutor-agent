## 教学正文

## I｜制度问题：专利制度到底保护什么

复盘专利实务时，代理人与审查员面对的往往是同一组技术事实，但切入角度不同。代理人要把客户的产品、方法、结构和外观拆开，寻找合适的保护客体；审查员要依据法定定义核对申请主张，并判断后续审查条件是否匹配。最稳妥的起点不是“这项技术有没有商业价值”，而是先问：它属于哪一种法定专利客体？

## R｜法条与制度框架

《中华人民共和国专利法》第二条明确规定，发明创造包括发明、实用新型和外观设计。发明针对产品、方法或者其改进提出新的技术方案；实用新型针对产品的形状、构造或者其结合提出适于实用的新的技术方案；外观设计针对产品整体或者局部的形状、图案或者其结合，以及色彩与形状、图案的结合，提出富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：本法所称的发明创造是指发明、实用新型和外观设计；发明，是指对产品、方法或者其改进所提出的新的技术方案；实用新型，是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计，是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计〕

第三条规定，国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请，依法授予专利权；地方专利管理部门负责本行政区域内的专利管理工作。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门负责管理全国的专利工作；统一受理和审查专利申请，依法授予专利权；省、自治区、直辖市人民政府管理专利工作的部门负责本行政区域内的专利管理工作〕

对发明和实用新型，第二十二条规定了新颖性、创造性和实用性三项授权条件，并将现有技术界定为申请日以前在国内外为公众所知的技术。该条同时把申请日前已经提出、但在申请日以后公布或者公告的同样发明或者实用新型申请纳入新颖性判断的特殊情形。〔RAG: 中华人民共和国专利法.txt — 第二十二条：授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性；本法所称现有技术，是指申请日以前在国内外为公众所知的技术；新颖性还涉及申请日以前提出并在申请日以后公布或公告的同样发明或者实用新型〕

审查程序上，现有检索材料直接支持：发明专利申请经实质审查没有发现驳回理由的，可以授予专利权；实用新型和外观设计专利申请经初步审查没有发现驳回理由的，可以授予相应专利权，专利权均自公告之日起生效。〔RAG: 中华人民共和国专利法.txt — 第三十九条：发明专利申请经实质审查没有发现驳回理由的，由国务院专利行政部门作出授予发明专利权的决定；第四十条：实用新型和外观设计专利申请经初步审查没有发现驳回理由的，由国务院专利行政部门作出授予相应专利权的决定；专利权自公告之日起生效〕关于发明专利“早期公开、延迟审查”的完整流程，以及相关制度的历史沿革，本轮检索上下文未提供足以逐项核验的直接原文，因此这里只确认发明与实用新型、外观设计在实质审查和初步审查上的程序差异，不补充未经核验的具体时间规则。

中国专利制度的规范框架可以按“专利法—专利法实施细则—专利审查指南”理解：专利法提供基本制度和授权边界，实施细则细化程序与手续，审查指南提供审查和代理实践中的操作性说明。审查指南必须在法律和实施细则范围内适用，不能修改或替代上位法。本轮检索未提供实施细则和审查指南的具体条文，涉及具体程序时仍应回到相应权威文本核验。

专利制度的基本特征可作三维定位：独占性强调权利人在法定范围内具有排他实施地位；时间性强调保护并非永久；地域性强调一国或一地区授予的专利权不当然在其他国家或地区生效。保护期限方面，第四十二条规定发明为二十年、实用新型为十年、外观设计为十五年，均自申请日起计算。〔RAG: 中华人民共和国专利法.txt — 第四十二条第一款：发明专利权的期限为二十年，实用新型专利权的期限为十年，外观设计专利权的期限为十五年，均自申请日起计算〕注意区分“期限起算”和“权利生效”：期限自申请日起算，权利生效则以授权公告为节点。

制度作用方面，本节点教学框架将专利制度概括为激励发明创造、促进技术公开、推动技术应用和经济发展。该概括用于理解制度目的，不替代具体授权条件或权利范围条文；本轮检索上下文未提供《专利法》第一条的直接原文，故不对其作逐字引述。

## A｜双视角适用

代理视角的基本顺序是“拆事实、定客体、查条件”。例如，同一产品既可能包含内部结构改进，也可能包含外观图案；不能因为它们附着于同一产品，就认定法律上只能选择一种客体。内部结构应依据其是否构成产品形状、构造或者其结合的技术方案，核对实用新型定义；如果申请主张的是产品、方法或其改进的新的技术方案，还应核对发明定义。方法方案不能直接作为实用新型客体，但是否属于发明，仍需判断其是否构成法定的新的技术方案。外壳形状、图案和色彩组合，则应核对外观设计定义。

审查视角的基本顺序是“核客体、定程序、查门槛”。先依据第二条核对申请文件实际主张的客体，再依据第三十九条、第四十条识别相应的审查路径，最后对发明和实用新型进入第二十二条的授权条件判断。客体识别不等于当然授权；即使客体定位正确，也仍须分别处理新颖性、创造性和实用性。

进入后续新颖性与创造性学习时，务必先问两个问题：第一，对比材料属于一般现有技术，还是属于申请日前提出、申请日后公开的同样申请这一抵触申请情形；第二，现在判断的是新颖性，还是创造性。新颖性原则上对每份对比文件进行单独对比，不能把两份文献拼接后直接否定新颖性；创造性评价才进入最接近现有技术、区别特征及技术启示的分析。抵触申请用于新颖性判断，不作为创造性评价中的一般现有技术组合材料。这里是后续节点的防混淆主线，不替代具体审查指南对证据和判断步骤的完整规定。

## C｜结论与复盘

本节点可以收束为四句话：第一，第二条解决“保护什么”，即发明、实用新型和外观设计的客体分类；第二，第三条解决“谁来统一受理和审查”；第三，第三十九条、第四十条解决不同客体的审查程序位置；第四，第二十二条解决发明和实用新型进入授权条件后的三性判断。独占性、时间性、地域性说明专利权的排他范围、存续限制和效力边界；专利法、实施细则、审查指南构成从基本规则到操作说明的制度框架；制度作用则帮助理解专利制度为什么同时强调保护与公开。

常见误区一是把“方法”直接放进实用新型。正解是：实用新型的法定对象限于产品的形状、构造或者其结合；区分判据是看权利要求主张的对象是否为产品及其形状、构造，而不是看它是否有技术效果。

常见误区二是把客体识别等同于授权成功。正解是：客体定位只是第一道门，发明和实用新型仍须满足新颖性、创造性和实用性；区分判据是分别检查第二条的客体定义与第二十二条的授权条件。

常见误区三是把两份文献直接组合用于否定新颖性。正解是：新颖性通常以单份对比文件判断，创造性才讨论组合及技术启示；区分判据是先看当前法律问题是“是否被单一公开完整揭示”，还是“对本领域技术人员是否显而易见”。

常见误区四是把抵触申请当作一般现有技术，或者用于创造性评价。正解是：抵触申请属于新颖性判断中的特殊来源，应与申请日前已为公众所知的现有技术区分；区分判据是看公开时间、申请时间及同样发明或实用新型的对应关系。

常见误区五是把授权公告生效时间与保护期限起算时间混同。正解是：专利权自公告之日起生效，但保护期限自申请日起计算；区分判据是分别回答“何时产生可行使的专利权”和“期限从何时开始计算”。

### 从同一产品进入代理与审查双视角（anchor_scenario）

> 某初创企业研发了一款可折叠手机支架：支架臂采用新型铰链结构，内部控制程序还包含姿态调节方法，外壳则形成独特的曲面、线条和配色。企业准备在中国申请专利，并计划参加国际展会。代理人希望把结构、方法和外观分别布局，审查员则要先判断申请主张是否分别落入发明、实用新型或外观设计的法定范围，再决定后续审查路径。双方的冲突在于：同一产品能否包含不同客体，以及客体定位、审查程序和授权条件应按什么顺序处理。

**锚定**：该情境锚定三类专利客体、独占性时间性地域性以及代理端与审查端共同遵循的“先定客体、再定程序、后查条件”框架。

**先想一想**：看到同一产品同时包含方法、结构和外观时，你会先依据什么事实区分客体，而不是先依据产品名称或商业宣传作结论？

### 法条锚点：客体、程序与授权门槛（legal_anchor）

- **《中华人民共和国专利法》第二条**：第二条把可申请保护的对象分成发明、实用新型和外观设计，并分别规定技术方案、产品形状构造和视觉设计的边界。
- **《中华人民共和国专利法》第三条**：第三条确定国家统一受理、审查并依法授予专利权的主管机关，同时说明地方专利管理部门的区域管理职责。
- **《中华人民共和国专利法》第二十二条**：第二十二条是发明和实用新型的三性门槛，并区分申请日前公众所知的现有技术与申请日前提出、申请日后公开的同样申请情形。
- **《中华人民共和国专利法》第三十九条、第四十条**：第三十九条、第四十条说明发明进入实质审查，实用新型和外观设计经初步审查没有发现驳回理由时授予专利权；专利权自公告之日起生效。
- **《中华人民共和国专利法》第四十二条第一款**：第四十二条规定通常保护期限：发明二十年、实用新型十年、外观设计十五年，均自申请日起计算。

**为何重要**：这些条文分别回答“保护什么、谁来审、怎样审、要满足什么条件以及保护多久”。掌握它们，才能把代理布局、审查分流和后续新颖性与创造性判断放在同一条法律主线上。

### 示例：一件产品中的三类事实如何拆分（worked_example）

**案情/例题**：某公司提交一套可折叠手机支架资料：支架臂采用新型铰链结构，控制系统包含调节支架姿态的方法，外壳采用独特曲面和配色。请演示代理人如何识别可能的专利客体，以及审查员如何衔接相应审查程序和后续授权条件。
**适用规则**：《中华人民共和国专利法》第二条规定发明、实用新型和外观设计的定义；第三十九条规定发明专利申请经实质审查没有发现驳回理由时授予专利权；第四十条规定实用新型和外观设计经初步审查没有发现驳回理由时授予专利权；第二十二条规定发明和实用新型应具备新颖性、创造性和实用性。
**分步推演**：
1. 先拆分事实，而不是按“手机支架”这一产品名称整体归类。铰链结构对应产品的形状、构造或其结合；姿态调节方法对应方法技术方案；曲面、图案和配色主要体现产品视觉设计。 → *第一步：把技术结构、方法和视觉设计分开。*
2. 对铰链结构，核对其是否属于产品形状、构造或者其结合的适于实用的新的技术方案；如果申请主张的是产品、方法或其改进的新的技术方案，也可以进一步核对发明定义。 → *第二步：结构改进可能进入实用新型或发明的客体分析。*
3. 对姿态调节方法，实用新型的法定对象限于产品的形状、构造或者其结合，因此不能仅因该方法服务于支架就直接归入实用新型；是否属于发明，仍需判断其是否构成新的技术方案。 → *第三步：方法不能直接作为实用新型，发明资格仍需依法判断。*
4. 对曲面、图案和配色，核对其是否构成针对产品整体或局部、富有美感并适于工业应用的新设计；符合定义时进入外观设计客体分析。 → *第四步：视觉设计按外观设计定义核对。*
5. 完成客体定位后，审查员再按客体匹配程序：发明进入实质审查，实用新型和外观设计进入初步审查。对发明和实用新型，还要继续检查新颖性、创造性和实用性，不能把客体识别当成授权结论。 → *第五步：客体、审查程序和授权条件依次衔接。*
**结论**：同一产品可以分别包含发明、实用新型和外观设计的不同保护内容，但每一部分都要独立核对第二条定义；方法不能直接作为实用新型，发明和实用新型还须继续满足第二十二条的三性条件。
**本题要点**：代理与审查共同的第一能力是把事实拆成法定客体，再按客体匹配审查程序和授权条件。

### 把专利制度基础讲成人话（verbal_explanation）

咱们复盘专利实务时，先别急着问“这项技术有没有创新”，先问它到底是什么。产品、方法或者改进的技术方案，先看发明；如果重点是产品的形状、构造或者它们的结合，再看实用新型；如果重点是产品外观的形状、图案、色彩组合，并且有美感、能工业应用，就看外观设计。接下来再看谁来审、怎么审：国务院专利行政部门统一受理和审查申请，发明要进入实质审查，实用新型和外观设计主要对应初步审查。最后才进入发明和实用新型的三性判断。专利权也不是永久、全球通行的门票：独占性说的是法定范围内排他，时间性说的是有期限，地域性说的是一国授权不当然覆盖别国。遇到新颖性和创造性问题时，再提醒自己先分清一般现有技术和抵触申请，再分清是在做单独对比的新颖性判断，还是涉及组合和技术启示的创造性判断。

**点破术语**：独占性；时间性；地域性；发明；实用新型；外观设计；抵触申请

**类比**：可以把制度理解为一套分层检票系统：先检查你拿的是什么类型的票，即客体；再看哪个窗口受理和审查，即主管机关与程序；最后检查是否满足入场条件，即授权条件。类比只帮助记忆，正式结论仍以法条文字为准。

### 客体—主管—程序—条件记忆表（mnemonic）

**记忆锚**：四步记忆表：客体—主管—程序—条件；客体用“发明实外”，主管看“国专局统一审查”，程序记“发明实审、实用新型外观初审”，条件记“新颖性、创造性、实用性”。进入后续判断时，再加“来源—问题”二分表：先分一般现有技术与抵触申请，再分新颖性与创造性。
**映射**：
- 客体
- 主管
- 发明实审
- 实用新型外观初审
- 三性
- 来源
- 问题
**何时用**：阅读申请文件、撰写代理意见或复盘审查意见时，先按“客体—主管—程序—条件”定位制度层次；遇到对比文件时，再按“来源—问题”避免把抵触申请、现有技术、新颖性和创造性混用。

### 代理与审查双视角反思（reflect_prompt）

**反思问题**：如果客户把结构、控制方法和外观全部塞进一份“专利方案”，你会如何分别从代理布局和审查核对两个角度处理？

**关注要点**：是否把技术结构、方法方案与视觉设计分别描述，而不是按产品名称整体归类。；是否用第二条的法定定义，而不是“创新”“设计”等日常称谓确定客体。；是否在客体识别后，继续区分发明和实用新型的授权条件，以及发明与实用新型、外观设计的审查程序。；遇到对比材料时，是否先判断一般现有技术还是抵触申请，再判断新颖性还是创造性。；是否区分专利权自公告之日起生效与保护期限自申请日起计算。

**连接**：连接到代理撰写中的技术特征拆分经验，以及后续专利授权条件、审查程序和相关法律知识学习；本节点先建立制度顺序，后续节点再深化具体判断标准。

### 专利法律制度基础知识网络（knowledge_synthesis）

**知识框架**：
- 制度基本特征：独占性、时间性、地域性分别说明专有实施、期限限制和地域效力边界。
- 中国专利制度体系：专利法提供基本规则，专利法实施细则细化程序，专利审查指南提供操作性说明，但不得替代或修改上位法。
- 保护客体：第二条将发明创造分为发明、实用新型和外观设计，并分别规定技术方案、产品形状构造和视觉设计的定义。
- 制度作用：本节点教学框架将专利制度的作用概括为激励发明创造、促进技术公开、推动技术应用和经济发展；具体法律效果仍须以相应规范为准。
- 审查制度发展与程序特点：现有材料直接支持发明经实质审查、实用新型和外观设计经初步审查；关于早期公开、延迟审查的完整历史和具体流程，本轮检索上下文未提供直接依据。
**概念关系**：客体识别是制度入口，主管机关和审查程序是组织与流程层，授权条件是实体判断层，三者按“客体—程序—条件”递进。；第二十二条中的现有技术与同样在先申请分别对应不同来源判断；分析时先分来源，再分新颖性与创造性问题。；独占性、时间性和地域性共同限定专利权的排他范围、存续时间和空间效力；制度作用则解释保护与公开之间的政策联系。
**必记**：先依据第二条定位发明、实用新型或外观设计，再依据第三条、第三十九条和第四十条匹配主管机关与审查程序。；发明和实用新型进入第二十二条后，还须满足新颖性、创造性和实用性；客体识别不等于当然授权。；新颖性通常以单份对比文件判断，不能把多份文献直接组合来否定新颖性；抵触申请只作为新颖性判断中的特殊来源。；专利权自授权公告之日起生效，但保护期限从申请日起计算；通常发明二十年、实用新型十年、外观设计十五年。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **制度特征**：独占性是法定范围内排他，时间性是保护有期限，地域性是一国授权不当然覆盖其他国家或地区。
- **三类客体**：发明看产品、方法或其改进的新的技术方案；实用新型看产品形状、构造或其结合；外观设计看富有美感且适于工业应用的新设计。
- **审查程序**：发明经实质审查，实用新型和外观设计经初步审查；专利权自公告之日起生效。
- **授权条件**：发明和实用新型还须满足新颖性、创造性和实用性，客体正确不等于当然授权。
- **时间基准**：通常保护期限为发明二十年、实用新型十年、外观设计十五年，均自申请日起计算。
- **易混判断**：先分一般现有技术与抵触申请，再分新颖性与创造性；新颖性不把多份文献直接拼接。
**必背**：《专利法》第二条规定发明创造包括发明、实用新型和外观设计，并分别规定三者定义。；《专利法》第三条规定国务院专利行政部门统一受理和审查专利申请，依法授予专利权。；《专利法》第二十二条规定发明和实用新型应具备新颖性、创造性和实用性。；发明经实质审查，实用新型和外观设计经初步审查；专利权自公告之日起生效。；保护期限自申请日起计算，通常为发明二十年、实用新型十年、外观设计十五年。；新颖性按单份对比，抵触申请用于新颖性，不把多份文献直接组合破坏新颖性。
**一句话总结**：专利实务先按法定定义拆分客体，再匹配审查程序，最后区分授权条件与对比材料来源。
