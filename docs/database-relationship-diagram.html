运行支撑

schema_migrations
初始 schema 版本记录
memory_items
Store 兼容记忆；非业务权威数据

学员与画像

students
学员根实体
student_profiles
当前完整画像
profile_history
不可变画像与 mastery 快照
student_node_mastery
当前 BKT 掌握度

会话与课程过程

sessions
课程、诊断、聊天和反馈会话
session_states
最新完整 StateDict、事件与活动窗口
rounds
专家协作和 Judge 整合尝试
learner_learning_plans
跨会话活动计划及游标
learner_learning_plan_nodes
完整路线的有序节点状态

学习闭环

onboarding_responses
原始问卷提交
questions
课程题及 CAT 诊断题快照
attempts
服务端判题和幂等作答
mastery_events
直接观测/推断 BKT 审计

产物与引用

artifacts
Markdown 路径、哈希及归属索引
legal_citations
法条、来源和核验状态
artifact_citations
产物—引用多对多关系

主关系

  • students → sessions、画像、掌握度、计划、作答和问卷。
  • sessions → session_states（一对一）、rounds、题目和 Artifact；反馈会话通过 parent_session_id 指向课程会话。
  • learner_learning_plans → learner_learning_plan_nodes；活动窗口不是重复关系表，而在会话 StateDict 快照中。
  • questions → attempts → mastery_events → student_node_mastery。
  • artifacts ↔ legal_citations 通过 artifact_citations 关联。
