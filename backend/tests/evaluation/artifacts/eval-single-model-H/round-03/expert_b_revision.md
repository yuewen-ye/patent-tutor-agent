# 专家 B 修订稿

## teaching_content

## 1. 场景导入

想象一个材料研发团队完成了耐高温复合涂层：它既有树脂和陶瓷颗粒的组成，还包含制备工艺，最终涂在电池壳体上并呈现特定颜色纹理。团队准备申请专利时，最先遇到的不是“效果好不好”，而是三个入口问题：保护的究竟是技术方案还是外观表达？应当查哪一套规则？后续的授权条件应当从哪一条路径进入？

## 2. 人话解释

可以把专利学习想成“先分流、再查规则”。第一步是确认要保护的对象：发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计则聚焦产品外观的形状、图案、色彩及其结合。

这里有一个必须卡住的边界：制备方法属于发明客体，不能放进实用新型路径。材料组成也不能只因写了“材料”二字就当然归入实用新型；要看申请具体限定的是什么。只有当技术方案落实为产品的形状、构造或者其结合时，才可能进一步考虑实用新型。不同对象不能混用一套规则。

第二步是找到规则的层级。专利法像总规则，规定保护客体、基本门槛和基本权利；实施细则承接具体程序；审查指南帮助审查和申请实践具体化。人话说就是：先看“法律允许什么、要求什么”，再看“程序上怎么做”，最后用指南辅助操作，不能倒过来。

后续学习会分别进入发明、实用新型和外观设计的授权条件。其中，发明和实用新型的授权条件包括新颖性、创造性和实用性；外观设计也有不同于三性的专门条件。本节只建立入口，不在这里完成这些条件的具体判断。

专利权本身也有边界：它具有独占性、时间性和地域性。也就是说，权利人在法定范围和期限内享有排他保护，但专利权不是无限期、全球范围、没有边界的绝对权。

## 3. 法条回扣

《专利法》第二条明确，发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品外观要素所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明、实用新型和外观设计的定义〕

因此，看到“制备工艺”时，应先想到发明路径；看到产品形状、构造及其结合的技术方案时，才考虑实用新型路径；看到产品外观表达时，再考虑外观设计路径。具体授权条件将在后续专门章节学习。

本轮检索材料未提供早期公开、延迟审查以及初步审查与实质审查并存的完整、可定位依据。因此，本节不把相关历史沿革或程序分工当作必须掌握的事实，只提示后续将学习申请和审查程序。

## 4. 类比 / 口诀

记忆口诀是：“先看保护啥，再找哪条法；方法归发明，形构才实用，外观另分家。”这里的“分流”类比只用于记忆客体识别顺序：它不能替代对权利要求文字和申请文件的正式分析。

可以先把后续的授权条件记成“客体不同，门槛不同”。这只是导航提示，不能把复杂审查规则简化成机械口号，也不能据此直接判断一项申请能否授权。

## 5. 应试提示

看到材料领域题干，建议按三步扫描：第一，圈出要保护的是产品或方法技术方案、产品形状构造，还是产品外观；第二，先依专利法确认基本客体分类；第三，再确定应当进入后续哪个专门规则模块。

高频陷阱有三个：把制备方法误放进实用新型；看到材料组成就不分析具体限定而直接认定实用新型；把专利法、实施细则和审查指南的作用及层级颠倒。遇到题目时，先问适用对象，再问规则来源，最后才下结论。
