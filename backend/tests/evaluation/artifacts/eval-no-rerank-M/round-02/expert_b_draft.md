## 教学正文

## 1. 场景导入

在智能制造领域，一家初创企业研发了一款基于AI的柔性生产线控制系统，他们认为这是一项全新的技术方案，能显著提升生产效率。但担心在产品展示会上公开后，竞争对手可能快速复制。企业负责人想知道：这套系统能不能申请专利？申请后，别人再用类似方法生产是否会侵犯？这个真实情境同时触及专利保护客体（技术方案是否属于可专利对象）和授权三性（新颖性、创造性、实用性）的基础判断，以及后续侵权判定的大门。

## 2. 人话解释

专利制度就像给发明创造发一张‘时间限定版’的独占执照：它鼓励你把新东西公开出来，但同时保护你不被别人随便抄袭使用一段时间。具体来说，专利法把发明创造分成发明、实用新型和外观设计三种，发明是‘新的技术方案’，实用新型是‘适于实用的形状构造’，外观设计是‘有美感的新设计’。专利制度有独占性（别人不能用）、时间性（有限期限）和地域性（主要在中国境内）。中国专利体系通过专利法、细则和审查指南来运作，能激励研发、促进技术公开，推动经济发展。基础阶段先稳住这些概念边界，为后面新颖性判断（看有没有公开过）或侵权判定（看别人用没用你的技术）打好底子。

## 3. 法条回扣

《专利法》第二条明确规定发明、实用新型和外观设计的定义，是判断保护客体的核心依据。第六十四条规定发明和实用新型的保护范围以权利要求内容为准，说明书附图可解释；外观设计以图片照片为准。这些条款直接回扣到专利制度的基础框架，说明专利法是整个专利体系的根本法源，细则和审查指南是操作指南。

## 4. 类比 / 口诀

把专利制度比作商店的专利证：发明创造像一种‘新商品’，申请专利就是把它的生产秘方登记在政府商店里，获得独占销售权一段时间（时间性），但只限于特定地区（地域性），别人想抄袭就侵犯。口诀：‘三客体—独占权—有限期’。适用边界是：只适用于技术方案，不适用于纯商业方法或抽象概念；时间性保证是有限的，不是永远独占。

## 5. 应试提示

题干关键词：保护客体、独占性、时间性、地域性、初步审查与实质审查。判断步骤：先确认技术方案属于发明/实用新型/外观设计，再看是否满足三性。常见陷阱是把商业方法当作技术方案，或忽略地域性只看中国境内。考试题常结合‘申请日前公开’或‘权利要求范围’来考。

### 智能制造研发情境锚定（anchor_scenario）

> 智能制造领域，一家初创企业自主研发了基于AI的柔性生产线控制系统，该系统能显著提升生产效率。他们计划申请专利，同时担心在产品展会展示后，竞争对手可能复制使用。

**锚定**：用同一技术事实锚定专利保护客体与授权三性的基础概念。

**先想一想**：如果你是专利代理人，看到‘展会展示’这个动作，第一反应是风险还是安全？为什么？

### 法条锚定核心概念（legal_anchor）

- **《专利法》第二条**：发明、实用新型、外观设计三客体定义
- **《专利法》第六十四条**：保护范围以权利要求为准
- **《专利法》第二十二条**：三性授权门槛

**为何重要**：本条是专利制度基础框架，必须先立住法条，才能判断新颖性或侵权。

### 智能制造专利判定案例演示（worked_example）

**案情/例题**：某公司2024年5月在政府主办的国际智能制造展会上展示新型AI柔性生产线系统，2024年10月提出专利申请。问：该公开是否影响新颖性？后续侵权判定需注意什么？
**适用规则**：《专利法》第二十四条及第二条
**分步推演**：
1. 展出日在申请日前，属政府主办国际展会法定公开情形 → *落入宽限期适用范围*
2. 申请日距展出日约5个月，在6个月宽限期内 → *公开不丧失新颖性*
3. 但仍需判断技术方案是否为可保护客体，侵权时看权利要求范围 → *基础概念应用到判定链*
**结论**：展出不破坏新颖性，但后续侵权判定需结合权利要求内容。
**本题要点**：真实案例展示时间点与保护客体的结合应用。

### 知识框架综合（knowledge_synthesis）

**知识框架**：
- 保护客体：发明、实用新型、外观设计（专利法第2条）
- 制度体系：专利法、细则、审查指南
- 作用与特点：激励创新、早期公开延迟审查
**概念关系**：保护客体决定能否授权，三性是授权核心，侵权判定基于授权后效力
**必记**：三种专利客体定义不同；制度特点服务于创新激励

### 速查卡（summary_card）

**要点卡**：
- **保护客体**：三种专利：发明、实用新型、外观设计
- **制度特征**：独占性、时间性、地域性
- **中国特点**：早期公开延迟审查，审查制并存
**必背**：三客体定义；制度体系
**一句话总结**：先立保护客体与制度基础，再进新颖性与侵权判定。
