## 教学正文

## 1. 场景导入

某科技公司研发了一套用于仓储机器人的控制方案：其中既有控制程序和控制方法，也有机器人底盘的结构改进，还有设备外壳的局部图案设计。代理人准备一次性梳理申请策略，但审查员可能分别从保护客体、授权条件和申请文件修改边界进行审查。此时，代理人不能只问“这是不是新技术”，而要先问：它属于哪一种专利客体？应当适用哪套审查路径？申请日前的资料分别能证明什么？

## 2. 人话解释

专利制度可以理解为一项“用公开换保护”的法律安排：申请人把技术方案或设计公开出来，满足法定条件后，国家在一定范围和期限内给予专利权人排他性保护。这里有三个关键词。第一是独占性，专利权人在保护期限内可以依法排除他人未经许可实施其专利；第二是时间性，保护不是永久的，期限届满后技术进入公共领域；第三是地域性，一国授予的专利权原则上只在该国法律范围内发生效力。

判断一项成果能否进入专利制度，先看保护客体。发明主要对应产品、方法或者其改进提出的新的技术方案；实用新型对应产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计对应产品整体或局部的形状、图案、色彩及其结合形成的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明、实用新型和外观设计的定义〕

客体合格后，再进入授权条件判断。对发明和实用新型，核心是新颖性、创造性和实用性；新颖性重点看申请日前是否已有相同技术被公众知悉，创造性重点看相对于现有技术是否显而易见，实用性重点看能否制造或使用并产生积极效果。〔RAG: 中华人民共和国专利法.txt — 第二十二条：发明和实用新型应当具备新颖性、创造性和实用性，现有技术是申请日前在国内外为公众所知的技术〕

实务上可以采用“对象—时间—用途—结论”的顺序：先确定审查对象，再确定申请日和公开时间，接着判断某份材料只能用于新颖性、还是也能进入创造性分析，最后才作结论。特别要注意，申请日以后公开、但在申请日以前已经向国务院专利行政部门提出申请并记载同样发明的专利文件，可能影响新颖性判断；它不能因此当然成为创造性评价中的组合材料。〔RAG: 中华人民共和国专利法.txt — 第二十二条：申请日前提出、申请日后公布且记载同样发明的专利申请文件属于新颖性判断中的特殊情形〕

代理人答复审查意见时，还要守住修改边界。申请人可以修改申请文件，但发明和实用新型的修改不得超出原说明书和权利要求书记载的范围；外观设计的修改不得超出原图片或者照片表示的范围。〔RAG: 中华人民共和国专利法.txt — 第三十三条：修改不得超出原说明书和权利要求书记载的范围，外观设计不得超出原图片或者照片表示的范围〕

中国专利制度的规范体系不能只看一部法律：通常要结合专利法、专利法实施细则以及专利审查指南理解申请、审查和代理操作。国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请并依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：国务院专利行政部门负责管理全国的专利工作，统一受理和审查专利申请〕

专利制度的功能也不只是“给权利人一张证书”，还包括激励发明创造、促使技术公开、推动技术应用和经济发展。至于中国制度发展中的早期公开、延迟审查，以及初步审查与实质审查并存等制度沿革，本轮检索材料没有提供足以核验的历史原文，因此这里只作为制度结构提示，具体年份、制度来源和跨法域差异应另行检索核对。

从审查视角，重点是按照法律标准拆解客体、时间、对比文件和修改内容；从代理视角，重点是提前布局权利要求、保存原始记载、识别证据用途，并在答复时把每一项修改与原申请文件建立对应关系。两种视角的共同底线是：不能把不同法律问题混成一个结论。

## 3. 法条回扣

本节以《专利法》第二条确定保护客体，以第二十二条确定发明和实用新型的三性及现有技术范围，以第三十三条控制申请文件修改边界；《专利法》第三条则帮助定位中国专利制度的行政审查体系。上述条文构成“先认客体、再审三性、最后查程序动作”的基础框架。

## 4. 类比 / 口诀

可以记成“客体先分家，三性再过关，修改看原家”。“客体先分家”是把发明、实用新型、外观设计分开；“三性再过关”是分别检查新颖性、创造性、实用性；“修改看原家”是所有修改都要回到原说明书、权利要求书或原图片照片寻找依据。

这个口诀只用于建立审查顺序，不能替代具体法律判断。尤其是“先新颖性、再创造性”的顺序是实务上的高效分析路径，并不意味着任何案件都可以脱离具体法条、审查指南和证据直接套用。

## 5. 应试提示

看到“产品、方法、形状、构造、图案、色彩”等词，先识别保护客体；看到“申请日前公开”“申请日后公布”“同样的发明”等词，核对时间和材料用途；看到“补充技术特征”“增加参数”“删除限制”等修改动作，立即追问原申请文件是否有明确或可直接、明确得到的依据。

最常见的混淆有三组：第一，新颖性通常强调单独对比，创造性则要判断相对于现有技术是否显而易见，不能把两者的证明方法混为一谈；第二，抵触申请可能用于新颖性判断，但不能直接拿来评价创造性；第三，初步审查和实质审查承担的功能不同，不能因为申请文件形式合格就推断三性已经成立。

### 从一项机器人技术看专利制度基础（anchor_scenario）

> 某科技公司研发了一套仓储机器人系统，其中包括控制程序和控制方法、机器人底盘的结构改进，以及设备外壳的局部图案设计。研发负责人认为这些内容都属于“技术创新”，希望用一份申请全部解决；代理人却发现，不同成果可能对应不同专利客体，审查时还要分别面对三性判断、审查程序和修改范围问题。

**锚定**：用同一研发事实锚定保护客体、授权三性、中国专利制度体系和修改边界四个基础知识点。

**先想一想**：如果你是代理人，面对这套机器人方案时，第一步应当先判断技术是否先进，还是先判断每项成果属于哪一种专利客体？

### 用核心法条搭起制度底座（legal_anchor）

- **《专利法》第二条**：专利法保护的发明创造分为发明、实用新型和外观设计，三者的对象和定义不同。
- **《专利法》第二十二条**：发明和实用新型要过新颖性、创造性、实用性三道授权门槛，现有技术原则上看申请日前在国内外为公众所知的技术。
- **《专利法》第三十三条**：申请文件可以修改，但发明和实用新型不能超出原说明书、权利要求书记载范围，外观设计不能超出原图片或照片表示范围。
- **《专利法》第三条**：国务院专利行政部门负责全国专利工作的管理、专利申请的统一受理和审查以及专利权授予。

**为何重要**：这些条文分别回答“保护什么”“能否授权”“怎样修改”和“谁负责审查”四个基础问题，是从审查与代理双视角复盘专利实务的共同法律底座。

### 把对象、时间、用途、结论串起来（worked_example）

**案情/例题**：甲公司申请一项机器人控制方法专利。对比材料甲在申请日前已经公开，披露了权利要求中的部分技术特征；材料乙记载同样的发明，申请日前已向国务院专利行政部门提出申请，但申请日后才公布。答复审查意见时，甲公司还想加入原说明书和权利要求书没有记载的新技术特征。需要判断这些材料分别有什么法律用途，以及拟议修改是否存在边界问题。
**适用规则**：《专利法》第二十二条关于新颖性、创造性和现有技术的规定；《专利法》第三十三条关于修改不得超出原说明书和权利要求书记载范围的规定。
**分步推演**：
1. 先固定审查对象和时间点：对象是发明方法，基准时间是申请日；材料甲在申请日前公开，材料乙在申请日前提出但申请日后公布。 → *先确定客体、申请日和材料时间，避免把不同时间点混在一起。*
2. 材料甲属于申请日前在国内外为公众所知的技术，可以进入现有技术分析；如果单独材料甲没有公开权利要求的全部技术特征，就不能仅凭它否定新颖性，但可能成为创造性分析的基础材料之一。 → *现有技术可以用于新颖性和创造性分析，但具体作用取决于公开内容。*
3. 材料乙属于申请日前提出、申请日后公布且记载同样发明的特殊申请文件，法律用途重点在新颖性判断，不能因为它后来公布就把它直接当作创造性组合依据。 → *抵触申请与一般现有技术的法律用途不同，不能直接用于创造性评价。*
4. 拟加入的新技术特征必须在原说明书或权利要求书中有记载；如果原申请文件没有该内容，答复时补入会触及第三十三条的修改范围限制。 → *修改不是自由补充新方案，必须能够回到原始申请文件。*
**结论**：本例应先区分材料甲和材料乙的时间及法律用途，再分别判断新颖性与创造性；同时，原申请文件未记载的新技术特征不能通过答复审查意见任意补入。
**本题要点**：专利实务的稳定判定链是“先看对象，再看时间，再看材料用途，最后核对修改原始依据”。

### 把专利审查语言翻译成人话（verbal_explanation）

可以把专利基础判断拆成四个连续问题。第一，你到底要保护什么，是方法或产品技术方案，还是产品的形状构造，还是外观设计？第二，申请日前有没有相关公开，公开材料是否把同一方案完整呈现出来？第三，即使没有一份材料完整公开，组合起来对本领域技术人员是不是显而易见，这才进入创造性问题。第四，你想怎么改申请文件，改动能不能在原说明书、权利要求书或原图片照片中找到依据。审查员是在按法律门槛逐层筛选，代理人则要提前准备证据和文字，让每一步都能被核验。

**点破术语**：保护客体；新颖性；创造性；修改范围

**类比**：可把整个流程理解为“先验身份、再过三道门、最后核对改动记录”；这个类比只帮助记顺序，不能替代对具体条文和证据的判断。

### 客体三分与三性三关记忆锚（mnemonic）

**记忆锚**：两组记忆表：客体表“发—产方方改；实—产形构结合；外—形图色美感实用”，三性表“新看公开、创看显而易见、实看能制造使用且有积极效果”。修改再加一句“发实看原文，外观看原图”。
**映射**：
- 发
- 实
- 外
- 新
- 创
- 实用
- 看原文
- 看原图
**何时用**：遇到“保护对象是什么”“授权条件是什么”或“答复时能否补内容”等题干时，先调用客体表和三性表，再核对修改依据。

### 从审查员与代理人双视角复盘（reflect_prompt）

**反思问题**：复盘一项专利申请时，怎样避免把“技术很新”“材料已经公开”“修改有帮助”直接混成一个结论？

**关注要点**：审查员视角：每个结论对应哪一个法定问题和哪一份证据。；代理人视角：申请文件是否提前留下了足以支持保护范围和后续修改的原始记载。；时间与用途：同一份材料在新颖性、创造性和程序修改问题中的作用是否相同。

**连接**：连接到本节点的保护客体、三性判断、专利法体系和修改边界，并为后续审查意见答复与代理实务节点建立基础。

### 专利法律制度基础知识网（knowledge_synthesis）

**知识框架**：
- 专利制度基本特征：专利权具有独占性、时间性和地域性，保护范围和效力受法定期限及地域边界限制。
- 中国专利制度体系：专利法提供基本规则，专利法实施细则细化程序和文件要求，专利审查指南进一步说明审查操作。
- 专利保护客体：发明、实用新型和外观设计的定义不同，申请文件和审查重点也随客体变化。
- 专利制度功能：通过授予法定保护激励发明创造，并以技术公开促进技术应用和经济发展。
- 制度运行特点：初步审查、实质审查以及早期公开、延迟审查等属于制度运行和审查结构问题，具体历史沿革需结合权威材料核验。
**概念关系**：保护客体判断是进入具体授权和文件要求分析的前提。；确认申请日和公开时间后，才能判断材料属于一般现有技术还是申请日后公布的特殊申请文件。；新颖性判断通常先于创造性判断；只有在新颖性问题未否定时，才有必要进一步分析创造性。；审查视角强调法定门槛和证据用途，代理视角强调申请文件布局和修改依据，两者共同受法条约束。
**必记**：先识别保护客体，再选择相应的申请与审查分析路径。；发明和实用新型的授权条件包括新颖性、创造性和实用性。；新颖性侧重申请日前公开和单独对比，创造性侧重相对于现有技术是否显而易见。；抵触申请的法律用途重点在新颖性判断，不能直接作为创造性评价的组合依据。；发明和实用新型修改不得超出原说明书和权利要求书记载范围，外观设计修改不得超出原图片或照片表示范围。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **专利权三特征**：独占性、时间性、地域性共同限定专利权的保护方式和边界。
- **三类保护客体**：发明重产品或方法技术方案，实用新型重产品形状构造，外观设计重产品外观表达。
- **授权三性**：新颖性看是否公开，创造性看是否显而易见，实用性看能否制造或使用并产生积极效果。
- **中国制度体系**：专利法定基本规则，实施细则细化程序，审查指南提供审查操作说明。
- **修改边界**：修改必须回到原说明书、权利要求书或原图片照片寻找依据。
**必背**：发明、实用新型、外观设计的法定定义及区别；新颖性、创造性、实用性的判断重点；抵触申请不能直接用于创造性评价；发明和实用新型修改不得超出原说明书和权利要求书记载范围；外观设计修改不得超出原图片或者照片表示的范围
**一句话总结**：先分清保护客体，再按时间和证据判断三性，最后用原始申请文件校验修改边界。

### 三类测评：复习、探测与薄弱点挑战（assessment）

**三类覆盖**：backward_review、forward_probe、weakness_probe
**题目**：
- q_backward_01：识别实用新型的法定保护对象
- q_forward_01：探测相关法律知识与专利代理执业的关系
- q_weakness_01：区分现有技术、抵触申请的法律用途与修改超范围边界
