## 教学正文

## I — 法律问题

本节点要解决的不是某一项具体技术能否最终获权，而是建立专利法律制度的基础分析框架：专利法保护哪些客体，专利权具有什么基本边界，中国专利制度由哪些规范构成，以及不同专利类型进入何种审查程序。

## R — 适用规则

### 1. 保护客体

《专利法》第二条规定：“本法所称的发明创造是指发明、实用新型和外观设计。”其中，发明是“对产品、方法或者其改进所提出的新的技术方案”；实用新型针对“产品的形状、构造或者其结合”提出适于实用的新的技术方案；外观设计针对产品的形状、图案、色彩及其结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计；分别规定三类客体的定义〕

### 2. 授权条件的基础位置

对于发明和实用新型，《专利法》第二十二条规定应当具备新颖性、创造性和实用性；该条同时规定，现有技术是申请日前在国内外为公众所知的技术。〔RAG: 中华人民共和国专利法.txt — 第二十二条：授予发明和实用新型应具备新颖性、创造性和实用性；现有技术是申请日前在国内外为公众所知的技术〕外观设计适用第二十三条规定的现有设计、明显区别及不得与他人在先合法权利相冲突等条件。〔RAG: 中华人民共和国专利法.txt — 第二十三条：外观设计不得属于现有设计，并应具有明显区别且不得与在先合法权利相冲突〕

本节点只建立“三性”及外观设计条件的制度位置；新颖性、创造性、实用性和现有技术的具体判断方法将在相应后续节点展开。不能把本节的框架性认识误作对具体申请已经完成实体审查。

### 3. 中国专利制度体系

中国专利制度以《专利法》为基本法律，并由《专利法实施细则》以及专利审查指南等规范性、审查性材料共同支撑具体申请、审查和授权工作。检索到的实施细则第四十三条至第四十五条还涉及申请文件、申请日确定以及特定情形下补交文件等事项。〔RAG: 中华人民共和国专利法实施细则.txt — 第四十三条至第四十五条：明确申请日、申请号、受理条件及特定补交文件规则〕

### 4. 审查程序

发明专利申请经初步审查符合要求的，自申请日起满十八个月公布；申请人可以请求早日公布。发明专利申请自申请日起三年内可以请求实质审查。〔RAG: 中华人民共和国专利法.txt — 第三十四条、第三十五条：发明申请公布与三年内请求实质审查〕实质审查后，若没有发现驳回理由，可以作出授予发明专利权的决定。〔RAG: 中华人民共和国专利法.txt — 第三十九条：发明专利申请经实质审查没有发现驳回理由的，作出授予决定〕实用新型和外观设计专利申请经初步审查没有发现驳回理由的，可以作出相应授权决定。〔RAG: 中华人民共和国专利法.txt — 第四十条：实用新型和外观设计专利申请经初步审查没有发现驳回理由的，作出授予决定〕

### 5. 权利边界和制度功能

专利权的独占性，是指权利人依法在授权范围内排除他人未经许可实施专利；时间性，是指专利权只在法定期限内存在；地域性，是指权利效力不能仅因在中国取得授权就当然扩展到其他国家或地区。检索材料明确规定，发明专利权期限为二十年，实用新型为十年，外观设计为十五年，均自申请日起计算。〔RAG: 中华人民共和国专利法.txt — 第四十二条：三类专利权期限及起算日〕因此，专利制度是以法定程序和有限期限的排他保护，换取技术信息进入公开和应用秩序的制度安排。

## A — 规则适用

可以按照“客体—条件—程序—边界”四步分析：

第一，客体分类。先从技术事实出发，判断成果是产品、方法或其改进形成的技术方案，还是产品的形状、图案、色彩及其结合形成的外观设计；不能只用“创新成果”这一笼统表述代替分类。

第二，条件对应。确定客体后，再对应发明和实用新型的三性条件，或外观设计的相应法定条件。此时只能确认应当适用哪一类法律门槛，不能因为有研发成果或已经提出申请，就直接推定条件已经满足。

第三，程序区分。若属于发明专利申请，应关注公布、实质审查以及陈述意见或修改等环节；若属于实用新型或外观设计申请，则应关注初步审查程序。申请、审查和授权是不同法律状态。

第四，边界核对。即使获得授权，也要检查权利期限、授权范围和地域效力。专利权的排他性并不消除时间性和地域性；期限届满后，不能继续以该项专利权主张同等排他效力。

## C — 结论

专利法律制度基础可以压缩为一条主线：先识别发明、实用新型或外观设计这一保护客体，再对应授权条件和审查程序，最后核对专利权的期限与地域边界。专利制度通过公开与有限期限的排他保护激励创新、促进技术应用，但申请不等于授权，排他性也不等于永久或全球有效。

> 常见误区 / 易混淆点
>
> 1. 把专利申请当成专利权本身：申请只是程序起点，授权决定和公告等法律状态必须另行判断。
> 2. 把三类专利客体混为一谈：发明、实用新型和外观设计的法定定义及审查重点不同。
> 3. 把发明的实质审查套用于所有专利类型：实用新型和外观设计的基本审查路径不同。
> 4. 把排他性理解为永久性或全球效力：期限和地域是专利权不可忽略的法定边界。

### 从一项研发成果识别专利制度问题（anchor_scenario）

> 甲公司研发出一种用于工业设备的智能温控装置，准备申请专利。代理人首先发现，这项成果可能涉及产品结构、控制方法，也可能只体现为产品外观；不同表现形式会影响其属于发明、实用新型还是外观设计。公司随后还要决定采用哪种申请与审查路径，并面对专利权并非永久、也不能当然覆盖全球市场的问题。此时，研发负责人问：专利制度究竟保护什么，取得权利后又具有哪些边界？

**锚定**：以同一项研发成果引出专利保护客体、权利边界、审查程序和制度功能四个基础知识点。

**先想一想**：面对这项成果，你会先判断技术内容属于哪一种专利客体，还是先判断它是否具有商业价值？请说明你的判断顺序。

### 专利制度基础法条锚定（legal_anchor）

- **《专利法》第二条**：第二条先划定专利法保护客体：发明是产品、方法或其改进提出的新的技术方案，实用新型针对产品的形状、构造或其结合，外观设计针对产品外部设计并要求富有美感、适于工业应用。
- **《专利法》第二十二条**：第二十二条为发明和实用新型设置新颖性、创造性、实用性三项授权条件；现有技术是申请日前在国内外为公众所知的技术。
- **《专利法》第三十四条至第四十条**：第三十四条至第四十条区分了发明专利的公布、实质审查及授权程序与实用新型、外观设计的初步审查及授权程序。
- **《专利法》第四十二条**：第四十二条规定三类专利权期限均自申请日起计算，但期限分别为发明二十年、实用新型十年、外观设计十五年。

**为何重要**：本节点的核心不是背诵孤立条文，而是建立“先识别保护客体，再理解权利边界，最后区分授权与审查程序”的法律分析顺序。后续学习新颖性、创造性和申请程序时，都要回到这些法条锚点。

### 从研发成果到权利边界的分步分析（worked_example）

**案情/例题**：乙企业完成一项新产品研发，成果同时包含产品内部结构、控制该产品运行的方法以及产品外观设计。乙企业希望通过一次笼统的“专利申请”获得永久且全球有效的保护。请演示法律分析应如何拆分问题。
**适用规则**：《专利法》第二条、第二十二条、第二十三条、第三十四条至第四十条、第四十二条。对于本例涉及的具体技术方案，还需结合后续节点的授权条件审查，不在本例中提前展开。
**分步推演**：
1. 先看成果的法律表现形式：产品内部结构和控制方法可能分别对应发明或实用新型所称的技术方案；外观部分需要单独对照外观设计的法定定义。不能因为成果来自同一项目，就把不同客体自动视为同一种专利。 → *第一步：识别并区分专利保护客体。*
2. 完成客体分类后，再分别检查适用的授权条件。检索到的第二十二条针对发明和实用新型规定新颖性、创造性和实用性；外观设计则适用第二十三条的相应条件。 → *第二步：将客体分类与授权条件对应起来。*
3. 再看程序：发明专利申请经初步审查后公布，并可进行实质审查；实用新型和外观设计申请经初步审查没有发现驳回理由的，可以作出授权决定。不同程序不能混为一谈。 → *第三步：按照客体区分审查路径。*
4. 最后检查权利边界。第四十二条规定期限自申请日起计算且三类专利期限不同；专利权作为依申请取得的法定权利，也不能仅凭申请行为推定为已授权，更不能由中国专利法当然推出全球效力。 → *第四步：核对期限、地域和权利取得状态。*
**结论**：该企业应先将成果按法律客体进行分类，再分别确认适用的授权条件与审查程序；获得专利权后仍受期限和地域边界约束。仅凭“具有创新价值”不能直接推出已经取得专利权。
**本题要点**：专利基础分析遵循“先定客体、再审授权条件、再看程序、最后核对期限与地域边界”的顺序。

### 把专利基础拆成四个连续问题（verbal_explanation）

可以先把专利制度分成四个连续问题来听：第一，法律保护的到底是什么，先区分发明、实用新型和外观设计；第二，申请人能不能拿到权利，要看对应的授权条件；第三，申请进入哪一种审查程序，发明与实用新型、外观设计并不完全相同；第四，即使获得权利，也要检查期限和地域。专利不是把一个想法登记后永久占有，而是通过法定程序取得一种有边界的排他权。后面学习新颖性、创造性或申请程序时，都不要跳过这四步。

**点破术语**：保护客体；独占性；时间性；地域性；授权实质条件

**类比**：可将专利制度理解为一套有条件的交换安排：申请人以公开技术信息为基础寻求法定期限内的排他保护，但这不是无期限、无地域限制的所有权。

### 专利基础四步核对表（mnemonic）

**记忆锚**：专利基础四步表：客体—条件—程序—边界；每遇到一个专利问题，依次填写“保护什么、能否授权、如何审查、权利到哪里和多久”。
**映射**：
- 客体
- 条件
- 程序
- 边界
**何时用**：分析任何专利基础题、阅读申请流程材料或比较专利与其他知识产权制度时，先按“客体—条件—程序—边界”逐格核对。

### 反思：把研发事实拆成法律要素（reflect_prompt）

**反思问题**：当同一研发项目同时包含技术方案和产品外观时，你会怎样记录事实，避免在法律分析中把保护客体、授权条件和审查程序混为一谈？

**关注要点**：事实描述应分别指出产品结构、方法步骤与外观设计，而不是只写“有创新”。；不同客体对应的法条和审查程序可能不同。；取得专利权的时间、期限和地域边界需要单独核对。

**连接**：连接到本节的“保护客体—授权条件—审查程序—权利边界”框架，并为后续专利制度概论中的制度功能比较作准备。

### 专利法律制度基础关系网（knowledge_synthesis）

**知识框架**：
- 专利制度基本概念与特征：专利权具有排他性，但同时具有法定期限和法域边界。
- 中国专利制度体系：以《专利法》为基本法律，并由《专利法实施细则》和《专利审查指南》等规范与审查材料共同支撑具体实施。
- 三类保护客体：发明是产品、方法或者其改进提出的新的技术方案；实用新型针对产品的形状、构造或者其结合；外观设计针对产品的形状、图案、色彩及其结合所形成的设计。
- 专利制度的作用：通过授予法定期限内的排他权，激励发明创造、促进技术公开、推动技术应用和经济发展。
- 中国制度发展与审查特点：发明专利实行公布和实质审查相结合的程序，实用新型和外观设计主要经过初步审查后授权。
**概念关系**：先由保护客体分类确定适用的法律条件，再由申请类型连接到相应审查程序。；专利制度的激励与公开功能解释了为什么权利具有期限和法域边界，而不是永久、全球有效。；发明、实用新型和外观设计的客体差异，是理解后续授权条件和审查方式差异的前提。
**必记**：《专利法》第二条规定发明、实用新型和外观设计三类发明创造，三者的法定定义不同。；专利权的基本边界包括排他性、时间性和地域性，申请不等于授权。；发明专利与实用新型、外观设计在审查程序上存在重要区别。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **三类保护客体**：发明、实用新型和外观设计分别对应不同的法定定义，先分类再分析。
- **专利权三种边界**：排他性、时间性、地域性共同说明专利权不是无限制的权利。
- **中国专利制度体系**：《专利法》提供基本规则，实施细则和审查指南支撑具体实施与审查。
- **审查程序差异**：发明专利有实质审查，实用新型和外观设计主要进行初步审查。
- **制度功能**：专利制度以公开与有限期限保护的制度安排激励创新并促进技术应用。
**必背**：《专利法》第二条规定发明、实用新型和外观设计三类发明创造。；专利权具有排他性、时间性和地域性。；发明专利实行实质审查；实用新型和外观设计申请经初步审查后授权。；申请行为不等于已经取得专利权。
**一句话总结**：先识别保护客体，再对应授权条件和审查程序，最后核对专利权的期限与地域边界。
