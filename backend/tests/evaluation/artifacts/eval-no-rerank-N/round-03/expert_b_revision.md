# 专家 B 修订稿

## teaching_content

## 1. 场景导入

小陈是一家智能穿戴公司的研发负责人，团队刚做出一款可折叠柔性电池模组：既有新的层叠构造，又有一套充放电控制方法，外壳造型还做了圆角渐变设计。老板拍桌子说“赶紧全包专利”，小陈却犯了难——到底哪些能报发明、哪些只能走实用新型或外观设计？审查员会怎么卡“技术方案”门槛？代理师又该怎么帮他拆方案、排时间表？审查与代理两个视角同时压过来，基础概念一混，后面整条申请链路都会歪。

## 2. 人话解释

先把专利制度想成国家发的“临时独占通行证”。它有三个硬标签：独占性（别人未经许可不能用）、时间性（发明二十年、实用新型十年、外观设计十五年，到期进公有领域）、地域性（中国专利只管中国境内）。中国整套规则像三层楼：最上面是《专利法》定原则，中间《专利法实施细则》把程序和期限写细，底下《专利审查指南》告诉审查员和代理人具体怎么判。三种保护客体对应三种“东西”：发明覆盖产品和方法的新技术方案；实用新型只管有形状构造的产品方案；外观设计管富有美感、能工业应用的新设计。制度本身的作用也很直白——鼓励你发明、逼你公开换保护、再推动别人在公开基础上继续用和迭代，最后拉动经济发展。中国特色是“早期公开、延迟审查”：发明先公开再实质审查，实用新型和外观设计主要走初步审查，两套并行。

## 3. 法条回扣

核心回扣《专利法》第二条。发明是“对产品、方法或者其改进所提出的新的技术方案”；实用新型是“对产品的形状、构造或者其结合所提出的适于实用的新的技术方案”；外观设计是“对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计”。〔RAG: 专利法专题讲座.txt — 发明，是指对产品、方法或者其改进所提出的新的技术方案。〕审查实践里强调：第2条第2款着重点不是“新”，而是“技术方案”——采用技术手段、解决技术问题、获得符合自然规律的技术效果，通常可进入技术方案层面的客体判断，仍需继续审查法定排除事项及其他授权条件。〔RAG: 专利法专题讲座.txt — 专利法第2条第2款着重点并不是“新”，而是“技术方案”。〕气味、信号、能量本身，以及自然界原有物品，都不属于发明客体；实用新型只保护经产业方法制造、有确定形状构造并占据空间的产品，一切方法都排除。〔RAG: 专利法专题讲座.txt — 专利法第2条第2款着重点并不是“新”，而是“技术方案”。〕代理人拆方案、审查员卡客体，都绕不开这一条。

## 4. 类比 / 口诀

把三种客体想成“门禁级别”：发明是全能卡（产品+方法），实用新型是产品形状构造卡（方法刷不进去），外观设计是颜值卡（美感+工业应用）。三特征口诀“独时地”——独占、时间、地域，考试和实务一听到“能不能拦别人”“期限到没到”“跨境管不管用”就立刻对号。边界提醒：类比只帮记忆，真正判定仍以第2条“技术方案/适于实用/富有美感并适于工业应用”为准，不能拿类比替代审查指南里的排除情形。

## 5. 应试提示

题干关键词：看到“方法、程序、用途”先警惕实用新型；看到“气味、信号、自然物”先排除发明客体；看到“美感、工业应用、局部设计”锁定外观设计。判断步骤建议：①先定客体类型 → ②再看是否技术方案/适于实用/工业应用 → ③最后才进三性。常见陷阱：把“新”当成客体门槛（其实重点是技术方案）；把含方法步骤的产品权利要求硬塞进实用新型；混淆初步审查与实质审查的适用范围。审查视角写“不符合第2条”，代理视角就要提前拆分申请或补技术效果描述。
