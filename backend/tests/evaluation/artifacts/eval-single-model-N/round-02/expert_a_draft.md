## 教学正文

## I — 法律问题

本节点处理四个相互连接的基础问题：第一，专利制度中的权利具有什么基本边界；第二，中国专利法律制度由哪些规范材料构成；第三，技术方案如何对应发明、实用新型或外观设计；第四，不同专利类型适用何种审查与授权程序。

需要先稳定一个总判断：专利权具有排他保护功能，但并非没有期限、没有地域边界的绝对权利。对代理人而言，首先要准确识别技术方案的保护客体；对审查员而言，则要在相应法律和审查规范框架内审查申请是否符合要求。

## R — 适用规则

### 1. 三类专利保护客体

检索材料依据《专利法》第二条，将我国发明创造区分为发明、实用新型和外观设计。发明的客体范围较广，可以涉及产品、方法或者其改进；实用新型主要涉及产品的形状、构造或者其结合；外观设计涉及产品的外观。〔RAG: 专利法专题讲座.txt — 《专利法》第2条：发明、实用新型、外观设计；发明涉及产品、方法或者其改进，实用新型涉及产品形状、构造或者其结合，外观设计涉及产品外观〕

因此，客体分类不是名称选择，而是对技术事实进行法律归类。方法步骤不能仅因具有产品用途就当然变成实用新型；产品形状、构造的改进也不能仅因具有技术效果就跳过客体判断。

### 2. 中国专利制度的规范层次

本节点所依据的制度材料包括《专利法》《专利法实施细则》和《专利审查指南》。其中，《专利法》提供专利客体、申请审查和授权程序的基本规范；《专利法实施细则》对申请文件、程序事项和审查内容作进一步规定；《专利审查指南》用于理解审查实践中的具体适用口径。检索上下文未提供《专利审查指南》相关章节的完整原文，因此本稿不据此编造具体章节号或超出检索材料的细节。

### 3. 发明申请的早期公开与延迟实质审查

《专利法》第三十四条规定，国务院专利行政部门收到发明专利申请后，经初步审查认为符合本法要求的，自申请日起满十八个月即行公布；国务院专利行政部门可以根据申请人的请求早日公布其申请。〔RAG: 中华人民共和国专利法.txt — 第三十四条：发明专利申请经初步审查符合要求的，自申请日起满十八个月即行公布，申请人可以请求早日公布〕

《专利法》第三十五条规定，发明专利申请自申请日起三年内，国务院专利行政部门可以根据申请人的请求对其申请进行实质审查；申请人无正当理由逾期不请求实质审查的，该申请即被视为撤回。〔RAG: 中华人民共和国专利法.txt — 第三十五条：发明专利申请自申请日起三年内可以请求实质审查，逾期不请求的申请被视为撤回〕

这里至少要分清三个动作：初步审查是程序上的前置审查；公布是申请内容进入公开程序的法律动作；实质审查请求则是发明申请进入实质审查的重要程序节点。初步审查合格并不等于已经授权，满十八个月公布也不等于公告授予专利权。

### 4. 初步审查的范围与不同类型的审查制度

《专利法实施细则》第五十条将初步审查说明为：审查申请是否具备《专利法》第二十六条或者第二十七条规定的文件和其他必要文件、这些文件是否符合规定格式，并审查所列举的法定事项。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十条：初步审查包括申请文件和必要文件是否具备、格式是否符合规定以及相关法定事项〕

检索材料进一步表明，我国对不同专利类型采用不同审查制度：发明专利申请采用早期公开、延迟审查的实质审查制；实用新型和外观设计专利申请采用初步审查制。〔RAG: 专利法专题讲座.txt — 两种审查制度：发明专利申请采用早期公开、延迟审查的实质审查制，实用新型和外观设计专利申请采用初步审查制〕

根据检索到的《专利法》相关专题材料，发明专利申请经实质审查没有发现驳回理由，实用新型和外观设计专利申请经初步审查没有发现驳回理由，才进入授予专利权的程序。〔RAG: 专利法专题讲座.txt — 《专利法》第39条、第40条：发明经实质审查、实用新型和外观设计经初步审查没有发现驳回理由后授予专利权〕

### 5. 专利权基本特征与制度作用

检索材料将专利权的基本特征概括为客体的无形性、权利的排他性、授权的地域性和存在的期限性。〔RAG: 专利法专题讲座.txt — 专利权特点：客体的无形性、权利的排他性、授权的地域性、存在的期限性〕本节点重点掌握其中的独占性、时间性和地域性：独占性表示权利具有排他保护功能；时间性表示权利存续受期限限制；地域性表示权利效力与授权法域相联系。

检索材料将专利制度的作用概括为激励发明创造、促进技术公开、推动技术应用和经济发展。专利权的取得本质上体现为“以公开换保护”。〔RAG: 专利法律知识详细解读.txt — 专利制度的作用：以公开换保护，推动社会技术发展和进步〕这说明申请文件既是取得权利的基础，也是向公众公开技术内容的载体。

## A — 规则适用

面对一项新技术，第一步不是直接选择发明或实用新型的申请名称，而是提取技术方案的法律特征：它是产品、方法，还是产品外观；如果是产品，改进的是形状、构造，还是主要体现为外观设计。第二步把客体判断与审查路径对应起来：发明申请需要理解初步审查、公布和实质审查请求之间的关系；实用新型和外观设计申请则应先把握初步审查制及其审查事项。第三步确认授权结论不能从申请行为或公布行为直接推出，仍须满足相应程序中没有发现驳回理由的条件。

从审查员视角，重点是依据书面申请文件和适用规范检查申请是否具备必要文件、格式是否合规以及是否存在相应法定缺陷。从代理人视角，重点是把技术交底准确转换为适当的保护客体和申请文件，并及时管理发明申请的公布、实质审查请求等程序节点。两种视角的共同基础是同一套法律制度，但工作任务不同。

## C — 结论

本节点应形成一条稳定的判断链：先识别保护客体，再确定适用审查制度，随后区分公布、实质审查和授权，最后检查专利权的独占性、时间性和地域性。发明、实用新型和外观设计不能混同；发明申请与实用新型、外观设计申请的审查路径不能混同；初步审查合格、申请公布与最终授权也不能混同。

> 常见误区 / 易混淆点
>
> 1. “初步审查合格”不等于“已经授权”。发明申请还涉及后续实质审查；实用新型和外观设计也必须以没有发现法定驳回理由为前提进入授权程序。
> 2. “自申请日起满十八个月公布”不等于“十八个月后公告授权”。公布和授权是不同的法律动作。
> 3. 实用新型主要针对产品的形状、构造或者其结合；外观设计针对产品外观，不能仅凭“产品”二字作出归类。
> 4. 专利权具有排他性，但排他性不能推出永久性或全球自动效力。
>

### 从一项技术方案定位专利制度基础（anchor_scenario）

> 某研发团队完成了一种用于工业设备的技术方案，方案核心涉及产品的形状与内部构造。团队准备在中国申请专利，但成员对三个问题意见不一：这种技术方案属于哪一种专利保护客体；应当经过何种审查程序；取得专利权后，权利是否可以永久存在并在所有国家自动生效。代理人需要先用中国专利制度的基本框架拆解问题，再向研发团队说明申请与授权的边界。

**锚定**：该情境同时锚定专利权的独占性、时间性和地域性，中国专利制度体系，以及发明、实用新型、外观设计三类保护客体。

**先想一想**：面对这三个问题时，你会先判断技术方案属于哪类保护客体，还是先判断审查程序？请先指出你的判断顺序及理由。

### 法条锚定：客体、审查与授权程序（legal_anchor）

- **《专利法》第二条**：第二条划分发明、实用新型和外观设计三类专利保护客体；发明的范围较广，实用新型主要涉及产品的形状、构造或者其结合，外观设计涉及产品的外观设计。
- **《专利法》第三十四条**：第三十四条规定，发明专利申请经初步审查符合要求的，自申请日起满十八个月即行公布，申请人可以请求早日公布。
- **《专利法》第三十五条**：第三十五条规定，发明专利申请自申请日起三年内，国务院专利行政部门可以根据申请人的请求进行实质审查；无正当理由逾期不请求的，申请被视为撤回。
- **《专利法》第三十九条、第四十条**：第三十九条、第四十条对应不同类型专利申请的授权程序：发明申请经实质审查、实用新型和外观设计申请经初步审查，均以没有发现驳回理由为授权前提。
- **《专利法实施细则》第五十条**：实施细则第五十条说明，初步审查包括申请文件和必要文件是否齐全、格式是否符合规定，以及法定的明显缺陷等事项。

**为何重要**：本节点是后续学习新颖性、创造性、申请文件和审查实务的制度入口。只有先分清保护客体、审查层次和专利权的基本边界，才能正确理解审查员与代理人分别在审查和申请环节处理什么问题。

### 示范推演：从技术事实到审查制度（worked_example）

**案情/例题**：乙公司完成一项产品改进方案，改进内容仅表现为产品外壳的结构组合和内部部件的连接形态。乙公司准备在中国提交申请。请演示如何判断其可能对应的专利类型以及相应的审查制度。
**适用规则**：《专利法》第二条、第三十四条、第三十五条、第三十九条、第四十条，以及《专利法实施细则》第五十条。判断时先定位保护客体，再区分初步审查与实质审查，最后确认授权程序。
**分步推演**：
1. 先提取技术方案的客体特征：事实只描述产品的形状、构造及其结合，没有出现方法步骤或其他超出该范围的内容。将事实与《专利法》第二条关于三类专利客体的区分相对照。 → *第一步是定位保护客体，而不是直接判断授权结果。*
2. 由于事实指向产品的形状、构造或者其结合，按照检索材料对《专利法》第二条的说明，方案在客体分类上更接近实用新型，而非方法类发明或单纯外观设计。 → *第二步是完成专利类型的初步归类。*
3. 再审查程序类型。检索材料明确说明，实用新型和外观设计专利申请采取初步审查制；初步审查关注申请文件、格式以及法定的明显缺陷等事项，《专利法实施细则》第五十条对此作出列举。 → *第三步是把客体分类与审查制度对应起来。*
4. 最后区分授权与审查制度本身。初步审查制并不等于提交即获得专利权，仍须经过初步审查且没有发现驳回理由，才进入授予专利权的程序。 → *第四步是确认制度结论不能替代个案审查结果。*
**结论**：该方案若确属产品的形状、构造或者其结合，首先应按实用新型保护客体进行定位；其审查制度属于初步审查制，而不是发明专利申请的早期公开、延迟实质审查程序。是否最终授权，还要根据初步审查中是否发现法定驳回理由作出判断。
**本题要点**：处理专利基础问题时，固定使用“客体分类—审查制度—授权前提”的线性判断链。

### 把制度框架翻译成人话（verbal_explanation）

先把专利制度看成三个连续问题：法律保护的对象是什么，申请要经过哪一道审查，权利取得后边界在哪里。我国专利法第二条先把客体分成发明、实用新型和外观设计；这一步解决的是“申请的是什么”。接着看程序，发明申请不是只做形式检查，而是先初步审查、公开，再由申请人在法定期间内请求实质审查；实用新型和外观设计则以初步审查为主要授权前程序。最后不要把专利权想成无限制的永久权利，它具有排他性，但也受时间和地域边界约束。审查员关注申请是否满足法定要求，代理人则要把技术事实准确放入相应客体和程序框架。

**点破术语**：独占性；时间性；地域性；三类专利客体；审查制度

**类比**：可以把专利制度理解为一套有边界的法律授权机制：申请人以技术公开换取一定期间、一定地域内的排他保护，但这只是帮助记忆的表达，不能替代具体法条和个案审查。

### 三类两审三边界（mnemonic）

**记忆锚**：三类两审三边界对照表：三类=发明/实用新型/外观设计；两审=发明“初步审查后公布+实质审查”、实用新型和外观设计“初步审查”；三边界=独占性/时间性/地域性。复盘时按“先客体、再审查、后权利边界”的顺序默写。
**映射**：
- 三类
- 两审
- 三边界
- 先客体
- 再审查
- 后边界
**何时用**：复盘专利制度基础、审查程序或代理人接收新技术交底时，先默写“三类两审三边界”，再展开具体法条。

### 双视角复盘：谁先看什么（reflect_prompt）

**反思问题**：同一项技术交底提交到专利局后，审查员和代理人最先关注的问题是否相同？请比较两种视角的关注对象。

**关注要点**：代理人需要先确认技术方案落入哪一种法定保护客体，并据此组织申请文件。；审查员需要依据法条和实施细则检查申请文件、格式及相应的法定审查事项。；判断审查程序时，不要把申请公开、实质审查和最终授权混为同一个法律动作。

**连接**：连接到本节点的“专利保护客体”和“中国专利制度体系”，并分别代入审查员与专利代理人的工作视角。

### 专利法律制度基础知识网（knowledge_synthesis）

**知识框架**：
- 专利权基本特征：专利权具有独占性、时间性和地域性，三者共同限定权利边界。
- 中国专利制度体系：专利法、专利法实施细则和专利审查指南共同构成学习和实务中需要对照的规范与审查材料体系。
- 三类专利保护客体：发明可涉及产品、方法或者其改进；实用新型主要涉及产品的形状、构造或者其结合；外观设计涉及产品的外观。
- 专利制度的作用：通过技术公开与法律保护的制度安排，激励发明创造、促进技术公开，并推动技术应用和经济发展。
- 中国审查制度发展与特点：我国对不同专利类型采用不同审查制度，发明申请采用早期公开、延迟实质审查，实用新型和外观设计申请采用初步审查制。
**概念关系**：先根据技术事实识别保护客体，再确定适用的申请审查路径。；专利法提供基本制度和授权程序，实施细则具体列明初步审查中的文件、格式及相关审查事项，审查指南用于理解审查实践。；技术公开与专利保护相互联系，制度作用解释了为什么申请文件和审查程序必须同时关注公开与权利边界。
**必记**：三类专利客体必须区分：发明、实用新型、外观设计。；发明申请经初步审查符合要求后公布，并可在法定期间内请求实质审查；实用新型和外观设计申请采取初步审查制。；专利权的排他性不等于永久性或全球自动生效，时间性和地域性同样是权利边界。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **专利权三项基本特征**：独占性说明排他保护，时间性和地域性限定保护的期限与范围。
- **三类专利客体**：发明覆盖产品、方法或其改进；实用新型主要覆盖产品形状、构造或其结合；外观设计覆盖产品外观。
- **中国专利制度体系**：专利法、实施细则和审查指南分别提供基础规范、具体程序与审查实践依据。
- **不同审查制度**：发明申请实行早期公开、延迟实质审查；实用新型和外观设计申请实行初步审查制。
- **专利制度作用**：通过公开与保护的制度安排激励创造、促进技术公开和技术应用。
**必背**：独占性、时间性、地域性是专利权的基本边界特征。；发明、实用新型、外观设计是我国专利法规定的三类专利客体。；发明申请与实用新型、外观设计申请适用不同审查制度。；发明申请自申请日起满十八个月即行公布，申请人可以请求早日公布。；发明专利申请自申请日起三年内可以请求实质审查，逾期无正当理由不请求的，申请被视为撤回。
**一句话总结**：先按技术事实识别专利客体，再按专利类型确定审查路径，最后检查权利的时间与地域边界。
