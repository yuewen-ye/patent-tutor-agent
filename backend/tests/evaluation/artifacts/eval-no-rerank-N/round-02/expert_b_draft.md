## 教学正文

## 1. 场景导入
某公司研发了一种新型谐波减速器关节模组，内部形状构造经过改进。他们计划申请发明专利，但担心在政府主办的国际展会展示会破坏新颖性，同时想知道这种产品是否属于实用新型专利的保护客体。请问：（1）这个模组是否属于专利法第2条规定的保护客体？（2）展会展示是否会影响申请资格？这个场景同时涉及保护客体判断和公开行为范围，帮我们先建立直观的判断框架。

## 2. 人话解释
专利保护的三种客体分别是发明、实用新型和外观设计。发明是最广泛的，包括对产品、方法或其改进提出的新的技术方案，只要是采用技术手段解决技术问题并获得符合自然规律技术效果的，就属于发明专利。实用新型只保护产品，针对产品的形状、构造或者其结合提出的适于实用的新的技术方案，不能保护自然物、气味等非技术手段解决的问题。外观设计保护产品的视觉外观。掌握这些核心概念，能帮我们快速判断一件技术方案能不能申请专利。

## 3. 法条回扣
《专利法》第二条规定：发明，是指对产品、方法或者其改进所提出的新的技术方案。实用新型，是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。外观设计，是指对产品的形状、图案或者其结合所提出的富有美感并适于工业应用的新设计。
〔RAG: 专利法专题讲座.txt — 发明专利的保护对象范围最广，包括新产品、新方法、老产品新改进、老方法新改进而形成的技术方案。《专利法》第2条第2款着重点并不是“新”，而是“技术方案”〕
〔RAG: 专利法专题讲座.txt — 实用新型专利只保护产品，所述产品应当是经过产业方法制造的，有确定形状、构造且占据一定空间的实体〕
〔RAG: 专利法律知识详细解读.txt — 特殊情形判断：若权利要求中既包含形状、构造特征，又包含对材料本身提出的改进，则不属于实用新型专利保护的客体〕

## 4. 类比 / 口诀
把保护客体判断比作“找门票”：发明像“宽门票”（任何技术方案都行，只要是技术手段+技术效果）；实用新型像“窄门票”（只准产品形状构造改进）；外观设计像“视觉门票”（美观+工业应用）。口诀：形状构造结合（实用新型），技术手段效果（发明），避免自然物气味（非保护）。适用边界：只能保护实体产品，不能保护纯信息或自然存在物品。

## 5. 应试提示
题干关键词：形状构造结合、材料本身改进、技术方案、产业方法制造。常见陷阱：把形状视为材料本身改进，或把非技术手段（如单纯色彩）当作实用新型。判断流程：先看是不是产品（实用新型）→再看是不是形状构造改进→最后确认不是材料本身或自然物。

## 6. 互动提问
如果你是专利代理人，看到客户说“这是个新形状的减速器”，你会怎么问客户来确认是否属于实用新型？或者，如果一个方案用老材料做出新形状，能否申请专利？欢迎在评论区讨论你的判断依据。

**先想一想**：如果你是专利代理人，看到‘展会展示’这个动作，第一反应是风险还是安全？为什么？

### 法条锚定（legal_anchor）

- **《专利法》第二条**：发明是新的技术方案，实用新型是产品形状构造的适于实用的新的技术方案

**为何重要**：这是专利授权的起点，三种客体是后续审查三性的前提，必须先明确

###  worked_example（worked_example）

**案情/例题**：甲公司2024年5月在政府主办国际展会展出新型关节模组，2024年10月提出实用新型专利申请。问：展会展示是否破坏实用新型专利的保护客体？
**适用规则**：《专利法》第二条
**分步推演**：
1. 展出日在申请日前，且属政府主办国际展会 → *落入公开行为范围*
2. 实用新型保护客体是形状构造改进，展会展示本身不改变客体判断 → *公开行为不直接否定客体*
3. 但需确认形状构造是否适于实用且新 → *客体判断独立于公开行为*
**结论**：展会展示不否定保护客体，但后续仍需通过三性审查。
**本题要点**：保护客体判断先于公开行为分析，展会仅影响新颖性

###  verbal_explanation（verbal_explanation）

咱们把保护客体想成‘门票’：发明像宽门票，任何技术方案都行，只要是技术手段解决技术问题就行。实用新型像窄门票，只准产品形状构造的改进。外观设计像视觉门票，美观加工业应用。记住，实用新型不能保护自然物或气味，那些都不是技术方案。关键是看是不是实体产品且有形状构造改进。

**点破术语**：保护客体；技术方案；形状构造结合

**类比**：保护客体判断就像找门票：发明宽门票，实用新型窄门票，外观设计视觉门票

###  mnemonic（mnemonic）

**关注要点**：两个公开行为的日期各自如何算宽限期；论文发表是否也享宽限期

**连接**：连接到‘现有技术’与‘公开行为类型’

###  knowledge_synthesis（knowledge_synthesis）

**知识框架**：
- 保护客体：发明（技术方案）、实用新型（产品形状构造）、外观设计（视觉外观）
- 判断标准：技术手段解决技术问题+技术效果
- 实用新型限制：产品实体+形状构造改进，不能材料本身或自然物
**概念关系**：保护客体是授权前提，三性是授权条件；实用新型严格限制于产品形状构造
**必记**：专利保护客体必须是技术方案；实用新型限于产品形状构造的适于实用的新的技术方案

###  summary_card（summary_card）

**要点卡**：
- **保护客体**：能申请专利的‘东西’范围
- **发明专利**：技术方案即可
- **实用新型**：形状构造适于实用
**必背**：三种客体各有不同保护范围；实用新型不能保护自然物或气味
**一句话总结**：先过保护客体之门，再过三性安检
