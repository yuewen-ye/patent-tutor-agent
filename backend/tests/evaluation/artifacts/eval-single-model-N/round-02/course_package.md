## 教学正文

## I — 法律问题

本节点围绕五个相互连接的问题展开：专利权具有什么基本边界；中国专利制度由哪些规范材料构成；技术成果如何对应发明、实用新型或外观设计；专利制度发挥什么作用；不同类型申请如何进入相应审查程序。

先记住总主线：专利权具有排他保护功能，但不是没有期限、没有地域限制的绝对权利。代理人首先要把研发事实准确转换为法定客体和申请表达；审查人员则要依据法定定义、申请文件和适用规范确定审查入口。两种职业视角不同，但共同起点都是识别制度保护的对象和边界。

## R — 适用规则

### 1. 三类专利保护客体

《专利法》第二条规定，发明创造是发明、实用新型和外观设计。发明是对产品、方法或者其改进所提出的新的技术方案；实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计是对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计；发明、实用新型和外观设计的完整法定定义〕

因此，客体识别不是给成果贴一个笼统的“专利”标签，而是从技术事实出发逐项核对法定限定。方法步骤应按发明对象方向考察；产品的形状、构造或者其结合应按实用新型对象方向考察；产品整体或局部的视觉设计应按外观设计对象方向考察。但“方法”“结构改进”或“图案设计”的事实描述，只是初步识别线索，不等于已经满足完整法定定义。

### 2. 中国专利制度的规范体系与职责

本节点的规范主线是《专利法》《专利法实施细则》和《专利审查指南》。专利法提供基本制度、客体和程序框架；实施细则细化申请文件、程序事项和审查要求；审查指南用于理解审查实践中的具体适用口径。检索上下文未提供审查指南相关章节的完整原文，因此本稿不编造具体章节号或超出检索材料的细节。

《专利法》第三条规定，国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，依法授予专利权。〔RAG: 中华人民共和国专利法.txt — 第三条：负责管理全国的专利工作，统一受理和审查专利申请，依法授予专利权〕从代理视角看，应将研发事实组织为与法定客体相匹配的申请文件；从审查视角看，应在法定职责范围内确认申请对象并审查相关文件和事项。

### 3. 发明申请的早期公开与延迟实质审查

《专利法》第三十四条规定，发明专利申请经初步审查认为符合本法要求的，自申请日起满十八个月即行公布，国务院专利行政部门可以根据申请人的请求早日公布其申请。〔RAG: 中华人民共和国专利法.txt — 第三十四条：发明专利申请经初步审查符合要求的，自申请日起满十八个月即行公布，申请人可以请求早日公布〕《专利法》第三十五条规定，发明专利申请自申请日起三年内，国务院专利行政部门可以根据申请人的请求对其申请进行实质审查；申请人无正当理由逾期不请求实质审查的，该申请即被视为撤回。〔RAG: 中华人民共和国专利法.txt — 第三十五条：发明专利申请自申请日起三年内可以请求实质审查，逾期不请求的申请被视为撤回〕

要分清四个程序节点：初步审查、申请公布、实质审查请求和最终授权。初步审查符合要求不等于已经授权；申请公布也不等于公告授予专利权。检索材料将发明申请概括为早期公开、延迟审查的实质审查制，并说明发明申请与实用新型、外观设计申请的审查制度不同。〔RAG: 专利法专题讲座.txt — 发明专利申请采用早期公开、延迟审查的实质审查制；实用新型和外观设计专利申请采用初步审查制〕

### 4. 初步审查及授权前提

《专利法实施细则》第五十条所涉初步审查，重点包括申请文件和其他必要文件是否具备、文件格式是否符合规定以及相关法定事项。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十条：初步审查包括文件和必要文件是否具备、格式是否符合规定及相关法定事项〕检索材料进一步表明，发明申请经实质审查没有发现驳回理由，实用新型和外观设计申请经初步审查没有发现驳回理由，才进入授予专利权的程序。〔RAG: 专利法专题讲座.txt — 《专利法》第三十九条、第四十条：相应申请经审查没有发现驳回理由后进入授予专利权程序〕

这意味着“初步审查制”不是“提交即授权”，而是特定类型申请所适用的审查制度。无论从审查员还是代理人视角，都不能把申请、审查、公布、授权和权利边界视为同一个法律动作。

### 5. 专利权的基本特征与制度作用

检索材料将专利权的基本特征概括为客体的无形性、权利的排他性、授权的地域性和存在的期限性。〔RAG: 专利法专题讲座.txt — 专利权特点：客体的无形性、权利的排他性、授权的地域性、存在的期限性〕本节点重点掌握独占性、时间性和地域性：独占性表示权利在授权范围内具有排他保护功能；时间性表示权利存续受期限限制；地域性表示权利效力与特定授权法域相联系。

检索材料将专利制度的作用概括为“以公开换保护”，并指出其有助于推动社会技术发展和进步。〔RAG: 专利法律知识详细解读.txt — 专利权的取得本质是“以公开换保护”，专利制度有利于推动社会技术发展和进步〕结合本节点规划，制度作用可进一步归纳为激励发明创造、促进技术公开、推动技术应用和经济发展。但“公开换保护”只是理解制度功能的类比，不表示提交申请或公开技术就当然获得专利权。

## A — 双视角适用

处理一项研发成果时，固定使用以下顺序：第一，拆分方法步骤、产品结构和视觉设计等技术事实；第二，根据《专利法》第二条识别发明、实用新型或外观设计的客体方向；第三，核对新的技术方案、适于实用、富有美感并适于工业应用等相应法定限定；第四，根据客体类型确定初步审查、公布、实质审查请求等程序节点；第五，确认是否满足相应授权前提；第六，再检查专利权的时间性和地域性边界。

代理人侧重于准确接收技术交底、选择适当保护客体并组织申请文件，及时管理发明申请的公布和实质审查请求等程序节点。审查员侧重于依据法律、实施细则和相关审查规范，检查申请文件、格式、法定客体及相应审查事项。双方使用同一套法定分类标准，但工作任务和所处程序位置不同。

## C — 结论

本节点应形成一条稳定判断链：“拆分技术事实—识别保护客体—核对法定限定—确定审查路径—确认授权前提—把握权利边界”。发明、实用新型和外观设计不能混同；发明申请与实用新型、外观设计申请的审查路径不能混同；初步审查合格、申请公布和最终授权也不能混同。专利制度以公开和法定保护安排激励创造、促进公开和技术应用，但制度功能不能代替具体申请的法定审查。

### 从一件产品看专利制度基础（anchor_scenario）

> 某研发团队完成一项便携式检测设备成果：其中包含新的检测步骤、传感器支架的形状与构造改进，以及外壳局部图案设计。团队准备在中国申请专利，但成员对保护客体、审查程序和权利边界存在分歧。代理人需要先拆分技术事实，审查人员需要依照法定客体和适用规范进行审查；双方还要区分独占性、时间性与地域性。

**锚定**：具体研发场景同时引出三类专利客体、中国专利制度体系、不同审查程序以及专利权的独占性、时间性和地域性，便于从审查与代理双视角建立主线。

**先想一想**：面对同一产品中的方法步骤、产品结构和视觉设计，你会按照什么顺序判断？为什么初步识别保护客体后，还不能直接断言已经获得专利权？

### 法条锚定：客体、职责与审查程序（legal_anchor）

- **《中华人民共和国专利法》第二条**：《专利法》第二条将发明创造分为发明、实用新型和外观设计，并分别规定其基本客体边界。发明涉及产品、方法或者其改进提出的新的技术方案；实用新型针对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计针对产品整体或者局部的形状、图案或者其结合以及相关色彩结合所作出的富有美感并适于工业应用的新设计。
- **《中华人民共和国专利法》第三条**：《专利法》第三条规定，国务院专利行政部门负责管理全国专利工作，统一受理和审查专利申请，依法授予专利权。
- **《中华人民共和国专利法》第三十四条、第三十五条**：《专利法》第三十四条规定，发明专利申请经初步审查符合要求的，自申请日起满十八个月即行公布，申请人可以请求早日公布。《专利法》第三十五条规定，发明专利申请自申请日起三年内可以请求实质审查，无正当理由逾期不请求的，申请被视为撤回。
- **《中华人民共和国专利法》第三十九条、第四十条**：检索材料显示，发明申请适用早期公开、延迟实质审查的实质审查制；实用新型和外观设计申请采用初步审查制。发明申请经实质审查、实用新型和外观设计申请经初步审查没有发现驳回理由后，才进入授予专利权程序。
- **《中华人民共和国专利法实施细则》第五十条**：《专利法实施细则》第五十条所涉初步审查，重点包括申请文件和必要文件是否具备、格式是否符合规定以及相关法定事项。

**为何重要**：这些条文和检索材料构成后续学习授权条件、审查实践、申请文件和权利要求结构的制度入口。代理人据此组织技术事实与申请文件，审查人员据此确定客体、程序和审查范围。

### 示范推演：从技术事实到审查制度（worked_example）

**案情/例题**：某团队的便携式检测设备包含三项改进：新的样本检测步骤、传感器支架的形状与构造改进、外壳局部图案设计。请演示如何从技术事实识别保护客体，并连接到相应审查制度。
**适用规则**：《专利法》第二条规定三类专利客体及其基本限定；《专利法》第三十四条、第三十五条规定发明申请的公布和实质审查请求；检索材料显示《专利法》第三十九条、第四十条对应不同类型申请的授权程序。判断顺序是先识别客体，再对应审查制度，最后确认授权前提。
**分步推演**：
1. 先把检测步骤从实体设备中抽出。由于事实指向方法步骤，应按照发明对象方向考察；但“新的检测步骤”这一描述本身不能替代对“新的技术方案”等法定限定的核对。 → *方法事实先按发明对象方向考察，但不能由标签直接推出完整法定认定。*
2. 再看传感器支架，核心事实是产品的形状、构造或者其结合。应按实用新型对象方向考察，并继续核对其是否属于适于实用的新的技术方案。 → *产品结构事实先按实用新型对象方向考察，并核对相应法定限定。*
3. 最后看外壳局部图案，核心事实是产品局部的视觉设计。应按外观设计对象方向考察，并核对其是否满足外观设计的完整法定限定。 → *视觉设计事实先按外观设计对象方向考察，不能把图案标签等同于成立。*
4. 完成客体初步识别后，再连接程序：发明申请需区分初步审查、公布和实质审查请求；实用新型和外观设计申请主要适用初步审查制。无论哪种类型，初步识别都不等于当然授权。 → *客体分类、审查路径和授权结论属于三个不同层次。*
**结论**：新的检测步骤可按发明对象方向考察；传感器支架的形状、构造改进可按实用新型对象方向考察；外壳局部图案可按外观设计对象方向考察。但这些只是初步客体识别，仍须分别核对新的技术方案、适于实用、富有美感并适于工业应用等相应法定限定及其他审查条件。
**本题要点**：固定使用“拆分事实—识别客体—核对法定限定—对应审查制度—确认授权前提”的判断链；代理人据此组织申请，审查人员据此确定审查入口。

### 把制度语言翻译成实务动作（verbal_explanation）

先把专利实务拆成五个连续问题：权利边界是什么，依据哪些规范，技术事实属于哪类客体，制度要实现什么功能，申请处于哪一程序阶段。代理人先拆解研发事实并选择合适的客体表达；审查人员依据同一套法定定义和审查规范确认申请对象及程序入口。专利法第二条区分发明、实用新型和外观设计；发明和实用新型都要求新的技术方案，实用新型还针对产品的形状、构造或者其结合并要求适于实用。〔RAG: 中华人民共和国专利法.txt — 第二条：发明创造是指发明、实用新型和外观设计；发明是对产品、方法或者其改进提出的新的技术方案；实用新型针对产品的形状、构造或者其结合提出的适于实用的新的技术方案〕程序上，发明申请的初步审查、公布、实质审查请求和授权不能视为同一个动作；实用新型和外观设计则适用初步审查制。〔RAG: 中华人民共和国专利法.txt — 第三十四条、第三十五条：发明申请经初步审查后公布，并可在申请日起三年内请求实质审查〕

**点破术语**：独占性；时间性；地域性；三类专利客体；不同审查制度

**类比**：可以把专利制度理解为“公开技术内容，换取在法定范围内审查并获得保护的机会”。这个类比只帮助理解制度功能，不表示提交申请或公开技术就当然取得专利权；具体权利仍取决于法定客体、完整限定、程序和审查结论。

### 五格复盘：权—规—客—用—程（mnemonic）

**记忆锚**：“权—规—客—用—程”五格复盘表：先看权利边界，再找规范依据；接着辨认三类客体及其法定限定；然后理解制度作用；最后核对申请所处程序。口诀只用于组织复盘顺序，不替代具体条文。
**映射**：
- 权
- 规
- 客
- 用
- 程
**何时用**：复盘一份研发交底、申请文件或审查记录时，先默写“权—规—客—用—程”，再逐项回到法条和事实，不把客体识别直接当成授权结论。

### 专利制度基础关系网（knowledge_synthesis）

**知识框架**：
- 专利权基本特征：独占性提供排他保护，时间性和地域性限定保护边界。
- 中国专利制度体系：专利法提供基本制度，专利法实施细则细化程序事项，专利审查指南用于理解审查实践；具体引用应以可核验文本为准。
- 三类保护客体：发明涉及产品、方法或者其改进提出的新的技术方案；实用新型针对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计针对产品整体或者局部的形状、图案或者其结合以及相关色彩结合所作出的富有美感并适于工业应用的新设计。

- 制度运行特点：发明申请采用早期公开、延迟实质审查的实质审查制；实用新型和外观设计申请采用初步审查制。
**概念关系**：先拆分技术事实并识别保护客体，再核对完整法定限定，最后确定适用审查程序。；专利法、实施细则和审查指南具有不同规范功能；基本客体和制度职责先回到专利法，程序细节再核对相应规范。；发明申请的初步审查、公布、实质审查请求和授权彼此不同；实用新型和外观设计初步审查制也不意味着当然授权。；制度作用说明公开与保护的政策逻辑，但不能直接推出某一具体申请必然符合授权条件。
**必记**：专利权具有独占性、时间性和地域性，独占性不等于永久性或全球自动生效。；中国专利制度的基本规范主线包括专利法、专利法实施细则和专利审查指南。；《专利法》第二条规定的三类发明创造是发明、实用新型和外观设计，三者的客体和法定限定不同。；发明申请经初步审查符合要求后公布，并可在申请日起三年内请求实质审查；实用新型和外观设计申请采用初步审查制。；专利制度通过公开与保护的安排激励发明创造、促进技术公开并推动技术应用和经济发展。

### 专利制度基础速查卡（summary_card）

**要点卡**：
- **权利边界**：专利权具有独占性，但时间性和地域性限制其持续时间与适用范围。
- **规范主线**：先查专利法的基本制度，再按问题核对实施细则和审查指南。
- **三类客体**：发明看产品、方法或其改进的新的技术方案；实用新型看产品形状、构造或其结合的适于实用的新的技术方案；外观设计看产品整体或局部的视觉设计及其法定限定。
- **审查路径**：发明申请区分初步审查、公布、实质审查请求和授权；实用新型与外观设计申请采用初步审查制。
- **制度作用**：以技术公开与法定保护安排激励创造、促进公开、推动技术应用和经济发展。
**必背**：独占性、时间性、地域性共同构成专利权的基本边界特征。；发明、实用新型、外观设计是《专利法》第二条规定的三类发明创造。；发明和实用新型均涉及新的技术方案，实用新型还要求适于实用。；发明申请自申请日起满十八个月即行公布，申请人可以请求早日公布。；发明专利申请自申请日起三年内可以请求实质审查，逾期无正当理由不请求的，申请被视为撤回。
**一句话总结**：先拆分技术事实并识别客体，再核对法定限定和审查路径，最后检查专利权的时间与地域边界。
