## 教学正文

## I — 法律问题

本节点需要解决四个相互衔接的问题：第一，专利制度保护的对象是什么；第二，专利权具有什么制度属性；第三，中国专利制度由哪些规范层次构成；第四，在审查与代理实践中，如何按照适当顺序理解保护客体、授权条件、对比判断与申请文件修改边界。

需要特别说明：本节的主节点是“专利法律制度基础”。新颖性、创造性和修改范围的判断框架用于建立后续学习的入口，不在本节展开具体审查案例或跨法域结论。

## R — 适用规则

### 1. 保护客体

《专利法》第二条将发明创造分为发明、实用新型和外观设计。发明针对产品、方法或者其改进所提出的新的技术方案；实用新型针对产品的形状、构造或者其结合所提出的适于实用的新的技术方案；外观设计针对产品整体或局部的形状、图案、色彩及其结合所作出的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条：发明、实用新型和外观设计的定义〕

代理人首先要识别客户主张的创新成果属于哪一种客体；审查人员则要确认申请文件所表达的对象是否与该客体的法定边界相符。客体识别错误时，后续三性分析也会失去正确前提。

### 2. 专利制度的基本属性

专利权的制度理解可以从独占性、时间性和地域性三个维度展开。独占性意味着权利人在法定范围内获得排他性保护；时间性意味着保护并非永久存在；地域性意味着权利效力原则上依附于授予权利的法域。上述三项是制度属性的概括，不等同于某一项具体侵权成立规则。

### 3. 授权实质条件

《专利法》第二十二条规定，授予发明和实用新型专利权应当具备新颖性、创造性和实用性；该条同时规定，新颖性判断涉及现有技术以及特定的在先申请文件，创造性要求相对于现有技术具有相应的实质性特点和进步，实用性要求能够制造或者使用并产生积极效果。〔RAG: 中华人民共和国专利法.txt — 第二十二条：新颖性、创造性、实用性及现有技术定义〕

《专利法》第二十三条针对外观设计规定了不同的授权条件，包括不属于现有设计、与现有设计或现有设计特征组合相比具有明显区别，以及不得与他人在申请日前已经取得的合法权利相冲突。〔RAG: 中华人民共和国专利法.txt — 第二十三条：外观设计的现有设计、明显区别及合法权利冲突规则〕

在实务上，应先确认保护客体，再确认相关时间点和公开材料，随后分别处理新颖性、创造性和实用性问题。这里的“先后”是便于审查和代理工作的分析框架，不表示法律条文规定了唯一不可变更的办案顺序。

### 4. 修改边界

《专利法》第三十三条允许申请人修改申请文件，但对发明和实用新型申请文件的修改不得超出原说明书和权利要求书记载的范围；外观设计申请文件的修改不得超出原图片或者照片表示的范围。〔RAG: 中华人民共和国专利法.txt — 第三十三条：修改不得超出原说明书、权利要求书或原图片、照片表示的范围〕

因此，答复审查意见时不能仅以“修改后更容易授权”为理由增加新的技术内容。代理人应先寻找原始申请文件中的明确记载或能够直接、明确确认的支持，再决定修改方式；审查人员则应核对修改后的技术特征是否仍有原始文件依据。

## A — 规则适用

### 1. 审查视角

审查人员面对一件申请时，应先识别申请对象及其技术或外观表达，再根据申请日等时间基准确定相关公开材料的法律用途。对于发明和实用新型，第二十二条同时涉及新颖性、创造性、实用性和现有技术；对于外观设计，应转入第二十三条的现有设计、明显区别及合法权利冲突框架。不能把外观设计的判断标准直接套用于发明或实用新型。

### 2. 代理视角

代理人应把客户事实转化为三个层次：客体层——申请的是发明、实用新型还是外观设计；授权层——是否涉及新颖性、创造性、实用性或外观设计的明显区别；文件层——拟作修改的内容能否在原说明书、权利要求书或原图片、照片中找到支持。三个层次应依次核对，避免在尚未确认客体和依据时直接承诺授权结果。

### 3. 新颖性与创造性的边界

本节重点保留一个后续学习必须使用的区分：新颖性关注单一公开材料是否已经直接给出同样的技术方案；创造性则需要进一步评价相对于现有技术是否具有相应的实质性特点和进步。前者不能因为多个材料拼接后可以得到，就当然认定缺乏新颖性；后者也不能只因存在某一份材料，就跳过显而易见性或技术启示的分析。

### 4. 抵触申请与创造性评价

根据本节提供的规划提示，抵触申请与一般用于创造性评价的现有技术材料具有不同法律用途。处理相关材料时，应先确认其申请、公开及记载时间，再确认其究竟用于新颖性判断还是创造性判断。检索上下文未提供足以展开该区别的专门审查指南原文，因此本节只确立“先核对法律用途、不得混用”的方法，不对具体案件作超出资料范围的结论。

## C — 结论

专利法律制度基础的主线是：先识别法定保护客体，再理解专利权的独占性、时间性和地域性，随后以《专利法》第二十二条、第二十三条为授权条件入口，并在答复审查意见时始终受第三十三条修改范围的约束。审查人员重在按法条核对对象、时间、对比材料和原始记载；代理人重在把事实、证据和修改方案逐项对应到同一规则链条。

> 常见误区 / 易混淆点
>
> 1. 把“专利权具有独占性”理解为不受时间和地域限制；
> 2. 把发明、实用新型和外观设计的授权条件混为一谈；
> 3. 用多个对比文件拼接后直接否定新颖性；
> 4. 把抵触申请当然作为创造性评价材料；
> 5. 把答复审查意见中的任何有利修改都视为合法修改，而不核对原始记载范围。

### 审查与代理共同面对的一件申请（anchor_scenario）

> 甲公司研发出一种用于工业设备的温度控制装置，代理人准备分别申请发明专利和实用新型专利。研发人员还提交了装置结构图，并计划在技术交流会上介绍产品。审查员随后发现申请文件中既有方法步骤，也有结构特征；代理人在答复意见时又想增加一个原申请文件没有明确写出的参数。此时需要同时解决：申请对象如何归类、应适用哪组授权条件、公开材料如何评价，以及修改是否越过原始记载范围。

**锚定**：该情境锚定保护客体识别、授权条件区分、现有技术用途和修改不得超范围四个基础判断点。

**先想一想**：如果你同时站在审查员和代理人立场，面对这份申请时，第一步应先确认什么，为什么不能直接进入创造性判断？

### 法条锚定：客体、三性与修改边界（legal_anchor）

- **《中华人民共和国专利法》第二条**：第二条先回答“保护什么”：发明、实用新型和外观设计分别有各自的法定对象。
- **《中华人民共和国专利法》第二十二条**：第二十二条规定发明和实用新型必须同时满足新颖性、创造性和实用性，并界定现有技术。
- **《中华人民共和国专利法》第二十三条**：第二十三条规定外观设计的现有设计、明显区别和合法权利冲突要求。
- **《中华人民共和国专利法》第三十三条**：第三十三条允许修改，但修改不能超出原说明书、权利要求书或原图片、照片表示的范围。

**为何重要**：这些条文共同构成基础判断链：先识别客体，再选择授权条件，最后在申请程序中控制修改边界。后续审查意见答复、无效和侵权复盘都需要回到这条法条主线。

### 从申请事实到修改边界的完整推演（worked_example）

**案情/例题**：甲公司提交一件发明专利申请，文件中记载了一种温度控制装置及其控制方法。审查意见涉及授权条件，代理人拟在答复中增加一个原说明书和原权利要求书没有明确记载的温度参数。需要演示如何确定适用规则，以及如何检查该修改是否存在超范围风险。
**适用规则**：《专利法》第二条、第二十二条、第二十三条和第三十三条；其中第二条用于识别保护客体，第二十二条用于发明和实用新型的授权条件，第二十三条用于外观设计，第三十三条用于修改范围。
**分步推演**：
1. 先观察申请文件主张的对象：如果主张的是产品、方法或其改进所提出的新的技术方案，进入发明客体识别；如果主张的是产品形状、构造或其结合并适于实用，则需要考虑实用新型边界；如果核心是产品整体或局部的形状、图案、色彩及其结合，则进入外观设计框架。 → *第一步是确定保护客体，不能先假定适用同一套审查标准。*
2. 确认客体为发明后，适用第二十二条的授权条件框架，分别核对新颖性、创造性和实用性；如果对象是外观设计，则应转入第二十三条的现有设计、明显区别和合法权利冲突框架。 → *第二步是按客体选择授权条件。*
3. 对拟增加的温度参数，回到原说明书和原权利要求书逐项核对，看该参数是否已有明确记载或能够从原始文件中直接、明确确认。仅仅因为参数有助于克服审查意见，不足以替代原始文件支持。 → *第三步是单独核对修改的原始依据。*
4. 如果增加参数超出原说明书和权利要求书记载范围，则触及第三十三条的修改边界；如果原始文件已有相应记载，仍需继续检查修改后的权利要求是否清楚、是否得到说明书支持以及是否满足相应授权条件。 → *第四步是把修改合法性与授权实质条件分开判断。*
**结论**：该案不能只围绕“加入参数后是否更容易授权”作判断。应先识别客体并选择第二十二条或第二十三条框架，再依据第三十三条核对修改是否有原始记载，最后分别评价授权条件。
**本题要点**：专利申请复盘应坚持“先定客体、再定规则、核对原始依据、最后评价授权条件”的顺序。

### 把法条翻译成审查与代理语言（verbal_explanation）

可以把这一节理解为一条审查工作台上的固定路线。先不要急着讨论“有没有创造性”，先看客户到底拿什么来申请：是产品、方法，还是产品外观。对象一旦不同，适用的法条就不同。接着看授权条件，发明和实用新型要过新颖性、创造性、实用性三道门，外观设计则有自己的现有设计和明显区别要求。最后看代理人准备怎么改文件：修改不是越多越好，而是必须能在原来的说明书、权利要求书或者图片、照片中找到依据。审查员是在逐项核对，代理人是在逐项证明；两边使用的判断链其实是同一条。

**点破术语**：保护客体；现有技术；三性；修改不得超范围

**类比**：可把判断链理解为文件审查清单，但清单只是帮助排序，不能替代法条和原始文件核对。

### 基础判断四步表（mnemonic）

**记忆锚**：“客—规—据—界”四步表：客体识别、规则选择、依据核对、边界控制。遇到具体申请时依次写出四栏，不跳栏。
**映射**：
- 客
- 规
- 据
- 界
**何时用**：复盘审查意见、撰写答复或判断一项新增技术特征能否加入权利要求时使用。

### 双视角复盘提示（reflect_prompt）

**反思问题**：同一份申请文件中，审查员和代理人分别最需要防止哪一种判断错误？

**关注要点**：审查员是否把不同专利客体的授权条件混用；代理人是否只关注克服审查意见而忽略修改的原始记载依据；双方是否先确认时间点、公开材料和法律用途，再进入结论

**连接**：连接到后续的新颖性、创造性、审查意见答复和修改限制节点。

### 专利制度基础知识网络（knowledge_synthesis）

**知识框架**：
- 保护客体：发明、实用新型和外观设计是专利法规定的三类发明创造对象。
- 专利权基本属性：独占性、时间性和地域性共同说明专利保护的范围与边界。
- 中国专利制度体系：专利法提供基本规范，专利法实施细则和专利审查指南承担程序与审查实践中的细化作用。
- 授权条件：发明和实用新型围绕新颖性、创造性和实用性展开，外观设计适用现有设计、明显区别及合法权利冲突框架。
- 修改边界：申请文件修改必须受原说明书、权利要求书或原图片、照片表示范围的约束。
**概念关系**：保护客体决定主要适用的授权条件框架。；授权条件判断需要以申请日及相关公开材料为时间和证据入口。；修改边界判断依赖对原始申请文件的核对，并与修改后的授权条件判断相互衔接但不能混同。
**必记**：先识别保护客体，再选择相应授权条件规则。；发明和实用新型的三性是新颖性、创造性和实用性，三者不能相互替代。；抵触申请、现有技术和对比文件的法律用途必须结合时间点分别确认。；答复审查意见时，修改能否克服问题与修改是否超出原始记载范围是两个不同问题。

### 专利法律制度基础速查卡（summary_card）

**要点卡**：
- **三类保护客体**：发明、实用新型和外观设计分别对应不同的法定对象。
- **专利权三项属性**：独占性说明排他保护，时间性说明保护期限，地域性说明效力依附法域。
- **发明和实用新型三性**：新颖性、创造性和实用性是第二十二条确立的授权条件。
- **外观设计授权条件**：重点核对现有设计、明显区别及与他人合法权利是否冲突。
- **修改边界**：修改不得超出原说明书、权利要求书或原图片、照片表示的范围。
**必背**：《专利法》第二条：发明、实用新型和外观设计的定义。；《专利法》第二十二条：发明和实用新型的新颖性、创造性、实用性及现有技术。；《专利法》第三十三条：申请文件修改不得超出原始记载范围。；复盘顺序：客体—规则—证据与时间—授权条件—修改边界。
**一句话总结**：专利实务先定保护客体，再按法条判断授权条件，并以原始文件记载控制修改边界。

### 三类测评：基础、前探与易错点（assessment）

**三类覆盖**：backward_review、forward_probe、weakness_probe
**题目**：
