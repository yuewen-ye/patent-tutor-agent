# 专家 B 修订稿

## teaching_content

## 1. 场景导入
某研发团队正在开发一种新型机器人关节模组，他们希望申请专利，但担心在下月展会展示时会影响申请。团队成员甲是专利代理人，他需要判断该模组是否属于专利保护范围，同时考虑新颖性审查和授权条件。乙是审查员，他需要评估申请是否满足实质审查要求。这样的情境同时涉及专利客体判断、授权三性和审查程序，让我们先从具体问题切入，理解专利制度的核心框架。

## 2. 人话解释
专利制度的核心是保护发明创造，让发明者获得独占性、时间性和地域性保护。中国专利制度以《专利法》为核心，包括专利法实施细则和审查指南。它保护三种客体：发明（对产品、方法或改进的技术方案）、实用新型（对产品形状、构造的实用技术方案）和外观设计（对产品整体或局部的形状、图案、色彩等富有美感的设计）。专利制度的作用在于激励发明创造、促进技术公开，推动经济发展。审查方面，中国采用早期公开延迟审查制度，结合初步审查和实质审查，确保专利授权后能产生积极效果。

## 3. 法条回扣
《专利法》第二条：本法所称的发明创造是指发明、实用新型和外观设计。发明，是指对产品、方法或者其改进所提出的新的技术方案。实用新型，是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。外观设计，是指对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计。

《专利法》第二十二条：授予专利权的发明和实用新型，应当具备新颖性、创造性和实用性。新颖性，是指该发明或者实用新型不属于现有技术，也没有任何单位或者个人就同样的发明或者实用新型在申请日以前向国务院专利行政部门提出过申请，并记载在申请日以后公布的专利申请文件或者公告的专利文件中。创造性，是指与现有技术相比，该发明具有突出的实质性特点和显著的进步，该实用新型具有实质性特点和进步。实用性，是指该发明或者实用新型能够制造或者使用，并且能够产生积极效果。本法所称现有技术，是指申请日以前在国内外为公众所知的技术。

《专利法》第二十三条：授予专利权的外观设计，应当不属于现有设计；也没有任何单位或者个人就同样的外观设计在申请日以前向国务院专利行政部门提出过申请，并记载在申请日以后公告的专利文件中。授予专利权的外观设计与现有设计或者现有设计特征的组合相比，应当具有明显区别。授予专利权的外观设计不得与他人在申请日以前已经取得的合法权利相冲突。本法所称现有设计，是指申请日以前在国内外为公众所知的设计。

《专利法》第二十四条：在中国政府主办或者承认的国际展览会上首次展出的作品，自展出之日起六个月内，申请专利不受新颖性限制。

《专利法》第二十九条：申请人要求发明、实用新型专利优先权的，应当在申请的时候提出书面声明，并且在十二个月内提交第一次提出的专利申请文件的副本；申请人要求外观设计专利优先权的，应当在申请的时候提出书面声明，并且在六个月内提交第一次提出的专利申请文件的副本；自申请日起三十个月内，享有优先权。

《专利法》第三十条：申请人要求发明、实用新型专利优先权的，应当在申请的时候提出书面声明，并且在第一次提出申请之日起十六个月内，提交第一次提出的专利申请文件的副本。申请人要求外观设计专利优先权的，应当在申请的时候提出书面声明，并且在三个月内提交第一次提出的专利申请文件的副本。申请人未提出书面声明或者逾期未提交专利申请文件副本的，视为未要求优先权。

## 4. 类比 / 口诀
用‘三性审查’比喻考试流程：新颖性像查重（没被公开过），创造性像深度分析（非显而易见），实用性像实际测试（能用且有用）。区分边界：新颖性看公开行为，创造性看是否突出进步，实用性看能否产生积极效果。记忆口诀：'新-没公开、创-非显见、实-能制造有用'。适用边界：仅适用于授权判断，不适用于侵权或合同纠纷。

## 5. 应试提示
题干关键词：专利客体（发明/实用新型/外观设计）、授权三性（新颖性/创造性/实用性，仅适用于发明和实用新型）、现有技术/抵触申请定义、优先权要求。判断步骤：先定保护客体（外观设计不适用三性），再查现有技术或抵触申请，最后评估对应条件。常见陷阱：混淆抵触申请与现有技术、权利要求解释顺序不清、优先权期间（发明/实用新型12个月，外观设计6个月）与副本提交期限（16个月或3个月）混淆。审查时优先看申请日、公开行为、是否符合实质审查。
