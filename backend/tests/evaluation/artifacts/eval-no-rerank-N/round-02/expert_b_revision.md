# 专家 B 修订稿

## teaching_content

## 1. 场景导入
某公司研发了一种新型谐波减速器关节模组，内部形状构造经过改进。他们计划申请发明专利，但想知道这种产品是否属于实用新型专利的保护客体。请问：（1）这个模组是否属于专利法第2条规定的保护客体？

## 2. 人话解释
专利保护的三种客体分别是发明、实用新型和外观设计。发明是最广泛的，包括对产品、方法或其改进提出的新的技术方案，只要是采用技术手段解决技术问题并获得符合自然规律技术效果的，就属于发明专利。实用新型只保护产品，针对产品的形状、构造或者其结合提出的适于实用的新的技术方案，不能保护自然物、气味等非技术手段解决的问题。外观设计保护产品的视觉外观。掌握这些核心概念，能帮我们快速判断一件技术方案能不能申请专利。

## 3. 法条回扣
《专利法》第二条规定：发明，是指对产品、方法或者其改进所提出的新的技术方案。实用新型，是指对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。外观设计，是指对产品的形状、图案或者其结合所提出的富有美感并适于工业应用的新设计。

## 4. 类比 / 口诀
把保护客体判断比作“找门票”：发明像“宽门票”（任何技术方案都行，只要是技术手段+技术效果）；实用新型像“窄门票”（只准产品形状构造改进）；外观设计像“视觉门票”（美观+工业应用）。口诀：形状构造结合（实用新型），技术手段效果（发明），避免自然物气味（非保护）。适用边界：只能保护实体产品，不能保护纯信息或自然存在物品。

## 5. 应试提示
题干关键词：形状构造结合、材料本身改进、技术方案、产业方法制造。常见陷阱：把形状视为材料本身改进，或把非技术手段（如单纯色彩）当作实用新型。判断流程：先看是不是产品（实用新型）→再看是不是形状构造改进→最后确认不是材料本身或自然物。

## 6. 互动提问
如果你是专利代理人，看到客户说“这是个新形状的减速器”，你会怎么问客户来确认是否属于实用新型？或者，如果一个方案用老材料做出新形状，能否申请专利？欢迎在评论区讨论你的判断依据。
