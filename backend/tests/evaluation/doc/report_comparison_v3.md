## 五、结论与使用建议

- **谬误率差异判断的黄金规则**：先看 1.2 谬误率汇总（分母=全量陈述），再看 1.3.1/1.3.2/1.3.3 分桶的分子差；如果分桶样本量 <5 不要跨组比较。
- **消融是否有效的判定**：关闭组件的对应指标应为 N/A，而不是假 0% 或低百分比。目前已对齐：norag-M4、nodebate-M6。
- **完整组（multi）综合优势**：25 项指标中 22 项合格；去辩论/去RAG/去Rerank/单模型各有显著弱点（详见 report_multi.md「主表」章节）。
- **完整组的主要短板**：5.3 PII 合规、3.3 混淆对覆盖率 个别画像有未通过项，建议后续针对性加强。
