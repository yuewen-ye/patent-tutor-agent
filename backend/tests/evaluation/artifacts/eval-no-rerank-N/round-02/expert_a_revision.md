# 专家 A 修订稿

## teaching_content

## I — 法律问题

本节围绕“专利法律制度基础”回答：哪些成果属于专利法保护客体；专利权具有哪些基本边界；不同类型采用何种审查路径；权利何时生效、期限从何时起算；以及如何在证据边界内理解中国专利制度的发展特点。审查员重在依据法定分类和程序审查，代理人重在据此选择类型、准备文件并控制程序风险。

## R — 适用规则

### 1. 保护客体

《专利法》第二条规定，发明创造是指发明、实用新型和外观设计。发明是对产品、方法或者其改进提出的新的技术方案；实用新型是对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计是对产品整体或局部的形状、图案及其结合，或者色彩与形状、图案的结合所作的富有美感并适于工业应用的新设计。〔RAG: 中华人民共和国专利法.txt — 第二条〕

第一步不是直接讨论技术是否先进，而是确认事实对象是否符合相应法定客体。分类错误会连带导致申请类型、审查路径和期限判断错误。

### 2. 专利权基本特征

检索材料将专利权概括为独占性、时间性和地域性。独占性是指除专利法另有规定外，未经许可，他人不得实施专利；时间性是指权利仅在法定期限内存在，届满后进入公有领域；地域性是指效力以特定国家或地区的法律授予为基础，不因一国获得保护而当然扩及其他法域。〔RAG: 专利法律知识详细解读.txt — 专利权具有排他性、时间性和地域性〕

### 3. 审查路径

第三十九条规定，发明专利申请经实质审查没有发现驳回理由的，作出授予专利权决定。〔RAG: 中华人民共和国专利法.txt — 第三十九条〕第四十条规定，实用新型和外观设计申请经初步审查没有发现驳回理由的，作出授予相应专利权决定。〔RAG: 中华人民共和国专利法.txt — 第四十条〕

类型决定审查路径，但审查没有发现法定驳回理由才可能进入授予程序。不能仅以申请人的主观称呼替代客体判断，也不能把初步审查等同于发明申请的实质审查。

### 4. 生效时间与保护期限

专利权自公告之日起生效。〔RAG: 中华人民共和国专利法.txt — 第三十九条、第四十条〕第四十二条规定，发明、实用新型、外观设计专利权期限分别为二十年、十年、十五年，均自申请日起计算。〔RAG: 中华人民共和国专利法.txt — 第四十二条〕

公告日决定权利何时发生效力；申请日决定期限何时开始计算。两者不能替代。

### 5. 制度体系、作用、发展特点与证据边界

中国专利制度的规范体系包括专利法、专利法实施细则和专利审查指南。本轮检索上下文未提供实施细则和审查指南的具体条文，不能虚构条款号或审查口径。专利制度的作用包括保护专利权人合法权益、鼓励发明创造、促进技术公开和应用，并推动科学技术进步与经济社会发展。〔RAG: 专利法律知识详细解读.txt — 立法宗旨〕

本轮材料确认专利法自1985年4月1日起施行。〔RAG: 专利法律知识详细解读.txt — 第八十二条〕当前教学窗口将“早期公开延迟审查”列为中国专利制度发展特点；因此可以将其作为本节点的概括性制度特征识别。该表述仅依据窗口知识点，不表示本轮已经核验早期公开制度的具体历史阶段、程序条件或适用范围；对此仍须补充可靠材料后再作具体判断。发明申请的实质审查与实用新型、外观设计申请的初步审查并存，则有第三十九条、第四十条作为直接依据。

## A — 规则适用

面对一项技术成果，先核对事实特征与第二条的三类客体定义；再依确定类型选择审查路径；取得授予决定后确认公告日以判断权利生效；最后依申请日和类型核算期限。审查视角关注法定客体、适用程序和驳回理由；代理视角关注类型选择、文件准备、日期管理和地域保护布局。涉及国外申请、授权或跨法域实践时，必须分别核对目标法域依据，不能由中国授权直接推出域外结论。

## C — 结论

本节点的核心顺序是“先定客体，再定程序；公告看生效，申请日看期限；地域保护须有相应法域依据”。发明、实用新型、外观设计同属法定发明创造，但定义、审查路径和期限不同。中国专利制度发展特点可在当前窗口层面概括为早期公开延迟审查以及初步审查制与实质审查制并存；其中，早期公开延迟审查的具体历史规则尚缺直接检索依据，应在补充可靠资料后审慎复盘。

> 常见误区 / 易混淆点
>
> 1. 把“专利”泛称误作单一客体，忽略三类法定区分。
> 2. 把发明实质审查与实用新型、外观设计初步审查混同。
> 3. 把公告日当作期限起算日，或把申请日当作权利生效日。
> 4. 把一国授权误认为全球有效。
> 5. 将窗口概括的早期公开延迟审查发展特点误当作已经核验的具体历史规则。
