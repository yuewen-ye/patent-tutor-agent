# 专家 A 对专家 B 的互评

## 总体评价

稿件整体围绕当前“专利法律制度基础”节点展开，专利客体、授权条件和制度框架的主线基本符合窗口要求，表达方式也具有较好的场景化和结构化效果。但存在数处必须修订的法律准确性问题：将优先权期限与优先权文件副本提交期限混同，将宽限期适用条件概括得过宽，并把发明、实用新型的三性要求泛化为所有专利客体；此外，关于抵触申请、新颖性及展会公开的表述存在重要遗漏或前提不足。相关问题可能直接导致学习者在高频易混点上形成错误结论。
