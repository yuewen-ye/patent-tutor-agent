# 专家 B 修订稿

## teaching_content

## 1. 场景导入

李明是某电动汽车电池公司专利代理人，负责为客户申请新型固态电池专利。客户担心：1) 展会展示后是否能顺利申请？2) 申请授权后，公司能否在中国境内独家生产并销售？3) 保护期后技术是否会成为公众财产？李明需同时回答保护客体、授权实质条件、专利权特征三大核心问题。

## 2. 人话解释

咱们把专利制度基础说成‘护照加保险’：发明、实用新型、外观设计是‘护照’（专利法第2条），给发明创造盖章才能上路；独占性像‘独家旅行证’，别人未经许可不能用（这是专利权效力的制度概括，直接条文依据主要看第十一条等效力规则，不是第九条）；地域性像只限国内护照，国外没用；时间性像护照有效期，过期就失效。审查员看到OA就看是否符合这三关，代理人则用这些特征帮客户算风险和权利边界。

## 3. 法条回扣

《专利法》第二条：发明创造专指发明、实用新型、外观设计三客体。

《专利法》第九条：同样的发明创造只能授予一项专利权；两个以上的申请人同日分别申请的，应当协商确定申请人（先申请原则与禁止重复授权，不是‘未经许可不得实施’的直接依据）。

《专利法》第十一条：专利权被授予后，除另有规定外，他人未经许可不得实施其专利（独占性的主要效力依据）。

《专利法》第十二条：任何单位或者个人实施他人专利的，应当与专利权人订立实施许可合同（原则性要求；另有法定例外等情形时，不能简单理解成‘一切实施都必须订合同并付费’）。

《专利法》第十五条：共有人对权利行使有约定的，从其约定。

《专利法》第二十四条：申请日以前六个月内，在中国政府主办或者承认的国际展览会上首次展出的，不丧失新颖性。

《专利法实施细则》第五条：期限起算与届满日计算规则（第一日不计入等）。

## 4. 类比 / 口诀

专利权特征三件套：独（独占）—区（地域）—时（时间）。独占性=未经许可他人不得实施（制度概括，效力依据重点看第十一条，切勿误写成第九条）；地域性=仅在授权地域内有效；时间性=不同类型客体保护期限不同。适用边界：用于把握权利范围与主体边界；第九条只解决‘能否重复授权/谁先申请’，不替代独占效力条文。

## 5. 应试提示

题干关键词：专利法第2条、独占性、地域性、时间性、先申请原则、宽限期。判断步骤：1. 确认保护客体类型；2. 分清第九条（禁止重复授权/先申请）与第十一条（独占效力）；3. 涉及展会公开时，核对是否属于第二十四条情形且是否在六个月内；4. 明确地域与期限。常见陷阱：把第九条当成‘未经许可不得实施’的依据；把宽限期算错（起算与届满）；混淆初步审查与实质审查。
