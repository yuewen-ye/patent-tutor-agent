# 专家 B 修订稿

## teaching_content

## 1. 场景导入

你在材料所带一组研发：刚做出一种高导热陶瓷基板配方，同事催着“赶紧报专利”，市场部又说下个月要在国内行业展上放样品。会议室里同时甩出三句话——“这算发明还是实用新型？”“展了还能不能申请？”“专利到底管几年、管哪国？”

先别急着跳到新颖性、创造性细则，也不要在本节点先给申请文件清单或宽限期结论。材料领域后面所有审查争论，都先落在同一块地基上：什么是专利、保护什么、权利有什么边界、中国用哪几本“规则书”在审。把地基立住，后面进入申请程序、授权条件判断时才不会串台。展会公开会不会影响申请、文件怎么交，留给后续申请程序等相关节点再判断。

## 2. 人话解释

把专利想成国家发给你的“有期限、有地盘的独占通行证”：

- **独占性**：未经许可，别人原则上不能为生产经营目的实施你的专利技术方案（制造、使用、许诺销售、销售、进口等，具体以权利类型为准）。
- **时间性**：保护不是永久会员——发明、实用新型、外观设计各有法定期限，到期权利终止，技术进入公有领域。
- **地域性**：中国专利主要在中国法域内发生效力；要在别国获得保护，通常还要按该国/地区途径去申请或进入。

中国专利制度像“三层规范楼”：
1. **专利法**——全国人大常委会制定的主干规则（能不能保护、授权条件框架、申请与保护框架）；
2. **专利法实施细则**——配套程序与操作细则（怎么走程序、初步审查看什么等）；
3. **专利审查指南**——审查员与代理人共用的审查操作手册（具体判法多在后续节点展开）。

保护客体只有三条赛道（专利法第2条）：
- **发明**：产品、方法或其改进的新的技术方案；
- **实用新型**：产品的形状、构造或其结合的适于实用的新的技术方案（不保护方法）；
- **外观设计**：对产品的整体或者局部的形状、图案或者其结合以及色彩与形状、图案的结合所作出的富有美感并适于工业应用的新设计（不是只有“立体外形”，平面图案、色彩结合等也可能落入外观设计，但仍须满足产品依附、美感与工业应用等法定条件）。

制度要干四件事：激励创造、换取公开、推动应用、服务经济发展。中国审查结构的特点是：**发明走早期公开、请求实质审查**；**实用新型与外观设计以初步审查为主**——“初步审查制与实质审查制并存”。初步审查重点看文件齐不齐、格式对不对，以及是否明显属于不授权情形等。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十条：专利法第三十四条和第四十条所称初步审查，是指审查专利申请是否具备专利法第二十六条或者第二十七条规定的文件和其他必要的文件，这些文件是否符合规定的格式，并审查下列各项……〕

材料研发里常见“踩线”提醒（仍属基础边界，不是本节深讲授权条件细则）：科学发现本身、单纯智力活动规则、疾病诊治方法等，属于不授予专利权的对象清单。〔RAG: 中华人民共和国专利法.txt — 第二十五条：对下列各项，不授予专利权：（一）科学发现；（二）智力活动的规则和方法；（三）疾病的诊断和治疗方法……〕至于展会首次展出等公开情形会不会影响后续申请，本节点只把问题提出来，具体规则放到后续相关节点判断，避免把程序节点内容提前讲成掌握要求。

## 3. 法条回扣

- **客体三分法**：发明 / 实用新型 / 外观设计的法定定义在专利法第2条——材料配方与工艺路线通常走发明；有形状构造的器件结构可考虑实用新型；产品的形状、图案或者其结合以及色彩与形状、图案的结合等设计方案，在符合法定条件时可走外观设计。
- **不授权边界提醒**：科学发现、纯智力规则、疾病诊治方法等见专利法第25条，避免把“发现了现象”误当成“可授权的技术方案”。
- **程序分流信号**：初步审查相关安排在实施细则第50条有解释，对应发明早期公开与实用新型/外观设计以初步审查为主的制度特点。〔RAG: 中华人民共和国专利法实施细则.txt — 第五十条……〕
- **后续节点接口（不展开规则）**：申请文件准备、申请日与优先权、宽限期，以及授权条件如何具体判断，将在后续“专利申请程序”及授权条件相关节点学习；本节点只要求先把客体归类、权利三特征和规范层级立住。

## 4. 类比 / 口诀

**类比（有边界）**：专利像“有期限的地块产权证”——
- 独占性 ≈ 你有权排除他人擅自在你的地块上经营；
- 时间性 ≈ 产权有年限，到期收归“公地”；
- 地域性 ≈ 中国证主要管中国地界，不管自动覆盖全球。

**边界说明**：物权类比便于记三特征，但专利是**非物质的技术方案/设计**上的排他权，侵权判断、无效程序、权利要求解释都不能按“实物地契”硬套。

**口诀**：权属三性——**独、时、域**；规范三层——**法、则、指**；客体三道——**发、实、外**；审查双轨——**初审常在、实审发明**。

（“外”记：形状/图案/色彩结合的设计，不是只会“外形”二字。）

## 5. 应试提示

题干关键词与判断步骤：
1. 看见“保护多久/哪国有效/能否禁止他人”→先答**时间性/地域性/独占性**，别跳到授权条件细节。
2. 看见“配方/工艺/方法”→优先**发明**；“产品形状构造”→可**实用新型**；“形状/图案/色彩结合且依附产品的设计”→**外观设计**；方法一般不能用实用新型保护。
3. 看见“审查指南怎么写的”→它是审查操作依据，位阶上配合专利法与实施细则，不是替代法律。
4. 看见“早期公开、延迟/请求审查”→对应**发明**程序特点；实用新型、外观设计侧重**初步审查**。
5. 常见陷阱：把“科学发现/自然规律表述”当成可授权发明；把“中国专利”当成全球自动保护；把外观设计误记成“只有立体外形才算”。
