## 教学正文

## 1. 场景导入

某研发团队完成了一套智能温控设备：设备本身有新的结构，控制程序还包含一套调节温度的方法，外壳另有新的图案和色彩。团队准备申请专利，但成员争论：有人认为只要“有创意”就能申请，有人认为只有已经公开销售的产品才算专利客体。这里的第一关不是马上判断“新不新”，而是先确认申请内容属于哪一种法定保护对象。

## 2. 人话解释

可以按“先分类、再判断”的顺序理解。专利制度给权利人的是在一定时间、一定地域内排斥他人实施的权利，因此具有独占性、时间性和地域性。与此同时，专利制度并不是单纯奖励一个想法，而是用法律保护换取技术公开，进而鼓励发明创造、促进技术应用。

中国专利制度可以看成三层规范：专利法规定基本规则，专利法实施细则补充具体实施要求，专利审查指南进一步细化审查中的判断方法。审查员据此检查申请是否落入法定客体，代理人则要把研发事实准确拆分并表达出来。

三类客体要分开看：发明可以涉及产品、方法或者它们的改进；实用新型主要针对产品的形状、构造或者其结合；外观设计关注产品呈现的外观。一个方案属于法定客体，只是进入后续审查的起点，并不等于已经满足全部授权条件。

## 3. 法条回扣

《专利法》第二条第二款规定：“发明，是指对产品、方法或者其改进所提出的新的技术方案。”《专利法》第二条第三款规定，实用新型是对产品的形状、构造或者其结合所提出的适于实用的新的技术方案。〔RAG: 专利法专题讲座.txt — 《专利法》第二条第二款、第三款关于发明和实用新型保护客体的规定〕

检索材料还提示，发明客体判断的重点并不只是“新”，而是是否属于技术方案；如果方案采用技术手段、解决技术问题并获得符合自然规律的技术效果，才具有相应的技术方案特征。〔RAG: 专利法专题讲座.txt — “着重点并不是‘新’，而是‘技术方案’”；采用技术手段、解决技术问题、获得符合自然规律的技术效果〕

《专利法》第六十四条规定，发明或者实用新型专利权的保护范围以权利要求的内容为准，说明书及附图可以用于解释权利要求。〔RAG: 中华人民共和国专利法.txt — 第六十四条：发明或者实用新型专利权的保护范围以其权利要求的内容为准〕

需要明确证据边界：本节检索上下文足以支持三类客体和权利要求解释的基础讲解，但不足以完整证明制度沿革的具体年份、修法节点或跨法域最新趋势；这些内容应另行检索核验。

## 4. 类比 / 口诀

记忆时使用“拆—对—定—再审”四步表：先拆分产品结构、方法步骤和外观事实；再对照《专利法》第二条；然后确定权利要求、图片照片等申请表达；最后再进入其他授权条件和程序判断。这个顺序只是学习工具，不能代替法条，也不能把“属于保护客体”误记成“必然授权”。

## 5. 应试提示

题干出现“属于哪类专利”“保护对象是什么”时，先找对象是产品、方法、产品形状构造，还是产品外观。出现“技术方案”时，再检查是否有技术手段、技术问题和相应技术效果，不要被“智能”“商业模式”或“有经济价值”等名称带偏。代理视角重在拆清技术事实和准确撰写；审查视角重在按法定客体和申请文件进行核对。常见陷阱是把保护客体判断与新颖性、创造性或最终授权混为一谈。

### 先看见一份专利申请（anchor_scenario）

> 某研发团队完成了一套智能温控设备：设备本身有新的结构，控制程序还包含一套调节温度的方法。团队准备申请专利，但成员争论不休：有人认为只要“有创意”就能申请，有人认为只有已经公开销售的产品才算专利客体。审查员需要先判断这些技术内容分别属于什么保护对象；代理人则要把技术事实准确翻译成申请文件中的客体类型，避免把方法、产品结构和外观混为一谈。

**锚定**：用产品、方法和产品结构的申请场景锚定保护客体、专利制度特征及审查与代理的基本分工。

**先想一想**：在判断一项技术能否进入专利审查之前，你会先看它解决了什么技术问题、采用了什么技术手段，还是先看它是否已经产生经济收益？

### 法条锚定：先确定保护对象（legal_anchor）

- **《专利法》第二条第二款、第三款、第四款**：发明是对产品、方法或者其改进提出的新的技术方案；实用新型是对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计则围绕产品的整体或局部外观设计作出界定。〔RAG: 专利法专题讲座.txt — 《专利法》第二条第二款规定“发明，是指对产品、方法或者其改进所提出的新的技术方案”；第三款规定实用新型保护产品的形状、构造或者其结合〕
- **《专利法》第六十四条**：处理保护范围时，发明或实用新型以权利要求的内容为准，说明书及附图可以用于解释权利要求；外观设计则以图片或者照片中的外观设计为准，简要说明可以用于解释。〔RAG: 中华人民共和国专利法.txt — 第六十四条：发明或者实用新型专利权的保护范围以其权利要求的内容为准，说明书及附图可以用于解释〕

**为何重要**：第二条解决“保护什么”的入口问题，是区分发明、实用新型和外观设计的法定坐标。第六十四条提醒代理人在撰写和审查时，不能只看技术名称，还要回到权利要求及其解释范围。

### 演示：把一项研发成果拆成三个判断对象（worked_example）

**案情/例题**：某公司开发一台具有新型外壳结构的检测设备，并设计了一种控制检测步骤的方法，同时为设备外壳设计了新的图案和色彩。公司希望用一份笼统的“智能检测方案”覆盖全部内容。请演示审查员和代理人应如何先进行保护客体识别。
**适用规则**：《专利法》第二条第二款、第三款、第四款关于发明、实用新型和外观设计的规定；《专利法》第六十四条关于保护范围的规定。
**分步推演**：
1. 先把技术事实拆成设备结构、控制方法和产品外观三个部分，而不是按照“智能检测方案”这一宣传名称整体判断。 → *第一步：拆分技术事实。*
2. 设备结构涉及产品的形状、构造或者其结合；控制检测步骤的方法可能属于发明所称的产品或方法技术方案；图案和色彩则应从外观设计客体角度单独观察。 → *第二步：分别对照法定客体。*
3. 代理人应据不同客体安排权利要求或图片、照片及简要说明；审查员则检查申请表达是否真正对应相应法定客体。 → *第三步：将技术内容与申请表达对应。*
4. 即使客体判断通过，仍不能据此推出已经具备授权资格，还要进入相应的审查环节。 → *第四步：区分客体判断与最终授权。*
**结论**：该案应先把设备结构和控制方法分别识别为可能的发明或实用新型技术内容，再把外观装饰单独判断是否属于外观设计保护对象；不能因为技术方案具有商业价值，就直接跳过保护客体判断。具体能否授权，还需在后续程序中继续审查相应法定条件。
**本题要点**：遇到复杂技术申请时，先拆事实、再对照客体、最后检查申请表达，审查客体与最终授权不能混为一谈。

### 把“保护客体”说成人话（verbal_explanation）

我们先别急着问“这个发明新不新”，第一关是问“它是不是专利法要保护的那类东西”。发明的范围相对宽，可以落在产品、方法以及它们的改进上，但核心仍是技术方案；实用新型更集中在产品的形状、构造或者它们的结合。外观设计则主要看产品呈现出来的外观。审查员的工作，是把申请内容放进法定分类并检查表达是否匹配；代理人的工作，是先把客户的技术事实拆清楚，再选择准确的撰写方式。客体通过不等于已经授权，后面还可能有其他审查门槛。

**点破术语**：保护客体；发明；实用新型；外观设计

**类比**：可以把保护客体看成“入场券分类”，但这只是记忆辅助：它不能替代法条，也不能据此判断新颖性、创造性或最终是否授权。

### 四步记忆：拆—对—定—再审（mnemonic）

**记忆锚**：“拆—对—定—再审”四步表：拆分技术事实；对照发明、实用新型、外观设计法定客体；确定申请表达；再审查其他授权条件。
**映射**：
- 拆
- 对
- 定
- 再审
**何时用**：做专利基础题、阅读申请文件或复盘审查意见时，看到“属于哪类专利”“是否属于保护客体”就按四步依次检查。

### 反思：同一份申请的双视角复盘（reflect_prompt）

**反思问题**：复盘一份专利申请时，如果申请人只用一个宽泛的技术名称描述产品结构、控制方法和外观设计，你会如何分别记录审查员的识别任务与代理人的表达任务？

**关注要点**：技术事实是否已经拆分为产品、方法和外观三个层次；法条客体定义与申请文件表达是否一一对应；是否把保护客体判断误写成已经满足全部授权条件

**连接**：连接到你已有的法条阅读和程序法经验：先识别法律问题，再确定适用规范，最后检查程序结论是否越界。

### 本节点知识关系网（knowledge_synthesis）

**知识框架**：
- 专利制度基本概念与特征：专利权通常表现为具有独占性的法定权利，并受时间和地域范围限制；这些是制度理解框架，不等同于某一具体权利要求的保护范围。
- 中国专利制度体系：专利法提供基本规范，专利法实施细则补充程序和具体操作，专利审查指南为审查判断提供更细化的工作指引。
- 三类保护客体：发明针对产品、方法或者其改进提出的新的技术方案；实用新型针对产品的形状、构造或者其结合提出的适于实用的新的技术方案；外观设计针对产品外观形成法定保护对象。〔RAG: 专利法专题讲座.txt — 《专利法》第二条第二款、第三款〕
- 专利制度的作用：通过专利权与技术公开之间的制度交换，激励发明创造、促进技术公开，并推动技术应用和经济发展。
- 中国制度运行特点：发明专利、实用新型和外观设计在审查方式和保护对象上存在差异；学习时应把制度层面的程序安排与客体分类分开掌握。
**概念关系**：先理解专利权的独占性、时间性和地域性，再理解为何法律需要划定保护客体。；先按《专利法》第二条确定属于哪类客体，再根据对应申请表达进入审查；客体判断不是最终授权结论。；专利法、实施细则和审查指南构成由基本规则到具体操作的规范层次。
**必记**：专利制度的基本特征可概括为独占性、时间性和地域性，但具体权利范围仍须回到法律规定和权利要求。；发明、实用新型、外观设计是三类不同保护客体，不能仅凭“技术含量高低”或商业名称区分。；《专利法》第二条是保护客体判断的起点；判断客体通过，不等于已经满足全部授权条件。

### 专利法律制度基础速查卡（summary_card）

**要点卡**：
- **专利权三特征**：独占性说明权利排他，时间性和地域性说明排他效力并非无限、也非全球自动生效。
- **制度规范层次**：专利法定基本规则，实施细则补充具体制度，审查指南细化审查操作。
- **三类保护客体**：发明重在产品、方法或其改进的技术方案，实用新型重在产品形状构造，外观设计重在产品外观。
- **客体与授权**：先判断是不是法定保护客体，再进入其他授权和程序判断。
**必背**：《专利法》第二条规定发明、实用新型和外观设计的基本定义。；专利制度的基本特征是独占性、时间性和地域性。；保护客体判断是专利审查入口，不等于最终授权结论。
**一句话总结**：先以法条确认保护什么，再以审查程序判断能否获得并维持保护。
