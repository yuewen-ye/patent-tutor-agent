## M1 幻觉率

> 幻觉率为系统核心评估指标，整合过程异议、裁判评分、外部LLM评估器维度、
> 三类谬误子分、溯源验证/支撑及跨轮自洽六个层面。

### 1.1 闭环率

| 项目 | 说明 |
|---|---|
| **计算公式** | 闭环率 = `闭环条数 / 总🔴条数 × 100%` |
| **数据来源** | `expert_a_cross_review.md` + `expert_b_cross_review.md` + `m1_objection_loop_*.json` |
| **核心逻辑** | 由外部 LLM 判定异议是否形成完整闭环 |
| **评估标准** | 闭环率越高越好（≥ 80% 良好） |
| **所属表** | 表1：脚本计算指标 |

### 1.2 裁判Agent准确性评分

| 项目 | 说明 |
|---|---|
| **计算公式** | 直接取 `judge_report.md` 中 `准确性：X/5` 的 X 值 |
| **数据来源** | `judge_report.md` |
| **核心逻辑** | 正则匹配提取裁判评分 |
| **评估标准** | 满分 5 分。5/5 = 完全准确；4/5 = 基本准确 |
| **所属表** | 表1：脚本计算指标 |

### 1.3 外部LLM评估器维度（3个核心概念）

> 以下 3 个维度由外部 LLM 基于 `m1_llm_dimensions.md` 提示词生成，
> 结果存储在 `judge_{model}_{profile}_{round:02d}.json` 中。
> 每个维度采用 **100 分制**，单独展示，不进行加权合并。

#### 1.3.1 上下文正确性（Context Correctness）

| 项目 | 说明 |
|---|---|
| **计算公式** | 外部LLM评估：事实准确性 + 关键信息完整性（0–100分） |
| **数据来源** | `judge_*.json` → `overall_evaluation.scores.context_correctness` |
| **评估标准** | 90–100 分：所有事实准确且关键信息无遗漏；80–89 分：基本准确 |
| **所属表** | 表2：外部LLM评价指标 |

#### 1.3.2 答案正确性（Correctness）

| 项目 | 说明 |
|---|---|
| **计算公式** | 外部LLM评估：生成内容与专利法/实践/逻辑的一致性（0–100分） |
| **数据来源** | `judge_*.json` → `overall_evaluation.scores.correctness` |
| **评估标准** | 90–100 分：所有陈述与专利法完全一致；80–89 分：基本正确 |
| **所属表** | 表2：外部LLM评价指标 |

#### 1.3.3 幻觉评估（Hallucination）

## M2 匹配度

> 匹配度评估教学内容与学员实际需求、难度、动态状态的匹配程度。

### 2.1 难度符合度

| 项目 | 说明 |
|---|---|
| **计算公式** | `L_low ≤ 题.difficulty ≤ L_high 的题数 / 总题数 × 100%`（双边区间） |
| **数据来源** | `course_package.md` + `learning_path.md` + `learner_profile_update.md` |
| **核心逻辑** | L_low: pl < 0.30 → L1; pl ≥ 0.30 → L2; 再封顶 difficulty_cap。角色特例: weakness → L3, forward_probe → L1 |
| **评估标准** | ≥ 80% 为良好 |
| **所属表** | 表1：脚本计算指标 |

### 2.2 有用性

| 项目 | 说明 |
|---|---|
| **计算公式** | 外部LLM评估：内容对学员的实际帮助程度，含清晰性/友好性（0–100分） |
| **数据来源** | `judge_*.json` → `overall_evaluation.scores.helpfulness` |
| **评估标准** | ≥ 85 分为良好 |
| **所属表** | 表2：外部LLM评价指标 |

### 2.3 相关性

| 项目 | 说明 |
|---|---|
| **计算公式** | 外部LLM评估：内容与学习主题的聚焦程度，无冗余/跑题（0–100分） |
| **数据来源** | `judge_*.json` → `overall_evaluation.scores.relevance` |
| **评估标准** | ≥ 85 分为良好 |
| **所属表** | 表2：外部LLM评价指标 |

### 2.4 动态迭代触发率

| 项目 | 说明 |
|---|---|
| **计算公式** | 每轮指标：是否触发动态迭代（布尔值）；画像指标：`触发次数 / 有效轮次数 × 100%`（通常为 100%）。分母根据数据来源确定为 `n-1` 或 `n-2` |
| **数据来源** | `learner_profile_update.md`（跨轮比对） |
| **核心逻辑** | 检查 BKT 掌握度值是否发生变化（不论上升或下降），统计每轮是否触发迭代。最终统计每轮是否触发动态迭代。 |
| **评估标准** | 画像级通常为 100%（只要系统执行过迭代即为触发），轮次级用于监控迭代是否发生 |
| **所属表** | 表1：脚本计算指标 |

### 2.5 检索正确性

> 评估对象为 RAG 检索链路返回的**真实检索 chunk**，而非 Expert 合成后的课程章节。
> 评估器从 `retrieval_context*.md`（含主检索 + Expert A/B tool calling 的检索结果）
> 中解析 JSON 格式的 chunk（含 chunk_id/source/text/score/rerank_score），
> 按 chunk_id 去重后逐条送外部 LLM 评估准确性与完整性。
> 若无 retrieval_context 文件，则回退为 course_package 章节切片代理（JSON 中 `chunk_source` 字段标注来源）。

#### 2.5.1 检索准确率

| **计算公式** | `准确检索chunk数 / 总检索chunk数 × 100%` |
| **数据来源** | `retrieval_context*.md` → `round_indicator_*.json` 的 `retrieval` section |
| **评估标准** | ≥ 90% 为良好 |
| **所属表** | 表2：外部LLM评价指标 |

#### 2.5.2 检索完整率

| 项目 | 说明 |
|---|---|
| **计算公式** | `完整检索chunk数 / 总检索chunk数 × 100%` |

## 附录

### A. 外部 LLM 评估框架

外部 LLM 评估使用 `LLM/evaluator_LLM.py`，支持以下模式：

| 模式 | 对应指标 | 说明 | 输出文件 |
|---|---|---|---|
| `--mode overall` | M1.3 + M2.2 + M2.3 | 通用评估（上下文正确性/答案正确性/幻觉评估 + 有用性/相关性） | `judge_*.json` |
| `--mode statement` | M1.4 + M1.5 | 陈述级评估（三类谬误率 + 知识溯源） | `statement_judge_*.json` |
| `--mode m1` | M1.1 | 异议闭环率评估 | `m1_objection_loop_*.json` |
| `--mode m1_cross_round` | M1.6 | 跨轮自洽率评估 | `m1_cross_round_*.json` |
| `--mode m2_retrieval` | M2.5 | 检索正确性评估 | `m2_retrieval_*.json` |
| `--mode m4` | M4.2 | 资源形态评估 | `m4_resource_morphology_*.json` |
| `--mode m6_adversarial` | M6.1 | 对抗稳健率评估（系统级） | `m6_adversarial_*_system.json` |
| `--mode m6_boundary` | M6.2 | 边界拒答恰当率评估（系统级） | `m6_boundary_*_system.json` |
