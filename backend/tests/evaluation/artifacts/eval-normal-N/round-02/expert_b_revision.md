# 专家 B 修订稿

## teaching_content

## 1. 场景导入
小张，某AI芯片初创团队的工程师，2024年5月1日在政府主办的国际半导体展会上首次展示了他们研制的谐波减速器新方案原型。2024年10月1日，他们向国家知识产权局提交了专利申请。展出后，他们在内部会议上反复讨论：这个公开会不会让申请失败？同时，他们担心如果把申请日定为优先权日，是否能享受6个月缓冲？团队里有人提议“先申请再说”，但他们清楚，保护客体、授权条件和公开行为的时间界限三者密不可分，如果判断错了，专利就可能被拒或被宣告无效。

## 2. 人话解释
咱们把专利保护客体想象成‘什么东西可以申请专利’的大门。发明是最宽的‘门’——只要是产品、方法或其改进的新的技术方案（用技术手段解决技术问题，产生自然规律效果），就行；实用新型是‘窄门’——只保护有确定形状、构造、占据空间的实体产品，方法、形状+方法组合都不行；外观设计是‘美观门’——产品整体或局部的形状、图案、结合及色彩搭配的富有美感并适于工业应用的东西。申请前，审查员要先看你投的‘什么货’。再看发明和实用新型的三性（外观设计授权条件另由第二十三条规定，不适用三性）：新颖性是‘查重’——申请日前有没有一模一样的公开？创造性是‘不显而易见’——本领域技术人员从已有技术组合中是否容易想到？实用性是‘能做有用’——能不能制造、使用并产生积极效果？诚实信用原则是贯穿始终的‘品质把关’，申请时不能弄虚作假，授权后也不能滥用权利。公开行为（比如展会展示）只在特定情况下给6个月缓冲，但不改变三性。简单说，先确定保护客体，再过发明和实用新型的三性关，最后看时间线和诚实信用。

## 3. 法条回扣
《专利法》第二条规定发明、实用新型、外观设计三类保护客体；《专利法》第二十二条规定发明和实用新型的新颖性、创造性、实用性三性；《专利法》第二十四条规定中国政府主办或者承认的国际展览会上首次展出公开6个月不丧失新颖性；《专利法》第二十条规定诚实信用原则。审查指南第二部分第十一章第2节进一步明确发明专利保护对象的判断标准。

## 4. 类比 / 口诀
三性记忆表：新（未公开）/创（不显而易见）/实（能做有用）。保护客体分类：发（产品/方法/改进）/实（形状/构造）/外观（美感+工业应用）。宽限期是临时通道，中国政府主办或者承认的国际展览会首次展出等6个月内走即可，仅适用于第二十四条列举情形。

## 5. 应试提示
题干关键词：保护客体（发明/实用新型/外观设计）、三性（新颖性/创造性/实用性）、公开行为（中国政府主办或者承认的国际展览会）、诚实信用原则。判断步骤：先判保护客体，再判三性，最后看公开时间。常见陷阱：把方法当作实用新型客体；混淆现有技术与抵触申请；忘记宽限期仅限特定公开。
